# 🧬 전압의존성 나트륨 채널 (Voltage-Gated Sodium Channel, Nav)

> **핵심 3줄 요약 (Key Summary)**:
> 🧬 정체: 막전위 변화에 반응해 Na⁺를 세포 안으로 들여 활동전위를 개시하는 이온채널. α 소단위 9종(Nav1.1~1.9)이 조직·기능별로 분담한다.
> 🎯 통각 관련: [[Nav1.7]]은 역치 설정, [[Nav1.8]]은 C섬유 활동전위 유지, Nav1.9은 지속성 전류를 담당한다. 이 세 아형이 [[신경병증성 통증]]과 [[말초 감작]]의 주 표적이다.
> 💊 임상: [[카바마제핀]]·리도카인 같은 고전 차단제는 사용의존성(use-dependent) 차단으로 작동하고, 2025년에는 Nav1.8 선택적 억제제(수제트리진)가 승인되며 아형 선택성 시대가 열렸다.

## 1. 정의·구조

- **α 소단위**: 4개의 상동 도메인(I~IV)이 각각 6개 막관통 나선(S1~S6)을 가진 단일 폴리펩타이드. S4가 전압 감지기, S5~S6 루프가 이온 통로 입구를 만든다.
- **유전자**: SCN1A~SCN11A가 아형을 부호화한다(Nav1.1~1.9).
- **보조 소단위**: β1~β4가 발현·국소화·개폐 특성을 조절한다.
- **게이트 3상태**: 닫힘 → 열림 → 빠른 불활성화. 불활성화는 III-IV 연결부의 IFM 모티프가 입구를 막는 방식이다.

## 2. 기능·기전

1. 탈분극이 S4를 밖으로 밀면 통로가 열리고 Na⁺가 유입된다.
2. 유입된 전류가 이웃 막을 탈분극시켜 활동전위를 전파한다.
3. 곧바로 불활성화되어 재흥분을 막고, 회복되어야 다음 활동전위가 가능하다.
4. **사용의존성 차단**: 고빈도로 열린 채널이 불활성화 상태에 머무는 시간이 길어, 차단제가 불활성화 상태에 잘 붙는다. [[카바마제핀]]이 [[삼차신경통]]의 발작성 발화를 줄이는 이유가 여기에 있다.

## 3. 아형별 분포와 질환

| 아형 | 주 발현 | 기능 | 대표 병태 |
| :--- | :--- | :--- | :--- |
| Nav1.1·1.2 | 중추 신경 | 억제성 개재뉴런 발화 | 유전성 간질·편두통 |
| Nav1.3 | 손상 후 후근신경절 재발현 | 이소성 발화 | 신경손상 후 통증 |
| Nav1.6 | 랑비에 결절 | 활동전위 도약 전도 | 소뇌 실조 |
| [[Nav1.7]] | 후근신경절·삼차신경절 | 역치·발화 개시 | SCN9A 기능획득 → 유전성 홍색사지통증·발작성 직장통 |
| [[Nav1.8]] | 소형 후근신경절(C섬유) | 활동전위 상승 유지 | 급성 통증 치료 표적 |
| Nav1.9 | 소형 후근신경절 | 지속성 하위역치 전류 | 가족성 발작성 통증 |

- SCN9A **기능상실** 변이는 선천성 통증 무감각증을 만든다 — Nav1.7이 통각에 필수임을 보여주는 자연실험이다.
- 나트륨 통로병증은 통증 표현형과 무통 표현형이 같은 유전자에서 갈린다는 점에서, 통증이 '선택적 차단'이 가능한 전기적 현상임을 시사한다.

## 4. 약리·중재 연계

- **비선택적 차단제**: [[카바마제핀]], 라모트리진, 리도카인. 아형 선택성이 없어 어지럼·졸림·심장전도 이상이 용량제한 요인이 된다.
- **느린 불활성화 촉진**: 라코사미드.
- **국소 제제**: 리도카인 5% 첨부제 — 전신 부작용을 줄인 국소 접근.
- **아형 선택적 억제제**: 수제트리진(Nav1.8)이 2025년 승인되며 '통증 전용 나트륨 차단제'의 가능성을 열었다.
- **비약물 접근**: [[전침]]·TENS는 채널을 직접 차단하지 않고 상위 조절과 [[GABA]]성 억제를 통해 활동전위 빈도를 낮춘다. 작용 층위가 다르므로 약물과 병용이 가능하다.

⚠️ 유전자 검사는 임상에서 일상적이지 않다. 비정형 양상(어린 나이 발병, 심한 발작성 통증, 가족력)에서만 고려한다.

## 5. 오늘 논문에서의 위치 (2026-11-20)

[[2026-11-20_신경계통증의학_심층리뷰]] 논문 1번(삼차신경통 전침·카바마제핀 2×2 요인설계)에서 **약물 축의 작용점**이 이 채널이다. 카바마제핀 300 mg/일 저용량이 전침과 상호작용(P=0.041)을 보인 것은, 두 중재가 서로 다른 층위(채널 vs 척수·하행 조절)에서 작동한다는 해석과 맞물린다. 논문 2번(당뇨병성 신경병증)에서도 나트륨 통로 재분포가 이소성 발화의 배경으로 언급된다.
