# 말산 (Malic Acid)

> **핵심 요약 (Key Summary)**
> 생체 내 모든 호기성 세포의 미토콘드리아 기질에서 일어나는 TCA 회로(크렙스 회로)의 핵심 4탄소 디카르복실산 중간체.
> 말산-아스파르트산 셔틀(Malate-Aspartate Shuttle)을 통해 세포질의 NADH 환원당량을 미토콘드리아 전자전달계로 수송하여 ATP 합성을 유도.
> 세포 에너지 고갈로 인한 만성 피로, 섬유근육통 병태생리 개선 및 유기산 대사 균형 유지의 분자 물질적 기초.

---

## 1. 화학 구조 및 물리화학적 특성

말산(2-하이드록시부탄이산)은 4개의 탄소로 이루어진 디카르복실산으로, 2번 탄소에 비대칭 키랄 중심이 존재한다. 생체 내 대사계에서 활성을 나타내는 천연 입체이성질체는 **L-말산(L-Malic acid)**이다.

```
            COOH
            │
       H ── C ── OH  (C-2 chiral center, L-form)
            │
            CH2
            │
            COOH
   [화학명: (2S)-2-hydroxybutanedioic acid]
```

| 항목 | 내용 |
| :--- | :--- |
| IUPAC 명칭 | (2S)-2-hydroxybutanedioic acid |
| 분자식 | $\text{C}_4\text{H}_6\text{O}_5$ |
| 분자량 | $134.09\text{ g/mol}$ |
| PubChem CID | 222656 (L-말산) |
| 성상 | 백색의 결정성 분말, 특유의 상쾌한 신맛 |
| 용해도 | 물에 매우 잘 녹음 ($558\text{ g/L at }20^\circ\text{C}$), 에탄올에 가용 |
| 천연 공급원 | 사과, 포도 등 과실류 및 생체 내 세포질·미토콘드리아 |

## 2. 생화학적 대사 경로 및 기능

```
                      [TCA 회로 내 말산의 위치]

                  푸마르산 (Fumarate)
                          │
                          │ ── 푸마라아제 (Fumarase) + H2O
                          ▼
                    [L-말산 (L-Malate)]
                          │
                          │ ── 말산 탈수소효소 (MDH) + NAD+
                          ▼ (NADH + H+ 생성)
                옥살로아세트산 (Oxaloacetate)
                          │
                          ▼ (+ 아세틸-CoA → 시트르산)
```

### ① TCA 회로(Citric Acid Cycle)에서의 역할
- **기질 반응**: 푸마라아제(Fumarase)에 의해 푸마르산의 이중결합에 물 분자가 입체특이적으로 첨가되어 L-말산이 생성된다.
- **NADH 생성 및 회로 완결**: 미토콘드리아 말산 탈수소효소(mMDH)가 L-말산의 2번 하이드록실기를 산화시켜 [[옥살로아세트산]]을 재생하며, 이 과정에서 $\text{NAD}^+$를 $\text{NADH} + \text{H}^+$로 환원시킨다.
- 이렇게 생성된 $\text{NADH}$는 미토콘드리아 내막의 복합체 I(Complex I)으로 전달되어 약 2.5개의 ATP 합성을 구동한다.

### ② 말산-아스파르트산 셔틀 (Malate-Aspartate Shuttle)
미토콘드리아 내막은 세포질에서 해당과정(Glycolysis)을 통해 생성된 $\text{NADH}$를 직접 투과시키지 못하므로, 심근과 간세포에서는 말산-아스파르트산 셔틀을 통해 전자를 전달한다:

```
[세포질 (Cytosol)]                      [미토콘드리아 (Mitochondria)]
  옥살로아세트산                          옥살로아세트산
     │  ▲                                    ▲  │
     │  │ cMDH                               │  │ mMDH
     ▼  │                                    │  ▼
    [L-말산] ─── (말산/α-KG 수송체) ───────► [L-말산]
   (NADH → NAD+)                           (NAD+ → NADH) ──► 전자전달계
```

1. 세포질에서 옥살로아세트산이 세포질 말산 탈수소효소(cMDH)에 의해 $\text{NADH}$를 소모하며 L-말산으로 환원된다.
2. 생성된 말산이 미토콘드리아 내막의 말산/$\alpha$-케토글루타르산 역수송체를 통해 기질로 들어간다.
3. 기질 내에서 mMDH에 의해 다시 산화되면서 $\text{NAD}^+$를 $\text{NADH}$로 환원시켜 전자전달계로 넘긴다.

### ③ 당신생합성(Gluconeogenesis)의 전구체 수송
- 간에서 당신생합성이 일어날 때, 미토콘드리아에서 피루브산 카르복실화효소에 의해 생성된 옥살로아세트산은 막을 통과하지 못하므로 말산으로 환원되어 세포질로 나온 뒤 다시 옥살로아세트산으로 재산화되어 포도당 합성에 쓰인다.

## 3. 임상 의학적 응용 및 병태생리

- **만성 피로 증후군 및 섬유근육통**:
  - 저산소 상태나 미토콘드리아 기능 부전 환자에서 말산과 마그네슘 복합체(Magnesium Malate) 투여 시 TCA 회로 회전율을 높이고 젖산(Lactate) 축적을 방지하여 근육통과 피로를 유의하게 경감시킨다.
- **운동 수행 능력 및 젖산 역치 개선**:
  - 고강도 운동 시 세포질 NADH의 빠른 재산화를 돕고 당신생 경로를 촉진하여 글리코겐 고갈을 지연시킨다.
- **신장 결석 억제 및 요 알칼리화**:
  - 체내에서 중탄산염으로 대사되어 요중 pH를 완만하게 높이고 요중 구연산 배설을 도와 옥살산칼슘([[옥살산칼슘]]) 결정 침착을 억제한다.

## 4. 한의학적 연계 및 본초 산미(酸味) 생리

- **산미수렴(酸味收斂)과 생진지갈(生津止渴)**:
  - 사과, 모과([[모과]]), 오미자([[오미자]]), 산수유([[산수유]]) 등 산미(酸味)를 지닌 본초들에 다량 함유된 말산은 한의학에서 진액(津液)을 생성하고 기운이 밖으로 흩어지는 것을 거두어들이는 수렴약효의 분자 실체이다.
- **간주근(肝主筋)과 피로 회복**:
  - 한의학에서 간은 근육을 주관하고 피로를 견디는 파극지본(罷極之本)이라 하였는데, 간과 근육의 미토콘드리아에서 젖산 대사를 해소하고 글리코겐을 재합성하는 말산의 대사 경로는 산미입간(酸味入肝) 이론과 일치한다.
