# PGI2 (Prostacyclin, 프로스타사이클린)

> **핵심 요약 (Key Summary)**:
> 혈관내피세포에서 COX-1 및 COX-2와 프로스타사이클린 합성효소(PGIS)에 의해 아라키돈산으로부터 합성되는 에이코사노이드.
> 혈소판과 혈관 평활근의 IP 수용체에 결합하여 cAMP 농도를 상승시킴으로써 강력한 혈관 확장 및 혈소판 응집 억제 발휘.
> 혈소판 유래 트롬복산 A2(TXA2)와 동적 균형(TXA2/PGI2 Balance)을 이루며 죽상동맥경화·혈전 형성 억제 및 폐동맥고혈압 치료의 핵심 분자.

## 2. 분자 약리 및 TXA2와의 동적 균형 (Homeostasis)

```
                    혈관벽 손상 및 염증
                             │
       ┌─────────────────────┴─────────────────────┐
       ▼                                           ▼
[혈관내피세포 (Endothelium)]             [혈소판 (Platelets)]
아라키돈산 ──→ COX-2 / PGIS            아라키돈산 ──→ COX-1 / TXAS
       │                                           │
  ★ PGI2 (프로스타사이클린) ★              ★ TXA2 (트롬복산 A2) ★
       │                                           │
   IP 수용체 결합                             TP 수용체 결합
   Gs 단백질 → cAMP 상승                      Gq 단백질 → IP3/DAG → Ca2+ 상승
       │                                           │
┌──────┴──────────────────────┐            ┌──────┴──────────────────────┐
▼                             ▼            ▼                             ▼
혈관 확장 (Vasodilation)  혈소판 응집 차단  혈관 수축 (Vasoconstriction) 혈소판 응집 촉진
└─────────────────────────────┬────────────┴─────────────────────────────┘
                              ▼
           정상 혈류 유지 vs 혈전/허혈 (동적 평형)
```

1. **혈소판 응집 억제 분자 기전**:
   - PGI2가 혈소판 막의 IP 수용체에 결합하면 아데닐릴 시클라아제(AC)가 활성화되어 세포 내 cAMP가 급증, 칼슘 유입을 차단하여 혈소판 활성화(GPIIb/IIIa 복합체 노출)를 완전히 억제.
2. **혈관 평활근 이완**:
   - 세동맥 평활근 세포 내 cAMP 상승은 미오신 경쇄 인산화효소(MLCK)를 불활성화하여 강력한 혈관 확장을 유도.
3. **선택적 COX-2 억제제(콕시브계)의 심혈관 위험 기전**:
   - 선택적 COX-2 억제제(셀레콕시브 등)는 내피세포의 PGI2 합성을 선택적으로 억누르는 반면, 혈소판 COX-1 매개 TXA2 합성은 억제하지 못해 혈전증, 심근경색, 뇌졸중 위험을 유의하게 증가시킴.

## 3. 임상 의학적 의의 및 치료 응용

* **폐동맥 고혈압 (Pulmonary Arterial Hypertension, PAH)**:
  - 폐혈관 내피의 PGI2 합성 결핍으로 극심한 폐혈관 수축이 일어난 환자에게 합성 유도체(에포프로스테놀, 일로프로스트, 트레프로스티닐) 지속 투여.
* **동맥경화 및 말초동맥 폐색증 (버거씨병)**:
  - 사지 말초 혈류 부전을 개선하고 허혈성 궤양을 치유하기 위해 PGI2 유도체 정맥 주사.

## 4. 한의학 활혈거어(活血祛瘀) 약리와의 매핑

```
[어혈(瘀血) 병태: 혈류 지체, 자통, 설암]  ──→  PGI2 결핍 및 TXA2 우세 상태
                    │
[활혈거어약 투약]   ──→  내피세포 PGI2 분비 촉진 및 혈소판 응집 억제
  - [[단삼]] ([[살비아놀산 B]])
  - [[당귀]] (페룰산)
  - [[천궁]] (천궁소, 리구스티라이드)
```

* 활혈거어제의 핵심 약재들은 혈관내피세포의 PGIS 활성을 보호하고 PGI2 방출을 유도하여 미세순환 혈전을 방지하는 현대 생화학적 기전을 가짐.
