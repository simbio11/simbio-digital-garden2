# PCSK9 (Proprotein convertase subtilisin/kexin type 9)

> **핵심 요약**: 간세포에서 분비되는 **세린 프로테아제**. 세포 표면의 **LDL 수용체(LDLR)에 결합해 LDLR의 분해를 촉진**한다. 따라서 **PCSK9 활성이 높으면 LDLR이 줄어 혈중 LDL-C가 상승**하고, **PCSK9을 억제하면 LDLR이 재활용돼 LDL-C가 강하**한다. 스타틴과 기전이 독립적이어서 **스타틴의 보완 표적**이 된다.

## 정의·구조·합성
- *PCSK9* 유전자(1번 염색체) → 전구단백 → 자가촉매 분해 → 성숙 분비형
- 주로 간세포에서 합성되어 혈중으로 분비
- **기능획득(gain-of-function) 변이** → 가족성 고콜레스테롤혈증 / **기능상실 변이** → 평생 낮은 LDL-C·심혈관 위험 감소

## 기능·기전
- LDLR의 EGF-A 도메인에 결합 → LDLR–PCSK9 복합체가 리소좀으로 표적 → **LDLR 재활용 차단·분해↑** → 간의 LDL 청소율↓ → **혈중 LDL-C↑**
- 반대로 PCSK9 억제 → 간세포 표면 LDLR 발현↑ → **LDL-C 강하**
- **[[베르베린]]**: 간세포 **PCSK9 mRNA 분해를 촉진** → LDLR 안정화 → LDL-C 강하(스타틴과 다른 기전)
- 스타틴은 SREBP-2를 통해 LDLR을 늘리지만 **PCSK9도 함께 증가**시켜 일부 효과가 상쇄됨

## 임상 의의 (치료 연계)
- **PCSK9 억제제**: 단클론항체(에볼로쿠맙·알리로쿠맙), siRNA(인클리시란) — 스타틴 불내성·가족성 고콜레스테롤혈증·ASCVD 고위험에서 LDL-C 강력 강하
- 한의: [[황련]]·[[황백]]의 [[베르베린]] — 2026-09-10 심층리뷰 3번(PMID 39998703)에서 [[베르베린]]+[[육계]](시나몬) 12주 병용이 **LDL-C 유의 감소(P=0.039)**, 총콜레스테롤·HDL-C·중성지방은 차이 없음
