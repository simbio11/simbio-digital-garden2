# 광생물조절 (Photobiomodulation, PBM)

> **핵심 요약**: 저출력 레이저·LED(적색~근적외선, 약 600~1100 nm) 빛을 조직에 조사했을 때 **열 손상 없이(비열적)** 세포 대사·염증·통증을 조절하는 생물학적 반응. 빛을 흡수한 **미토콘드리아 호흡사슬의 시토크롬 c 산화효소(CCO)**가 일차 표적으로, ATP 생산 증가 → 산화환원 신호·전사인자 활성 → 항염·조직 재생·진통으로 이어진다. [[레이저침]](경혈 조사), 저출력 레이저 치료(LLLT), 적외선·광선 요법의 공통 분자 기전이다.

## 정의·구조
- **비열적 원리**: 출력밀도(mW/cm²)와 조사시간으로 결정되는 **선량(J/cm²)**이 낮아 조직 온도 상승(±0.1~0.5℃)이 거의 없다 → 고출력 레이저의 응고·절단과 구분
- **용량 처방식**: `에너지(J) = 출력(W) × 시간(s)`, `선량(J/cm²) = 에너지 ÷ 조사면적(cm²)`. 파장(nm)·출력(mW)·조사면적·시간을 모두 명시해야 재현 가능
- **대표 파라미터(문헌)**: 810 nm·150 mW·프로브 0.13 cm²(출력밀도 1.19 W/cm²)·혈위당 15초 → **2.5 J/cm²** (2026-09-13 월경통 RCT)

## 기능·기전
- **일차 표적 = 시토크롬 c 산화효소(CCO)**: 600~900 nm 대역의 광자를 흡수하는 미토콘드리아 내막 효소. 광흡수 → 전자전달계 활성·**ATP 생산 증가**, 활성산소(ROS)의 신호 수준 조절, 산화질소(NO) 결합 해리
- **전사인자 활성**: 세포내 신호 → **NF-κB·AP-1·HIF-1** 등 활성 → 항염 사이토카인·성장인자 발현 조절
- **혈류·림프**: 국소 미세순환 증가, 부종 감소
- **신경 조절**: 감각신경(Aδ·C) 및 자율신경 자극 → [[하행성 통증억제계]] 활성, [[Substance P]]·[[CGRP]] 등 신경펩타이드 방출 조절, [[말초 감작]] 억제
- **자율신경 효과**: 피부·근육의 구심성 자극과 국소 대사 변화를 통해 **HF%(미주 긴장) 상승·LF/HF 정상화** 방향의 재균형이 보고된다 → [[심박변이도]]
- **세포 수준**: 세포 증식·이동 촉진, [[MMP]] 활성 변화(혈관활성 펩타이드 분해), 아폽토시스 억제

## 임상 의의(치료 연계)
- **비침습·무통**: 자침이 부담스러운 소아·고령·항응고제 복용자, 출혈 경향, 눈 주위 혈위에 실무적 이점
- **적응 영역**: 만성 근골격계 통증(목·어깨·무릎), 편두통 예방, 월경통, 구강 점막염, 창상 치유, 림프부종 등 — 적응마다 근거 수준 편차가 크다
- **한의 임상 포인트**: PBM은 **'경혈 자극의 물리적 대체 수단'**이라는 위치 설정이 합리적이다. 장비가 없으면 동일 혈위를 [[전침]]·수기침·온침으로 운용하되, **파장·출력·선량이 다르면 근거를 그대로 승계할 수 없다**는 점을 환자에게 밝힌다
- **주의**: 임신부 하복부·천골부 신중, 광과민성 약물(테트라사이클린·아미오다론 등)·광과민성 질환 확인, 눈 직접 조사 금지(보안경), 암 병변·활동성 감염 부위 회피

## 논문 연결

## 📎 개념 학습 보충 (2026-10-12 논문 연계)

- **침 끝에서 조사하는 광생물조절(2026-10-12 리뷰 1번, [PMID: 40495966](https://pubmed.ncbi.nlm.nih.gov/40495966/))**: 650 nm 관침형 레이저침(ILA)은 광섬유 내장 침을 피부 아래로 자입해 **침 끝에서 직접 레이저를 조사**한다 — 표피의 산란·반사·흡수로 손실되는 에너지를 줄여 경혈 심부에 유효 선량을 전달하려는 설계다. 즉 침의 기계적 자극과 광자극을 **같은 혈위에 중첩**시킨다 → [[레이저침]] · [[저출력 레이저 치료]]
- **650 nm 특이 기전**: 20 mW·50 Hz 펄스파·혈위당 12 J 조건에서 아세틸콜린에스터레이즈·substance P·leu-enkephalin·c-Fos/GFAP 발현 조절이라는 신경전달 조절 기전이 제시됐다 — 기존 노트의 810 nm 계열(편두통·월경통) 근거와는 **파장이 다르므로 그대로 승계할 수 없다** → [[Substance P]]
- **진통 기전 정리**: ① 말초신경 전도 억제 ② 내인성 오피오이드 방출 ③ 비만세포 탈과립 ④ 세로토닌성 경로 활성 ⑤ 부종·산화스트레스 감소를 통한 항염 → [[하행성 통증억제계]] · [[ROS]]
- **임상 주의**: 이 시험은 기능(ODI)·삶의 질(EQ-5D-5L)에서 군간 차이가 없었고 기간이 4주로 짧다 — '통증 지표 개선 = 기능 회복'으로 확대 해석하지 않는다 → [[요통]]
- 관련: [[2026-10-12_근골격계-척추관절_심층리뷰]] 1번

## 📎 개념 학습 보충 (2026-10-14 논문 연계)

**이 논문에서의 역할** — 2026-10-14 심층리뷰 3번([PMID 36171024](https://pubmed.ncbi.nlm.nih.gov/36171024/))은 하지 건병증·족저근막염에서 광생물조절의 **용량-반응 규칙**을 사람 임상 데이터로 정리한 메타분석이다.

- **선량이 결과를 좌우한다**: 파장과 지점당 에너지(J)를 맞춘 군에서만 위약 대비 이득이 유지됐다(WALT 권고 용량군 14.98 mm). 너무 적거나 과도하면 효과가 사라지는 양방향 용량 반응을 임상 수준에서 재확인한 셈이다 → [[양방향 용량 반응]]
- **건 조직 특이 기전**: 660~1100 nm 광자가 [[시토크롬 c 산화효소]]의 일산화질소를 분리해 ATP 생성을 높이고, 염증성 사이토카인(IL-1β·TNF-α)과 통증 매개물질을 줄이며, 국소 혈류·림프 순환 개선과 신경 말단 흥분 역치 상승을 만든다. 건 조직에서는 콜라겐 합성·섬유모세포 활성 증가로 회복기 구조 개선에 관여한다 → [[시토크롬 c 산화효소]]
- **임상 배치**: 운동(편심성 운동·족저근막 스트레칭) 직전 또는 같은 내원일에 적용하는 순서가 근거 설계와 가장 가깝다 → [[운동요법]]
- **주의**: 본 노트의 810 nm·650 nm 기록과 이번 시험군(904 nm 포함)은 **파장이 다르면 선량을 그대로 승계할 수 없다**는 원칙을 다시 확인시킨다.
