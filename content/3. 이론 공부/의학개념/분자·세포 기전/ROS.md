# ROS (Reactive Oxygen Species, 활성산소종)

> **핵심 요약**: 산소 대사 과정에서 생성되는 반응성 높은 분자들(수퍼옥사이드 O₂⁻, 과산화수소 H₂O₂, 하이드록실라디칼 ·OH). 저농도에서는 세포 신호전달에 필요하지만, **과잉 생성(산화스트레스)은 연골세포 손상·염증·세포사멸을 유발**한다. 항산화 방어계(SOD, 카탈라아제, GPx, GSH)와 균형이 중요하다.

## 생성과 방어
- **생성원**: 미토콘드리아 전자전달계 누출, NADPH 산화효소(면역세포의 respiratory burst), 크산틴 산화효소, 염증·허혈재관류
- **방어계**: SOD(→H₂O₂), 카탈라아제·글루타치온퍼옥시다아제(GPx)(→H₂O), 글루타치온(GSH), 비타민 C·E, Nrf2 전사인자(항산화 유전자 유도)

## 기능·기전
- **생리적 역할**: 저농도 ROS는 세포 증식·분화·면역 신호전달의 2차 전령
- **병적 역할(산화스트레스)**: 지질과산화·DNA 손상·단백질 변성 → 연골세포(chondrocyte) 아폽토시스, MMP 활성화, 염증성 사이토카인 증폭
- 관절 내 ROS 축적은 OA 진행(연골 마모·활막염)과 근골격계 만성 염증에 기여

## 임상 의의 (치료 연계)
- OA에서 'ROS 제거 → 연골세포 보호 → MMP·caspase 경로 억제'가 치료적 표적으로 연구됨
- 2026-09-01 심층리뷰 2번: 저주파 전침이 관절강 내 ROS를 소거하고 연골세포 아폽토시스(caspase-3)를 억제한다는 기전 보고
- 2026-09-01 심층리뷰 4번: 항산화 효소 활성 증가를 통한 연골 보호가 한약재 연구의 주요 기전
- 항산화 성분이 풍부한 본초·식이(영양학) 개념과 연결해 학습하면 좋음
