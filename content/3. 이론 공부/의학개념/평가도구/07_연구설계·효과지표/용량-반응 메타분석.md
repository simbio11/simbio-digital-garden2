# 📐 용량-반응 메타분석 (Dose-response Meta-analysis)

> **핵심 3줄 요약 (Key Summary)**:
> 🎯 목적: 여러 연구의 용량-결과 데이터를 통합해 "얼마나 해야 효과가 생기는가"를 곡선으로 추정한다. 단순한 "효과 있음/없음"을 넘어 최소 유효 용량과 최대 효과 용량을 구간으로 제시한다
> 🔍 구성: 총 누적 용량·1회 용량·주당 횟수 같은 노출 변수를 설정하고, 연구별 효과크기를 선형 또는 비선형(제한 삼차 스플라인) 모형으로 적합시킨다
> ⚠️ 한계: 포함 연구의 용량 범위 밖으로 외삽할 수 없고, 연구 수준 데이터에 기반하면 개인 수준 인과로 읽으면 안 된다. 곡선의 모양은 포함 연구의 설계 이질성에 민감하다

## 1. 목적·구성

- 일반 메타분석이 "중재군 대 대조군"의 평균 차이를 합산하는 반면, 용량-반응 메타분석은 각 연구의 용량 수준을 노출 변수로 놓고 결과와의 관계를 모형화한다
- 노출 변수 설계가 분석의 핵심이다. 같은 운동 중재라도 ① 총 누적 시간(예: 10주간 총 분) ② 회당 시간 ③ 주당 빈도 ④ 상대 강도(%HRmax) 중 무엇을 축으로 잡느냐에 따라 임상 결론이 달라진다
- 비선형 모형은 제한 삼차 스플라인(restricted cubic spline)을 주로 쓴다. 마디(knot) 수를 3~4개로 두고, 노출 범위의 양 끝에서 곡선을 선형으로 제약해 과적합을 줄인다 → [[네트워크 메타분석]]
- 연구 수준 용량-반응은 각 연구 안의 범주별 효과크기를 이용한다. 개인 수준 데이터(IPD)가 없으면 연구 내 용량 간격이 거칠어져 곡선이 계단식으로 왜곡될 수 있다

## 2. 해석·채점

| 지표 | 읽는 법 |
| :--- | :--- |
| 최소 유효 용량 | 곡선이 유의한 개선을 보이기 시작하는 하한. 문턱값(threshold) |
| 최대 효과 용량 | 곡선이 정점에 도달하는 지점. 이 위로는 추가 이득이 없거나 역전된다 |
| 곡선의 모양 | 선형이면 용량 비례, U자형이면 과용량에서 역효과, 평탄부는 이득 포화 |
| 효과크기 | SMD는 0.2·0.5·0.8을 소·중·대 효과로 읽는 관례가 있으나, 환자 체감과 1:1로 대응하지 않는다 |
| 이질성 | I²와 τ²를 함께 본다. 강도 정의가 연구마다 다르면 곡선 자체의 신뢰도가 낮아진다 |

- 곡선의 정점은 "가장 좋은 용량"이 아니라 "포함된 연구들의 범위 안에서 관찰된 최대 효과 지점"이다. 범위 밖은 추정하지 않는다
- U자형은 생물학적으로 흔하다. 역치 상향(적당한 자극)과 과부하(역치 하락)가 공존하는 중재 — 운동·온열·전기자극 — 에서 자주 나온다

## 3. 임상 사용·한계

- 처방을 "분·세트·주기"로 말할 수 있게 해 준다. "운동하세요"보다 "주 3회 30분, 10주에 총 900분"이 순응도를 높인다
- 최소 유효 용량은 치료 시작 문턱으로, 최대 효과 용량은 목표 상한으로 쓴다. 상한을 넘겨 더 요구하지 않는 것이 오히려 안전하다
- 한계 ① 포함 연구 수가 적으면 곡선이 불안정하다(10편 미만이면 마디 수를 줄여야 한다) ② 노출 변수가 연구마다 다르게 정의되면 통합 자체가 왜곡된다 ③ 준실험연구가 섞이면 효과크기가 과대추정된다 ④ 관찰된 용량 범위 밖 외삽 금지
- 임상 번역 원칙: 곡선의 정점은 목표이지 의무가 아니다. 환자의 시간·체력·동반질환을 먼저 두고, 최소 유효 용량을 통과하는 것을 1차 목표로 삼는다
