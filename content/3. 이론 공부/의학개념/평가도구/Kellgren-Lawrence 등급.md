# Kellgren-Lawrence 등급 (K/L grade, KL 등급)

> **핵심 요약**: 단순 방사선(X-ray)으로 골관절염(OA)의 **구조적 중증도를 0~4등급**으로 분류하는 국제 표준. 골극(osteophyte), 관절 간격 협착, 변형 등을 종합해 판정하며, 연구에서는 **KL 2등급 이상**을 방사선학적 OA로 정의하는 것이 일반적이다.

## 등급 정의 (Kellgren & Lawrence, 1957)
| 등급 | 판정 |
| :--- | :--- |
| **0** | 정상 — 골극·간격 협착 없음 |
| **1** | 의심 — 미세 골극(의심스러운 소견) |
| **2** | 경도 — 확실한 골극(+간격 협착 가능) → **방사선학적 OA 기준점** |
| **3** | 중등도 — 중등도 다발 골극, 확실한 간격 협착, 일부 변형 |
| **4** | 중증 — 대형 골극, 현저한 간격 협착, 심한 변형(경화·낭종 동반) |

## 임상 사용·한계
- 역학·임상시험의 대상자 선정(예: KL 2~3 무릎 OA)과 중증도 층화에 표준 사용
- **주의**: 방사선 등급과 통증·기능(WOMAC 등)은 자주 불일치 — 구조적 중증도와 환자 보고 증상을 분리해 해석해야 함
- 판독자 간 변이 존재 → 표준 참조 방사선 사진(atlas) 활용
