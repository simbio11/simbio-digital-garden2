# 📊 fALFF (저주파 변동 진폭 분율, fractional Amplitude of Low-Frequency Fluctuation)

> **핵심 요약 (Key Summary)**:
> 휴지기 기능적 MRI(rs-fMRI)의 BOLD 신호에서 저주파(0.01~0.08 Hz) 대역 진폭이 전체 주파수 대역에서 차지하는 비율을 나타내는 지표. ALFF가 저주파 진폭의 절대값인 데 반해 fALFF는 비율이므로 혈류·호흡·뇌척수액 등 생리적 잡음의 영향을 상대적으로 줄인다고 본다.
> 값이 높을수록 그 영역의 휴지기 자발 신경활동이 크다는 뜻으로 해석한다.
> 2026-10-14 심층리뷰 1번(회복기 [[허혈성 뇌졸중]] [[두침]] 다기관 RCT)에서 두침 병행군의 [[중심전회]] 기저 fALFF가 [[FMA]] 개선폭과 가장 강하게 상관해, 운동 회복 예후 후보 지표로 제시됐다.

## 1. 목적·구성
- 무엇을 보는가: 과제를 수행하지 않는 휴지 상태에서 뇌 각 영역이 스스로 보이는 자발적 활동의 크기. 뇌는 쉬는 동안에도 0.01~0.08 Hz 대역에서 규칙적으로 요동친다.
- ALFF와의 차이: ALFF = 저주파 대역 진폭의 합. fALFF = 저주파 대역 진폭 ÷ 전체 주파수 대역 진폭. 분모가 있어 큰 혈관·뇌척수액·호흡 잡음의 영향을 상대적으로 줄인다.
- 표준 처리 흐름: 전처리(움직임 보정·공간 정규화·대역 통과 필터) → 복셀별 주파수 스펙트럼 계산 → 0.01~0.08 Hz 대역 합을 전체 합으로 나눔 → z-점수 변환 후 군·시점 비교.

## 2. 계산·해석
| 항목 | 내용 |
| :--- | :--- |
| 단위 | 무차원 비율(z 변환 값) |
| 해석 방향 | 값 상승 = 해당 영역 자발 활동 증가 |
| 비교 방식 | 군간(중재 대 대조), 시점간(전후) 변화량 |
| 표준화 | z-점수 변환으로 개인차 축소 |
| 통계 | 복셀 단위 다중비교 보정 필수 |

- 주의: fALFF는 절대 진폭이 아니라 비율이다. 값이 올라간 것이 저주파가 늘어서인지 고주파가 줄어서인지 구분해 읽어야 한다.
- 휴지기 네트워크 해석과 짝지어 볼 때 [[디폴트모드네트워크]]·[[체성감각피질]] 등 영역별 표상과 함께 읽는다.

## 3. 임상 사용·한계
- 임상 사용: 뇌졸중·뇌손상 회복 예후 연구, 침·전침의 중추 조절 기전 연구, 휴지기 네트워크 평가.
- 해석 한계
  - 상관은 인과가 아니다: 기저 fALFF가 회복 폭과 상관한다는 결과는 예후 예측 후보라는 뜻이지 치료 표적이 아니다.
  - 군 평균과 개인 예측은 다르다: 현재 근거는 치료 전후 군 비교 수준이며, 개인 환자의 예후 예측 정확도는 검증되지 않았다.
  - 잡음 민감: 두개골·호흡·심박·환자 움직임에 민감해 촬영·전처리 규격이 결과를 좌우한다.
- 한의 임상 포인트: 두침이 뇌의 어느 부위를 깨우는지 환자에게 설명할 때 근거로 쓸 수 있으나, MRI 지표 자체를 치료 목표처럼 제시하지 않는다.

## 4. 논문 연결
- 2026-10-14 심층리뷰 1번(회복기 [[허혈성 뇌졸중]] 두침 다기관 RCT, Acupuncture in Medicine 2023;41(2):86-95). [PMID 35673804](https://pubmed.ncbi.nlm.nih.gov/35673804/)
  - [연구 요약] 두침 병행군에서 fALFF가 증가한 영역은 소뇌·설전소엽·[[중심전회]]·상전두회·두정엽이었고, FMA 개선폭은 건측 중심전회의 기저 fALFF와 가장 강한 상관을 보였다.
  - 관련: [[두침]] · [[피질 재조직화]] · [[뇌졸중]] · [[FMA]]
