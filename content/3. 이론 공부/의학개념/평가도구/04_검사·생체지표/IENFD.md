# 📊 IENFD (Intraepidermal Nerve Fiber Density / 표피내 신경섬유밀도)

> **핵심 3줄 요약 (Key Summary)**:
> 📊 무엇: 피부 생검 조직에서 표피-진피 경계를 지나 표피 안으로 뻗은 무수초 신경섬유를 단위 길이당 개수로 세는 정량 지표.
> 🎯 용도: [[당뇨병성 말초신경병증]]·소섬유신경병증처럼 굵은 신경 전도는 정상인데 통증·자율신경 증상만 있는 경우의 진단 근거가 된다.
> ⚠️ 해석: 연령·부위별 정상 하한(5백분위수)을 적용해야 하며, 침습적이고 표본 오차가 있어 단독으로 진단을 확정하지 않는다. 최근에는 치료 반응 예측 지표로도 연구된다.

## 1. 목적

- 소섬유(small fiber)는 얇은 무수초 C섬유와 얇은 유수초 Aδ섬유다. 굵기가 작아 [[신경전도검사]]에서 정상으로 나오는 경우가 많다.
- IENFD는 이 소섬유의 **해부학적 소실**을 직접 확인하는 표준 방법이다.
- 통증·작열감·이질통이 있으나 전도검사가 정상인 환자에서 '설명되지 않는 증상'을 객관화하는 데 쓴다.

## 2. 시행·구성

1. **부위**: 원위 하지(외측 복사뼈 상방 약 10 cm)가 표준. 필요 시 근위부(대퇴)를 함께 채취해 길이의존성 소실을 판단한다.
2. **조직**: 국소마취 후 3 mm 천공 생검(punch biopsy). 봉합 1~2바늘.
3. **처리**: 냉동 절편 50 µm 두께로 절단.
4. **염색**: PGP9.5(pan-neuronal marker) 면역염색으로 표피 내 신경섬유를 표지.
5. **계수**: 진피-표피 경계를 통과하는 신경섬유 수를 절편 길이(mm)로 나눠 **fibers/mm**로 보고. 3개 절편 이상의 평균을 쓴다.
6. **참조**: 연령·성별·부위별 정상치의 5백분위수를 하한으로 적용한다.

## 3. 채점·해석

| 결과 | 해석 |
| :--- | :--- |
| 정상 하한 이상 | 소섬유 구조는 보존. 기능이상(QST 이상)만 있으면 기능성 소섬유병증으로 분류 |
| 정상 하한 미만 | 말초 소섬유 소실 — 소섬유신경병증 진단 지지 |
| 근위-원위 차이가 큰 경우 | 길이의존성(말단부 우세) 손상 — 당뇨·독성·유전성 양상과 부합 |

- 판정은 **임상 증상 + 신경학적 진찰 + 정량감각검사**를 함께 본다. 수치 하나로 진단하지 않는다.
- 검사실마다 염색·계수 방식이 달라 자체 정상치가 필요하다. 타 기관 수치를 그대로 인용하면 오판이 난다.

## 4. 임상 사용·한계

- **장점**: 소섬유 손상을 구조적으로 확인, 다른 말초신경병증(아밀로이드·파브리·유전성) 감별에 도움.
- **한계**: ① 침습적(흉터·감염·출혈) ② 국소 표본이라 오차가 큼 ③ 굵은 신경섬유 상태는 알 수 없음 ④ 추적검사에 반복 시행이 부담 ⑤ 자율신경 기능은 별도 평가 필요.
- **대안**: 각막 공초점현미경(비침습 대체), 정량감각검사, [[신경전도검사]](굵은 섬유 평가), 자율신경 검사.
- **해석 주의**: 소섬유 소실이 있어도 통증 강도와 비례하지 않는다. 구조와 증상은 별개 축이다.

## 5. 오늘 논문에서의 위치 (2026-11-20)

[[2026-11-20_신경계통증의학_심층리뷰]] 논문 3번(BOTNEP, Attal 등)에서 **치료 반응 예측 인자**로 쓰였다. 표피내 신경섬유밀도가 보존된 환자에서 [[보툴리눔 톡신 A]] 반응 오즈비가 약 6.2로 보고됐다. 즉 말초 신경말단이 살아 있어야 절단·수송 조절이라는 BoNT/A 기전이 성립한다는 해석이 가능하다. 이는 '어떤 [[신경병증성 통증]] 환자에게 어떤 중재를 쓸 것인가'를 표현형으로 나누는 접근의 예가 된다.
