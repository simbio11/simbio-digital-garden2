# ODI (Oswestry Disability Index, 오스웨스트리 장애 지수)

> **핵심 요약**: 요통 환자의 **일상생활 기능 장애**를 측정하는 대표적인 환자보고 평가도구(PROM). 10개 항목을 0~5점으로 채점해 백분율(%)로 환산하며, 임상시험·진료에서 요통의 기능적 중증도와 치료 반응을 객관화한다. 임상적으로 10% 포인트 전후를 최소유의차(MCID)로 보는 경우가 많다.

## 목적과 구성
- 개발: Fairbank 등, 1980
- 10개 항목(각 0~5점): 통증 강도, 개인 관리, 들기, 걷기, 앉기, 서기, 수면, 성생활, 사회생활, 여행
- 채점: 항목 합계(최대 50점) → **백분율 환산** (합계/50 × 100)

## 해석(백분위 구간)
- 0~20%: 경미한 장애 / 20~40%: 중등도 / 40~60%: 심한 장애 / 60~80%: 폐질 수준 / 80~100%: 와상 수준(심한 통증)
- 변화 해석: 흔히 **10% 포인트(또는 8~10점) 전후를 MCID**로 활용

## 임상 사용·한계
- 요통·척추 질환 임상시험의 표준 1차 평가지표 중 하나
- 성생활 항목 때문에 응답 거부 가능성 → 변형본(ODI 2.1a 등) 사용 고려
- 통증 강도(VAS/NRS)와 달리 '기능'을 본다는 점에서 치료 효과 판정에 유용

## 논문 연결
