# MAS (Modified Ashworth Scale)

> **핵심 3줄 요약 (Key Summary)**:
> - 🎯 목적: 상부운동신경원 손상 후 [[경직(Spasticity)]]의 정도를, 수동 신장에 대한 저항으로 검사자가 등급화하는 임상 척도다.
> - 📊 구성: 0 / 1 / 1+ / 2 / 3 / 4의 6단계 서열. 도구 없이 수 초에 시행할 수 있어 임상·RCT의 표준 경직 지표로 쓰인다.
> - ⚠️ 한계: 검사자 간 변이와 주관성이 크고, 속도 의존성은 반영하지 못한다. 속도 성분을 보려면 Tardieu 척도를 병행한다.

## 1. 목적·구성
- 목적은 경직의 '양'을 치료 전후로 비교하는 것이다. 관절을 초당 약 1회 속도로 수동 신장하면서 느껴지는 저항의 크기와 나타나는 가동범위 위치로 등급을 정한다.
- 평가 자세는 앉거나 누운 상태에서 관절을 중립에 두고 시작한다. 상지는 어깨·팔꿈치·손목, 하지는 고관절·무릎·발목을 각각 평가하며, 좌우를 따로 기록한다.
- 결과는 합산 점수가 아니라 관절별·동작별 등급으로 보고한다. 총점화하려면 관절별 점수를 합산하는 변형을 쓰되, 원 척도가 총점 도구가 아님을 밝혀야 한다.

## 2. 채점 (0~4+)
| 점수 | 판정 |
| :--- | :--- |
| 0 | 근긴장 증가 없음 |
| 1 | 신장 말기에서 잡아당김(catch) 후 풀림 — 저항 경미 |
| 1+ | 관절 가동범위 절반 미만에서 잡아당김 + 최소 저항 |
| 2 | 가동범위 대부분에서 현저한 긴장 증가 — 수동 운동은 비교적 쉬움 |
| 3 | 뚜렷한 긴장 증가 — 수동 운동 어려움 |
| 4 | 사지가 굴곡·신전에서 강직(rigid) |

## 3. 해석
- 1과 1+의 구분이 실무에서 가장 흔들린다. 잡아당김이 가동범위 후반부에만 나타나면 1, 전반부부터 나타나면 1+로 읽는다.
- 서열 척도이므로 평균±표준편차보다 중앙값(사분위 범위)으로 보고하는 것이 원칙이다. 등급 간 간격이 등간이 아니기 때문이다.
- 4는 '경직'이 아니라 강직(rigidity)에 가까운 상태로, 파킨슨증의 강직과 감별이 필요하다. 강직은 속도와 무관하게 일정한 저항을 보인다.

## 4. 임상 사용·한계
- 빠르고 도구 없이 시행 가능해 임상·RCT의 표준 경직 지표로 쓰인다. 치료 반응 판정(약물·보툴리눔·[[두침]]·[[rTMS]] 등)에도 흔히 사용된다.
- 한계는 ① 검사자 간 변이 ② 저항의 주관성 ③ 속도 의존성 반영 제한이다. 특히 같은 환자를 다른 검사자가 재면 1등급 이상 차이가 날 수 있어, 가능하면 같은 검사자가 전후를 측정한다.
- 경직이 기능을 방해하는지와 경직의 크기는 별개다. MAS가 높아도 보행·파지에 쓰이고 있으면 무리하게 낮추지 않는다. 기능 지표([[FMA]])와 함께 읽어야 하는 이유다.
- 속도 의존성과 조직 자체의 단축(구축)을 구분하려면 [[Tardieu 척도]]를 병행한다. Tardieu는 나타나는 각도(X)와 잡아당김 속도(V)를 따로 기록해 구축과 경직을 분리한다.

## 5. 논문 연결
- **2026-09-02 심층리뷰 1번(두침 메타분석)**: 두침+재활군 경직 MAS **MD −0.56(95% CI −0.75~−0.37)**.
  - [연구 요약]: 두침 병행이 재활 단독보다 경직 등급을 낮췄다는 메타분석 결과로, MAS를 연속형처럼 다룬 분석이다.
- **2026-11-04 심층리뷰 3번(뇌졸중 상지 경직 rTMS, [PMID 40399427](https://pubmed.ncbi.nlm.nih.gov/40399427/))**: 상지 MAS 중앙값이 시험군 4(3~4) → 2(2~2.75), 대조군 3(3~4) → 3(2~3), 군간 **Z=−2.918(P=0.004)**. 분석 85명(시험군 32 / 대조군 53).
  - [연구 요약]: 피질 고주파 + 말초 저주파 동시 자극 15회기가 상지 경직을 두 등급 낮췄다. 저자들은 중앙값·사분위로 보고해 서열 척도의 성질을 지켰다.
- **읽기 규칙**: MAS 수치를 인용할 때는 ① 어느 관절·동작인지 ② 평균인지 중앙값인지 ③ 검사자 눈가림 여부를 함께 적는다. 셋 중 하나가 빠지면 다른 시험과 비교할 수 없다.
