# 연결체 기반 예측모델링 (Connectome-Based Predictive Modeling, CPM)

> **핵심 요약**: 개인의 **뇌 연결체(connectome)** 데이터에서 임상 지표를 예측하는 **데이터 주도(data-driven) 모델링 기법**. 휴지기 fMRI의 기능연결 행렬에서 전체 피험자·전체 연결을 놓고, 임상 결과와 상관이 유의한 연결을 **양(+)·음(−) 방향 네트워크로 나눠 뽑아낸 뒤(특징 선택)** , 각 네트워크의 연결 강도 합으로 개인의 결과값을 회귀 예측하고 **교차검증**한다. '뇌 지문으로 누가 치료에 반응할지 예측한다'는 발상의 표준 방법론이다.

## 목적·구성
- **입력**: 휴지기 fMRI BOLD 시계열 → 뇌 영역(아틀라스 기반 노드) 쌍별 **기능연결값 행렬**
- **3단계**
  1. **특징 선택**: 훈련 데이터에서 임상 점수와 상관이 유의한 연결만 선택 — **양의 연결(positive network)** 과 **음의 연결(negative network)** 을 따로 구성
  2. **점수화**: 각 피험자의 네트워크별 연결 강도 합산값(summary score) 계산
  3. **교차검증·예측**: 훈련→검증 분할(leave-one-out 등)로 회귀모델을 만들고 별도 피험자의 임상 결과를 예측 → 예측-실제 상관(r)과 p값 보고
- **흔한 혼동**: CPM은 **상관 기반 예측**이지 인과 모델이 아니다. 연결이 '원인'이라는 뜻이 아니라 '예측 단서'라는 뜻
- **검증 요건**: 독립 외부표본 검증이 없으면 임상 도구로 쓰면 안 된다

## 해석·채점
- 결과는 보통 **r값 + p값**으로 보고 — 예: r=0.23~0.29(P<.05) 수준은 **통계적 유의는 있어도 예측력이 낮다**(분산 설명 5~8% 수준)
- **어떤 결과를 예측하는지**를 구분해 읽어야 한다 — 통증강도(VAS)와 기능·장애점수(HIT-6)는 서로 다른 연결 지문에 대응할 수 있다
- **다중비교·과적합 위험**: 연결 수가 수만 개인데 표본은 수십~수백 명 → 임계값 설정에 따라 결과가 변하고, 외부 검증 없이는 재현성 미확인
- **임상 해석 금지선**: 개별 환자의 치료 선택을 CPM으로 정하는 단계가 아니다

## 임상 사용·한계
- **현재 위치**: 연구 지표(mechanistic biomarker 후보). 진료에서는 통상적 평가도구(두통 일기·VAS·[[HIT-6]]·[[MIDAS]])로 반응을 추적하는 것이 표준
- **기대되는 활용 방향**: 중재 반응자 선별(개인화), 기전 분리(진통 vs 기능 개선), 플라시보·맥락 효과와의 구분
- **한계 요약**: ① 표본 크기 부족·외부 검증 부재 ② fMRI 스캐너·전처리 파이프라인 의존(기관 간 이식성 문제) ③ 예측된 지표만 검증되고 나머지는 실패할 수 있음 ④ 비용·시간

## 논문 연결
- 2026-09-18 심층리뷰 1번(JAMA Netw Open 2026;9(1):e2555454, PMID 41591775, 무조짐편두통 120명 침 RCT): 기저 휴지기 fMRI로 CPM 적용 — **음의 연결 네트워크 12개 연결 → VAS 감소 예측(r=0.23, P=.04)**, **양의 연결 네트워크 120개 연결 → HIT-6 개선 예측(r=0.29, P=.02)**. 반면 **월 편두통 일수(MMD)·월 두통일수(MHD)·급성기 약물사용일·MSQ는 예측 실패** → 적용 범위가 제한적이며 외부 검증이 필요하다고 저자들이 명시
