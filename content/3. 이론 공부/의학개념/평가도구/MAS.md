# MAS (Modified Ashworth Scale)

> **핵심 요약**: 뇌졸중 등 상부운동신경원 손상 후 **경직(spasticity)의 정도**를 검사자가 수동 신장에 대한 저항으로 평가하는 0~4+ 척도. 임상·연구에서 가장 널리 쓰이는 경직 평가 도구로, 2026-09-02 두침 메타분석에서도 1차 결과 지표로 사용되었다.

## 채점 (0~4+)
| 점수 | 판정 |
| :--- | :--- |
| 0 | 근긴장 증가 없음 |
| 1 | 신장 말기에서 잡아당김(catch) 후 풀림 — 저항 경미 |
| 1+ | 관절 가동범위 절반 미만에서 잡아당김 + 최소 저항 |
| 2 | 가동범위 대부분에서 현저한 긴장 증가 — 수동 운동은 비교적 쉬움 |
| 3 | 뚜렷한 긴장 증가 — 수동 운동 어려움 |
| 4 | 사지가 굴곡·신전에서 강직(rigid) |

## 임상 사용·한계
- 빠르고 도구 없이 시행 가능 → 임상·RCT의 표준 경직 지표
- **한계**: 검사자 간 변이, '저항'의 주관성, 속도 의존성 반영 제한 → Tardieu 척도 병행 권장
- 치료 반응 판정(약물·보툴리눔·두침 등)에 흔히 사용

## 논문 연결
