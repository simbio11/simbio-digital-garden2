# SCORAD (SCORing Atopic Dermatitis)

> **핵심 요약**: **아토피피부염의 중증도를 '범위 + 강도 + 주관 증상'의 3요소로 합산하는 표준 임상 평가도구**. A(병변 범위, 0~100%) + B(6개 항목 강도, 각 0~3) + C(소양감·수면장애, 각 0~10)를 정해진 가중식으로 합쳐 **0~103점** 범위를 갖는다. <25 경증 / 25~50 중등도 / >50 중증으로 대별하며, **아토피 임상시험의 1차 종점**으로 가장 널리 쓰인다.

## 목적·구성
- **목적**: 아토피피부염 중증도를 연속 변수로 정량 → 치료 반응 판정·시험 종점·급여 판단 근거
- **A. 범위(Extent)**: 인체를 9의 법칙(rule of nines)으로 나눠 침범 면적을 평가, 0~100%
- **B. 강도(Intensity)**: 대표 병변 부위에서 6개 항목을 0(없음)~3(심함)으로 채점
  1. 홍반(erythema) 2. 부종·구진(edema/papulation) 3. 삼출·가피(oozing/crusting) 4. 찰상(excoriation) 5. 태선화(lichenification) 6. 건조(dryness) — **6항목 최대 18점**
- **C. 주관 증상(Subjective)**: 소양감(pruritus)과 수면장애(sleep loss)를 각각 0~10 VAS로 평가, 최대 20점
- **합산식**: **SCORAD = A/5 + 7×B/2 + C** (최대 103점)

## 채점·해석
| 구간 | 점수 | 임상적 의미 |
| :--- | :--- | :--- |
| 경증 | < 25 | 보습·국소 치료 중심 |
| 중등도 | 25 ~ 50 | 국소 스테로이드·칼시뉴린 억제제, 광선치료 고려 |
| 중증 | > 50 | 전신 치료(면역억제제·생물학적 제제)·입원 고려 |
- **변화 해석**: 총점 감소가 곧 임상 개선. 문헌에서 최소 임상적 중요 차이(MCID)로 **약 8.7점**이 인용되나, 단일 숫자로 단정하기보다 **범위·강도·주관 항목별 변화**를 함께 볼 것
- **객관부 vs 주관부**: 소양감·수면(C)은 환자 보고라 위약 반응에 민감 → **1차 지표는 객관부(A+B)로, 주관부는 2차로** 분리해 읽는 것이 안전하다

## 임상 사용·한계
- **장점**: 사용이 널리 퍼져 있어 **연구 간 비교(메타분석)가 가능**하고, 삶의 질·위장 증상 척도와 병용하면 다차원 평가가 된다
- **한계**
  1. **관찰자 간 변이** — 6개 강도 항목이 관찰자 주관에 의존
  2. **소양감·수면(20점)이 전체에 섞여** 있어, 항히스타민·수면 약물이나 위약 효과에 점수가 흔들린다
  3. 경증~중등도에서 **바닥효과(floor effect)** — 원래 점수가 낮으면 개선을 표현할 여지가 적다
  4. 범위(A) 산정의 실제 정밀도 문제 — 소아·광범위 병변에서 과대/과소 산정 가능
- **대안·보완 도구**: EASI(강도 위주, 병변 면적 가중), DLQI(삶의 질), POEM(환자 보고), itch NRS(소양감 단독). 목적에 따라 선택·병용
- **한의 임상 적용**: 한약·침 중재를 평가할 때 **SCORAD 변화 + 소양감 NRS + 수면·삶의 질(EQ-5D)** 을 사전에 정해 추적하면 "피부는 그대로인데 속·컨디션이 좋아졌다"는 변화도 정직하게 기록할 수 있다

## 논문 연결
