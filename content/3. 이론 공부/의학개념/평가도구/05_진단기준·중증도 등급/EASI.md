# 📏 EASI (Eczema Area and Severity Index)

> **핵심 요약 (Key Summary)**:
> - 📏 **무엇을 재는 도구**: [[아토피 피부염]]의 범위(면적)와 중증도(4개 징후)를 결합한 표준 중증도 지수(0~72점).
> - 🎯 **구성**: 4개 신체 부위(두경부 10%·몸통 30%·상지 20%·하지 40%)별로 면적 점수(0~6)와 4개 징후(홍반·부종/구진·찰상·태선화) 각 0~3점.
> - 🛠️ **해석**: EASI 75(75% 개선)가 생물학적 제제·전신치료의 대표 반응 기준.

## 1. 목적·구성

| 부위 | 체표면 비율 | 가중치 |
| :--- | :--- | :--- |
| 두경부 | 10% | 0.1 |
| 몸통 | 30% | 0.3 |
| 상지 | 20% | 0.2 |
| 하지 | 40% | 0.4 |

* **면적 점수(A, 0~6)**: 0%(0점), 10% 미만(1), 10~29%(2), 30~49%(3), 50~69%(4), 70~89%(5), 90~100%(6).
* **중증도 점수(S, 0~3)**: 홍반, 부종·구진, 찰상(excoriation), 태선화(lichenification)를 각각 0(없음)~3(심함)으로 평가.
* **부위 점수 계산**: (S 합계 0~12) × A × 가중치.
* **총점**: 4개 부위 합 = 0~72점.

---

## 2. 채점·해석

| 총점 | 중증도 |
| :--- | :--- |
| 0 | 없음(clear) |
| 0.1 ~ 1.0 | 거의 없음 |
| 1.1 ~ 7.0 | 경도 |
| 7.1 ~ 21.0 | 중등도 |
| 21.1 ~ 50.0 | 중증 |
| 50.1 ~ 72.0 | 매우 중증 |

* **반응 기준**: EASI 50/75/90 = 기저 대비 50%·75%·90% 개선. 임상시험 1차 결과로 가장 많이 쓰인다.
* **최소임상중요차이(MCID)**: 대략 6~7점 수준의 절대 감소가 체감 개선과 대응한다고 보고된다.

---

## 3. 임상 사용·한계

* **장점**: 부위별 가중치가 있어 전신 범위를 반영하고, 치료 전후 비교가 명확하다. 생물학적 제제([[dupilumab]]) 반응 판정의 표준이다.
* **한계**: 관찰자 간 변이, 태선화·찰상 판정의 주관성, 소아에서 두경부 비중 과소평가 등의 문제가 지적된다. 소양·삶의 질은 별도 도구로 보완한다.
* **한의 임상 활용**: 한약·침 치료 전후 EASI를 4주 간격으로 기록하면 습진 병변의 범위 변화를 보여주기 좋다. 사진 촬영 각도·조명을 고정하면 신뢰도가 올라간다.
* **동반 지표**: [[IGA]], 소양 NRS, DLQI, [[IgE]]·호산구는 보조 지표로 함께 본다.
