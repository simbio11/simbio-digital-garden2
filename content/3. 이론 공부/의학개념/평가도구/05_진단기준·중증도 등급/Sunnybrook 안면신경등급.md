# Sunnybrook 안면신경등급 (Sunnybrook Facial Grading System, SFGS)

> **핵심 요약**: [[안면신경마비]]의 중증도를 **정지 시 대칭 · 자발적 표정 움직임 · 연합운동(synkinesis)** 세 요소로 나눠 하나의 점수로 합성하는 안면신경 평가 도구. **0(완전마비)~100(정상)** 범위로 산출하며, 총점 = 자발적 표정 움직임 점수 − 정지 대칭 점수 − 연합운동 점수. [[7. 얼굴신경]]의 5대 종말 분지가 지배하는 표정 동작을 부위별로 평가하므로, 회복기 후유증(연합운동)을 별도 점수로 드러낼 수 있다.

## 목적·구성
- 목적: 안면신경 기능을 **하나의 연속 점수**로 정량화해 경과 추적·치료 반응 판정에 쓰는 것. [[안면신경마비]]의 예후·회복 판정과 임상시험의 결과지표로 사용된다
- 평가 대상 근육군은 [[7. 얼굴신경]]의 분지가 지배하는 안면 표정근이다 — 측두지(이마), 관골지(눈 둘레·광대), 협근지(볼·입술), 하악연지(아랫입술·턱)

| 요소 | 평가 항목 | 배점 |
| :--- | :--- | :--- |
| 정지 시 대칭 (Resting Symmetry) | 눈(정상 0 / 좁아짐·넓어짐·수술 1), 볼·비순구(정상 0 / 덜 뚜렷 1 / 더 뚜렷 1 / 없음 2), 입(정상 0 / 입꼬리 처짐 1 / 위·아래로 당김 1) | 부위 점수 합 × 5 → 0~20 |
| 자발적 표정 움직임 (Symmetry of Voluntary Movement) | 5개 표준 표정 — 이마 주름 잡기, 부드럽게 눈 감기, 입 벌리고 웃기, 코 찡그리기, 입술 오므리기. 각 1(시작 못함)~5(완전) | 5동작 합 × 4 → 20~100 |
| 연합운동 (Synkinesis) | 같은 5개 표정을 지을 때 나타나는 비수의적 근수축. 각 0(없음)~3(심한 연합운동·다근육 총동원) | 5동작 합 → 0~15 |

## 채점·해석
- **종합점수(composite score) = 자발적 표정 움직임 점수 − 정지 시 대칭 점수 − 연합운동 점수**
- 범위는 **−15~100**(이론적 하한 −15)이며, 점수가 높을수록 정상에 가깝다. 100은 정상 안면 기능
- 세 요소를 각각 따로 읽는 것이 핵심이다. 예를 들어 자발 움직임 점수는 회복됐는데 연합운동 점수가 크면 '기능은 돌아왔지만 후유증이 뚜렷한' 상태로 해석한다
- 반복성(신뢰도): 이탈리아어판 검증에서 종합점수 평가자 간 ICC 평균 0.98, 세 영역 ICC 0.85~0.98로 보고되었다

## 임상 사용·한계
- **한의·임상 활용**: ① 초진·경과 시 같은 5개 표정을 같은 순서로 평가해 종합점수를 기록하면 회복 추세가 숫자로 남는다 ② 연합운동 점수를 따로 적어두면 매선·추나 등 후유증기 치료의 반응 판정 근거가 된다 ③ "이마 주름·눈 감기·미소·코 찡그리기·입술 오므리기"를 환자에게 시연 동작으로 안내하는 것 자체가 표정근 재활 훈련이 된다
- **시점 해석 주의**: 이번 회차 시험에서 6주 시점 SFG 변화량은 두 군 간 유의한 차이가 없었고 12·24주에서 차이가 관찰됐다. 즉 치료 직후 점수만으로 최종 결론을 내리지 않는다
- **한계**: 5개 표정의 시각적 판정이라 관찰자 훈련이 필요하고, 부위별 배점이 세밀해 초심자보다 숙련자가 안정적이다(정지 대칭 영역의 ICC가 상대적으로 낮음). 연합운동은 환자 스스로 인지하지 못하는 경우가 많아 검사자가 관찰로 잡아야 한다
- 기존 하우스-브랙만 등급보다 안면 부위별 기능과 후유증(연합운동·정지 대칭)을 분리해 드러내는 장점이 있어, 회복기 후유증 평가에서 선호된다
