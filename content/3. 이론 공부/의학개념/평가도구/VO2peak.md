# VO2peak (최대 산소섭취량)

> **핵심 요약**: 점증 운동부하 검사에서 **더 이상 산소섭취가 증가하지 않는 지점의 산소섭취량(mL/kg/분)**. 심폐체력의 표준 지표로, 노인에서는 **자립성·심혈관 사건·사망 위험과 강하게 연관**되며 운동 중재 시험의 핵심 이차 종점이다. 임상에서는 '이론적 최대'를 뜻하는 VO2max 대신 실제 달성치인 **VO2peak**로 표기한다.

## 목적·구성
- 장비: 가스분석기(대사카트) + 트레드밀 또는 자전거 에르고미터, 12-lead ECG·혈압·SpO2 감시
- 프로토콜: 단계적 증부하(예: 2~3분 단계), 종료 기준 = 호흡교환율(RER) ≥1.1, 연령 예측 최대심박 도달, 증상(흉통·어지럼)·이상 ECG
- 검사 전 심혈관 위험 평가(병력·ECG)가 선행되어야 함

## 채점·해석
- 절대값이 낮을수록 심폐체력 저하 — 고령·심부전·수술 전 위험도 평가에 사용
- 연령·성별 예측치(또는 정상 백분위)와 비교, 추적 시 변화량으로 해석
- 변화 해석에는 측정 오차·최소 임상적 차이([[MCID]])를 함께 고려

## 임상 사용·한계
- 한의원에서 직접 측정은 어려우나 **6분 보행거리, 보행속도, 계단 과제([[mPPT]])** 같은 대리지표로 심폐·기능 개선을 추적할 수 있다
- 한계: 운동부하 검사는 고위험군(불안정 협심증·조절 안 되는 고혈압 등)에서 금기 — 검사 전 안전 평가 필수
- 동기부여·프로토콜·기기 보정에 따라 값 차이가 큼 → 같은 프로토콜로 추적

## 논문 연결
- 2026-09-12 심층리뷰 3번(DEMFOS, Lancet Healthy Longev 2026;7(7):100883, [PMID: 42532077](https://pubmed.ncbi.nlm.nih.gov/42532077/)): 이차지표로 VO2peak 6개월 변화 **ILI+Met +3.6 / ILI+Pbo +3.5 / HL+Met +0.2 mL/kg/분** — 복합운동을 포함한 집중 생활습관 중재군만 개선, 메트포르민 추가는 영향 없음
- 같은 시험에서 6분 보행거리 +52.2 / +50.1 / +6.0 m, 보행속도 +0.12 / +0.13 / +0.01 m/초 — 심폐체력 개선이 보행 기능으로 이어진 결과
