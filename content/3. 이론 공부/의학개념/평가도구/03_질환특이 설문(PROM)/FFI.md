# 📚 FFI (Foot Function Index / 족부기능지수)

> **핵심 3줄 요약 (Key Summary)**:
> - 🎯 목적: 발·발목 질환 환자가 보고하는 통증·장애·활동 제한을 정량화하는 자기보고 설문(PROM)이다.
> - 📍 구성: 통증(pain)·장애(disability)·활동 제한(activity limitation)의 3개 영역. 원판 23문항, 개정판 FFI-R, 단축형 FFI-RS가 함께 쓰인다.
> - 📊 해석: 0~100%로 표준화해 점수가 높을수록 기능이 나쁘다. [[족저근막염]]·[[류마티스 관절염]]·[[당뇨발]] 연구에서 1차 결과로 사용된다.
> - <font color="#fa7e7e">⚠️ 주의: 버전(원판·FFI-R·FFI-RS)에 따라 문항 수와 점수 범위가 다르므로 버전 간 수치를 직접 비교하면 안 된다.</font>

---

## 1. 목적·구성

- 목적: 발·발목 병변의 통증과 기능 장애를 환자 관점에서 측정한다. 진료실에서는 초진 기저값을 기록하고 치료 후 같은 버전으로 반복 측정한다.
- 영역 구성: 통증, 장애, 활동 제한의 3영역. 원판 FFI는 23문항이며, 개정판 FFI-R은 심리·사회 항목을 보강했고, 단축형 FFI-RS는 문항 수를 줄여 외래에서 빠르게 작성하게 한다.
- 2026-10-06 리뷰 2번 시험에서는 FFI 총점을 1차 결과 중 하나로 사용했다 — [[족저근막염]] 48명에서 8주 후 실험군 74.1 → 10.9, 대조군 77.0 → 13.2(두 군 모두 유의 개선, 군 간 p=0.330).

## 2. 채점·해석

- 원칙: 각 문항을 합산해 영역별 점수와 총점을 계산하고, 백분율(0~100%)로 표준화한다. 점수가 높을수록 통증·장애가 크다.
- 버전 주의: 원판·FFI-R·FFI-RS는 문항 수·척도가 다르다. 같은 환자에서 버전을 바꿔 비교하면 변화량이 왜곡된다(2026-09-28 [[WOMAC]] 버전 주의와 같은 원리).
- 해석 보조: 통증 영역과 기능 영역을 분리해 읽는다. 통증은 줄었는데 기능 점수가 남아 있으면 부하·두려움 회피 요인([[두려움-회피 모델]])을 함께 평가한다.

## 3. 임상 사용·한계

- 사용 장면: [[족저근막염]]·[[족근 터널 증후군]]·후족부 병변·[[당뇨발]]에서 치료 반응 추적. 대기시간에 작성하게 하고 세션 시작 시 검토한다.
- 함께 쓰는 지표: [[발 자세 지수]](자세), 기상 첫 걸음 NRS(특이 통증), 배굴 ROM, [[6분 보행검사]](수행능력).
- 한계: 지역·언어별 타당화 버전이 나뉘어 있어 한국어 버전 사용 시 적용된 검증 근거를 확인해야 한다. 문항이 통증·기능을 자기보고로만 측정하므로 수행 기반 검사와 병행하는 편이 안전하다.
- 원판 FFI는 1991년 개발된 도구이나, 본 노트는 원판 PMID를 확인하지 못해 검증·활용 근거가 확인된 개정판 문헌으로 인용한다(원판 서지는 미확인 항목으로 남긴다).

## 4. 논문 연결

- FFI-RS 타당화 — The Importance of Foot Function Assessment Using the Foot Function Index-Revised Short Form (FFI-RS) Questionnaire in the Comprehensive Treatment of Patients with Rheumatoid Arthritis. Journal of Clinical Medicine 2022;11(9), [PMID: 35566422](https://pubmed.ncbi.nlm.nih.gov/35566422/).
  - [연구 요약] 단축형 FFI-RS의 구성과 임상 활용을 정리한 검증 연구로, 외래에서 빠르게 반복 측정하는 근거가 된다.
- FFI를 결과지표로 쓴 최신 고찰 — Impact of Graston Technique and Deep Friction Massage on Plantar Fasciitis Using the Foot Function Index: A Scoping Review. International Journal of Therapeutic Massage & Bodywork 2026;19(3):70-79, [PMID: 42688872](https://pubmed.ncbi.nlm.nih.gov/42688872/).
  - [연구 요약] [[족저근막염]] 수기 중재 연구에서 FFI가 반복 사용되는 지표임을 보여준다. 수기 요법의 통증·기능 개선 폭과 근거 수준은 연구마다 차이가 크다.
- 2026-10-06 심층리뷰 2번 — 다요소 재활 RCT(BMC Musculoskeletal Disorders 2026;27(1):168, [PMID: 41715005](https://pubmed.ncbi.nlm.nih.gov/41715005/))의 1차 결과 FFI 수치(74.1→10.9 vs 77.0→13.2, p=0.330).
  - [연구 요약] 두 군 모두 큰 폭으로 개선됐으나 군 간 차이는 없었다. 통증·기능 지표의 천장효과를 보여주는 사례다.
