# STarT Back 도구 (STarT Back Screening Tool — 요통 만성화 위험 선별)

> **핵심 요약**: 일차의료 요통 환자를 **만성화 위험도(저·중·고)로 층화(stratified)** 하기 위한 9문항 자기보고 선별도구다. 목적은 진단이 아니라 **치료 강도·구성의 배분** — 저위험군은 최소 개입, 고위험군은 심리사회적 요소까지 다루는 맞춤 치료로 연결한다. 2026-09-21 심층리뷰 2번(PACBACK, JAMA 2026)은 이 도구로 **만성화 중등도~고위험군만** 선별해 "수기요법보다 자기관리 코칭이 만성화 예방을 만든다"는 결론을 도출했다.

## 목적·구성
- **9문항** 자기보고(예/아니오 형식 8문항 + 마지막 '지난 2주간 요통의 성가심' 5점 문항)
  - **신체(physical) 하위**: 하지로 방사된 통증, 목·어깨 통증 동반, 짧은 거리만 보행, 통증으로 인한 느린 옷 입기, 통증의 성가심
  - **심리사회적(psychosocial) 하위**: "이런 상태에서 신체 활동은 안전하지 않다"(운동공포), 걱정되는 생각, "요통이 끔찍하고 절대 나아지지 않을 것"(파국화), 즐거움 상실(기분)
- 개발: Keele 대학 그룹(Hill 등, 2008) — 일차의료 요통 층화 치료(stratified care) 모델의 핵심 도구

## 채점·해석
- **총점 0~9**
  - **저위험(low)**: 총점 0~3
  - **중간위험(medium)**: 총점 4~9 이면서 **심리사회적 하위점수 ≤3**
  - **고위험(high)**: 총점 4~9 이면서 **심리사회적 하위점수 ≥4**
- **해석의 핵심**: 총점만 보지 말고 **심리사회적 하위점수**를 함께 본다 — 고위험군 판정은 **운동공포·파국화·기분 저하**가 치료 표적임을 알리는 신호다 → [[운동공포]] · [[통증 파국화]] · [[두려움-회피 모델]]
- **치료 배분 원칙**: 저위험 → 교육·자가관리 중심 / 중간위험 → 물리치료 등 표준 치료 / **고위험 → 심리사회적 중재 결합**

## 임상 사용·한계
- **한의원 실전 활용**: 초진에서 ① 통증 강도(VAS/NRS)와 함께 **만성화 위험을 먼저 층화** ② 고위험군이면 수동 중재만 반복하지 말고 **통증 교육("아프다 ≠ 다쳤다")·단계적 활동 재개·호흡/이완·생활습관**을 8주 감독 코스로 묶어 처방 → [[생물리사회적 모델]] · [[자기효능감]]
- **문진 최소 세트(도구를 안 쓸 때)**: ① 이 통증 때문에 어떤 움직임을 피하는가 ② 그 움직임이 다치게 할까 두려운가 ③ 통증이 절대 낫지 않을 것 같다고 느끼는가 ④ 즐기던 일을 못 하고 있는가
- **한계**
  - 자기보고 선별도구 — **진단 도구가 아니며**, 결과가 치료 방향을 자동 결정하지 않는다(공유 의사결정 필요)
  - 문화·언어 번역본의 측정 특성 차이, 급성기 초기 평가 시 상태 변동 가능성
  - 도구 점수 자체가 결과지표는 아니다 — 결과는 [[RMDQ]]·[[ODI]] 같은 기능 지표로 평가한다

## 논문 연결
- 2026-09-21 심층리뷰 2번(JAMA 2026;335(6):497-510, [PMID: 41460638](https://pubmed.ncbi.nlm.nih.gov/41460638/) / DOI 10.1001/jama.2025.21990, NCT03581123): **급성·아급성 요통 + STarT Back 중등도~고위험** 성인 1,000명 2×2 요인설계 RCT — 1년 평균 [[RMDQ]] 군간 차 유의(omnibus P=.001). **SSM(자기관리)이 표준의료보다 우수(−1.2, 95% CI −1.9~−0.5)**, SMT 단독은 차이 없음(−0.4, −1.2~0.4)
- **해석 포인트**: 위험 층화를 하지 않았다면 이 시험의 결론(자기관리 우위)이 희석되었을 가능성이 크다 — **환자 선별이 곧 근거 적용의 전제**다
