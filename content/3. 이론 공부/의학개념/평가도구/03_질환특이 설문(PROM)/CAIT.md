# 📊 CAIT (Cumberland Ankle Instability Tool)

> **핵심 요약 (Key Summary)**:
> 발목 불안정성을 환자가 스스로 보고하는 9문항·30점 자기기입 설문(PROM)이다. 통증·불안정감·기능 제한을 묻고 점수가 낮을수록 불안정이 심하다.
> 만성 발목 불안정증([[만성 발목 불안정증]], CAI) 선별의 표준 도구로, 문헌에서 널리 쓰이는 감별 기준은 24점 이하이다.
> 2026-10-14 심층리뷰 2번(CAI 이중과제 균형훈련 RCT)에서는 CAIT 24점 미만이 포함 기준이었다.

## 1. 목적·구성
- 목적: 발목 염좌 후 남는 기능적 불안정(주관적 헛디딤·불안정감)을 정량화한다.
- 구성: 9문항. 좌·우 발 점수를 각각 산출하며, 문항은 통증, 불안정감과 접질림 빈도, 일상·운동 기능 제한을 다룬다.
- 응답 방식: 문항별 서열 선택(문항별 배점 상이) 후 좌·우 별로 합산한다.
- 점수 범위: 0~30점(높을수록 안정).

## 2. 채점·해석
| 구분 | 내용 |
| :--- | :--- |
| 점수 범위 | 0~30점 |
| 해석 방향 | 점수 낮을수록 불안정 심함 |
| CAI 감별 기준 | 24점 이하(문헌 다빈도) |
| 비교 | 좌·우 별 산출, 시점별 변화량 추적 |
| 최소 중요 변화 | 도구·모집단별 보고 편차가 있어 사용 문헌 값을 그대로 인용 |

- 측정 대상 구분: CAIT는 주관적(자가보고) 불안정을 본다. 기계적 불안정은 전방 서랍 검사·거골 경사검사로, 동적 균형은 [[SEBT]]·한 발 서기 시간으로 따로 평가한다.
- 해석 시 [[전거비인대]]·[[종비인대]] 손상 이력과 [[장비골근]] 반응 시간을 함께 보면 기능적 불안정의 층위가 나뉜다.

## 3. 임상 사용·한계
- 임상 사용: 염좌 후 재발 위험 층화, 재활 전·중·후 추적, CAI 연구 대상자 선정(국제 발목 컨소시엄 권고와 병용).
- 한계
  - 주관 지표다. 통증·불안정감이 실제 동적 안정성과 항상 일치하지 않는다.
  - 좌·우를 각각 산출하므로 양측 계산 누락이 흔한 실무 오류다.
  - 번역판·청소년판(CAIT-Y) 등 버전별 절단값과 심리측정 특성이 다르다.
- 한의 임상 포인트: 진료실에서 수 분 내 시행 가능해 초진·재진 점수표로 그대로 쓸 수 있고, [[SEBT]]·[[장비골근]] 반응속도 같은 객관 지표와 짝지어 설명하면 순응도가 올라간다.

## 4. 논문 연결
- 2026-10-14 심층리뷰 2번(CAI 이중과제 균형훈련 RCT, Journal of Athletic Training 2024;59(11):1077-1088). [PMID 38419428](https://pubmed.ncbi.nlm.nih.gov/38419428/)
  - [연구 요약] CAIT 24점 미만 CAI 환자 24명을 단일과제군과 이중과제군으로 나눠 6주간 훈련했고, 이중과제군이 족저굽힘 관절위치감과 [[장비골근]] 반응 개시시간에서 우월했다.
