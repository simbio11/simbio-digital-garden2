# PRTEE (Patient-Rated Tennis Elbow Evaluation)

> **핵심 요약**: 외측상과염(테니스엘보) 환자의 **통증과 기능 장애**를 측정하는 15문항 환자보고 도구. 통증 5문항(0~50) + 기능 10문항(특정 활동 6 + 일상 활동 4, 합계를 2로 나눠 0~50)으로 총점 0~100이며, 점수가 높을수록 통증·장애가 크다. 팔꿈치 힘줄병증 임상연구의 표준 1차 결과(기능) 지표다.

## 목적·구성
- 개발 배경: Patient-Rated Wrist Evaluation(PRWE)에서 파생 — 원래 'Patient-Rated Forearm Evaluation Questionnaire(PRFEQ)'로 불리다가 외측상과염 특이 도구임을 명확히 하기 위해 PRTEE로 개명(Overend 등 1999 최초 신뢰도 연구)
- **PAIN 하위척도 5문항**(0=통증 없음 ~ 10=상상 가능한 최악): 휴식·반복 동작·물건 들기 등 통증
- **FUNCTION 하위척도 10문항**(0=어려움 없음 ~ 10=전혀 못함): 특정 활동 6문항(문손잡이·젖병/가방·식기·젖은 수건 짜기 등) + 일상 활동 4문항(개인 관리·가사·일/학업·레크리에이션)
- 지난 1주간 증상을 기준으로 응답, 소요 약 5분

## 채점·해석
- Pain Score = 통증 5문항 합(0~50) / Function Score = 기능 10문항 합 ÷ 2(0~50)
- **총점 = 통증 + 기능 (0~100)** — 통증과 기능 장애가 동일 가중
- 점수가 높을수록 통증·기능 장애 큼(0 = 무장애). 치료 전후 총점 변화로 중재 효과 평가
- 결측 문항은 해당 하위척도 평균으로 대체 가능(도구 매뉴얼)

## 임상 사용·한계
- 외측상과염·외측 팔꿈치 힘줄병증 연구의 표준 PROM — 통증(NPRS/VAS)만으로는 잡히지 않는 기능 제한을 포착
- 테스트-재테스트 신뢰도 우수(ICC 0.83~0.89 수준), 통증 없는 파악력(pain-free grip)과 유의한 상관
- 환자 주관 보고 — 악력·관절가동범위 등 수행 기반 지표와 병행 권장
- 한국어판 사용 시 번역·교차문화 타당도 확인 후 적용

## 논문 연결
- 2026-09-08 심층리뷰 3번(건침+도수 추가 다기관 RCT, Clin Rehabil 2024 — PMID 38676324): 1차 기능 결과로 3개월째 실험군 우위(F=19.675, P<0.001), **군 간 효과크기 SMD 1.13(95% CI 0.78~1.48) = '큰 효과'**

## 📎 개념 학습 보충 (2026-09-22 논문 연계)

- **3개월 시점 세부 수치(2026-09-22 리뷰 2번 재확인 — 09-08 리뷰 3번과 동일 논문)**: Clinical Rehabilitation 2024;38(8):1063-1079, [PMID: 38676324](https://pubmed.ncbi.nlm.nih.gov/38676324/) / NCT03167710
  - **1차 결과(3개월)**: 군간 차이 **−15.0점(95% CI −19.4 ~ −10.6)** — 이 도구의 **MCID 11점을 초과**, **SMD 1.13(95% CI 0.78–1.48)** = 큰 효과크기
  - **시점별 군내 변화(실험군 vs 대조군)**: 1주차 −11.9 vs −5.8(군간차 −6.1, P<0.001) / 4주차 −25.3 vs −18.0(군간차 −7.2, P<0.001) / **3개월 −33.4 vs −18.4**
  - **효과 크기 F값**: PRTEE F=19.675, NPRS F=22.769, TEFS F=13.269(모두 P<0.001)
- **환자 체감과의 교차 확인**: 3개월 **GRoC '큰 변화' 보고율 24.7%(+6)·32.9%(+7) vs 대조군 7.1%·10.0%** — **PRTEE의 개선이 환자 총평으로도 확인된 사례**다. MCID 초과 + 총평 일치라는 두 조건이 함께 성립한 좋은 예 → [[GRoC]] · [[MCID]]
- **해석 금지선**: 추적 3개월 단기, **위약 건침 대조군 없음**(패키지 부가 효과), 시술자 편향 위험 — PRTEE 15점 개선을 '건침 단독 효과'로 인용하지 말 것 → [[건침]] · [[외측상과염]]
