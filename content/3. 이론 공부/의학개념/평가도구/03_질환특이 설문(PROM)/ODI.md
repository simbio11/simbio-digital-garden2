# ODI (Oswestry Disability Index, 오스웨스트리 장애 지수)

> **핵심 요약**: 요통 환자의 **일상생활 기능 장애**를 측정하는 대표적인 환자보고 평가도구(PROM). 10개 항목을 0~5점으로 채점해 백분율(%)로 환산하며, 임상시험·진료에서 요통의 기능적 중증도와 치료 반응을 객관화한다. 임상적으로 10% 포인트 전후를 최소유의차(MCID)로 보는 경우가 많다.

## 목적과 구성
- 개발: Fairbank 등, 1980
- 10개 항목(각 0~5점): 통증 강도, 개인 관리, 들기, 걷기, 앉기, 서기, 수면, 성생활, 사회생활, 여행
- 채점: 항목 합계(최대 50점) → **백분율 환산** (합계/50 × 100)

## 해석(백분위 구간)
- 0~20%: 경미한 장애 / 20~40%: 중등도 / 40~60%: 심한 장애 / 60~80%: 폐질 수준 / 80~100%: 와상 수준(심한 통증)
- 변화 해석: 흔히 **10% 포인트(또는 8~10점) 전후를 MCID**로 활용

## 임상 사용·한계
- 요통·척추 질환 임상시험의 표준 1차 평가지표 중 하나
- 성생활 항목 때문에 응답 거부 가능성 → 변형본(ODI 2.1a 등) 사용 고려
- 통증 강도(VAS/NRS)와 달리 '기능'을 본다는 점에서 치료 효과 판정에 유용

## 논문 연결
- 2026-09-01 심층리뷰 1번(고령 만성 요통, 침+물리치료 RCT): 침 병행군이 대조군 대비 **ODI 평균 14.2점(퍼센트 포인트) 유의 개선** — 기능 회복의 객관적 근거로 사용됨

## 📎 개념 학습 보강·보충 (2026-09-24 논문 연계)

> 보강 사유: 본 노트는 2KB 미만·frontmatter 누락 상태였고, 최대 보행거리 등 짝 지표가 정리되지 않았다. 원문 내용은 그대로 보존하고 누락 섹션과 오늘 근거를 채웠다.

### 채점·해석 심화
- **채점**: 10개 항목(통증 강도·개인위생·물건 들기·걷기·앉기·서기·수면·사회생활·이동·여행)을 각 **0~5점**으로 채점 → 총점을 백분율로 환산(총점 ÷ 50 × 100). 버전·변형본에 따라 항목 수가 달라 총점 스케일이 다르므로 **버전 명시가 필수**다.
- **해석 구간(통상)**: 0~20% 최소 장애 / 21~40% 중등도 / 41~60% 중증 / 61~80% 심한 장애 / 81~100% 침상-속박 수준 — 단, 절대 구간은 연구·번역본마다 차이가 있어 시험 값을 그대로 인용한다.
- **변화 판정**: 10% 포인트 전후를 최소 중요 변화(MCI/MCID) 참고값으로 쓰는 문헌이 많으나, 09-24 시험처럼 **시험 자체의 1차 지표와 2차 지표 위치를 구분**해 읽어야 한다 → [[MCID]]
- **한계(재확인)**: 성생활 항목 응답 거부가 있어 변형본(ODI 2.1a 등) 사용을 검토하고, 통증 강도(NRS/VAS)와 별개로 **기능**을 본다는 점에서 짝 지표가 필요하다.

### 짝을 이루는 지표 — 최대 보행거리·무통 보행시간
- 요추 척추관 협착증에서 [[신경인성 파행]]의 중증도는 **자기보고(PROM)만으로는 부족**하다 — 보행거리·보행시간은 수행 기반 지표로 환자 체감과 기능을 교차 확인한다.
- 09-24 시험은 ODI·[[EQ-5D-5L]]·SF-12(자기보고)와 최대 보행거리(수행)를 함께 측정해 개선 방향이 일치함을 확인했다.

### 09-24 근거 연결
- 2026-09-24 심층리뷰 1번(Integrative Medicine Research 2026;15(3 Part A):101323, [PMID: 42099446](https://pubmed.ncbi.nlm.nih.gov/42099446/)): 약침군에서 ODI 포함 2차 지표가 통상 진료 대비 유의하게 개선되고 **53주까지 유지**됐다.
  - [연구 요약] 통증(NRS)·보행거리·기능(ODI)·삶의 질(EQ-5D-5L)이 같은 방향으로 움직인 사례로, ODI를 '기능 축'으로 읽는 전형적 사용 예다.

## 📎 개념 학습 보충 (2026-10-09 논문 연계)

- **이 논문에서의 역할**: 만성 좌골신경통 침 RCT([PMID 39401008](https://pubmed.ncbi.nlm.nih.gov/39401008/))의 **1차 공동 종료점 중 하나**로 ODI가 쓰였다 — 4주 ODI 변화 침군 −13.0점 대 샴군 −4.9점(**군간차 −8.1점, 95% CI −11.1~−5.1**), 사전 정의한 MCID 7점을 넘었고 52주에도 −4.8점 차이로 유지됐다
- **짝 지표 운용**: 같은 시험에서 다리 통증 [[시각아날로그척도(VAS)]](군간차 −16.0 mm)와 ODI가 함께 움직였다. ODI는 '요추 기능·장애' 축, VAS는 '통증 강도' 축이므로 두 축을 함께 보고해야 중재의 위치가 판정된다 → [[MCID]]
- **해석 주의**: ODI는 요통 특이 기능지표라 하지 방사통의 체감을 온전히 반영하지 않는다. 좌골신경통에서는 다리 통증 지표와 기능 지표를 분리해 읽는다 → [[요추 추간판 탈출증]] · [[좌골신경통]]
