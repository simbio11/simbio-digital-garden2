# 운동공포 (Kinesiophobia, 통증 관련 움직임 공포)

> **핵심 요약**: **움직임이나 신체 활동이 손상을 유발할 것이라는 과도한 두려움**으로 인해 활동을 회피하게 되는 심리 상태(Miller 등, 1991 제안 / Kori 등이 개념화). 통증 파국화와 함께 [[두려움-회피 모델]]의 핵심 변수이며, 만성 요통·근골격 재활에서 **치료 표적**으로 다룬다. 2026-09-21 심층리뷰 2번(PACBACK)의 매개분석에서 **운동공포 감소가 1년 자기관리 효과의 상당 부분을 설명**했고, [[STarT Back 도구]]에서는 운동공포 문항이 **심리사회적 하위점수**에 포함된다.

## 정의·구성
- **핵심 인지**: "이 동작을 하면 다시 다칠 것이다", "허리를 움직이면 디스크가 더 나빠질 것이다"
- **결과**: 회피 → 사용 저하 → [[디트레이닝]]·근위축 → 재손상 감수성 증가 → 통증 지속(악순환)
- **감별**: 단순한 통증 회피(급성기 보호 반응)와 달리, **조직 치유 이후에도 회피가 지속**되며 **기능·참여 수준을 제한**한다

## 측정 (대표 도구)
| 도구 | 구성 | 특징 |
| :--- | :--- | :--- |
| **TSK (Tampa Scale for Kinesiophobia)** | 17문항 4점 리커트(총 17~68점) | 원판 — 요통 연구에서 가장 널리 사용 |
| **TSK-11** | 11문항 축약판 | 임상·연구 활용도 높음, 반복 평가에 실용적 |
| **TSK-13 / TSK 심장판 등** | 질환별 변형 | 대상 질환별 확인 필요 |
| **[[STarT Back 도구]]** 내 문항 | "이런 상태에서 신체 활동은 안전하지 않다" | 선별용 단문항 접근 |

- **해석**: 점수가 높을수록 운동공포가 큼 — 통상 절대 컷오프보다 **치료 전후 변화 추적**이 임상적으로 유용하다

## 기능·기전
- **행동 경로**: 파국화 → 공포 → 회피 → 기능 저하·우울(두려움-회피 모델)
- **생리 경로 제안**: 움직임에 대한 예기 불안이 주의·기대 체계를 통해 통증 증폭에 관여([[중추 감작]]), 반대로 **'안전하다'는 학습(단계적 노출·성공 경험)** 이 회피를 줄인다 → [[중추 감작]] · [[운동유발 진통]]
- **개입 작동 기전**: 통증신경과학 교육(PNE) + **점진적 노출·단계적 활동 재개** + 자기효능감 강화가 핵심 조합

## 임상 적용
- **초진 질문**: "이 통증 때문에 어떤 움직임을 피하고 있나 / 그 움직임이 다치게 할까 두려운가" — 이 답이 향후 1년 장애를 예측하는 방향의 정보를 준다
- **교육 메시지**: "아프다 ≠ 다쳤다" / "이것은 안전하다(this is safe)" — 단 **"아프지 않을 것이다"라는 약속은 하지 않는다**(불필요한 기대·신뢰 훼손 방지)
- **처방 설계**: ① 호흡·이완·심신 기법으로 각성 낮추기 ② **통증을 크게 올리지 않는 강도**의 활동부터 시작해 성공 경험 누적([[점진적 과부하]]) ③ 주 1회 검사가 아니라 **일상 수행 기록(걷기일기·만보계)** 으로 자기효능감 강화 → [[걷기 운동]] · [[자기효능감]]
- **한의 접점**: 침·추나로 통증·움직임을 확보한 직후 **'그 자리에서 움직여 보게 하는'** 것이 수동 중재를 능동 재활로 연결하는 실전 요령이다 → [[도수치료]] · [[운동요법]]

## 주의·한계
- 운동공포 점수가 높다고 통증이 모두 심리적이라는 뜻이 아니다 — 조직 병리·신경병증성 성분을 먼저 배제한다
- 공포가 큰 환자에게 강한 수동 신장·고강도 운동을 초기에 밀어붙이면 오히려 회피가 강화될 수 있다
- 급성 손상 초기의 보호적 회피는 정상 반응 — **'회피 = 나쁨'의 도식적 적용 금지**

## 논문 연결
- 2026-09-21 심층리뷰 2번(JAMA 2026;335(6):497-510, [PMID: 41460638](https://pubmed.ncbi.nlm.nih.gov/41460638/) / DOI 10.1001/jama.2025.21990): PACBACK — 8주 자기관리(SSM) 프로그램 구성에 **통증 교육, 심리·행동 전략, 심신 접근, 통증 대처 훈련**이 포함되었고, 매개분석(JAMA Intern Med 2026;186(8):952-963, PMID 42223934)에서 **6개월 시점 운동공포 감소·자기효능감 상승·파국화 전환**이 1년 SSM 효과의 76%를 설명
