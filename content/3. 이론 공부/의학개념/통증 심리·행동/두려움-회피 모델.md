# 두려움-회피 모델 (Fear-Avoidance Model)

> **핵심 요약**: 급성 통증을 **위협으로 해석하는 인지·정서 반응**(파국화·운동공포)이 **회피 행동 → 사용 저하(disuse) → 우울·장애**로 이어져 통증을 만성화시킨다는 심리사회적 모델이다(Vlaeyen & Linton, 2000). 반대로 통증을 위협으로 보지 않고 **직면(confrontation)** 하면 회복 경로로 들어간다. 2026-09-21 심층리뷰 2번(PACBACK)은 **6개월 시점의 심리사회적 요인 변화(자기효능감 상승·운동공포 감소·파국화 전환)가 1년 자기관리 효과의 76%를 설명**한다고 보고해 이 모델을 임상 데이터로 뒷받침했다.

## 정의·구성
```
통증 경험 → (파국화·통증 관련 두려움) → 회피 행동 → 사용 저하·디트레이닝
                                        ↑                    ↓
                                     재발/통증 지속 ← 우울·장애·사회적 위축
통증 경험 → (낮은 위협 해석) → 직면·활동 지속 → 회복 경로
```
- **핵심 변수 3종**: ① **통증 파국화**(반추·확대·무력감) ② **운동공포(kinesiophobia)** ③ **자기효능감** 저하 — 셋이 서로 상호작용한다 → [[통증 파국화]] · [[운동공포]] · [[자기효능감]]
- **'아픔 ≠ 손상' 명제**: 통증 강도와 조직 손상이 일치하지 않음을 교육하는 것이 개입의 출발점이다. PACBACK의 중재 제공자 교육에서도 "이것은 안전하다(this is safe)"는 표현을 쓰고 "아프지 않을 것이다"라는 약속은 피하도록 훈련했다

## 기능·기전 (임상적 함의)
- **만성화의 예측 인자**: 요통에서 **옐로 플래그(yellow flags)** — 공포-회피 신념, 파국화, 직무 스트레스·직업 만족도 저하, 우울·수면장애 — 가 만성화의 최대 예측 인자로 정리된다 → [[만성 요통]]
- **신경생리 연결**: 반복되는 위협 해석과 회피는 [[중추 감작]]·하행성 통증억제 기능 저하와 맞물려 통증 증폭을 유지한다 → [[중추 감작]] · [[하행성 통증억제계]]
- **치료적 함의**: 모델은 **'통증을 없애는' 것이 아니라 '통증과 함께 기능하는 능력'을 바꾸는 개입**을 정당화한다 — 통증신경과학 교육(PNE), 단계적 노출, 능동 운동 처방, 자기관리 코칭

## 임상 적용
- **초진 문진(가장 실용적인 2문항)**: "이 통증 때문에 어떤 움직임을 피하고 있나" / "그 움직임이 다치게 할까 두려운가" — 통증 강도보다 이 질문이 치료 설계를 바꾼다
- **중재 묶음(PACBACK의 SSM 구성 참조)**: 통증 교육 + 심리·행동 전략 + 심신(mind-body) 접근 + 생활습관 조언 + 통증 대처 훈련을 **8주 감독 코스**로 제공, 이후 자가관리로 이관
- **한의 진료 설계**: 추나·침 같은 수동 중재는 **초기 통증·움직임 회복용 징검다리**로 쓰고, 종료 시점에 자가관리 프로토콜을 넘겨준다 → [[도수치료]] · [[운동요법]]
- **설명 스크립트**: "수기치료는 통증이 심한 초기에 움직임을 되찾는 데 도움이 되지만, 1년 뒤 만성 통증으로 넘어가는 것을 막는 힘은 스스로 관리하는 능력에서 나왔습니다"

## 주의·한계
- 모델은 **설명 틀**이며, 만성 통증 환자 전부를 심리 요인으로 환원하는 것은 오류다 — 조직 병리·신경병증성 성분·동반 질환은 별도로 평가해야 한다
- 최근 연구들은 두려움-회피 경로가 **일부 환자군에 국한**될 수 있고, 회피가 항상 나쁜 것도 아니라는(조직 치유기 보호적 회피) 이분법 비판을 제기한다
- '심리 문제'라는 낙인 방지: 환자에게는 **"통증에 대한 몸의 방어 반응"** 으로 설명한다

## 논문 연결
- 2026-09-21 심층리뷰 2번(JAMA 2026;335(6):497-510, [PMID: 41460638](https://pubmed.ncbi.nlm.nih.gov/41460638/) / DOI 10.1001/jama.2025.21990): PACBACK 2×2 RCT 1,000명 — **자가관리(SSM)군이 표준의료보다 1년 장애 개선**(−1.2, −1.9~−0.5), SMT 단독은 무효. 동반 매개분석(JAMA Intern Med 2026;186(8):952-963, PMID 42223934)에서 **심리사회적 요인 변화가 SSM 효과의 76%를 설명**
