# 생물리사회적 모델 (Biopsychosocial Model)

> **핵심 요약**: 질병·통증을 **생물학적(biological) + 심리적(psychological) + 사회적(social)** 세 축의 상호작용으로 설명하는 의학 모델이다(Engel, 1977 — 의학 일반; Waddell, 1987 — 요통). 요통·만성 통증 임상에서는 **조직 손상만으로 통증·장애를 설명할 수 없다**는 근거가 축적되면서 표준 틀이 되었고, 치료도 이 세 축을 함께 겨냥하도록 설계된다. 2026-09-21 심층리뷰 2번(PACBACK)은 **척추 수기요법(생물학적 축) 단독은 1년 장애를 개선하지 못했고, 임상의가 지지하는 자기관리(심리·사회 축)가 개선을 만들었다**는 결과를 보고했다.

## 정의·구성
| 축 | 요통에서의 내용 | 치료 표적 |
| :--- | :--- | :--- |
| **생물학적** | 조직 손상·관절 기능장애·염증·중추 감작, 근위축·[[디트레이닝]] | 수기·침·운동·약물 |
| **심리적** | 통증 파국화·운동공포·자기효능감 저하·우울·수면장애 | 통증 교육(PNE)·인지행동 전략·단계적 활동 재개 |
| **사회적** | 직무 스트레스·직업 만족도·보상 체계·가족 반응·의료 접근성 | 작업 조정·의사소통 코칭·사회적 지지 |

- **옐로 플래그(yellow flags)**: 심리사회적 만성화 위험 인자군 → [[두려움-회피 모델]] · [[만성 요통]]
- **선별 도구**: [[STarT Back 도구]] — 위험 층화로 치료 강도를 배분하는 운영 장치
- **재활 틀과의 관계**: 기능·활동·참여를 함께 보는 ICF(국제 기능·장애·건강 분류) 관점과 정합한다

## 기능·기전 (왜 중요한가)
- **통증 ≠ 손상**: 영상 소견과 통증 강도·장애의 상관이 낮다는 근거가 축적되었다 — 불필요한 조기 MRI는 불안·파국화를 악화시킬 수 있어 **신경학적 결손·레드플래그가 없으면 영상 검사를 자제**한다
- **중추 처리 변화**: 두려움·주의·기대가 통증 증폭([[중추 감작]])과 하행성 조절 기능에 직접 관여한다 → [[중추 감작]] · [[하행성 통증억제계]] · [[디폴트모드네트워크]]
- **능동 vs 수동**: 수동 중재(수기·주사·도구)는 단기 증상 조절, 능동 요소(운동·교육·자기관리)가 장기 결과를 만든다 — PACBACK·PROP OA·WalkBack이 반복적으로 보여준 패턴이다 (→ [[무릎 보조기]] · [[걷기 운동]])

## 임상 적용 (한의원 프로토콜)
1. **초진 3축 평가**: 레드플래그 선별(생물) → [[STarT Back 도구]] 또는 문진으로 심리사회적 위험 확인(심리) → 직업·생활·지지 체계 확인(사회)
2. **중재 묶음 설계**: 침·추나 등으로 통증·움직임을 확보한 뒤 **8주 감독 코스**로 ① "아프다 ≠ 다쳤다" 통증 교육 ② 운동공포 감소를 위한 단계적 활동 재개 ③ 호흡·이완·심신 기법 ④ 생활습관 조언 ⑤ 통증 대처 훈련을 제공
3. **종료 시 자기관리 이관**: 주 2~3회 수동 치료를 종료 시점 없이 반복하기보다 **기간을 정한 코스**로 설계하고 자가관리 프로토콜을 넘긴다
4. **결과 측정**: 통증 숫자만이 아니라 **기능([[RMDQ]]·[[ODI]])·자기효능감**을 함께 추적 → [[MCID]]

## 주의·한계
- 심리사회적 요인은 **진단명이 아니며**, 환자에게 '심리 문제'로 낙인찍히지 않도록 설명에 주의한다(신체 증상의 실재성을 먼저 인정)
- 만성화 위험이 높지 않은 환자(급성·비파국화)에서는 수동 중재가 크게 작동한다 — **모든 환자에게 동일 처방을 적용하는 것도 모델의 오용**이다
- 장기 결과를 만든 중재도 **효과 크기는 작다**(예: RMDQ 차 1.2점) — 한계를 정직하게 공유하는 것이 상담의 핵심이다

## 논문 연결
- 2026-09-21 심층리뷰 2번(JAMA 2026;335(6):497-510, [PMID: 41460638](https://pubmed.ncbi.nlm.nih.gov/41460638/) / DOI 10.1001/jama.2025.21990): PACBACK 2×2 RCT(급·아급성 요통 + 만성화 중등도~고위험 1,000명) — **생물학적 축(SMT 단독)은 표준의료와 차이 없음**(−0.4, 95% CI −1.2~0.4), **심리사회적 축(SSM)은 우수**(−1.2, −1.9~−0.5), 병용(SMT+SSM)도 −1.1로 SMT 추가 이득 없음. **통증 강도(NRS)는 군간 차이 없음**
