# 다약제 복용 (Polypharmacy)

> **핵심 요약**: 한 사람이 동시에 여러 약물을 복용하는 상태. 통상 5종 이상을 다약제, 10종 이상을 과다다약제로 구분한다. 문제는 약물 수 자체가 아니라 서로 다른 처방 주체·적응증이 만들어내는 상호작용·처방 연쇄·복약 이탈이며, 한약과 건강기능식품을 포함해 세어야 실제 위험이 보인다.

## 정의·범위

- 수량 기준: 5종 이상(다약제), 10종 이상(과다다약제)이 국제적으로 통용된다. 연구마다 기준이 달라 유병률을 비교할 때는 정의를 먼저 확인한다.
- 포함 범위: 처방약만 세는지, 일반약·건강기능식품·한약·차·주스까지 포함하는지가 결과를 크게 바꾼다. 2026-11-05 리뷰 2번에서 만성질환자의 48.6%가 생약을 복용 중이었고 그중 96%가 의료진에게 알리지 않았다([PMID 42536629](https://pubmed.ncbi.nlm.nih.gov/42536629/)).
- 임상적으로 유용한 구분: 적응증이 분명한 다약제(필요)와 중복·연쇄로 늘어난 다약제(불필요). 숫자보다 적응증 검토가 먼저다.

## 위험이 커지는 경로

| 경로 | 설명 | 대표 예 |
| :--- | :--- | :--- |
| 상호작용 | 약물 수가 늘면 조합 수가 급격히 증가 | [[한약-양약 상호작용]] |
| 처방 연쇄 | A의 부작용을 B로 치료하며 목록이 늘어남 | 진통제 → 위장약 → 변비약 |
| 중복 처방 | 같은 계열·같은 성분이 여러 진료과에서 겹침 | [[아스피린]] + 다른 항혈소판제 |
| 복약 이탈 | 복용 시간·식후 조건이 복잡해져 임의 중단 | 하루 4회 이상 분복 |
| 노화 취약성 | 신기능·간기능 저하로 같은 용량이 과량이 됨 | [[메트포르민]] 축적 위험 |

## 임상 평가

- 브라운백 리뷰: 환자가 실제 복용하는 모든 제품을 봉투에 담아 오게 해 하나씩 확인한다. 처방전 목록만 보면 실제 복용과 어긋난다.
- 3문항 스크리닝(2026-11-05 리뷰 2번의 외래 동선 이식): ① 병원 약 외에 한약·건기식·차·즙이 있는가 ② 최근 4주 안에 새로 시작한 것이 있는가 ③ 수술·시술 예정이 있는가
- 구조화 도구: STOPP/START, Beers 기준 같은 노인 처방 점검 도구를 감약 검토에 쓴다. 도구는 후보를 찾는 용도이고 최종 판단은 적응증·예후를 함께 본다.

## 감약(deprescribing) 원칙

1. 적응증이 사라진 약, 이득이 근거보다 작은 약, 환자가 임의 중단한 약을 먼저 목록화한다.
2. 한 번에 하나씩, 4~8주 간격으로 줄인다. 여러 개를 동시에 줄이면 원인 판정이 불가능하다.
3. 감약 후 나타날 수 있는 금단·반동(베타차단제·벤조디아제핀·PPI)은 미리 taper 계획을 세운다.
4. 한약·건기식도 감약 대상에 넣는다. "자연물이라 안전하다"는 이유로 목록에서 빼면 상호작용 감시가 끊긴다.

## 한의 임상 적용

- 한약을 처방할 때 기존 복약 목록을 같은 표에 적고, 시작·종료 시점을 기록한다. 다약제 환자에서는 처방 추가 자체가 위험 증가 요인이다.
- 다약제 + 고령 + 신기능 저하 조합에서는 이뇨·사하 작용이 강한 처방을 피하거나 감량한다.
- 환자 설명: "약이 많다는 것 자체보다, 서로 부딪히는 조합이 문제입니다. 드시는 것을 다 적어 오시면 조합을 확인해 드리겠습니다."
