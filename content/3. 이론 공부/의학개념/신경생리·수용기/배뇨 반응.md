# ⚡ 배뇨 반응 (Micturition Reflex)

> **핵심 3줄 요약 (Key Summary)**:
> - 🧠 회로: 방광 충만 → 골반신경 구심성(Aδ·C섬유) → 천골(S2–S4) 척수 반사 + 뇌교 배뇨중추(PMC) → 골반신경 부교감 원심성 → 배뇨근 수축.
> - ⚙️ 저장과 배출의 스위치: 저장은 [[교감신경]](T10–L2, β3 이완 + α1 내요도괄약근 수축)과 음부신경(외요도괄약근)이 담당하고, 배출은 부교감이 지배한다. 뇌교가 두 모드를 전환한다.
> - 🩺 임상: 척추마취·골반 수술·마미증후군·항콜린제는 이 회로를 끊거나 늦춘다. 과팽창이 오래 지속되면 구심성 감각이 둔해져 [[산후 요폐]]가 만성화된다.

---

## 1. 정의·구조

* **정의**: 방광에 소변이 차오르면 저장 모드에서 배출 모드로 전환되어 배뇨근이 수축하고 요도괄약근이 이완되는 신경 반사. 단순 척수 반사가 아니라 뇌교–시상하부–대뇌피질의 통제를 받는 “조건부 반사”다.
* **핵심 구성**:
  * 구심성: 골반신경(S2–S4) — 장력 민감 Aδ섬유(정상 배뇨), 무수 C섬유(병적 상태에서 활성).
  * 원심성 부교감: 골반신경 → 배뇨근(아세틸콜린 M3, ATP-P2X).
  * 원심성 교감: 하복신경(T10–L2) → 배뇨근 β3 이완, 내요도괄약근 α1 수축.
  * 체성: 음부신경(S2–S4) → 외요도괄약근·골반저(보호 반사).
  * 중추: 뇌교 배뇨중추(PMC, Barrington 핵) — 배출 명령, 뇌교 저장중추(L-region) — 저장 유지. 대뇌(전전두·전대상)는 사회적 통제(화장실까지 참기)를 담당한다.

---

## 2. 기능·기전

* **충만기(저장)**: 방광 용적이 늘어도 압력이 완만히 오르는 “적응 이완”이 일어난다. 교감 β3가 배뇨근을 이완하고 α1이 내요도괄약근을 조이며, 음부신경이 외요도괄약근을 유지한다. 이 동안 척수 반사는 억제된다.
* **배출기**: 충만 신호가 역치를 넘으면 PMC가 활성화되어 부교감 출력이 폭발적으로 늘고, 동시에 교감·체성 출력이 억제된다(스위치 전환). 배뇨근 수축 + 요도 이완이 동시에 일어나야 소변이 나온다.
* **과팽창의 결과**: 장기간 과팽창은 배뇨근 평활근의 수축 단백질 구성과 무스카린성 신경전달을 변화시키고, 구심성 감각 역치를 올려 “방광이 찼다는 느낌” 자체를 감소시킨다. 이 감각 저하가 지속성 요폐의 예후를 가른다.

---

## 3. 임상 의의

* **산후 요폐**: 척추마취·경막외 진통은 천골 부교감 신경근을 일시 차단한다. 마취 회복 후에도 과팽창이 남아 있으면 감각 저하 → 배뇨 지연이 고리처럼 반복된다. 따라서 “마취 회복 = 배뇨 회복”이 아니다.
* **약물**: 항콜린제(요실금 치료제·항우울제·항히스타민)는 배출을 억제하고, [[미라베그론]](β3 작용제)은 저장 모드를 강화한다. 오피오이드도 배뇨 반사를 억제한다.
* **신경 병변**: 마미증후군은 천골 신경근 압박으로 배뇨·배변·안장감각을 동시에 잃는다 — 요폐의 응급 감별. [[신경성 방광]]은 병변 위치에 따라 과활동형·무수축형으로 갈린다.
* **치료 표적**: 부교감 출력을 올리는 접근(배뇨 유도·온열·전기자극), 저장 모드를 낮추는 접근(β3 작용제·항콜린제), 신경조절(천골 신경조절·경골신경 자극)이 같은 회로의 서로 다른 지점을 건드린다.
  * 실험 연구에서는 음부신경 자극이 뇌교 배뇨중추 자극으로 유도된 방광 수축을 억제했고, 경골신경 자극은 그렇지 않았다 — 말초 전기자극이 회로 수준에서 다르게 작동함을 보여주는 사례다.

---

## 4. 논문 연결

* [[산후 요폐]] — 배뇨 반응 회복 지연이 병태의 중심. 2022년 다기관 시험(PMID 35604687)은 천골 경혈 온열로 요폐 발생을 4.5% vs 7.7%로 낮췄다(기전은 제안 수준).
* [[골반저근]] · [[골반저근훈련]] — 골반저가 배뇨·배변 조절의 체성 축을 이룬다.
* [[교감신경]] · [[부교감신경]] · [[자율신경계]] — 저장·배출 스위치의 상위 개념.
* 마미증후군 · [[신경성 방광]] — 응급·만성 감별 축.
