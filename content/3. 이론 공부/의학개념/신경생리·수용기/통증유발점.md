# 통증유발점 (Myofascial Trigger Point, MTrP)

> **핵심 요약**: 골격근의 **긴장띠(taut band) 속에 만져지는 과민성 소결절**로, 압박 시 국소 통증과 함께 특징적인 **연관통(referred pain)** 패턴을 재현하고, 자극 시 **국소 연축 반응(local twitch response)**을 보인다. 활성 통증유발점은 자발 통증·운동 제한·근력 약화를 일으키며, 건침(드라이 니들링)·수기 압박·스트레칭의 대표적 표적이다.

## 정의·특성
- **활성(active) MTrP**: 자발 통증·연관통 유발 / **잠재(latent) MTrP**: 압박 시에만 통증 — 일상에서 무증상이나 운동 조절·유연성에 영향
- 만지면 **단단한 띠(taut band)**, 압통, 연관통 재현, 국소 연축 반응(LTR)이 진단의 4대 특징
- 연관통 패턴은 근육마다 일정해 임상 감별에 활용(예: 상완요골근·신전근군 → 팔꿈치·전완부)

## 병태생리·기전
- **비정상 운동종판(endplate) 가설**: 신경근 접합부의 과도한 아세틸콜린 유리 → 종판 전위 지속 → 국소 근섬유 수축(연축) 유지
- **에너지 위기 가설**: 지속 수축 → 국소 혈류 차단·허혈 → ATP 고갈·에너지 위기 → 수축 유지 악순환(저산소·산성 환경)
- 국소에는 통증 감작 물질(염증 매개체·신경펩티드)이 축적되어 침해수용기를 예민하게 만들고, 장기간 지속되면 [[중추 감작]]으로 이행 가능
- 말초·중추 통증 기전이 함께 관여 — 근막 통증이 만성화되면 척수후각·피질 수준의 감작까지 동반

## 임상 의의 (치료 연계)
- **건침의 표적(2026-09-08 심층리뷰 3번)**: 외측 팔꿈치 힘줄병증 8개 지점 표준 프로토콜 — 근내 통증유발점·건-근 접합부·건-골 부착부(teno-osseous)를 표적으로 경피 건침+전기자극. 바늘로 LTR을 유발하면 통증유발점이 소실되고 즉각적 진통(hypoalgesia)이 나타남
- 통증유발점 자극 → 분절성(척수후각) 통증 억제 + 하행성 조절 활성화 → 건침·전침·수기 치료의 진통 기전
- 감별: 같은 근육 부위의 내장성 연관통·신경병증성 통증(요골신경 포착 등)과 감별 필요
