# 흑질 (Substantia Nigra)

> [!summary] 핵심 3줄 요약
> - 흑질은 중뇌(midbrain)에 위치한 기저핵 구조로, **치밀부(SNc, 도파민성)** 와 **망상부(SNr, GABA성)** 로 나뉜다.
> - 치밀부는 선조체로 도파민을 보내 운동 조절의 핵심이며, 파킨슨병에서 이 부위 뉴런이 소실된다.
> - 망상부는 기저핵의 **출력 관문**으로 시상·상구에 억제 신호를 보내며, 통증·운동의 문턱 조절에 관여한다.

## 1. 해부와 구분 — SNc와 SNr을 섞지 말 것

| 구분 | 신경전달물질 | 주요 투사 | 기능 |
| :--- | :--- | :--- | :--- |
| 치밀부(SNc) | 도파민 | 선조체(니그로스트리아탈로) | 운동 개시, 보상 학습 |
| 망상부(SNr) | GABA | 시상(운동핵 경유), 상구 | 기저핵 출력 억제, 운동·안구 문턱 |

- 중뇌의 흑색은 신경멜라닌 색소 때문이며, 이 색소는 도파민 합성 경로의 부산물이다.
- 임상에서 "흑질"이라는 말이 나오면 **도파민(SNc)인지 GABA 출력(SNr)인지** 반드시 확인해야 한다. 해석이 정반대로 뒤집힌다.

## 2. 통증 조절에서의 역할

- 기저핵–시상–피질 회로는 통증의 **동기·정서 차원**과 운동 반응 선택에 관여한다. SNr은 이 회로의 출력 관문으로, 억제성 톤을 조절해 통각 반응의 문턱을 바꾼다.
- 도파민성 경로(SNc–선조체)는 보상·동기와 연결되며, 만성 통증에서 도파민 기능 저하가 무쾌감·운동 회피와 연관된다는 가설이 있다.
- [[하행성 통증억제계]](중뇌수도주위회색질–연수 복측내측부)와는 해부학적으로 구분되지만, 기능적으로 상호작용한다.

## 3. 임상 의의

- 파킨슨병: SNc 도파민 뉴런 소실 → 운동완서·진전·경직. 통증은 파킨슨병의 흔한 비운동 증상이며, 도파민 치료에 반응하는 경우가 있어 기저핵–통증 연결의 임상적 단서가 된다.
- 추체외로 증상: 도파민 차단제(항정신병약·진토제) 사용 시 SNr–시상 억제 톤이 깨져 약물유발 파킨슨증후군이 생긴다. 진료실에서 반드시 확인할 약물력이다.

## 4. 논문 연결 — 표기 주의

- 2026-11-16 리뷰 1번(PMID 41846592)은 "IFGtri.R–SNpr 연결"을 보고하며 SNpr을 "도파민 매개 통증조절" 부위로 서술했다. 그러나 **SNpr(망상부)은 GABA성 출력핵**이고, 도파민은 치밀부(SNc)다. 원문 표기가 SNr/SNc 중 무엇을 가리키는지 확인하지 않은 채 "도파민"으로 단정하면 기전 해석이 어긋난다.
- 실무 원칙: 원문 그림·보충자료의 좌표(MNI)와 확률지도로 실제 표적을 확인하고, 노트에는 **"흑질(망상부 표기, 원문 기준)"** 처럼 표기를 병기한다.
