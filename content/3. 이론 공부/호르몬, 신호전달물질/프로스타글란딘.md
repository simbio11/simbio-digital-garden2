# 1. 아라키돈산 산화효소 1: 
- COX1, 2(매우 중요) COX 는 염증 반응에서 염증을 조절하기 위한 표적이 되는 여러 대사물질을 만들어내어 세포 활성을 조절한다. 
## 1.1. COX-1 
- 내피세포, 위점막, 신장, 혈소판 등의 모든 조직에서 구조적 발현 
  1) [[아라키돈산]]으로부터 프로스토글란딘과 [[트롬복산]] A2(TXA2)를 생성 
  - 위장관, 염증 반응이 있는 곳에서 [[3. 이론 공부/호르몬, 신호전달물질/프로스타글란딘]]([[3. 이론 공부/호르몬, 신호전달물질/PGE2]], [[PGI2]])을 만들고 혈소판의 cox-1 은 [[TXA2]] 를 생성 
  - [[PGI2]]= 혈소판 응집억제, [[3. 이론 공부/호르몬, 신호전달물질/PGE2]]= 세포 증식, 혈관 생성, 침습 자극, 통증 유발, 발열기전에 관여(암유발) 
  - 프로스토글란딘은 위장관에서 산 분비 억제, [[펩신]
  - 농도 저하, 점액 생성/ 혈소판의 TXA2= 혈소판 응집을 촉진   
1) [[아스피린]]과 다른 NSAIDs 등에 의해 억제 
- 프로스토글란딘, TXA2 이 [[NSAIDs]] 등에 의해 억제되면 위장관 보호 기능이 사라지면서 위장관 출혈, 궤양 등이 생기지만 혈소판 응집이 억제되면서 심장질환 위험도가 감소함. 
- 하지만 아스피린 과다 복용 시 혈소판 응집이 안되고 이로 인해 지혈이 잘 되지 않음 
## 1.2. COX-2 
- 염증 매개체에 의해 합성 증가가 유도됨 [[PGH2]] 를 생성하고 이는 [[3. 이론 공부/호르몬, 신호전달물질/PGE2]] 나 [[PGI2]] 로 전환됨 [[3. 이론 공부/호르몬, 신호전달물질/프로스타사이클린]](혈소판 응집)을 생성함 
1) COX-2 는 COX-1 보다 염증 세포에 집중 
- 유도 효소: 염증매개체에 의해 합성 증가 유도 
- 염증 유발 및 유지에 관여/ 많은 종류 암에서 발현이 증가함. 
2) COX-2 선택적 억제제는 위장관 궤양 발생 가능성을 낮추지만 NSAIDs 의 부작용을 줄이지는 못해 다른 심혈관질환 위험을 증가(심부전 / 심근경색 / 뇌졸중)
- COX-1 과 COX-2 는 균형을 맞춰서 발현해야 한다. [[3. 이론 공부/호르몬, 신호전달물질/PGE2]] 는 여러 종류의 암 성장을 자극하기에 COX2 를 억제하여 암을 예방하고 치료함 
- 다시 설명하면 COX2 는 혈소판 응집을 억제하는 프로스타사이클린을 생성하는 효소인데 COX2 효소를 억제하는 NSAIDs 를 투여하면 혈소판 응집이 되니까 심근경색이나 뇌졸중이 나타나는 것임. 쉽게 말하면 COX2 의 프로스타사이클린과 아스피린은 혈소판이 응집되지 않는 방향으로, 이와 반대로 COX1.2 의 PG 시리즈, TXA2 는 혈소판이 응집되는 방향으로 작용하는 효소나 약물임. 그래서 COX1 과 COX2 는 균형이 잘 맞아야 한다
# 프로스타글란딘과 [[프로게스테론]]
1) PG의 기전 
- 프로스타글란딘이 증가하기 위해서는 프로게스테론이 증가해야 하고 이를 위해서는 배란이 일어 나야 함. 이후 프로게스테론이 떨어지면 COX(싸이클로 옥시게나제)가 나오고 프로스타글란딘이 나옴. 이때 Fα가 제일 문제가 됨. → COX를 억제하여 월경통을 방지하고자 함. 
2) COX의 종류 
- COX-1 
  ➀PG E2 (위산분비억제, 위점막보호) 
  ➁TBX A2 (위장관 출혈 방지, 혈소판 응고) → COX-1은 위장관 보호 역할 
  - COX-2 
  ➀PG F2α (병리적 상황 유도, 염증 상황 발현) 
  ➁Prostacyclin (트롬복산과 반대로 작용하여 혈액순환 촉진, 혈관 확장)   
3) 약물의 종류와 부작용 
   (1) [[이부프로펜]] 제제(NSAIDs): COX 기전을 막아 진통하는 약(말초성 진통제)  
   - 기전: COX-1, 2를 비선택적으로 억제함 → 해열, 진통, 소염의 효과 
   +) 비슷한 약물인 아스피린은 COX 생성 자체를 차단하는 강력한 약임. → 아스피린 외 다른 비선택적 COX 억제 약들은 COX 활성화를 막는 기전에 해당.   
   - 부작용: 
    ➀ COX-1까지 제거하여 위장관 부작용 유발 + 출혈 가능성 (위장관 출혈) 
    ➁ 신장독 → 신독성이 간독성에 비해서는 덜 위험하므로 그럼에도 권장됨. 
   (2) [[아세트아미노펜]]: COX-2 억제제(Coxib) 
   - [[이부프로펜]] 제제의 부작용 때문에 COX-2만 선택적으로 억제하는 약을 개발하였음. 
   - 특히 중추에 작용하는 약으로 해열제 목적으로 개발된 [[아세트아미노펜]]이 대표적임.  (이후 COX-2를 간접적으로 억제한다는 것이 밝혀지면서 해열진통제로 사용되기 시작함.) 
   - 기전: COX-2를 간접적으로 억제함. → 해열, 진통의 효과 (소염은 X) → COX-1에 관여하지 않으므로 위장관 문제 가능성이 적음 (’빈속에 먹어라‘ 광고)   
   - 부작용: 
    ➀ 간독성이 큰 약물   
    ➁ 심혈관 질환과 관련될 수 있다는 연구 有 → 따라서 월경통에 [[타이레놀]]([[아세트아미노펜]])보다는 이지엔6([[이부프로펜]])를 추천함.

## 📎 개념 학습 보충 (2026-09-06 논문 연계)

- **월경통에서 PGF2α/PGE2 균형**: PGF2α는 자궁근 수축·혈관수축 → 자궁 허혈·저산소성 통증, PGE2는 자궁근 이완·진통 방향 — 비율 증가가 원발성 월경통 통증과 연관 → [[PGF2a]] · [[PGE2]] · [[월경통]]
- 2026-09-06 리뷰 1번(통경첩 경혈부착 RCT, PMID 41821745): 기체울결·혈어형 월경통에서 외용 활혈화어 패치(포황·유향·몰약·혈갈)가 혈청 **PGF2α 감소(p=0.027)·PGE2 증가(p=0.041)·PGF2α/PGE2 비 개선(p<0.001)** 와 통증·CMSS 개선 동반 — 단 혈중 농도는 자궁 국소를 온전히 대변하지 못함
- 2026-09-06 리뷰 2번(운동 Cochrane, PMID 31538328): 운동의 진통 기전으로 항염 사이토카인 증가 + 월경량 감소 → 프로스타글란딘 총량 저하 가설 — NSAIDs(COX 억제)와 다른 비약물 경로
