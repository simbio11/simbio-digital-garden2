# 🧠 알도스테론 (Aldosterone)

> **핵심 요약**: 부신 피질 **사구대(zona glomerulosa)** 에서 분비되는 **미네랄코르티코이드**. 원위세뇨관에서 **나트륨 재흡수·칼륨 배설**을 촉진해 체액량·혈압을 조절한다. 나트륨 저류 → 부종·고혈압, 칼륨 배설 → **저칼륨혈증**(근력약화·부정맥). [[RAAS]]의 최종 실행 호르몬이며, **감초([[글리시리진]])는 11β-HSD2를 억제해 가성알도스테론증**을 유발한다.

## 분비·조절
- 부신 피질 사구대에서 분비 — **ACTH가 아니라** 세포외액 **칼륨(K⁺) 상승**과 **[[안지오텐신]] II 상승**이 주 분비 자극 (나트륨 증가는 미약하게 억제)
- 경동맥·신장·심방의 혈압(용적) 조절기에 의해 조절 — 즉 RAAS·K⁺가 축
- 사상의학 연결: 소양인 패턴에서 땀을 많이 흘리고 **상열하한**된 상태에서 신장 혈류량이 줄어 알도스테론↑·혈압↑ → **상하망동**

## 작용 기전
- 원위세뇨관·집합관 주세포에서 **ENaC(나트륨 채널)·Na⁺/K⁺-ATPase** 발현↑ → 나트륨 재흡수(물 동반) → 혈압↑
- 나트륨 흡수와 교환으로 **칼륨 배설↑ → 저칼륨혈증**(근력약화, 근육경련, 감각이상, 피로, 변비, 장운동 마비, 부정맥, 심정지)
- **알도스테론 vs [[코르티솔]]**: 코르티솔이 1000배 많이 분비되지만 미네랄코르티코이드 활성은 알도스테론이 훨씬 강함(알도스테론: 글루코 ≈30·미네랄 100 / 코르티솔: 글루코 100·미네랄 0.03)
- 알도스테론 수용체(MR)는 코르티솔과 알도스테론을 구별하지 못하므로, 원위세뇨관은 **11β-HSD2** 효소로 코르티솔을 비활성형 코르티손으로 전환해 MR을 보호함(간에서는 다시 활성화)

## RAAS (Renin–Angiotensin–Aldosterone System)
- 체액량↓·신장혈류량↓ → 교감신경 항진 + 레닌 분비 → 안지오텐시노겐 → [[안지오텐신]]1 → (폐 ACE) 안지오텐신2
- 안지오텐신2: 심박수↑, 신장 혈류량↑, **알도스테론 활성화** → 나트륨·수분 재흡수
- 한의 연결: 신장 혈류량 감소 = 전신 혈액량 감소 → 혈압↑·안면 홍조·소변불리 → **[[교감신경]] 항진 완화**, 소음인은 [[감초]]로 수분 저류·[[육계]]로 신장 혈류량 증가, 소양인은 [[복령]]·[[택사]]로 신장 혈류량 증가
- 소변자리는 [[부교감신경]] 항진 완화 / 소음인은 혈당 문제, 소양인은 혈압 문제가 많음

## 📎 개념 학습 보충 (2026-09-10 논문 연계)

### 가성알도스테론증 (Pseudohyperaldosteronism) — 감초 유발 (신규)
- **정의**: 알도스테론 자체는 낮은데 **미네랄코르티코이드 수용체(MR) 과활성**으로 **고혈압·저칼륨·대사성 알칼리증·부종**이 나타나는 상태
- **기전**: [[감초]]의 [[글리시리진]] → 글리시레티닉산(GA) → **11β-HSD2 억제** → [[코르티솔]]이 코르티손으로 비활성화되지 못하고 MR을 자극 (위 ‘알도스테론 vs 코르티솔’ 문단과 직결). 나트륨 재흡수↑·칼륨 배설↑
- **임상**: 감초 함유 처방([[육군자탕]]·[[작약감초탕]]·[[자감초탕]] 등) 장기 복용, 고령·이뇨제·ACEi/ARB 병용 시 위험. **저칼륨(근력약화·부정맥)·고혈압·부종·대사성 알칼리증** 감시, K⁺·혈압 모니터링
- **감별**: 원발성 알도스테론증(알도스테론↑, ARR↑)과 달리 **알도스테론·레닌 모두 낮음** — 문진에서 감초·한약 복용력이 결정적
