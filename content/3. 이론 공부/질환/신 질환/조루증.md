# 설명 
- 정의: 조기사정, 미숙사정, 과속사정
- 정자는 정낭에 있다가 전립선에서 쿠퍼액과 만나 [[외요도괄약근]]이 잡그고 있다가 풀어주면서 사정을 하는 것이기에 조루증은 [[외요도 괄약근]]과 [[골반저근]]이 풀리는 것이 원인이다.(근지구력)
1. [[골반저근]]의 근지구력 저하
   -> [[음부신경]] 포착, 골반 부정렬 치료)
2. 복압 상승으로 [[코어 근육]] 약화([[복횡근]], [[골반저근]], [[다열근]]), 자궁
   -> [[글리코겐]] 보충, 무산소 운동, 복압 내려줌. [[오가피]], [[곡기생]], [[상기생]], [[우슬]], [[두충]] 사용
3. 정자 부족([[테스토스테론]] 부족)
   -> [[오자환]]([[오미자]], [[구기자]], [[토사자]], [[복분자]], [[사상자]])와 같은 지용성 비타민이 많은 처방을 통해 [[테스토스테론]] 전구물질 보충
