- 성기가 발기하지 못하는 질환
- 한의학적으로 발기부전이라 한다. 
# 병리적 특징
- 정의: 발기가 되지 않거나 유지되지 않는 상태
- 원인: 고령, 흡연, 음주, [[당뇨]], [[고혈압]], 뇌혈관질환, 약물, 척수 손상, [[다발성경화증]], [[신부전]], [[간부전]], [[만성 폐쇄성 폐질환]], 심리적 요인
- 증상: 발기가 안된다.

# 치료 방법
1. [[아르기닌]] 섭취(단백질 섭취로 질소를 뽑아내어 활용)
2. 스트레스 줄이기(시상하부 성선축 조절)
3. [[cGMP]]를  [[GMP]]로 바꾸는 것을 억제([[비아그라]], [[PDE5]]를 분해하여 [[cGMP]] 분해를 감소시킴)
   -> [[음양곽]]의 Icariin noricariin 성분이 [[PDE5]]를 억제함
4. 복강내 혈류량 증가
   -> [[오령산]], [[평위산]], [[계지탕
# 치료 및 고찰
- 책에서 나온 내용은 신부전에 의한 발기부전에 가깝다. 
- [[적작약]], [[당귀]], [[숙지황]], [[백출]], 보혈, 보기하는 약재와 [[도인]], [[홍화]], [[목단피]], [[오가피]]와 같은 활혈하는 약재를 사용한다.
- 회양혈과 같은 골반신경총이나 팔료혈과 같은 천골신경이 통과하는 부위에 자침
