# 병리적 특징
- 정의: 소변의 불수의적 배설로 자기도 모르게 나오는 것(소변실상은 소변이 나오는 것을 알지만 멈추지 못하는 것)
- 증상: 소변이 흐름

- 허실을 구분하고 허한 경우 기허, 혈허, 음허로 구분, 실한 경우 간울, 혈어, 한응으로 구분하여 치료
# 치료
- 포기불고: 방광에 기운이 없어 괄약근을 조절하지 못하는 경우로 [[축천환]] 사용
- 비폐기허: 전체적으로 허약한 상태로 [[승함탕]], [[보중익기탕]] 사용
- 하초허냉: 하초가 허하고 차가운 상태로 [[토사자환]], [[공제환]] 사용
- 간실소설: 소간청열하는 [[소요산]], [[용담사간탕]] 사용
- 폐열울결: 기침하고 기침으로 인해 오줌 나올 때 [[마행감석탕]] 사용
