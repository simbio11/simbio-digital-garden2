# 위축성 위염 (Atrophic Gastritis)

> **핵심 요약**: 만성 염증으로 **위점막의 정상 위선(胃腺)이 소실·위축**되고 점막이 얇아진 상태. 위암의 **전구 병변(precancerous lesion)** 으로, 헬리코박터 파일로리(H. pylori) 제균 후에도 위암 발생 위험이 잔존한다. 임상적으로 소화불량·조기포만감·식욕부진이 흔하며, **펩시노겐 I·PGR, 가스트린-17, 내시경 OLGA/OLGIM 병기**로 추적한다.

## 정의·분류
- 만성 위염의 진행형 — 표재성(비위축성) → 위축성 → [[장상피화생]] → 이형성 → 위암(Correa cascade)
- **A형(자가면역)**: 내인자·벽세포 항체, 위체부 위축, 악성빈혈 동반 — 서구 드묾
- **B형(H. pylori)**: 다초점(multifocal) 위축, 한국 위축성 위염의 대부분
- 병리: 위선 소실·점막 얇아짐·장형(腸型) 화생, 섬유화
- 중증도·범위(OLGA/OLGIM III~IV)에 따라 위암 위험이 커짐

## 병태생리·기전
- H. pylori 만성 감염 → 만성 활동성 염증([[NF-κB]]·IL-8 등) → 점막 위축·화생
- **저산증(hypochlorhydria) → 음성 되먹임 소실로 [[가스트린]]-17 상승**, 위체부 주세포 소실로 **[[펩시노겐]] I 감소(PGR 저하)**
- 위산 저하 → 철분·[[비타민 B12]] 흡수 저하(빈혈), 장내 세균 과성장
- 발암: 위축·화생 조직의 이형성 → 위암

## 진단·평가
- **혈청학(비내시경 위축 표지)**: [[펩시노겐]] I, PG I/II 비(PGR), [[가스트린]]-17
- **내시경 + 조직검사**: OLGA/OLGIM 병기, Kimura-Takemoto 지도생검
- **H. pylori 검사**: 요소호기검사(UBT)·조직·혈청, 제균 후 추적
- 감별: [[기능성 소화불량]](증상 유사), [[위궤양]], [[위암]], [[만성 위염]](비위축성)

## 치료 (근거 기반 + 한의)
- **양방**: H. pylori 제균(표준 삼제·사제요법), 위점막 보호([[PPI]]·H2RA·레바미피드 등). **위축을 역전시키는 확립된 약물은 제한적** → 제균 + 정기 내시경 감시가 기본
- **한의**: 비위기허(脾胃氣虛) 겸 담음·기체 → **[[육군자탕]] 계열 병용**
  - 2026-09-10 심층리뷰 1번(PMID 40812557, J Ethnopharmacol 2025;353:120414, RCT 22편 n=2,086): **육군자탕 + 양방 병용**이 양방 단독 대비 총임상유효율·증상개선유효율을 유의하게 향상(근거 확실성 중등도), 제균율·펩시노겐 I·가스트린-17 상승, 이상반응은 양방군보다 적음
  - 가감: 습열 잔존 시 황련·황금, 담음·기체 시 진피·반하, 식욕부진 뚜렷 시 그렐린 분비 촉진 처방
- 추적: 전후 헬리코박터 검사·펩시노겐 I/II·PGR·가스트린-17을 지표로, 내시경(OLGA/OLGIM) 일정과 병행
