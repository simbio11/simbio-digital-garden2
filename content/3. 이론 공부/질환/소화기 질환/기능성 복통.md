# 기능성 복통 (FAPD / AP-DGBI, 소아 복통-장뇌 상호작용 장애)

> **핵심 요약**: 기질적 원인 없이 반복되는 복부 통증·불편감을 특징으로 하는 소아·청소년의 **장-뇌 상호작용 장애(Disorders of Gut-Brain Interaction)** 군. 과민성장증후군(IBS)·비특이성 기능성 복통(FAP-NOS)·기능성 소화불량(FD)·복부 편두통(AM)을 포함한다. 병태생리는 **장-뇌축 이상·내장 과민성·장내미생물 불균형·점막 장벽 저하**이며, 치료의 중심은 **적색기 신호 감별 + 식이·심리·수면 중재 + 제한적 보조요법**이다.

## 정의·분류 (Rome IV 기준)
| 아형 | 특징 |
| :--- | :--- |
| **과민성장증후군(IBS)** | 복통 + 배변 양상 변화(빈도·형태) 연관 → [[과민성 장 증후군]] |
| **비특이성 기능성 복통(FAP-NOS)** | 배변·식사와 무관하게 반복되는 복통, Rome 기준을 충족하지 않는 경우 |
| **기능성 소화불량(FD)** | 상복부 통증·불편감(조기 포만·식후 팽만) → [[기능성 소화불량]] |
| **복부 편두통(AM)** | 반복 복통 + 두통·구토·빛/소리 공포 등 편두통 동반 |
- **용어 변화**: 과거 FAPDs → 최근 AP-DGBIs로 개칭('기능성'이 정신과적 원인이라는 오해를 줄이기 위함)
- **역학**: 소아·청소년의 흔하고 부담이 큰 질환. 4~18세에서 호발, 여아 우세

## 병태생리·기전
- **장-뇌축 신호 이상** — 미주·척수 구심로와 중추 처리의 증폭 → [[장-뇌축]]
- **내장 과민성** — 정상적 팽창 자극이 통증으로 인지 → [[내장 과민성]]
- **장내미생물 불균형** — [[단쇄지방산]] 등 대사산물 변화, 점막 면역 조절 이상
- **점막 장벽 기능 저하** — [[밀착결합]] 단백질 감소 → 내독소·항원 전위
- **정신사회·스트레스 요인** — [[코르티솔]]·불안·수면장애가 증상 악화 인자

## 진단·평가
- **임상 진단**: 병력·신체검사로 Rome IV 기준 충족 여부 확인 후, 기질 질환 배제
- **평가 도구**: 통증 강도(VAS)·주당 통증 횟수·완전 관해 여부 — 2026-09-13 메타분석의 결과지표와 동일 세트를 진료실 통증일지로 사용
- <font color="#fa7e7e">🚩 **적색기 신호(즉시 의뢰)**: 체중 감소·성장 지연, 야간에 잠을 깨는 통증, 혈변·흑색변, 발열, 관절통·피부 병변, 항문 주위 병변, 빈혈</font>
- **감별**: 염증성 장질환, 복강병(셀리악병), 유당불내증, 기생충 감염, 요로감염, 만성 변비

## 치료 (근거 기반 + 한의)
- **1단계 — 상담·생활**: 식이(규칙 식사, 유제품·탄산·카페인·과당 조절), 수면 위생, 심리·스트레스 중재. **환자·부모에게 병의 실체를 설명하는 것 자체가 치료**(증상-불안 양성 되먹임 차단)
- **2단계 — 제한적 보조요법**: **[[프로바이오틱스]] 4주 시험 투여**(LGG 3×10⁹ CFU 1일 2회 또는 L. reuteri DSM 17938 10⁸ CFU 1일 1회가 근거가 가장 명확) → 4주 시점 통증일지로 지속 여부 결정. 기타: 페퍼민트 오일, 저용량 삼환계 등(연령·근거 확인)
- **3단계 — 한의 접근**: 변증은 **비위허약·간위불화·식적(食積)** 이 많다. 처방으로 소건중탕·이중탕·향사육군자탕·백출산 계열, 침은 자극을 최소화한 **복부 천자(중완 CV12·천추 ST25·기해 CV6)·족삼리(ST36)·내관(PC6)·사봉(四縫)** 위주로 **유침 5~10분** 단시간 시행
- **약·보조요법 병용 주의**: 프로바이오틱스는 위산·항생제에 민감 → **한약과 1~2시간 간격**, 항생제 종료 후 시작

## 논문 연결
- 2026-09-13 심층리뷰 3번(Eur J Pediatr 2026;185(8):592, PMID 42477222 / DOI 10.1007/s00431-026-07161-5): 18세 미만 AP-DGBI 21개 RCT·1,899명 — 프로바이오틱스가 위약 대비 통증 강도 MD −0.80(95% CI −1.45~−0.15), 주당 통증 횟수 MD −1.02회, 완전 관해 35.3% vs 22.8%(NNT≈7). **IBS군(MD −1.20)·FAP-NOS군(MD −1.08)에서는 VAS 개선, 기능성 소화불량군(MD −0.42, 95% CI −2.08~1.24)에서는 유의하지 않음**.
