# 병리적 특징
- 정의: 대장에 염증이 발생한 상태
- 원인: 바이러스, 세균, 원충, 자가면역, 방사선, 허혈, 약제
- 증상: 복통, 체중감소, 혈변, 발열, 오심, 설사

- 감염성 장염과 비감염성 장염으로 구분된다.  
- 감염균은 [[바이러스성 장염]](노로 바이러스, 로타 바이러스), [[세균성 장염]](콜레라, 대장균, 이질, 장티푸스), [[원충 대장염]](아메바), [[위막성 대장염]], 결핵균
- 비감염성 대장염은 [[염증성 장질환]](크론병, 궤양성 대장염), [[방사선성 대장염]], [[허혈성 대장염]], [[베체트 장염]], [[약재유발성 장염]]이 있다. 
# 의안 분석
- 습열증
- 허한증: 설태가 하얗고, 활세맥이며, 몸이 차가운 경우이며, 비장을 온중하여 치료한다. 
- 어혈증, 습열
- 비허증
# 고찰
- 위염과 유사하며, 변증하여 치료한다. 
- 비위허약에 [[상삼]], [[백출]], [[복령]],[[계지]], [[후박]], [[사인]]을 사용하여 온중건비, 이기화위한다. 
- 비신양허하고 설사도 하는 경우 [[보골지]], [[적작약]], [[오미자]], [[오수유]]를 가감하여 온보비신, 수삽지설한다. 
- 비허약에 [[산약]], [[창출]], [[사인]], [[백작약]]을 사용한다.
