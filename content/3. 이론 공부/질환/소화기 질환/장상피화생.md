# 장상피화생 (Intestinal Metaplasia)

> **핵심 요약**: 만성 위축성 위염이 진행하면서 **위점막 상피가 소장·대장형 점막(배상세포·장형 상피)으로 바뀌는 화생성 변화**. 위암의 주요 **전구 병변**이며, 특히 **불완전형(대장형) 화생**이 위암 위험이 높다. 내시경 협대역영상(NBI)·확대 관찰 + 조직검사로 진단하고 **OLGIM 병기**로 추적한다.

## 정의·분류
- 화생(metaplasia) = 한 조직형이 다른 조직형으로 바뀌는 적응성 변화
- **완전형(소장형, type I)**: 장 상피세포·배상세포·파네트세포까지 완전 분화 → 위암 위험 상대적으로 낮음
- **불완전형(대장형, type II·III)**: 배상세포 + 미성숙 점액세포, 술잔세포 → **위암 위험 높음**
- 진행 모델: H. pylori → [[위축성 위염]] → 장상피화생 → 이형성 → 위암 (Correa cascade)

## 병태생리·기전
- 만성 염증·저산증 환경에서 위 줄기세포의 분화 운명이 장형으로 재프로그래밍
- CDX1·CDX2 등 장형 전사인자 발현, 위산-담즙 역류가 촉진 인자
- 화생 자체는 방어적 적응일 수 있으나, **불완전형·이형성 동반 시 발암 촉진**

## 진단·평가
- 내시경: **협대역영상(NBI)·확대내시경**, 메틸렌블루/초자화(chromoendoscopy) 염색
- 조직: **OLGIM 병기**(화생의 범위·중증도), 완전형/불완전형 판정
- 혈청학: [[펩시노겐]] I·PGR 저하, [[가스트린]]-17(전정부 위축 시 저하·위체부 위축 시 상승)
- 감별: 정상 소장 점막, 위 이형성(이형성증), 조기 위암

## 치료 (근거 기반 + 한의)
- **화생을 역전시키는 확립된 약물은 없음** → **H. pylori 제균 + 정기 내시경 감시**가 표준
- 한의: 비위기허·담음·습열 변증 처방으로 **증상 개선·점막 환경 관리**를 목표로 함. 2026-09-10 심층리뷰 1번(PMID 40812557)의 육군자탕 병용 근거는 위축성 위염·전구 병변 환자군의 유효성·안전성을 지지(근거 확실성 중등도)하나, **화생 '역전'을 단정하지 말 것**
- 추적: 병기에 따라 1~3년 간격 내시경, 이형성 동반 시 간격 단축·내시경 절제 검토
