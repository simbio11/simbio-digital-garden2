- [[사각근]], [[소흉근]] 등의 과긴장, 단축이 [[상완신경총]] 압박하여 통증, 저림, 이상감각, 청색증, 약맥, 부종 증상이 나타남
- [[Abson test]]: 팔을 외전, 외회전 시키고, 고개를 검사방향으로 돌려 통증이나 요골동맥 감소 확인
- 선천적 기형으로 갈비뼈 위에 경늑골을 추가로 가져 흉곽 출구의 신경, 동맥, 정맥이 압박될 수 있음.

>**치료포인트**
>[[전사각근]], [[중사각근]] [[소흉근]] 신경 포착
>+거북목 자세 교정(모니터 위로 올리기)

- [[상완신경총]] 눌림> 손과 손가락 팽만감, 통증, 저림, 이상감각
- 액와동맥 눌림> 청색증, 약맥
- 액와정맥 눌림> 표재정맥 확장, 부종

- [[가쪽흉근신경]], [[안쪽흉근신경]] 포착> [[대흉근]] 등척성 수축(허혈성 통증), 등장성 수축(골막자극, 염증성 통증)
- [[내측상완피신경]], [[내측하완피신경]] 포착> 상완의 내측과 전완 내측 감각신경성 통증
- [[견갑상신경]], [[견갑하신경]], [[견갑중신경]] 포착> [[견갑하근]], [[광배근]], [[대원근]]의 등장성 수축> 골막 자극, 염증성 통증(허혈성 통증)
- [[요골신경]] 포착> 상완, 전완 신전근 등척성 수축(허혈성 통증), 등장성 수축(손가락 골막 자극, 염증성 통증), 감각신경성 통증
- [[정중신경]] 포착> 감각신경성 통증, [[요측수근굴근|요측수근굴근]] 단축과 [[원회내근(|원회내근]] 포착이 동반
- [[척골신경]] 포착: 흉곽 출구보다는 C8, T1 척추주위심부근육이나 [[소흉근]]을 확인
- [[근피신경]]: [[오훼완근]] 확인
- [[액와신경]]: [[소원근]] 확인
