# 신경인성 파행 (Neurogenic Claudication)

> **핵심 요약**: **보행 시 하지 통증·저림·쇠약이 유발되고, 허리를 굽히거나 앉으면 수 분 내 완화**되는 증후군. 요추관협착증([[척추 협착증]])의 대표 증상이며 '걷다 아프고 허리 굽히면 좋아짐'이 특징. 말초혈관 질환에 의한 혈관성 파행과 감별이 치료 방향을 결정한다.

## 정의·기전
- 기전: 요추 신전(젖히기) 시 척추관 협소 → **신경근·마미총의 정맥울혈 + 허혈성 압박** → 보행 중 산소 요구 증가로 증상 유발
- 허리 굴곡은 척추관 단면적·경막낭 용적을 확장시켜 압박·울혈을 즉시 감소 → 완화되는 임상 패턴
- 감각·통증이 우세한 '통증형'과 저림·이상감각이 우세한 '감각형'이 있으며, 통증형이 침·운동 반응이 더 좋을 수 있음(2026-09-07 리뷰 임상 팁)

## 진단·감별 (혈관성 파행과 대비)
| 항목 | 신경인성 파행 | 혈관성 파행 |
| :--- | :--- | :--- |
| 유발 | 보행·**허리 신전** | 보행(일정 거리) |
| 완화 | **허리 굴곡·앉기** | 서 있기만 해도 완화 |
| 증상 | 통증+저림·이상감각, 양측성·방사상 | 쥐어짜는 통증, 종아리 중심 |
| 맥박·피부 | 정상 | 족배동맥 약화·창백·탈모 동반 |
- 감별 질환: [[요추 추간판 탈출증]], [[좌골신경통]], 고관절 병변, 당뇨병성 신경병증
- 레드플래그: 회음부 감각 저하·배뇨 장애(마미증후군), 급격한 근력 저하 → 영상·수술 의뢰

## 평가·치료 연계
- 보행 유발 검사(증상 유발 거리), 신전-굴곡 자세 변화로 증상 재현 확인, MRI/CT로 협착 확인
- 침(2026-09-07 심층리뷰 1번, PMID 38950397): BL25 대장수 심자 등 요부·하지 배혈 18회/6주가 통증-특이 장애 개선 — 샴 대비 30% 반응률 +16.0%p
- 운동(2026-09-07 심층리뷰 2번, PMID 37715644): **굴곡 자세 유산소(사이클)·스트레칭·체간근** — 걷기 통증이 심하면 실내 자전거부터
- 환자 설명: "완치가 아니라 파행 거리·보행 자신감 회복"을 목표로 2~4주 내 반응 평가
