- 위산 역류로 인한 신물을 토하는 상태이다.(신물이 위중으로부터 올라옴)
# 병리적 특징
- 정의: 위의 신물을 토하는 증상
- 원인: 하부 식도 괄약근의 기능 이상, 위의 문제/ 간화내울, 위기불화, 비위허한
- 증상: 신물을 토함
# 치료
- 설간화위, 고신통감하여 간을 다스리고 열증의 토산을 내린다. 온중산한, 화위제산하여 비위나 중초의 허한, 한체를 완화
- [[상삼]], [[복령]], [[백출]], [[목향]], [[귤피]]를 사용하여 위산 역류를 치료한다.
- 열증: 설간화위, 고신통강하는 [[좌금환]]
- 한증: 온중산화, 화위제산하는 [[향사육군자탕]] 가 [[오수유]]
- [[증미이진탕]], [[정전가미이진탕]] 활용
# 탄산 vs 조잡
- 탄산은 위중불적, 구토산수가 나타나며, 조잡은 위중공허, 배고픈 것 같은데 고프지 않고, 매운 것 같은데 맵지 않음, 흉중오뇌
- 탄산은 위산과다, 조잡은 위산 부족
