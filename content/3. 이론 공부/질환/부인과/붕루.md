# 설명 
- 정의: 월경주기와 무관한 불규칙적 출혈
- 허, 열, 어가 원인이며, 이들은 단독으로 나타나지 않는다. 
- 출혈량이 적을 때: [[자궁내막암]] 주궁목 미란, 용종, 배란기 출혈, 경구피임제 복용
- 출혈량이 많거나 갑자기: 유산, 포상기태, 임신 융모암, [[자궁외임신]], 임신 합병증
# 기능성 자궁출혈의 호르몬
- 소퇴: 분비가 꺾이면서 발생, 파탄: 대상 기관이 견디지 못해 발생

# 치료
- 치료 목표: 급성 출혈의 지혈(색류), 재발의 방지와 정상 월경주기의 회복(증원), 수태능력 보존(뽁구)
- 급성 출혈만 막으면 다음에 환자가 안 올 수 있는데, 출혈이 발생한 근본적인 원인을 치료해야 한다고 지도하는 것이 중요하다. 
- 색류: [[십회산]]을 사용하여 지혈, [[가감석홍전]]도 변혈, 하부 출혈에 활용, 지혈 처방을 너무 오래 쓰면 어혈 발생 가능
- 증원: 근본을 맑게하는 치료의 시작, 정상 월경 주기 회복
- 복구: 조리하는 것
