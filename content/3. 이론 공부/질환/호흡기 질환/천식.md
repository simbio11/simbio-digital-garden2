# 🩺 천식 (哮喘, Asthma)

> **핵심 요약 (Key Summary)**:
> **기관지의 만성 염증**으로 기도가 좁아져 **반복성 천명·호흡곤란·가슴 답답함·기침**이 발작적으로 나타나는 질환. 가역적 기류 제한과 **기도 과민성**이 특징이며, 소아 만성질환 중 가장 흔하다.
> 치료의 축은 **① 급성 악화 = 속효성 β2 작용제(+이프라트로피움) + 전신 코르티코스테로이드 ② 만성 = 흡입 스테로이드(ICS) 유지**다. 한의학에서는 哮證·喘證으로 보고 宣肺平喘·化痰·補肺健脾腎으로 접근한다. **중등도 이상 악화에서 조기 비침습적 환기(NIV)는 2026년 무작위시험에서 이득이 확인되지 않았다.**

## 1. 정의·분류
- **정의**: 기관지의 염증에 의해 기관지가 심하게 좁아져 **기침·천명·호흡곤란·가슴 답답함**이 반복적으로 발생하는 상태
- **분류**
  - **표현형**: 아토피성(알레르기 감작 동반) / 비아토피성
  - **중증도·조절 수준**(GINA): 간헐·경증 지속·중등도 지속·중증 — 유지치료 단계 결정
  - **급성 악화 중증도**: 경증 / 중등도 / 중증(침묵폐·의식 변화·SpO₂ 저하)
  - 한의: **哮(천명) = 담·한응이 폐에 결림**, **喘(호흡곤란) = 기폐실강**, 虛證은 肺脾腎 허손

## 2. 병태생리·기전
- **① 기도 염증**: 비만세포·호산구·Th2 사이토카인(IL-4·IL-5·IL-13)·IgE 매개 염증 → 점막 부종·점액 분비 증가
- **② 평활근 수축·기도 과민성**: 자극(알레르겐·운동·한랭·자극성 기체)에 대한 과도한 수축 반응
- **③ 점액 마개·기도 재형성**: 만성 경과에서 배상세포 증식·기저막 비후
- **④ 호흡역학**: 기류 제한·공기 포획 → **내재적 말기 호기 양압(PEEPi)** 형성 → 호기 부담·호흡일 증가 → CO₂ 저류·호흡성 산증 → [[폐쇄성 수면무호흡증]]과는 다른 축이지만 야간 증상·수면 악화가 흔하다
- **원인·악화 인자**: 유전적 요인, 비만, 알레르기 항원, 감염, 직업성 감작물질, 흡연, 대기오염, 음식, 운동·한랭 공기

## 3. 진단·평가
- **증상 패턴**: 반복성·발작성 천명, 야간/새벽 악화, 운동·찬 공기 유발
- **폐기능**: 기관지확장제 반응(FEV1 12%·200 mL 이상 증가), PEF 변동성
- **알레르기 평가**: 피부단자·특이 IgE, 호산구 수(치료 선택에도 활용)
- **감별**: 모세기관지염·흡인·이물·기관연화·심인성 천명, 후두 질환, COPD(성인)
- **급성 중증도 도구**: 소아는 **PRAM 12점**(흉골상함몰·사각근 수축·공기 유입·천명·SpO₂) → [[PRAM]]
- **원문 필기 취지**: "폐기(肺氣)가 막혀 숨이 차는 병증으로 현대의 천식·천명과 유사하다"

## 4. 치료 (근거 기반 + 한의)
- **급성 악화(1차 표준치료)**
  - **속효성 β2 작용제(SABA)** 반복/지속 네뷸라이제이션 → [[알부테롤]]
  - **이프라트로피움** 병용(첫 1시간 3회) — 중등도~중증에서 입원 감소 이득 → [[이프라트로피움]]
  - **전신 코르티코스테로이드**(경구 프레드니솔론 등) 조기 투여 → [[프레드니솔론]]
  - 보충 산소(SpO₂ 목표 유지), 반응 평가 후 **1시간 내 뚜렷한 호전 없으면 이송**
  - **NIV(BPAP)**: 2026년 sham 대조 RCT에서 중등도군 이득 없음 → **적응 확립된 치료로 보지 않는다** → [[비침습적 환기]]
- **만성 유지**
  - **ICS(흡입 스테로이드)** 가 기본, 단계별 add-on(LABA·LAMA·LTRA·생물학적제제)
  - 흡입 기법 교육과 **SABA 주 2회 초과 여부를 조절 지표**로 삼는다
- **한방 접근**
  - 급성기: **宣肺平喘·疏風散寒** — 소청룡탕(한증·담음), 마행감석탕(폐열·천명) → [[소청룡탕]] · [[마행감석탕]]
  - 완화기: **補肺健脾補腎**(폐·비·신 허손), 化痰祛瘀, 三伏貼(폐수 BL13·고황 BL43·대추 GV14) → [[경혈 첩부요법]]
  - 침구: 폐수(BL13)·정천(LU10)·천돌(CV22)·족삼리(ST36)·풍륭(ST40), 定喘(EX-B1)
  - **원칙**: 한방 단독으로 급성 악화를 관리하지 않는다. **SABA 흡입이 필요한 중증도면 한약·첩부는 보조**이며, 지속형 알부테롤이 필요한 상황은 한의원 외래 관리 범위 밖이다

## 5. 논문 연결
- **2026-09-20 심층리뷰 2번** — 소아·청소년 66명 sham BPAP RCT(JAMA Netw Open 2026;9(8):e2630627, [PMID: 42646841](https://pubmed.ncbi.nlm.nih.gov/42646841/)): **IPAP 10/EPAP 5 cmH₂O 4시간** 조기 적용에도 지속형 알부테롤 투여시간 **8.3 vs 8.7시간(P=.84)** 으로 차이 없음 → 50% 중간분석에서 **조기 종료**. PRAM 감소 속도·PICU 입원율·재원 기간 모두 군간 차이 없음 → [[비침습적 환기]] · [[PRAM]]

## 7. 원문 진료 필기 (보존)
- 발작적으로 목 안에서 그르렁거리며 가래 끓는 소리가 나며 숨이 차는 병증으로 현대에 천식, 천명과 유사하다고 본다.
- 정의: 기관지의 염증에 의해 기관지가 심하게 좁아져 기침, 천명, 호흡곤란, 가슴 답답함이 반복적으로 발생하는 상태이다.
- 원인: 유전적 요인, 비만, 알레르기 항원, 감염, 작업성 감작물질, 흡연, 공기 오염, 음식
- 증상: 가래, 천명, 호흡곤란, 가슴 답답함, 기침
