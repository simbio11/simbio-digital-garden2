# 당뇨병 (Diabetes Mellitus)

> **핵심 요약**: 혈중 포도당이 만성적으로 높아지는 대사질환. 제2형(T2DM)은 **인슐린 저항성 + 인슐린 분비 저하**가 겹쳐 발생하며, 혈당 조절을 넘어 **심혈관·신장 위험(동맥경화성 사건, 알부민뇨) 통합 관리**로 치료 패러다임이 전환된 질환이다. 진단·추적은 공복혈당·HbA1c·식후혈당으로 하고, 합병증은 대혈관(심근경색·뇌졸중)·미세혈관(망막·신장·신경)으로 나눈다.

## 정의·분류
- 1형: 췌장 β세포 파괴로 인슐린 절대 부족(면역·특발)
- 2형(T2DM): 인슐린 저항성 + 상대적 분비 저하 — 전체 당뇨의 90% 이상
- 임신성 당뇨, 기타 특정 유전·약물·질환 관련 당뇨

## 병태생리·기전
- **인슐린 저항성**: 근육·지방·간의 인슐린 신호 감소 → 포도당 이용 저하, 간 포도당 신생 증가 ([[GLUT4]] 전위 저하가 근육의 핵심 기전)
- **β세포 기능 저하**: 분비능 감소 + 세포사 (당독성·지질독성, 만성 염증)
- 고혈당이 지속되면 AGEs·산화스트레스로 혈관 내피 손상 → 대혈관·미세혈관 합병증

## 진단·평가
- 공복혈당 ≥126 mg/dL, HbA1c ≥6.5%, 식후 2시간(75g OGTT) ≥200 mg/dL 등
- 추적: [[HbA1c]](3개월 주기), 식후혈당. 신장 위험 평가는 [[UACR]]·eGFR
- 인슐린 저항성 지표: HOMA-IR 등 (임상 연구에서 사용)

## 치료(근거 기반+한의)
- 생활습관(식이·운동)이 기본 — 근감소증 예방 위해 [[저항운동]]·단백질 병행 권장
- 약물: 메트포르민 1차 → 심혈관·신장 고위험군은 [[세마글루타이드]](GLP-1 RA)·[[SGLT2 억제제]] 계열 우선, 인슐린은 필요 시
- 한의: 침 보조요법이 HbA1c·공복혈당을 유의 개선(약물 대체 아님), 소화기능·식후혈당 변동 관리에 한약 병행 가능

## 논문 연결
