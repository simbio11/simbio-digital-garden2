# 설명 
- 간질액이 비정상적으로 축적된 상태로 전신 부종과 국소 부종으로 구분할 수 잇다. 
- 원인: 정수압 증가(심부전, 심낭염, 알도스테론증, 구획증후군, 교감신경 영양장애 등), 교질 삼투압 감소(알부민 합성 감소: 영양실조, 흡수장애, [[간경화]], 알부민 손실 증가: [[쿠싱 증후군]]. 신장질환, 전자간증), 혈관 투과성 증가(두드러기, 혈관염, 감염, 지방부종, 약물, [[갑상선 기능 저하증]])
- 주로  [[만성 사구체 신염]], [[급성 사구체 신염]], 울혈성 [[심부전]], 내분비 장애, [[신장 증후군]], 영양장애성 질병 등에 의해 발생
- 정수압과 혈관 투과성과 혈액 내 삼투압(교질 삼투압)을 고려하여 치료할 것
