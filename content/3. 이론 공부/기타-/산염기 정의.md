- 산화: 전자를 잃는 과정(산소를 얻거나 수소를 잃는 과정)->다른 물질을 안정적으로 만들어줌, 본인은 불안정 (염기성 물질은 전자를 내놓으려고 함)
- 환원: 전자를 얻는 과정(산소를 잃거나 수소를 얻는 과정)->다른 물질을 불안정하게 만들어줌, 본인은 안정(산성 물질은 전자를 가져가려고 함)
- 산성 물질이 물이나 다른 물질을 만나서 수소 이온을 내놓는 것은 산-염기 반응이다. 
- 산성 물질은 전자나 수소 이온을 가져가려는 경향을 보이는 물질임 
- 산염기 반응이 발생 한 다음 산성 물질은 전자나 수소 이온을 가져오고 싶어하는(환원되고) 경향을 가지기에 다른 물질을 만나면 전자나 수소 이온을 뺏어서 해당 물질을 불안정하게 만든다. 
# 항산화제 
- 활성 산소는 다른 물질로부터 수소를 강하게 뺏어가려는(환원) 경향을 가지며, 이는 다른 물질을 산화시켜 불안정하게 만들게 된다. 
- 항산화제는 피해자의 역할을 하여 대신 산화되어 다른 물질의 산화를 막아준다. 
- 전달형 항산화제: [[비타민 C]], [[비타민 K]]는 자기 자신이 먼저 산화되면서 전자를 제공하여 산성 물질을 안정적으로 만듦
- 제거형 항산화제: [[글루타치온]], 카로티노이드는 활성 산소와 직접 결합하여 무해한 물질로 변환 
# 산성도
- 산성도는 수소 이온을 얼마나 많이 가지고 있느냐보다는 수소 이온을 얼마나 잘 내보내느냐를 의미한다. 
- 산성도가 높을수록 물 속에서 수소 이온을 잘 내놓는 것이고, 이로 인해 pH가 낮아지는 것 
- 산-염기 반응에서 수소 이온을 많이 내보낼수록 다른 물질과 만났을 때, 수소 이온을 잘 가져가므로 산성도가 높을 수록 다른 물질을 잘 파괴하는 것
