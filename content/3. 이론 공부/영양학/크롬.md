# 생리적 기능
- [[인슐린]] 작용 증강: 인슐린 수용체의 [[타이로신 카이네이스]] 활성을 증강시켜 [[글루코스]]를 세포 아느로 빨아들이는 글루코스 수송체가 세포막 표면에 잘 발현될 수 있도록 한다. 
- 지방 세포의 세포막에 있는 [[포스포타이로신 포스파테이스]] 활성을 통해 지질 대사에 관여
- 철결합 단백질인 [[트랜스페린]]과 결합하여 혈액을 통해 간으로 운반

# 임상
- 결핍증: 포도당 불내성, 운동 실조, 신경 장애, 체중 감소
- 과잉증: 흡수율이 매우 낮아 과잉 섭취해도 이상이 없으며, 간질성 폐렴 발생
