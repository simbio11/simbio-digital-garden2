# 🥗 격일단식 (Alternate-Day Fasting, ADF)

> **핵심 요약 (Key Summary)**:
> - 📍 **정체**: 단식일과 섭취일을 하루씩 교대하는 [[간헐적 단식]] 전략. 단식일에는 통상 소량 섭취 또는 24시간 단식으로 운영한다.
> - 🚩 **근거**: 무작위시험 99편·6,582명 NMA에서 **지속적 열량제한보다 체중을 더 줄인 유일한 전략**이었다(평균차 -1.29 kg, 95% CI -1.99~-0.59, 중등도 근거확실성). [[시간제한식이]]보다 -1.69 kg, 종일단식보다 -1.05 kg 더 감소 — [PMID 40533200](https://pubmed.ncbi.nlm.nih.gov/40533200/).
> - 🛠️ **임상 위치**: 총콜레스테롤·[[중성지방]]·non-HDL을 [[시간제한식이]]보다 더 낮췄으나, [[HbA1c]]·[[HDL]]은 전략 간 차이가 없었다. **24주 이상에서는 우월성이 사라졌다**.
> - <font color="#fa7e7e">⚠️ **주의**: 고령자에서는 감량분이 지방이 아니라 근육에서 나올 수 있다. 노인·[[근감소증]] 위험군은 격일단식 대신 [[시간제한식이]]로 시작한다.</font>

## 1. 정의 & 시행법

* **정의**: 단식일(섭취 제한)과 섭취일(자유 섭취)을 하루씩 교대한다. 단식일에는 통상 소량 섭취(약 25% 열량) 또는 24시간 완전 단식으로 운영한다
* **시행 예**: 시험별로 단식일 정의·섭취량이 달라, 환자를 지도할 때는 적용하려는 시험의 프로토콜을 원문에서 확인한다
* **핵심 원리**: 단식일에 총 열량이 크게 줄고, 섭취일에도 완전한 보상 섭취가 일어나지 않아 **주간 총 열량이 감소**한다

---

## 2. 기전

* 단식일: [[글리코겐]] 고갈 → 지방산 산화·[[케톤체]] 생성, [[AMPK]] 활성화·[[mTOR]] 억제·[[자가포식]] 증가
* 섭취일: 지방 조직 지질분해·[[아디포넥틴]] 증가, 일주기 리듬 정렬
* **단서**: 대부분의 효과는 **총 섭취 열량 감소**로 설명되며, 단식 시간 구조 자체의 추가 이득은 제한적으로 해석한다 ([PMID 27810402](https://pubmed.ncbi.nlm.nih.gov/27810402/))

## 3. 임상 근거

| 비교 | 결과 |
| :--- | :--- |
| ADF vs 지속적 열량제한 | 체중 -1.29 kg (95% CI -1.99~-0.59, 중등도 근거) |
| ADF vs [[시간제한식이]] | 체중 -1.69 kg |
| ADF vs 종일단식 | 체중 -1.05 kg |
| 지질(총콜레스테롤·중성지방·non-HDL) | [[시간제한식이]]보다 더 감소 |
| HbA1c · HDL | 전략 간 차이 없음 |
| ≥24주 추적(17편) | 간헐적 단식 대 지속적 열량제한 차이 소실 |

* **[PMID 36508320](https://pubmed.ncbi.nlm.nih.gov/36508320/)** 의 시행 예 — 주 3회 비연속 단식일·12주(인슐린 치료 T2DM 46명): HbA1c -7.3 mmol/mol, 중증 저혈당 없음
* **역사적 리뷰**: Varady KA, *Am J Clin Nutr* 2007;86(1):7-13, [PMID 17616757](https://pubmed.ncbi.nlm.nih.gov/17616757/)

## 4. 주의·금기

* **노인·근감소증**: 감량분이 근육에서 나올 수 있다 → [[시간제한식이]] 우선, [[단백질]] 1.0~1.2 g/kg 배분 + 주 2회 저항운동 병행
* **약물 병용**: 인슐린·설폰요소제 저혈당, [[SGLT2 억제제]] [[정상혈당 케톤산증]] 위험
* **대상 제외**: 임신·수유, 1형 당뇨병, 섭식장애 병력, 노쇠·투석 환자
* **중단**: 어지럼·심한 두통·기력 저하 지속 시 중단
