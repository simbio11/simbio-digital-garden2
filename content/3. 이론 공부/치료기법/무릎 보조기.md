# 무릎 보조기 (Knee Brace / Knee Orthosis)

> **핵심 요약**: 무릎 골관절염에서 통증 유발 활동 시 착용해 **관절 부하를 재분배하거나 슬개골 활주를 개선하는 보조 기기**. 2026-09-14 심층리뷰 3번(PROP OA, BMJ 2026, PMID 41587822)에 따르면 교육·운동(AIE)에 보조기를 **추가**하면 6개월 KOOS-5가 3.39점(ES 0.24) 개선되고 **통증 하위척도가 가장 크게 호전**되지만, **사전 MCID 8점에는 미달**하고 12개월에는 유의성이 사라진다. 즉 **1차 치료가 아니라 '운동·교육에 더하는 선택적 보조'**이며, 효과를 좌우하는 것은 기기 자체보다 **착용 순응도**다.

## 정의·기법(기기 계열과 처방)
- **슬개대퇴형(PF brace)**: 슬개골 활주 궤적(tracking) 개선 목적 — 슬개대퇴 증상 우세 환자([[슬개대퇴 증후군]])
- **경골대퇴 감압형(unloading brace)**: 관절에 **3점 굽힘력(three-point bending)**을 가해 손상 구획의 부하를 반대 구획으로 재분배 — **내측 구획 침범 + 경증~중등도 내반**에 적합
- **중립 안정화형(hinged sleeve)**: 힌지로 관절 운동을 안내하고 고유수용성 입력을 늘려 '무릎 꺾임' 불안감 감소
- **구획 판정**: 임상평가 + 체중부하 X선. 저자들에 따르면 **임상평가만으로도 X선과 약 86% 일치(κ=0.79)** — 영상이 없어도 대략적 선택 가능
- **착용 용량(dose)**: 통증 유발 체중부하 활동 시 **1일 1시간 이상·주 2일 이상**으로 시작 → 내약성에 따라 증량, 최대 8~12시간/일, **6개월 착용 후 재평가**

## 작용 기전
- 기계적: 3점 굽힘력에 의한 구획 부하 재분배, 슬개골 활주 정렬 개선, 관절 불안정 감소
- 신경생리적: 피부·관절 수용기 자극 증가 → **고유수용감각([[고유수용감각]])** 입력 강화 → 대퇴사두근 억제(arthrogenic inhibition) 완화
- **맥락 효과 주의**: PROP OA에서 보조기군은 접촉 시간(1시간+30분 vs 20분)과 접촉 빈도가 더 많았다 — 관찰된 이득의 일부는 주의·기대(맥락) 효과일 수 있음을 저자들이 한계로 명시

## 임상 적용 (근거 기반 + 한의)
- **위치 설정**: "보조기는 운동·체중관리·교육을 대체하지 않는다"를 환자에게 먼저 설명. ① 주 병변 구획 판정 ② 착용 시작 용량 결정 ③ **6개월 시점 재평가 후 유지/중단**
- **순응도가 효과** — 순응자 분석(CACE) 6개월 KOOS-5 +5.21점(95% CI 1.48~8.94)로 전체 분석(3.39)보다 큼. 6개월 시점 순응 기준 충족이 66%뿐이었고 **순응 저하 1위 이유는 '옷 위에 착용 불가'(24%)** → 실내용·외출용 등 **착용 맥락 분리 상담**이 실질적
- **보조기 코칭 번들**: 착용 일기(장벽·해결책 기록) + 2주 후 피팅 재점검 + 격주 문자 리마인드
- **한의 병용**: 침·약침·추나·운동치료와 병용 시 착용 시간대를 **'통증 유발 활동'에 한정**해 일상 근력 사용을 과도하게 대체하지 않게 한다(기능적 근력 저하 방지). 만성기에는 가정 근력(대퇴사두근·둔근) 처방과 함께 사용 → [[퇴행성 슬관절염]]·[[운동요법]]·[[도수치료]]
- **기대 효과 설명(정직 프레임)**: "6개월에 통증·기능이 약간 더 좋아지지만, **환자가 체감하는 최소 개선폭에는 못 미치고** 1년이 지나면 차이가 줄어든다. 꾸준히 착용한 분일수록 효과가 컸다."

## 주의·금기
- 주요 이상반응: **피부 자극·발적(최대 20%)**, 물집·피부 손상(최대 4%) — 압박 손상 우려는 이 RCT에서 해소
- 하지 혈관질환, **당뇨병성 신경병증·감각 저하**, 피부 질환 환자는 피부 손상 위험이 커 면밀한 추적 필요
- 부적절한 착용 시간(종일 착용)은 근력 사용 저하·의존 유발 가능 — '활동 한정' 원칙
- 6개월 무반응 시 지속 착용을 권하지 않는다(비용 대비 이득 없음)
