# 📍 소아추나 (小兒推拿, Pediatric Tuina)

> **핵심 요약**: 생후 0~6세 영·유아에게 손으로 특정 경혈·구역을 밀고(推) 주무르고(揉) 문지르는(摩) 한방 소아 수기요법. 침·약물 투여가 어려운 소아에서 순응도가 높다. 대표 술기는 揉法·摩腹·捏脊·推上七節骨·補脾經이고, 소아 설사·식적·변비·감기 등에 쓰인다. 2026-10-04 리뷰 1번(급성 설사 샴대조 RCT)에서 3일째 배변 횟수 감소는 있었으나 보정 후 유의성이 사라졌다 — **표준 보습요법에 더하는 보조요법**으로 위치시킨다.

---

## 1. 정의·기법

* **기본 술기 5종**:
  * **揉法** — 손가락·장심으로 특정 혈위(복부·하지·등)를 율동적 원형 압박. 소아는 가볍고 빠르게(대략 분당 120~160회).
  * **摩腹** — 신궐(神闕, CV8) 중심으로 복부를 손바닥으로 시계방향 원형 문지름. 위장관 연동 보조.
  * **捏脊** — 독맥(대추~장강) 피부를 집어올리며 아래에서 위로 진행. 소화·면역 조절 목적.
  * **推上七節骨** — 제4요추~천골(장강 부근)을 아래에서 위로 밀기. 설사에 쓰는 대표 배혈 술기.
  * **補脾經** — 엄지 요측면을 지단 방향으로 밀기. 비위 허약 보강.
* **배혈 예 (설사 기준)**: 천추(天樞, ST25)·족삼리(足三里, ST36)·장강(長强, GV1)에 揉法, 신궐(神闕, CV8) 중심 摩腹, 독맥 捏脊, 推上七節骨, 補脾經. 연령별(0~2세·2~4세·4~6세)로 혈위별 조작 시간을 달리한다.
* **매개물**: 마찰을 줄이기 위해 활석분·전분·오일을 얇게 바른다.
* **자세**: 2세 미만은 보호자 무릎, 그 이상은 침대·걸상에 앉힌다.

## 2. 환자 지도용 프로토콜

| 항목 | 내용 |
| :--- | :--- |
| 술기 | 揉法 · 摩腹 · 捏脊 · 推上七節骨 · 補脾經 |
| 부위 | 복부 · 등(척추) · 손(엄지 요측) · 하지 |
| 회당 시간 | 15~25분 (생후 2세 미만 10~15분) |
| 빈도 | 1일 1회 (보호자 자가 시행 시 1일 1~2회 10분) |
| 총 기간 | 3일 시험 적용 → 반응 평가(연구 설계와 동일) |
| 강도 | 가볍고 빠르며 부드럽게. 6개월 미만은 압력을 더 낮추고 5분 단위로 반응 확인 |
| 중단·금기 | 조작 부위 정맥염·개방창·골절·조직손상, 중증 탈수·의식장애·경련·쇼크, 혈변·고열 동반 시 시행하지 않음 |

* **보호자 교육**: 하루 1~2회 10분(摩腹·補脾經 중심) 시행을 가르치면 방문 부담을 줄일 수 있다. "아이가 아파 우는 것을 참고 세게" 지도는 금물.

## 3. 작용 기전

* **체성-내장 반사**: 복부·등의 율동적 기계자극이 체성 구심 → 척수 상행 구심신호 → 중추 자율신경핵 → [[미주신경]] 원심성 경로를 활성화하고, 위장관 호르몬([[모틸린]]·[[가스트린]]) 합성·분비를 조절해 장 연동·흡수를 정상화한다는 설명이 제시된다 → [[장신경계]]
* **국소 염증·장벽**: 실험 연구에서 특정 수기가 비만세포 침윤과 트립타제 유리를 줄여 장점막 염증·장벽 손상을 완화한다는 보고도 있다.
* **해석의 균형**: 혈위 특이적 효과보다 **복부·등 특정 구역의 기계자극 → 자율신경·ENS 조절**이라는 축이 크다는 해석이 가능하다. 단일 혈위의 특효로 단정하지 않는다.

## 4. 임상 적용

* **소아 급성 설사**: 표준진료(경구수액요법·아연·필요 시 항생제)에 더하는 보조요법 → [[소아 설사]]
* **식적·변비·기능성 소화기 증상**: 摩腹·捏脊·補脾經 중심.
* **소아 사경**: 경항부 揉法·拿法 위주(강한 회전·신연 금지) → [[사경]]
* **보호자 자가 시행**: 방문 부담을 줄이는 현실적 전략. 다만 메타분석에서는 전문가 시행이 더 큰 효과를 보이는 경우가 많다.

---

## 5. 주의·금기

* **절대 금기·지연**: 중증 탈수·대사산증·의식장애·경련·쇼크·질소혈증, 콜레라·말라리아 등 중증 감염, 조작 부위 피부 손상.
* **응급 선별 우선**: 탈수 위험 신호(소변량 감소·눈물 없음·구강점막 건조·피부 긴장도 저하·축 처짐)가 있으면 추나를 미루고 즉시 소아과 이송.
* **연령별 강도**: 생후 6개월 미만에서는 압력을 더 낮추고 5분 단위로 반응을 확인한다. 시행 중 울음이 멈추지 않으면 중단한다.
* **근거 수준**: 단일기관·소규모(84명, 목표 122명 미달), 보정 후 효과 소실 → 근거수준 낮음. 중증 설사·혈변·고열 동반 시 이송이 우선이다.

## 6. 논문 연결

* 2026-10-04 심층리뷰 1번 — Health Qual Life Outcomes 2021;19(1):4, [PMID 33407547](https://pubmed.ncbi.nlm.nih.gov/33407547/) · [DOI 10.1186/s12955-020-01636-1](https://doi.org/10.1186/s12955-020-01636-1)
  * **[연구 요약]** 급성 설사 0~6세 소아 86명(ITT 84) 샴대조 RCT — 3일째 배변 횟수는 추나군이 적었으나(비보정 RR 0.73, 95% CI 0.59-0.91) 인구·임상 변수 보정 후 유의성이 소실(조정 RR 0.82, 0.64-1.04). 설사 지속 일수·전반 인상·정상 변 회복은 군 간 차이 없음. 추나군 이상반응 0건.
* 2026-10-04 심층리뷰 1번 보조 — Zhu Y, et al. World J Gastroenterol 2025;31(44):113017, [PMID 41356531](https://pubmed.ncbi.nlm.nih.gov/41356531/)
  * **[연구 요약]** 소아 설사 통합치료(추나+한약) 총설 — 揉法·摩腹·捏脊·推上七節骨 등 표준 술기와 배혈, 자율신경·장신경계 기전을 정리.
