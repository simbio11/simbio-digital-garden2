# 📍 경혈 온찜질 (Acupoint Hot Compress)

> **핵심 3줄 요약 (Key Summary)**:
> - 🎯 정의: 경혈 부위에 40~45°C의 항온 열을 일정 시간 적용하는 비침습 온열 자극. 뜸이나 온구처럼 연소열을 쓰지 않고, 전기 패치형 의료기기 또는 온수 주머니로 표재열을 준다.
> - ⚙️ 기전: 국소 혈류 증가·조직 대사 개선 + 교감 긴장 저하·부교감 우위 유도. 경혈 부위(천골 부교감 신경절 근접)에서는 반사적 배뇨·자궁 혈류 조절이 가설로 제시된다.
> - ⚠️ 안전: 저온화상이 최대 위험이다. 44°C에서도 수시간 지속되면 화상이 생기므로, 병동 프로토콜(45°C·4시간)은 피부 점검 인력이 있을 때만 쓴다. 외래·가정은 40~42°C·30~40분.

---

## 1. 정의·기법

* **무엇인가**: 경혈 온찜질은 침습 없이 경혈 표면에 일정 온도의 열을 가하는 외치법이다. 한의학의 온법(溫法)·온엄(溫罨) 계열에 속하며, 뜸·온구와 달리 연소·연기를 쓰지 않아 병동에서 적용하기 쉽다.
* **도구**:
  * 병원형: 허가된 패치형 온열 의료기기(핫코어 2~4개 내장, 45±2°C 항온 유지).
  * 가정형: 전기 온열 패드, 온수 주머니(타월 1~2겹 완충), 찜질팩. 온도계가 없으면 “피부가 붉어지되 화끈거리지 않는” 수준으로 제한한다.
* **자세**: 복부·천골은 앙와위 또는 측와위, 족저는 앙와위에서 발을 편하게 둔다.

---

## 2. 작용 기전

* **국소**: 표재 혈관 확장 → 피부·근육 혈류 증가 → 조직 산소화와 대사산물 제거. 통증 유발점·근막 긴장 완화([[온열요법]]과 동일 계열의 표재열 기전).
* **반사·자율신경**: 온열은 교감신경 긴장을 낮추고 부교감 우위를 유도한다. 천골(S2–S4) 부교감 신경절에 근접한 팔료(BL31–BL34) 온열이 [[배뇨 반응]] 회복을 돕는다는 해석이 제시됐으나, 직접 측정된 매개 지표는 없다.
* **경혈 특이성**: 2022년 다기관 시험은 시험 설계상 위약 온찜질을 두지 못해 “온열 자체의 효과”와 “경혈 위치의 특이 효과”를 분리하지 못했다. 이 구분은 아직 미해결이다.

## 3. 임상 적용 (프로토콜)

### 3.1 검증된 프로토콜 — 산후 요폐 예방 (JAMA Netw Open 2022)

| 항목 | 내용 |
| :--- | :--- |
| 대상 | 질식분만 산모(특히 척추마취 하위군) |
| 혈위 | 신궐(CV8, 배꼽 중앙) · 팔료(BL31–BL34, 천골 후공) · 용천(KI1, 족저 전 1/3) |
| 온도 | 평균 45±2°C 항온 |
| 1회 시간 | 4시간 연속 |
| 빈도·총횟수 | 분만 후 30분 이내(1회) · 24시간(2회) · 48시간(3회) — 총 3회 |
| 평가 | 분만 후 6.5시간 초과 첫 배뇨 및/또는 72시간 내 유치도뇨 |
| 결과 | 요폐 4.5% vs 7.7%(RR 0.58, 95% CI 0.35–0.98), NNT 약 31 |
| 안전 점검 | 시술 후 2시간 내 피부(알레르기·소양감·통증·화상·궤양·출혈·감염) 확인 |

### 3.2 외래·가정용 변형 (환자 지도용)

| 항목 | 처방 |
| :--- | :--- |
| 온도 | 40~42°C (감각 저하·당뇨·척추마취 후에는 38~40°C) |
| 시간 | 1회 30~40분, 하루 1~2회 |
| 기간 | 3~7일, 증상 변화에 따라 조정 |
| 혈위 | 복부: 신궐(CV8)·관원(CV4) / 천골: 팔료(BL31–BL34) / 하지: 삼음교(SP6) / 족저: 용천(KI1) |
| 확인 주기 | 10분마다 피부색·감각 확인, 취침 중 사용 금지 |
| 중단 기준 | 화끈거림·물집·발적 지속·통증 증가 → 즉시 중단 |

### 3.3 응용 범위
* 산후 요폐·자궁수축통·초기 수유량: 같은 세션으로 겨냥(신궐·팔료·용천).
* 월경통·하복부 냉감·과민성 방광 보조: 복부(관원·기해)·천골부 적용. 단, 이 적응증들은 별도 대규모 시험 근거가 없다.
* 금기·주의가 적고 비용이 낮아 “저위험 부가요법”으로 위치시키는 것이 정직한 설명이다.

## 4. 주의·금기

* **저온화상**: 44°C에서도 수시간 지속 노출되면 표피 손상이 발생한다. 45°C·4시간 프로토콜을 가정에서 재현하면 위험이 이득을 넘는다.
* **감각 저하**: 당뇨병성 말초신경병증, 척추마취 잔효, 척수손상, 노인 — 온도를 낮추고 보호자 확인 하에 시행.
* **금기**: 피부 손상·개방창·발진, 급성 염증·발열, 활동성 출혈(산후 출혈 과다), 국소 감염, 열 감각 이상.
* **주의**: 임신 중 복부 온열은 피한다(복부 심부 체온 상승). 산후라도 자궁 압통·악취성 오로가 있으면 감염 평가가 먼저다.
* **기기 안전**: 전기 패드는 젖은 피부·금속 접촉을 피하고, 제조사 항온 유지 기능이 없는 제품은 사용하지 않는다.

## 5. 논문 연결

* [[산후 요폐]] — 이 중재의 1차 적응증이자 검증 대상. 다기관 RCT(PMID 35604687)에서 절대위험감소 3.2%p.
* [[신궐(CV8)]] · [[골반저근]] · [[배뇨 반응]] — 혈위·표적의 해부·생리 연결.
* [[옥시토신]] — 수유량 증가는 유즙 사출 반사(부교감 우위·이완 반응)로 설명되나 직접 측정은 없었다.
* [[뜸]] · [[온열요법]] — 연소열·표재열과의 차이를 구분해 설명한다.
