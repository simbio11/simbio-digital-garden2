# 📍 HVLA (High-Velocity Low-Amplitude Thrust — 고속저진폭 도수교정)

> **핵심 3줄 요약 (Key Summary)**:
> 🌿 관절을 **제한 장벽(restrictive barrier)까지 먼저 밀어 넣은 뒤**, 짧은 진폭으로 빠른 추력(thrust)을 한 번 가하는 직접 도수 기법 — "빠르게, 그러나 아주 짧게"가 정의다.
> 🧪 기전은 국소 가동성 회복과 **근방추·[[골지건 기관]] 구심 입력 변화**, [[관문조절설]]·[[하행성 통증억제계]]를 통한 진통, 추력 직후 일시적 통증역치 상승으로 설명된다(제안된 기전).
> 🎯 2026-10-11 리뷰 2번([[자궁내막증]] 골반통 도수 프로토콜)에서 후두-환추-축(C0-C1-C2)·흉요추(T12-L1)·[[천장관절]] 코스의 구성 요소로 쓰였다 — 반드시 저강도 연부조직 기법과 **함께** 운용되고, 단독 기법으로 인용하면 안 된다.

## 1. 정의·기법

### 1) 원리와 분류
- **정의**: 관절면을 생리적 범위 내에서 제한 장벽까지 이동시킨 후, **고속(high velocity)·저진폭(low amplitude)** 의 추력을 가해 관절 가동성을 회복시키는 기법. 추력 순간에는 관절강 내 기포가 붕괴하며 '딸깍(cavitation)' 소리가 날 수 있으나, **소리 자체는 성공 지표가 아니다**.
- **직접 기법**이다 — 기능부전 방향의 반대(제한 장벽)로 밀어 넣는다.
- 인접 개념과의 구분
  - [[Maitland 관절가동술]]: 진폭을 여러 번 반복하는 저속 가동(grade I~V). V등급만 HVLA에 해당한다.
  - [[Mulligan MWM]]: 환자 능동 동작과 결합한 위치·재교육 기법.
  - [[근에너지기법]](MET): 환자의 등척성 수축을 이용한 간접·저속 접근으로, HVLA를 쓸 수 없는 상황의 대체 기법이다.
  - [[근막이완술]]: 넓고 오래 가하는 장력(점탄성) — 진폭·속도의 축이 정반대다.

### 2) 시행법 — 환자 지도 가능 수준

| 항목 | 시행 기준 |
| :--- | :--- |
| 사전 준비 | 표본 기능부전(분절·방향) 진단 → 연부조직 이완·가동술로 조직 준비 → 환자 동의 |
| 자세 | 기능부전 분절을 전 세 평면에서 반대 방향으로 **잠금(locking out)** — 해당 분절만 남기고 상하 분절 고정 |
| 추력 시점 | 환자가 **깊게 들이쉬고 내쉬는 끝**에 맞춰 추력(호흡 협력이 근긴장을 낮춘다) |
| 추력 특성 | 1회, 짧고 빠르게. 큰 동작이 아니라 **분절에 집중된 작은 이동** |
| 시술 후 | 즉시 재평가(가동범위·촉진 소견). 필요 시 반복은 1~2회까지, 무리한 반복 금지 |
| 병용(원칙) | 시술 전 연부조직 이완, 시술 후 **능동 가동·부하 운동**으로 새 범위를 고정 → [[운동요법]] · [[등척성 운동]] |
| 빈도 | 주 1~2회, 코스로 설계하고 종료 시점을 정한다(무기한 반복 금지) → [[도수치료]] |

- **대표 코스(2026-10-11 리뷰 2번 프로토콜)**
  - **① 후두-환추-축(C0-C1-C2)**: 앙와위에서 축추 치돌기를 지나는 수직축 회전(굴곡·신전 없이 최소 측굴). 사전 미세 두측 압박·작은 원운동 후 두개 나선 운동으로 교정.
  - **② 흉요추(T12-L1)**: 반대측 측와위, 상·하지 굴곡으로 체간 회전을 완성한 뒤 하방 손으로 T12 하관절돌기 압박, 골반 전방 회전 방향 HVLA.
  - ③ [[천장관절]]: 반대측 측와위에서 체간 회전·하지 굴곡으로 접근, 장골능에 전완을 대고 미측→두측·후방→전방 방향 추력.
  - 세 코스 모두 좌우 양측 시행이고, 각 HVLA 사이에 복부 가동·[[광인대]] 가동·골반격막 이완·접형골 기법·제4뇌실 기법(각 5분)이 배치됐다.

### 3) 자궁내막증 골반통에서의 위치(2026-10-11)
- 도수치료군 통증 강도는 중재 직후·1개월·6개월 추적 모두 유의하게 감소했고(d=1.00·0.89·2.28), 위약 손 접촉군보다 우수했다. 그러나 이 시험은 **8단계 묶음 중재**여서 HVLA 단독 기여는 분리되지 않는다 → [[자궁내막증]] · [[만성 골반통]]

## 2. 작용 기전
- **기계적 효과**: 제한 장벽을 넘겨 관절면 활주를 회복하고 관절낭·주변 근막의 단기 가동성을 개선한다.
- **수용기 입력 변화**: 추력이 근긴장을 순간적으로 늘리면 **근방추 구심 발화가 변하고**, 중추가 반사적으로 근긴장을 낮춘다는 설명(자율억제)이 제시된다. [[골지건 기관]] 활성화를 통한 이완 기전도 함께 제안된다 → [[고유수용감각]] · [[신경근 적응]]
- **진통**: [[관문조절설]]·[[하행성 통증억제계]] 경로와 내재성 오피오이드 반응, 척수 흥분성 저하, 국소 염증 표지자 감소가 거론된다 → [[하행성 통증억제계]] · [[WDR 뉴런]]
- **비특이 효과**: 손 접촉·시술 기대·자세 변화 자체가 통증에 영향을 준다. 그래서 위약 대조(손 접촉군) 설계가 필요하다 → [[샴 대조군]]
- ⚠️ **소리의 의미**: cavitation은 관절강 내 기체 형성·붕괴 현상으로, 통증 개선과의 인과는 입증되지 않았다. "소리가 나야 잘 된 것"이라는 설명은 하지 않는다.

## 3. 임상 적용
- **적응**: 관절 가동 제한·분절 기능부전, 급성·만성 요통, 경부통, 골반통, 천장관절 기능부전, 두통(경추성).
- **진료실 운용 순서**: ① 레드플래그 배제 ② 분절 진단 ③ 연부조직 준비 ④ 잠금 → 추력 ⑤ 즉시 재평가 ⑥ 능동부하로 고정 ⑦ 다음 방문 재검.
- **한의 병용**: 추나의 교정 기법과 목적이 겹치므로 같은 방문에 중복 시행하지 않고 시간을 나눈다. 시술 전 통증유발점을 침·약침으로 처리하면 환자 이완도가 올라가 추력이 수월해진다 → [[추나]] · [[약침]] · [[건침]] · [[아시혈]]
- **임신부**: 복부 직접 압박과 요추·골반 HVLA는 고위험 임신에서 금기이며, 일반 임신에서도 [[근막이완술]]·[[근에너지기법]] 중심으로 대체한다 → [[골반대 통증]]

## 4. 주의·금기
- **절대 금기**: 척추 전이암·원발 종양, 감염성 척추염, 급성 골절·불안정 척추, 상부경추 불안정(치돌기 이상·류마티스 관절염 경추 침범), 척수 압박·마미증후군, 항응고 요법·중증 출혈 경향, 급성 추간판 탈출증의 진행성 신경학적 결손.
- **경추 특별 주의**: 추골뇌저동맥·내경동맥 손상 위험. 시술 전 이학적 스크리닝(추골뇌저동맥 검사 계열)과 신경학적 문진을 한다 → [[추골뇌저 동맥 청진 및 촉진]]
- **중단 기준**: 시술 중 통증 급증, 어지럼·오심·시야 이상, 감각 이상·근력 저하의 새 발생, 심한 두통 → 즉시 중단하고 신경학적 평가·영상 검사로 전환.
- **고령·골다공증**: 골절 위험. 시행 전 골밀도·취약골절 병력 확인, 필요 시 저속 가동술·MET로 대체.
- **환자 교육**: 다음 날 일시적 근육통(시술 후 통증)이 24~48시간 있을 수 있음을 미리 설명한다.
