# 주기화 (Periodization)

> **핵심 요약**: 운동 프로그램을 **일정 기간의 주기(cycle)로 나누어 강도·볼륨·동작을 단계적으로 변화·순환**시키는 설계 원리. 단조롭게 강도만 올리는 프로그램보다 **정체(plateau)·과사용 손상·순응도 저하를 줄이고** 장기 적응을 얻는 데 유리하다. 노인에서도 예외가 아니며, 2026-09-23 심층리뷰 3번(FrOST)은 **4주 주기 선형 주기화 + 4주차 회복주** 구조로 12개월간 손상 0건·출석률 95%를 기록했다 — 즉 **주기화는 고강도를 안전하게 유지하는 장치**다.

## 정의·기법
- **주기 계층**: 거시주기(macrocycle, 수개월~1년) → 중간주기(mesocycle, 수 주) → 미시주기(microcycle, 1주)
- **주요 모형**
  - **선형 주기화**: 볼륨을 줄이고 강도를 올리는 단조 진행(예: 8~15회 → 10~12회 → 5~10회 구간)
  - **블록 주기화**: 적응 목표별 블록(해부학적 적응 → 최대근력 → 파워)을 순차 배치
  - **파동형(undulating)**: 주·세션 단위로 강도·볼륨 변수를 교차시켜 자극을 다양화
- **핵심 변수 4종**: 강도(%1RM·RM 구간), 볼륨(세트×반복), 빈도(주당 세션), 휴식(세트 간·주간 회복주)
- **회복주(deload)**: 통상 3~6주마다 1주는 강도·볼륨을 낮춘다 — 노인·재활에서는 **4주 주기·4주차 회복주**가 무난한 출발점이다
- **테크닉 변주(고급)**: 슈퍼세트(두 동작 연속), 드롭세트(부하 10~20% 감량 후 즉시 추가 세트), 속도 변화(예: 4초-1초-4초 → 1초-1초-2초), 파워성(구심성 폭발적) 동작 도입

## 작용 기전
- **과부하와 회복의 교대**: 적응은 자극(과부하) + 회복(초과회복)의 반복에서 생긴다. 자극만 계속하면 기능 저하·피로 누적이 발생한다 → [[점진적 과부하]] · [[디트레이닝]]
- **신경계 적응 단계화**: 초기에는 협응·동원(신경), 이후 근비대·근지구력으로 적응 목표가 이동하므로 주기를 나눠 목표를 바꾸는 것이 효율적이다 → [[신경근 적응]]
- **손상 위험 관리**: 급격한 강도 상승을 막고 회복주를 삽입함으로써 건·근육 손상과 과사용을 줄인다 — 노인에게 특히 중요
- **순응도**: 동작·부하가 정기적으로 변하면 지루함·중도 이탈이 줄어든다(장기 프로그램 유지율)
- ⚠️ 위 원리는 운동생리 표준 문헌 범위이며, 2026-09-23 논문은 주기화 자체를 비교한 연구가 아니다(프로토콜의 일부로서 서술됨)

## 임상 적용 (근거 기반 + 한의)
- **근거**: 2026-09-23 심층리뷰 3번(FrOST, J Bone Miner Res 2020;35(9):1634-1644, [PMID: 32270891](https://pubmed.ncbi.nlm.nih.gov/32270891/)) — 12개월 프로토콜을 **5단계(적응·컨디셔닝 → 단일 세트 전환 → 파워 도입 → 슈퍼세트 → 드롭세트)** 로 진행하고 **4주 주기 선형 주기화(4주차 저강도 회복주)** 를 적용 → 손상 0건·출석률 95%·탈락 2명
- **진료실 번안**
  - 초심자: ① 1~4주 적응(동작 학습, 1~2세트, 낮은 부하) ② 5~8주 컨디셔닝(2세트, 여유 반복 2~3회) ③ 이후 4주마다 회복주
  - **강도 처방은 '여유 반복(RIR)' 언어로**: "한두 번 더 할 수 있을 것 같은 지점에서 세트를 끝내세요" — 노인에서는 완전 탈진(momentary failure)까지 밀지 않는다 → [[저항운동]]
  - **기록 장치**: 세트·반복·부하·다음날 통증을 환자가 적게 하면 다음 회차 조정 근거가 생긴다 → [[TIDieR]]
- **한의 연결**: 침·약침으로 통증이 낮은 주에 강도를 올리고, 발적기에는 **회복주로 자동 전환**하는 구조를 처방문에 미리 명시한다(환자가 스스로 강도를 낮추도록) → [[아시혈]] · [[전침]]

## 주의·금기
- 조절되지 않는 고혈압(수축기 ≥180 또는 이완기 ≥100 mmHg)·급성 심혈관 사건 직후에는 운동 자체를 보류한다
- 급성 손상·발적기에는 증량이 아니라 조절이 우선(통증 3/10 이하 원칙)
- 고령·[[골다공증]] 환자에서 파워성·점프성 동작 도입은 **단계별 조건을 모두 충족할 때만** 진행하고, 척추 부하가 큰 배부신전 동작은 파워 단계에서 제외한다
- "고강도"를 **환자에게 그대로 말하지 말 것** — 실제 처방 언어는 "여유를 남기고, 회복주를 지키는" 방식이다

## 논문 연결
- 2026-09-23 심층리뷰 3번(Journal of Bone and Mineral Research 2020;35(9):1634-1644, [PMID: 32270891](https://pubmed.ncbi.nlm.nih.gov/32270891/)): 12개월·주 2회 기계식 저항운동 프로토콜의 **5단계 진행 + 4주 주기 선형 주기화** 구조가 노인 남성 43명에서 안전성(손상 0건)과 완주율(95%)을 입증
