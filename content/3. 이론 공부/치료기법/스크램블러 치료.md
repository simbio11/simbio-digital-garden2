# 📍 스크램블러 치료 (Scrambler Therapy / Calmare Therapy)

> **핵심 요약 (Key Summary)**:
> - **정의**: 통증 부위에서 얻은 신호를 변형해 **'통증이 아닌' 합성 전기신호**로 만들어, 감각이 남아 있는 피부분절 주변부에 부착한 전극을 통해 같은 통증 경로로 되돌려 보내는 비침습 전기진통 기법이다. 차단이 아니라 정보 재조직을 노린다 → [[정보조절 모델]]
> - **표준 운용**: 전극 최대 5쌍, 1회 40분, 통상 **2주간 주 5회(총 10~12회)**. 세션 중 통증을 0점(최소 2/10 이하)으로 만드는 것을 성공 조건으로 삼고, 안 되면 전극 위치·강도를 다시 조정한다.
> - **근거 위치(중요)**: 뇌졸중 후 통증 20명 파일럿 샴대조 시험에서 5회 치료 직후 통증이 56% 감소(샴 16%)했고 4주 추적에서도 38% 대 4%로 유지됐다 — 다만 4주에 50% 이상 호전자는 30%로 줄어 **유지·보충 세션 계획이 필수다** → [[뇌졸중 후 통증]]
> - ⚠️ **금기**: 이식형 전자기기(심장박동기·제세동기·척수자극기), 6개월 내 심근경색, 조절되지 않는 뇌전증, 증상성 뇌전이. 전극 부위 피부 자극이 지속되면 위치를 옮기거나 중단한다.

---

## 1. 정의·기법 (Definition & Protocol)

- **한 줄 정의**: 만성 신경병증성·암성 통증에서 사용되는 **FDA 승인 비침습 전기진통 기기** 요법. 국내에서는 규제·급여 조건과 장비 보급이 제한적이어서, 실제 진료에서는 가용성을 먼저 확인해야 한다.
- **시행 절차**
  1. **전극 배치**: 통증이 있는 피부분절 **내부**에 최대 5쌍을 배치하되, 통증 부위 자체가 아니라 **정상 감각이 남아 있는 주변부**에 소형 심전도용 전극을 붙인다. 통증 부위에 붙이면 자극이 통증으로 인식되어 실패한다.
  2. **강도 조정**: '강하게 느껴지지만 불쾌하지 않은' 수준까지 올리고 세션 내내 유지한다. **세션 중 통증을 0점(최소 2/10 이하)으로 만드는 것이 성공 조건**이다.
  3. **유지·조정**: 통증이 0점이 된 분절은 전극을 옮겨 남은 부위를 겨냥한다. 40분간 통증이 남아 있으면 위치와 강도를 재조정한다.
  4. **세션 수**: 원 시험(뇌졸중 후 통증)은 1회 40분·5일 연속이었고, 2회 연속 0점이면 조기 종료했다. 통상 프로토콜은 2주간 주 5회 총 10~12회이며, 재발 시 1~2회 보충 세션으로 이득을 회복한다.
- **환자 지도용 요약표**

| 항목 | 내용 |
| :--- | :--- |
| 적용 대상 | 약물 반응이 부족한 신경병증성 통증, 중추성 통증, 암성 통증 |
| 전극 위치 | 통증 부위가 아니라 감각이 남은 주변 피부분절(최대 5쌍) |
| 강도 | 강하게 느껴지되 불쾌하지 않은 수준, 세션 내 고정 |
| 성공 조건 | 세션 중 통증 0점(최소 2/10 이하) |
| 시간·빈도 | 회당 40분, 통상 2주간 주 5회(총 10~12회) + 보충 세션 |
| 중단·조정 | 피부 자극 지속, 통증 미조절 시 전극 이동 후 재조정 |

## 2. 작용 기전 (Mechanism)

- **비차단 기전**: TENS처럼 굵은 [[Aβ 섬유]] 자극으로 통각 전달을 막는 방식이 아니라, **C섬유 표면 수용체를 통해 비통증 신호를 같은 경로로 투입**해 척수·상위 중추의 통증 네트워크 재조직(가소성)을 유도한다는 설명이다 → [[C섬유]] · [[정보조절 모델]]
- **중추 리듬 관점**: 뇌졸중 후 통증에서는 시상피질 리듬이상 가설이 제기되며, 정상 감각 정보를 반복 투입해 비정상 리듬을 재조정한다는 해석이 가능하다 → [[시상피질 리듬이상]]
- **자극 종료 후 효과**: 시험에서 치료 직후 효과가 4주까지 일부 유지됐다. 자극 기간을 넘겨 효과가 남는다는 점이 차단 모델과 구별되는 관찰이다.
- **시술자 의존성**: 전극을 어디에 붙이고 강도를 얼마로 맞추는지가 결과를 좌우한다. 원문도 시술자 의존성이 크다고 밝혔다.
- **기전의 한계**: 위 기전들은 모델·리뷰 수준의 제안이며, 이 시험에서 직접 측정된 지표가 아니다. **측정된 것과 해석된 것을 분리해 인용한다.**

## 3. 임상 적용 (Clinical Use)

- **뇌졸중 후 통증(현재 근거)**: 반교차가 아닌 샴대조 파일럿(20명)에서 치료 직후 평균 통증 변화 -3.73(56%) 대 샴 -0.94(16%, P=.012), 4주 추적 -2.57(38%) 대 -0.25(4%, P=.004). 50% 이상 감소 비율은 직후 70% 대 10%였으나 4주에는 30% 대 10%로 유의차가 사라졌다 → [[뇌졸중 후 통증]]
- **다른 적응의 근거 층위**: 만성 신경병증성·암성 통증에서는 반복적으로 효과가 보고됐으나 대부분 작은 시험이고, 체계적 고찰은 이질성·눈가림 한계를 지적한다 → [[신경병증성 통증]]
- **한의원 실무 판단**
  - 장비 도입 여부와 비급여 비용을 먼저 확인하고, 환자에게 **총 세션 수·비용·유지 치료 필요성**을 처음부터 제시한다.
  - 기기가 없을 때 이 기법의 '원리'(감각이 남은 분절에 비통증 자극을 넣고 통증이 0에 가까워지는 위치를 찾는다)는 [[TENS]]·[[전침]] 배치 설계에 참고할 수 있다. 단 **같은 효과를 낸다는 근거는 아니며 이론적 유추임을 환자에게 밝힌다.**
  - 뇌졸중 환자는 이식형 기기(심장박동기 등) 보유율이 일반인보다 높다. 시행 전 확인이 필수다.

## 4. 주의·금기 (Cautions & Contraindications)

- **절대 금기**: 심장박동기·제세동기·척수자극기 등 이식형 전자기기, 6개월 내 심근경색, 조절되지 않는 뇌전증, 증상성 뇌전이.
- **주의**: 피부 감각이 소실된 부위는 화상·피부 손상 위험이 있어 전극을 두지 않는다. 항경련제를 진통 목적으로 복용 중이면 반응이 느리고 불안정해 세션 수를 늘려야 한다.
- **중단 기준**: 전극 부위 피부 자극·불편감 지속, 세션 중 통증 악화, 어지럼·불쾌감 → 전극 위치를 옮기거나 중단한다.
- **과장 금지**: 파일럿 시험이며 4주 이후 유지 자료가 없다. "5일로 완치"라는 표현은 근거를 벗어난다.
