# 📍 포도당 프로로테라피 (Dextrose Prolotherapy, DPT)

> **핵심 요약 (Key Summary)**:
> 고삼투압 포도당 용액을 인대·건·관절낭의 부착부(enthesis)에 주입해 국소 회복 반응과 콜라겐 침착을 유도하는 비수술 재생 주사다
> 2026-10-08 실용적 RCT에서 만성 요추 방사통에 대해 경막외 스테로이드 주사(ESI)보다 하지 통증·기능이 6개월·12개월 모두 우세했다(NRS 12개월 5.2 대 6.9점, ODI 34 대 42점)
> 눈가림이 없고 시술 횟수(DPT 5회 대 ESI 3회)가 다른 설계 한계가 있어, 급성 신경근 압박에서 ESI를 전면 대체하는 결론은 아니다

## 1. 정의·기법 (Definition & Technique)

- **정의**: 비수술적 재생 기법으로, 소량의 자극성 용액(주로 고농도 포도당)을 통증을 유발하는 건·인대 부착부에 주입해 건강한 세포·조직 성장을 자극한다. 목표는 성장인자 자극을 통한 부착부 강화와 통증 감소다.
- **핵심 전제**: 정확한 신체검진과 해부학적 지식이 결과를 좌우한다 — 표적을 '증상 부위'가 아니라 '병리 해부 구조'로 잡는다.
- **대표 적응**: 외측상과병증, [[회전근개 건병증]], [[족저근막염]], [[아킬레스건병증]], [[퇴행성 관절염]], [[요통]], [[천장관절 증후군]], 악관절 이완 등.

## 2. 중재 프로토콜 (환자 지도용)

> 2026-10-08 실용적 RCT(만성 요통 + 하지 통증, NRS ≥6, 12주 이상)에서 실제 시행된 조건이다.

| 항목 | 내용 |
| :--- | :--- |
| **주입액** | 20% 포도당 용액 + 1% [[리도카인]] 혼합액 |
| **표적(6개 지점 선택)** | 요추 [[후관절]] 관절낭 인대, [[극간인대]], 후방 [[천장관절]] 인대 — 침범 수준에 따라 선택 |
| **주입량** | 각 지점 1 cc |
| **유도 방식** | 초음파 유도 |
| **침** | 초음파 확인이 가능하도록 22G(9 cm) 이상 굵기 사용(등록 문서에는 25G 척추침으로 기재 — 표기 혼재) |
| **안전 확인** | 주사침이 골면에 닿는 것을 확인(bone contact)한 뒤 주입 |
| **간격·횟수** | 약 4주 간격, 최대 5회 |
| **병행** | 두 군 모두 맞춤 운동지도 시행 |

- **농도 변형**: 경혈을 표적으로 한 별도 임상시험(그리스, 진행 중)에서는 15% 포도당 + 1% 리도카인을 신수(BL23)·대장수(BL25)·상료(BL31)·지변(BL54)·요양관(GV3)·명문(GV4)·아시혈에 초음파 유도로 3회기 주입하는 설계를 쓴다 — 표적을 경혈로 바꾼 응용이다.

## 3. 작용 기전 (Mechanism)

- **삼투 자극**: 고삼투압 포도당이 부착부 세포를 탈수·손상시킨다.
- **회복 반응**: 호중구·대식세포 유입 → PDGF·[[TGF-β]]·FGF·[[IGF-1]] 등 성장인자 방출.
- **구조 재건**: 섬유아세포 증식과 콜라겐 침착으로 인대·건·관절낭이 두꺼워지고 단단해진다.
- **결과**: 만성적으로 이완된 구조의 안정성이 회복되면서 침해수용 자극이 줄고 통증·기능이 개선된다.

## 4. 임상 적용·근거 (2026-10-08)

- **결과 요약**: 하지 통증 NRS 최소제곱평균 6개월 5.1±0.7 대 7.2±0.75점(P<0.001), 12개월 5.2±0.7 대 6.9±0.7점(P=0.001)으로 DPT군이 우세. 기능(ODI)도 6개월 33±5 대 45±4.5점, 12개월 34±4.5 대 42±5점으로 DPT군이 좋았다. 치료 완료 후 변화량 기준 6개월 3.1 대 1.1점, 12개월 3.0 대 1.3점으로 DPT군만 임상적 최소 중요 차이(통증 2점·ODI 10점)를 넘었다. 이상반응은 양군 0건이었다.
- **진료실 활용**: 시술은 한의원 진료 범위 밖이지만 협진 기준으로 실용적이다. 보존치료와 ESI를 여러 차례 받고도 만성 요추 방사통이 남은 환자를 영상유도 재생주사로 의뢰할 때, 위 2번 표의 프로토콜을 그대로 전달하면 의뢰 품질이 달라진다.
- **해부학적 연결**: 표적이 후관절·천장관절 인대라는 점에서, 우리가 도수치료·[[추나]]로 매일 다루는 구조를 '재생주사로 강화'하는 축이라는 설명이 가능하다 → [[후관절]] · [[천장관절 증후군]] · [[극간인대]]

## 5. 주의·금기·중단 기준

- **일반 금기**: 주사 부위 감염·피부 손상, 항응고제 복용이나 응고장애, 조절되지 않는 당뇨(고농도 포도당 사용), 임신, 주사 부위 종양·활동성 감염.
- **시술 안전**: 골면 접촉을 확인하지 않고 진행하면 신경 손상 위험이 있어 요추·천장관절 부위는 초음파 또는 투시 유도가 권장된다.
- **해석 주의 3가지**: ① 눈가림이 없어 주사 자체의 기대효과와 시술자 편향을 배제할 수 없다 ② DPT 최대 5회 대 ESI 최대 3회로 시술 횟수가 다르다 ③ 대상이 12주 이상·NRS 6점 이상의 만성 중등도 이상 환자이므로 급성기·경증에는 그대로 적용할 근거가 없다.
- **중단·조정**: 급성 신경근 압박 상황에서는 ESI가 여전히 유효한 선택지다 — [[경막외 스테로이드 주사]]

## 6. 다른 주입 기법과의 구분

| 기법 | 표적 | 농도 | 목적 |
| :--- | :--- | :--- | :--- |
| 프로로테라피(DPT) | 인대·건·관절낭 부착부 | 15~20% 포도당 | 구조 강화(증식 유도) |
| 말초신경 주사(PIT) | 신경 주위 | 5% 포도당 | 신경 염증·감작 조절 |
| 수압박리(hydrodissection) | 신경 주위 유착 | 생리식염수·국소마취 | 유착 박리 |

- 같은 '포도당 주사'라도 표적·농도·목적이 다르므로 진료기록·의뢰서에 구분해 적는다 → [[신경주위 주사요법]] · [[5% 포도당수(D5W)]]
