# 📍 마사지 (按摩, Massage)

> **핵심 요약**: 손·기구로 연부조직에 **문지르기(경찰)·주무르기(유압)·마찰**을 가하는 수기 중재. 기전은 국소 혈류 증가·근긴장 완화·관문조절·이완 반응의 복합이며, 항암 지지요법에서는 손발 저림·수면·불안·삶의 질 보완 축으로 쓰인다. 2026-10-01 리뷰 3번 메타분석에서 마사지 4편이 포함되어 통증·삶의 질·수면 개선에 기여했으나 근거 수준은 낮음~매우 낮음이었다.

## 1. 정의·기법
- **3대 기본 술기**:
  - 경찰법(effleurage) — 미끄러지듯 미는 표재성 스트로크. 도입·이완·림프 보조.
  - 유압법(petrissage) — 집어 올리고 주무르는 심부 조직 자극. 근긴장 완화.
  - 마찰법(friction) — 국소 원형·횡방향 마찰. 국소 열감·유착 완화. [[심부 횡마찰 마사지]]와 구분된다.
- **대상 부위**: 손·발·하지·등. 항암 환자는 말초(손·발) 중심이 안전하다.
- **매개물**: 무향 저자극 로션, 액체 파라핀, 올리브유·에센셜오일 혼합. 항암 환자는 피부가 건조·손상되기 쉬워 자극성 향료·알코올 계열을 피한다.
- **강도 판단**: 환자의 불편감 표현에 맞춘다. "아프면 세게 하는 것"이 아니다.

## 2. 환자 지도용 프로토콜

| 항목 | 내용 |
| :--- | :--- |
| 술기 | 경찰법 · 유압법 · 마찰법 |
| 부위 | 손 · 발 · 하지 · 등(항암 환자는 말초 중심) |
| 회당 시간 | 20~30분(연구에 따라 다리당 10~12.5분) |
| 빈도 | 주 1~3회 |
| 총 기간 | 4~12주 |
| 매개물 | 무향 저자극 로션 · 액체 파라핀 · 올리브유/에센셜오일 혼합 |

- **자가·보호자 시행**: 보호자 교육 시 "손바닥을 밀착해 천천히, 발가락 끝에서 발목 방향으로" 방향·속도를 지정해 준다. 메타분석에서는 자가·가족 시행보다 전문가 시행에서 삶의 질 개선이 컸다(SMD 1.28 대 0.58, P=0.03).

## 3. 작용 기전
- **국소 조직**: 혈류·림프 순환 증가, 근막 점탄성 변화, 근긴장 완화 → 조직 회복 환경 조성.
- **신경 생리**: 굵은 구심섬유(Aβ) 기계적 자극이 척수 후각 통각 전달을 억제하는 [[관문조절설]], 그리고 반복 자극에 따른 [[하행성 통증억제계]] 활성 → [[Aβ 섬유]]
- **내인성 진통**: 마사지·압박이 내인성 오피오이드([[엔돌핀]]·[[엔케팔린]]) 분비를 촉진한다는 보고 → [[오피오이드]]
- **이완·정서**: 접촉·리듬 자극이 교감 긴장과 [[코르티솔]]을 낮추고 수면을 개선한다.
- **복합 기전 정리**: 리뷰 3번(§6)은 국소 혈류·기계적 자극, 관문조절, 내인성 오피오이드, 이완을 **복합 기전**으로 제시했다. 단일 기전으로 단정하지 않는다.

## 4. 임상 적용
- **항암 유발 말초신경병증**: 손발 저림·부종·야간 통증·수면 문제에 병행 → [[항암치료 유발 말초신경병증]]
- **만성 근골격 통증**: [[통증유발점]]·근막 긴장 완화 목적. 국소 마찰은 [[심부 횡마찰 마사지]], 심부 근막 이완은 [[근막이완술]]로 구분해 선택한다 → [[도수치료]]
- **이완·불면·불안**: 항암·만성질환·말기 환자의 지지요법으로 널리 쓰이며, 약물 대체가 아닌 병행으로 위치시킨다.
- **림프부종**: 도수 림프드레나지는 별도 술기로, 훈련된 시술자가 시행한다(일반 마사지와 구분).
- **기대 관리**: 마사지 근거는 낮음~매우 낮음이므로 통증 자체의 1차 치료가 아니라 **증상·수면·삶의 질 보완**으로 설명한다.

## 5. 주의·금기
- 시행 금기·중단: 혈소판 감소(약 50,000/µL 미만)·출혈 경향, 활동성 감염·발열, 급성 심부정맥혈전증, 시술 부위 피부 손상·[[당뇨발]] 궤양, 뼈전이·병적 골절 위험 부위.
- **감각저하 환자(항암·당뇨)**: 압력 인지가 어려워 화상·압박 손상 위험이 크다. 오일 마찰은 줄이고, 발톱 주위·상처 부위는 회피하며, 시행 전후 시진을 습관화한다.
- 항암제 유발 말초정맥염·피부 균열 부위는 마찰 대신 부드러운 도포로 대체한다.
- 림프부종·심부전·신부전 환자는 마사지 강도·범위를 전문 판단에 맡긴다.

## 6. 논문 연결

  - **[연구 요약]** 마사지 4편을 포함한 수기 중재 메타분석(11편·646명)에서 통증(SMD −0.77)·감각 증상(SMD −0.62)·삶의 질(SMD 1.05)·수면(SMD −1.08)이 유의하게 개선됐고, GRADE 근거 수준은 낮음~매우 낮음이었다.
- 2026-09-27 심층리뷰 3번 — 영아 산통 도수치료([PMID: 37761797](https://pubmed.ncbi.nlm.nih.gov/37761797/)): 영아 대상 마사지·도수 중재의 안전 규칙(강도·금기)을 대비해 읽을 수 있다.
