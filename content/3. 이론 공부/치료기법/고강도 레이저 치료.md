# 고강도 레이저 치료 (High-Intensity Laser Therapy, HILT)

> **핵심 3줄 요약 (Key Summary)**:
> 🌿 1064 nm Nd:YAG 등 **고출력(수~십수 W)** 레이저를 넓은 면적에 조사해 심부 조직까지 광에너지를 전달하는 물리·기기 중재 — 저출력 레이저(LLLT, 수십~수백 mW)와 출력·선량 스케일이 다르다
> 🧪 진통 모드(짧고 낮은 총에너지)와 생체자극 모드(높은 총에너지·높은 선량)를 시기별로 나눠 쓰는 것이 임상 프로토콜의 특징이다
> 🎯 무릎 골관절염 2주 시험에서 [[체외충격파]]와 **동등**했다 — 두 기기 모두 VAS 7→6(2주)→5(6주)로 개선됐고 군간 차이는 없었다. 기기 선택보다 병행 운동이 결과를 좌우했다

## 1. 정의·기기

| 구분 | 저출력 레이저(LLLT/PBM) | 고강도 레이저(HILT) |
| :--- | :--- | :--- |
| 출력 | 수십~수백 mW | 수 W~십수 W (본 시험 12 W) |
| 파장 | 600~1100 nm(적색~근적외선) | 1064 nm Nd:YAG가 대표 |
| 조직 도달 | 표재~중간 | 심부(관절낭·근·건) |
| 총에너지 | 수 J~수십 J | 수백~수천 J |
| 열 효과 | 거의 없음(비열적) | 국소 온도 상승을 동반 |
| 대표 근거 | 건병증·족저근막염 | 관절염·심부 근육통 |

- 두 기기는 **같은 광생물조절 계열로 뭉뚱그리면 안 된다.** 파장·출력·총에너지가 다르면 근거를 승계할 수 없다.

## 2. 시행법 — 환자 지도 가능 수준

2026-11-02 리뷰 2번(무릎 골관절염, BTL-6000 HILT 12 W·1064 nm) 프로토콜:

| 항목 | 시행 기준 |
| :--- | :--- |
| 대상 | [[퇴행성 슬관절염]] — 슬관절 내측 관절면·압통점 |
| 1~3일차 | 진통(analgesic) 모드 — 25 Hz, 회당 총 300 J, 25 cm² 면적, 연속 원형 이동 |
| 4회기부터 | 생체자극(biostimulant) 모드 — 회당 총 3000 J, 120 J/cm² |
| 회기 | 주 5회 × 2주 = 총 10회 |
| 병용 | 대퇴사두근 등척성 수축·SLR·능동 관절가동범위·햄스트링/종아리 스트레칭, 1일 1회 20~30분 |
| 판정 | 2주(종료) · 6주(추적) |

- 조사는 **한 지점에 멈추지 않고 원형으로 이동**한다. 정지 조사는 국소 과열·화상 위험을 만든다.
- 환자에게는 "따뜻하고 약간 톡톡한 느낌"을 기준으로 하고, **뜨겁거나 아프면 즉시 중단**을 교육한다.

## 3. 작용 기전

- **광생체조절(PBM)**: 1064 nm 광자가 미토콘드리아 시토크롬 c 산화효소에 흡수돼 ATP 생산·산화환원 신호를 조절한다 → [[광생물조절]]
- **심부 온도 상승**: 고출력에서는 조직 온도가 올라가 국소 혈류 증가·근 긴장 감소·콜라겐 점탄성 변화가 더해진다. 즉 **비열적 PBM + 온열 효과의 혼합**이다.
- **진통**: 말초 통각신경 흥분 역치 상승, [[Substance P]]·[[CGRP]] 등 신경펩타이드 방출 조절, [[말초 감작]] 억제.
- **항염·부종 감소**: 국소 순환 개선과 염증 매개물질 감소.
- ⚠️ 이 시험은 기전을 측정하지 않았다. 위 설명은 인접 문헌에 근거한 해석이다.

## 4. 임상 적용

- 적응 영역: 무릎·고관절 골관절염, 심부 근육통(요방형근·둔근), 건병증, 경부·요부 통증 보조.
- 운용 원칙: ① **운동을 못 할 만큼 아픈 2주**를 여는 용도로 집중 → ② 통증이 내려오면 등척성·가동범위·점진 부하로 축 이동 → ③ 기기 의존을 길게 끌지 않는다.
- 미용·재생 목적의 고출력 조사는 이 노트의 범위가 아니다(적응·규제 별도).
- 한의 병용: 같은 날 침·약침과 병행할 때는 순서를 고정하고(예: 레이저 → 침), 조사 부위와 자침 부위가 겹치면 자극이 중첩되지 않게 한다 → [[약침]] · [[침 자극 강도와 용량]]

## 5. 주의·금기

- **눈**: 직접 조사·반사광 금지, 보호 안경 착용(시술자·환자 모두).
- 임신부 복부·천골, 활동성 악성종양 부위, 급성 감염·개방창, 조사 부위 감각 저하.
- 광과민성 약물(테트라사이클린·아미오다론·이소트레티노인 등) 복용자는 반응 확인 후 시행.
- 심박조율기 등 이식형 전자기기 근접 부위, 문신·모반 위 직접 조사는 피한다.
- 화상·수포·색소 변화가 생기면 즉시 중단하고 강도·조사 시간을 낮춘다.

## 6. 논문 연결

- 2026-11-02 심층리뷰 2번 — Clin Rheumatol 2026;45(6):3713-3720, [PMID: 41904772](https://pubmed.ncbi.nlm.nih.gov/41904772/) / [DOI: 10.1007/s10067-026-08052-8](https://doi.org/10.1007/s10067-026-08052-8)
  - [연구 요약] 원발성 무릎 골관절염 60명 단일눈가림 RCT. HILT(12 W·1064 nm, 진통 모드 300 J → 생체자극 3000 J/120 J/cm², 주 5회×2주)와 ESWT(0.05 mJ/mm²·1000 pulses, 주 3회×2주)를 같은 가정운동 위에 얹었다. 양군 모두 VAS 7→6→5, WOMAC 소척도·총점·Lequesne 지수 개선(각 p<0.001)이었으나 **모든 시점에서 군간 차이 없음**(VAS 6주 p=0.636, Lequesne p=0.988).
- 2026-09-30 심층리뷰 2번 — Am J Sports Med 2025;53(14):3396-3407, [PMID: 41243328](https://pubmed.ncbi.nlm.nih.gov/41243328/)
  - [연구 요약] 근위 햄스트링 건병증에서 ESWT가 12주 개별 물리치료와 동등했다. 기기 간 비교가 아니라 **기기 vs 운동** 비교라는 점에서 위 시험과 짝을 이룬다 → [[체외충격파]]
