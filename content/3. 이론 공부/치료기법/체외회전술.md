# 체외회전술 (External Cephalic Version, ECV — 자궁 외 조작을 통한 두위 전환)

> **핵심 3줄 요약 (Key Summary)**:
> 🌿 임신 말기 둔위 태아를 **산모 복벽 밖에서 손으로 조작**해 두위로 돌리는 산과 술기 — 초음파 유도 하에 시행하고 성공률은 약 50%다
> 🧪 자궁을 이완시킨 상태에서 태아의 체간·둔부를 축성 회전시키는 기계적 전환 — 자궁수축 억제제(β2 작용제 등 tocolysis) 병용이 성공률을 높인다
> 🎯 기록된 둔위에 대한 표준 옵션이지만 통증과 응급 제왕절개 전환 위험이 따르므로, **초음파·태아감시(EFM)·수술 분만이 가능한 시설에서 교육받은 시술자만** 시행한다

## 1. 정의·기법

### 1) 원리와 분류
- ECV는 태아를 산모 복벽 밖에서 조작해 두위(cephalic presentation)로 만드는 술기다. 뜸·체위요법과 함께 '둔위를 두위로 바꾸는 비수술 방법' 축에 속하지만, 시행 환경·감시 요건이 완전히 다르다 → [[뜸]] · [[둔위]]
- 시행 시점·방식에 따라 ① 만삭(37주 이후) ECV ② 미만삭 ECV ③ 마취·tocolysis 병용 ECV로 나뉜다

### 2) 시행 요건 (가이드라인 기준)

| 항목 | 기준 |
| :--- | :--- |
| 시행 시점 | 만삭 **37주 0일 이후**를 표준으로 제안. 초산부에서는 36주 0일부터 고려 가능 |
| 시행 장소 | **초음파·태아심박감시(EFM)·수술 분만이 모두 가능한 시설** — 응급 제왕절개 전환에 대비 |
| 시술자 | 교육받은 시술자 또는 직접 감독 하의 수련의만 |
| 시도 횟수·시간 | **4회 이내, 총 10분 이내** 권고 |
| 병용 | 자궁수축 억제제(tocolysis, β2 작용제 등)가 성공률을 높인다. 마취 전처치·금식·정맥로 삽입은 통상 권고되지 않는다 |
| 감시 | 시행 전 EFM, 시행 중·후 초음파로 태아 심박 확인. 시행 후 EFM 재확인 |

- 성공률은 약 **50%** 로 상담한다. 실패한 경우 36주 0일 이후에는 자연적으로 두위로 바뀌는 태아가 거의 없다는 점도 함께 설명한다

## 2. 작용 기전
- **기계적 축성 회전**: 자궁이 이완된 상태에서 태아 둔부를 들어 올리고 머리를 아래로 유도하는 두 방향(전방·후방 roll) 조작으로 태아 장축을 회전시킨다
- **자궁 이완의 역할**: 자궁 긴장이 높으면 조작에 대한 저항이 커져 실패율이 올라간다 — tocolysis 병용이 성공률을 높이는 이유다
- **효과 크기**: 만삭 ECV 8개 시험·1,308명 메타분석에서 분만 시 비두위를 유의하게 감소시켰다(RR 0.42, 95% CI 0.29~0.61)
- ⚠️ ECV 후 분만은 자연 두위 분만에 비해 제왕절개·기구 분만율이 약간 높다는 점이 함께 보고된다 — '성공 = 자연분만 보장'이 아니다

## 3. 임상 적용
- 적응: 만삭 단태 둔위로 두위 분만을 원하는 산모, 뜸·체위요법으로 교정되지 않은 경우
- **한의 임상에서의 위치**: ECV는 산과 고유 영역이며 한의원에서 시행할 술기가 아니다. 한의 임상의 역할은 ① 둔위를 조기에 인지해 산과로 연결 ② 뜸·체위요법·산전관리로 교정 가능성을 높이는 보조 ③ 교정 실패 후 분만 방식 결정은 산과에 위임으로 정리된다 → [[뜸]] · [[둔위]]
- 상담 흐름: 태위 초음파 확인 → 뜸(34~35주) 시행 → 10~14일 재평가 → 여전히 둔위면 산과에 ECV 상담 의뢰
- 산과 협진 문서화: 고위험 임신·다태·분만 시설 미확보 조건을 사전에 표기해 두면 의뢰 판단이 빨라진다 → [[전치 태반]]

## 4. 주의·금기
- 금기·주의(가이드라인 축): 전치 태반·태반 조기 박리 등 출혈성 병태, 다태, 조기양막파수, 비정상 태아심박, 자궁 기형·반흔 자궁, 중증 자간전증 등
- 시술 중 중단: 지속적 태아 서맥·비정상 EFM, 심한 통증, 태아 위치 이상 → 즉시 중단 후 평가
- 시술 후 반드시 태아심박 확인 및 Rh 음성 산모의 항D면역글로불린 처치 여부를 산과와 확인한다
- 뜸·체위요법과 달리 ECV는 **반드시 시설·인력 요건이 충족된 환경**에서 시행해야 하며, 한의원 외래에서 시행해서는 안 된다
- 뜸 관련 주의(중단 기준: 자궁수축감·복통·질출혈·태동 변화)는 별도로 [[뜸]] 항목을 따른다

## 5. 논문 연결
- 2026-09-27 심층리뷰 1번(Cochrane Database Syst Rev 2023;2023(5):CD003928, [PMID: 37158339](https://pubmed.ncbi.nlm.nih.gov/37158339/)): 뜸과 비교되는 대안으로 ECV가 배경에 배치된다. 뜸 병용군에서 **ECV 필요성은 RR 0.62(95% CI 0.32~1.21)로 신뢰구간이 이익과 위해를 모두 포함해 근거가 매우 불확실**했다 — '뜸이 ECV 필요성을 줄인다'고 단정할 수 없는 이유다 → [[둔위]]
- RCOG Green-top Guideline No. 20a(2017) — 만삭 ECV의 적응·시점·시설 요건·성공률(약 50%)과 뜸의 위치(33~35주, 교육받은 시술자 지도)를 명시 → [[뜸]] 참고 자료
- 관련 리뷰: [[2026-09-27_부인과소아과_심층리뷰]] 1번
