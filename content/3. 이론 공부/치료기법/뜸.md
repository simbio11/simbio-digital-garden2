# 뜸 (Moxibustion, 灸法 — 애엽 연소 온열 자극)

> **핵심 3줄 요약 (Key Summary)**:
> 🌿 애엽(艾葉)을 연소시켜 경혈에 온열 자극을 주는 한방 외치법 — 직접구·간접구·애조구·온구로 나뉘고, 둔위 교정에서는 지음(BL67)에 무연 애조로 시행한다
> 🧪 0.8~5.6 μm 근적외선~원적외선 복사열이 표재 온열 수용기를 자극하고, 이 자극이 반사 기전을 통해 자궁 활동·태아 운동성에 영향을 준다는 가설이 제시되어 있다(장기 직접 투과는 어려워 반사설이 우세)
> 🎯 Cochrane 2023에서 둔위 잔존 위험 RR 0.87(0.78~0.99)·옥시토신 사용 RR 0.28을 보였으나 제왕절개율 차이는 없었고, 이상반응 보고 체계는 부실했다

## 1. 정의·기법

### 1) 원리와 분류
- 뜸은 애융(艾絨, 애엽을 정제한 솜)을 연소시켜 경혈·국소에 온열·약물 자극을 주는 방법이다. 자극의 전달 방식에 따라 ① 직접구(艾炷를 피부에 직접 올림) ② 간접구(마늘·생강·부자 등 매개물 위에 艾炷) ③ 애조구(艾條를 들고 피부 상방에서 연소) ④ 온구기(溫灸器·스티커형 온구)로 나뉜다
- 응용 범위는 온경산한(溫經散寒)·보익(補益)·회양구역(回陽救逆)·태위 교정이며, 자침이 어렵거나 환자가 스스로 시행해야 하는 상황에서 강점을 가진다

### 2) 둔위 교정 뜸 시행법 — 환자·보호자 지도 가능 수준

| 항목 | 시행 기준 (Cochrane 2023 근거 + 전문가 합의) |
| :--- | :--- |
| 혈위 | 지음(至陰, BL67) 좌우 양측 — 제5족지 외측 조갑각 옆 0.1치 |
| 시작 시점 | 임신 34~35주(전문가 델파이 합의, 2014). 포함 시험은 28주~36주 5일에 시작했으나 32주 이전은 자연 교정과 섞여 판정이 어렵다 |
| 자극 방식 | 무연·무취 애조(艾條)를 피부 1~2 cm 상방에서 연소. 艾炷를 올리는 방식도 보고됨 |
| 회당 시간 | 15~30분(합의 프로토콜은 30분) |
| 빈도·기간 | 1일 1회 × 최소 10일(권장 2주 이내) |
| 온도 기준 | 따뜻하되 뜨겁지 않은 정도(온감) — 화상이 나지 않도록 거리를 조절. 환자에게 '뜨거우면 잘못된 것'을 반드시 교육 |
| 재평가 | 시행 전·후 초음파로 태위 확인, 10~14일째 재평가 |
| 시행 주체 | 포함 13편 중 7편은 산모·가족 자가 시행, 4편은 의료진, 1편은 첫 회만 의료진 후 자가 |

- 시행 시 환기는 필수다(연기·냄새). 대조군은 통상 산전관리 단독·샴 뜸이었고, 모든 군이 통상 산전관리를 함께 받았다는 점을 상담에 반영한다

### 3) 일반 임상 시행법
- 근골격 근긴장·한성 통증: 통증유발점·경혈에 온구 10~20분, 주 2~3회. 기존 노트의 심부 횡마찰·도수와 병용한다 → [[심부 횡마찰 마사지]] · [[도수치료]]
- 부인과 허한성 질환(하복냉통·월경통·붕루): 관원(CV4)·기해(CV6)·삼음교(SP6) 부위 온구를 변증 처방과 병용 → [[월경통]]
- 소아: 저온 온구로 복부 온열을 적용하되 화상 위험이 낮은 스티커형 온구를 쓰고 시간을 짧게 잡는다 → [[영아 산통]]

## 2. 작용 기전
- **온열 수용기 자극과 반사 경로**: 애조 연소 시 0.8~5.6 μm 범위의 근적외선~원적외선 복사열이 방출된다. 열이 장기까지 직접 투과하기 어렵기 때문에 표재 온열 수용기 자극 → 반사 기전을 통한 자궁 활동·태아 운동성 변화라는 반사설이 우세한 가설로 제시되어 있다(저자들은 둔위가 두위로 바뀌는 생물학적 개연성이 불명확하다고 결론지었다)
- **국소 온열·순환**: 피부·근육 온도 상승으로 국소 혈류가 증가하고 근 긴장·통증유발점 흥분이 낮아진다 → [[통증유발점]] · [[관문조절설]]
- **본초 성분 축**: 애엽의 정유·유파틸린 등 성분이 염증성 사이토카인과 NF-κB·NLRP3 신호를 억제한다는 전임상 근거가 누적되어 있다 → [[애엽]] · [[NF-κB]]
- ⚠️ 이상 기전은 해부·생리 연구와 전임상 데이터에 근거한 설명이며, 둔위 교정 효과 자체의 기전은 확립되지 않았다

## 3. 임상 적용
- 적응: 둔위 교정 보조, 한성·허한성 통증, 부인과 허한성 질환, 회복기 보익
- 진료실 운용(둔위): ① 태위 초음파·산과 진료 이력 확인 ② 34~35주 시작 → 무연 애조 1일 1회 30분 ③ 최소 10일 시행 ④ 10~14일째 초음파 재평가 ⑤ 교정 실패 시 체외회전술·분만 방식 판단은 산과 영역으로 이관 → [[체외회전술]] · [[둔위]]
- 산과 가이드라인도 둔위에서의 뜸을 **33~35주에 교육받은 시술자의 지도 아래 고려할 수 있는 옵션**으로 명시한다(아래 참고 자료 RCOG 20a)
- 한의 병용: 둔위 교정은 뜸 단독이 아니라 산전관리·체위요법과 병용했을 때의 근거이며, 산모 불안·수면·요통 관리에 침·한약을 병행할 수 있다 → [[전침]] · [[요통]]

## 4. 주의·금기
- 중단 기준(즉시 중단 후 산과 의뢰): 조기진통·자궁수축감·복통·오심·질출혈·태동 변화
- 감시 항목: 규칙적·통증 동반 자궁수축, 복통, 질출혈, 태동 감소, 오심·어지럼
- 시행하지 않는 조건: 고위험 임신(전치 태반·임신성 당뇨·전자간증 등)·다태·분만 시설 미확보 — 모두 포함 시험의 배제 기준이다 → [[전치 태반]]
- 화상 위험: 시술자·보호자 교육으로 감소하나, 감각 저하(당뇨병성 말초신경병증·척수손상) 환자는 온도 판단이 어려워 저온·단시간으로 제한한다 → [[당뇨병성 말초신경병증]]
- 연기 노출의 태아 영향은 근거가 없다(불명확) — 무연 애조 선택의 이유
- 상담 시 반드시 밝힐 한계: 1차 근거는 중등도 확실성이고, 제왕절개율 개선은 없었으며, 재분석 가능했던 1개 시험에서 중재군 27/65 vs 대조군 0/57(RR 48.33, 매우 낮은 확실성)의 이상반응 불균형이 남아 있다

## 5. 논문 연결
- 2026-09-27 심층리뷰 1번(Cochrane Database Syst Rev 2023;2023(5):CD003928, [PMID: 37158339](https://pubmed.ncbi.nlm.nih.gov/37158339/)): 단태 둔위 임신부 2,181명·13개 시험. 비두위 잔존 RR 0.87(95% CI 0.78~0.99, 7시험·1,152명, 중등도 확실성), 샴 뜸 대비 RR 0.74(0.58~0.95), 옥시토신 사용 RR 0.28(0.13~0.60). 제왕절개율 RR 0.94(0.83~1.05)로 차이 없음, ECV 필요성·조기양막파수·제대혈 pH는 근거 매우 불확실 → [[둔위]]
- 애엽(Artemisia argyi) 뜸의 항염 기전 전임상 근거는 [[애엽]] 보충 블록에 누적되어 있다
