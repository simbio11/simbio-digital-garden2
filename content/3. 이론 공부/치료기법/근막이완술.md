# 근막이완술 (Myofascial Release, MFR — 지속 저부하 근막 신장)

> **핵심 3줄 요약 (Key Summary)**:
> 🌿 근막(fascia)의 제한 부위에 지속적·저부하 장력을 오래 가해 점탄성 변화와 조직 이완을 유도하는 수기 기법 — 강한 추력이 아니라 시간(time under tension)이 핵심 변수다
> 🧪 근방추·[[골지건 기관]]의 긴장 수용기 입력을 바꾸고 조직 온도·점탄성(요소 크리프)을 변화시켜 근긴장과 통증유발점 흥분을 낮춘다고 설명된다
> 🎯 임신 제3삼분기 요통 OMT 시험에서 표준화된 구성 요소 중 하나로 포함되어 RMDQ 악화 폭을 줄였고, HVLA 없이도 운용 가능해 임신부 수기치료의 중심축이 된다

## 1. 정의·기법

### 1) 원리와 분류
- 근막은 전신을 연속적으로 감싸는 결합조직으로, 제한(restriction)이 생기면 장력이 사슬을 따라 전달되어 원거리 증상까지 만든다는 것이 근막 모델의 전제다. 근막이완술은 이 제한 부위에 **손바닥·전완 전체로 넓게 접촉해 지속적 장력**을 가하는 접근이다
- 변형: ① 직접 기법(제한 방향으로 천천히 밀어 들어가 멈춤) ② 간접 기법(제한과 반대 방향으로 유도) ③ 능동 근막이완(환자가 능동 동작으로 협력) ④ 도구 보조(폼롤러·테라피볼). 도구 보조는 가정 프로그램으로 이행하기 가장 쉽다
- 심부 횡마찰(Cyriax)과 혼동하기 쉬우나, 심부 횡마찰은 건 부착부에 **직각 방향으로 짧고 강한 마찰**을 주는 것(초점·국소)이고 근막이완은 **넓고 오래 가하는 장력**(광역·점탄성)이라는 점에서 축이 다르다 → [[심부 횡마찰 마사지]]

### 2) 시행법 — 환자 지도 가능 수준

| 항목 | 시행 기준 |
| :--- | :--- |
| 접촉 방식 | 손바닥·전완으로 넓게 접촉(손가락 끝으로 파고들지 않는다) |
| 강도 | '불편하지만 참을 만한' 수준 — 환자 NRS 3~5/10, 통증이 6 이상 올라가면 강도가 과하다 |
| 시간 | 제한 부위당 1~5분 유지(90초 이상 지속부터 점탄성 변화). 세션당 총 10~20분 |
| 세션·빈도 | 세션당 30분 내외 총 시술의 일부로 구성, 주 1~2회. 급성·허약 환자는 10분 이내로 시작 |
| 호흡 협력 | 유지 구간에서 환자가 **길게 날숨**을 하도록 유도 — 근긴장 하락과 함께 조직 이완이 촉진된다 |
| 병용(필수) | 시술 직후 **능동 가동·부하 운동**으로 새 가동범위를 고정한다 → [[운동요법]] · [[등척성 운동]] |

- 재평가는 시술 전후 같은 관절의 가동범위·압통역치로 판정한다 → [[압통역치(PPT)]]

### 3) 임신부 적용 시 변형
- 임신 제3삼분기에는 20주 이후 **앙와위를 피하고 측와위·반좌위**로 시행한다. 접촉은 넓게, 강도는 낮게, 시간은 짧게 잡는다
- 골반환 전체(천장관절·치골결합 주위 근막, 둔부 심부 근군)와 흉요추 이행부를 함께 다루면 요추 기능 유지에 유리하다 → [[천장관절 증후군]]

## 2. 작용 기전
- **조직 점탄성 변화(크리프)**: 결합조직은 지속 장력에서 점탄성 크리프를 보이며 이완된다 — 순간적 강한 신장보다 저부하 장시간 부하가 이 방향에 부합한다. 조직 온도 상승도 이완을 돕는다
- **수용기 입력 변화**: 근방추·[[골지건 기관]]의 긴장·길이 신호가 바뀌면 같은 길이에서도 근긴장이 낮아진다는 설명(자율억제)이 제시된다 → [[고유수용감각]] · [[신경근 적응]]
- **진통 기전**: 국소 자극은 [[관문조절설]]과 [[하행성 통증억제계]]를 통해 진통 방향으로 작용하고, 통증유발점의 국소 흥분을 낮춘다 → [[통증유발점]]
- **순환·림프**: 접촉 압력은 국소 순환·림프 배출을 돕는다 → [[도수치료]]
- ⚠️ 근막의 해부학적 연속성과 '근막 기억'에 대한 가설은 논쟁 중이며, 임상 연구는 결과지표 수준에서 이뤄졌다. 기전 설명은 추정임을 전제로 전달한다

## 3. 임상 적용
- 적응: 근긴장·가동범위 제한, 통증유발점, 만성 요통·경항통, 임신부 요통·골반통, 섬유조직성 흉터·유착 주변
- 진료실 운용: ① 제한 사슬 확인(가동범위·촉진·통증 유발 동작) ② 넓은 접촉으로 저부하 장시간 유지 ③ 시술 직후 능동 가동·등척성 수축으로 재교육 ④ 가정에서는 테라피볼·폼롤러로 이행
- 한의 병용: 침·약침으로 통증유발점을 먼저 처리한 뒤 근막이완 → 능동부하 순서가 순응도가 높다. 추나의 연부조직 기법과 목적이 겹치므로 중복 시 시간을 나눈다 → [[추나]] · [[건침]] · [[아시혈]]
- 임신부 프로토콜: 30주 이후 주 1~2주 간격, 회당 30분 내외의 저강도 연부조직·근막이완·[[근에너지기법]] 중심 구성

## 4. 주의·금기
- 절대 금기: 급성 감염·발열, 활동성 악성종양 부위, 급성 골절·불안정 척추, 심부정맥혈전증, 출혈 경향·항응고 중 심부 광범위 시술 → [[항응고·항혈소판제_침·약침·부항·추나_출혈위험_2026-09-23]]
- 임신부 금기: [[전치 태반]]·임신성 당뇨·전자간증 등 고위험 임신, 복부 직접 압박, HVLA(고속저진폭 교정), 제4뇌실 압박(CV-4) 두개골 기법
- 중단 기준: 시술 중 통증 급증, 어지럼·오심, 자궁수축감·질출혈·태동 감소(임신부), 감각 이상의 진행
- 신경학적 결손·의심 골절·종양이 배제되지 않은 상태에서는 시행하지 않고 영상·감별을 먼저 한다

## 5. 논문 연결
- 2026-09-27 심층리뷰 2번(Am J Obstet Gynecol 2010;202(1):43.e1-8, [PMID: 19766977](https://pubmed.ncbi.nlm.nih.gov/19766977/)): 임신 28~30주 등록 146명 3군 RCT(OMT 7회·회당 30분 vs 샴 초음파 vs 통상 산전관리). OMT군은 경추·흉추·요추, 흉곽출구, 흉곽과 [[횡격막]], 골반환을 대상으로 **연부조직 기법 + 근막이완 + MET + 가동범위 관절가동술**을 표준 순서로 조합 — 요추 기능(RMDQ) 악화 폭이 유의하게 작았다(효과크기 0.72, 95% CI 0.31~1.14, P=.001). 통증 강도는 군간 차이 없음 → [[도수치료]] · [[RMDQ]]
- ⚠️ 이 시험은 **묶음 중재**이므로 근막이완 단독의 기여는 분리되지 않는다 — '근막이완이 임신 요통을 개선했다'로 인용하면 안 된다
- 관련 리뷰: [[2026-09-27_부인과소아과_심층리뷰]] 2번 · [[2026-09-27_부인과소아과_개념학습]]
