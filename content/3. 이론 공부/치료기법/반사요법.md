# 📍 반사요법 (反射療法, Reflexology)

> **핵심 요약**: 발(주로)·손의 **반사구**에 엄지와 손가락으로 압박·연동운동을 가해 전신 장기·계통의 기능을 조절하려는 수기 중재. 발 반사구 지도(뇌·경추·척주·태양신경총 등)를 이론적 틀로 삼는다. 2026-10-01 리뷰 3번의 메타분석에서 반사요법 4편이 지압·마사지와 함께 분석되어 삶의 질·감각 증상·통증·수면 개선에 기여했으나, 근거 수준은 낮음~매우 낮음이었다.

## 1. 정의·기법
- **대상 영역**: 주로 발바닥·발등·발가락. 보조적으로 손·귀.
- **기본 동작**: 엄지 관절을 이용한 연동운동(peristaltic) 방식의 압박 → 문지르기·두드리기로 마무리.
- **매개물**: 올리브유 또는 에센셜오일. 건조·마찰을 줄이고 시행감을 높인다.
- **압력 기준**: 환자가 "편안하게 눌리는 느낌"을 유지한다. 통증을 참게 하지 않는다.
- **원리적 서술**: 발 반사구가 전신 장기와 대응한다는 전통적 이론을 따르나, 현대 기전 설명은 국소 순환·자율신경·관문조절 축으로 정리된다.

## 2. 환자 지도용 프로토콜

| 항목 | 내용 |
| :--- | :--- |
| 주요 반사구 | 뇌 · 경추 · 척주(척추) · 태양신경총 |
| 시행법 | 엄지·손가락 연동운동 압박 중심, 문지르기·두드리기로 마무리 |
| 매개물 | 올리브유 또는 에센셜오일 |
| 회당 시간 | 20~40분 |
| 빈도 | 주 1회 ~ 하루 2회(연구별 차이 큼) |
| 총 기간 | 4~6주 |

- **하이브리드 운용**: 진료실에서 주 1~2회 시행하고, 나머지 날은 보호자·환자가 발바닥 전체를 부드럽게 마사지하는 수준으로 채운다. 메타분석 하위분석에서 전문가 시행 + 4주 초과 조건에서 삶의 질 개선이 컸다.

## 3. 작용 기전
- **국소 순환·림프**: 발의 부종·정체 완화, 조직 회복 환경 조성.
- **자율신경 조절**: 태양신경총(복강신경총) 영역 자극이 부교감 우세로 기울게 한다는 가설 — 수면·불안 개선과 연결 → [[자율신경계]] · [[부교감신경]]
- **관문조절·하행성 억제**: 반복 압자극이 굵은 구심섬유를 통해 통각 전달을 억제 → [[관문조절설]] · [[Aβ 섬유]] · [[하행성 통증억제계]]
- **이완 반응**: 접촉·반복 리듬이 [[코르티솔]]·교감 긴장을 낮춘다는 보고 → [[스트레스]]
- **한의학적 해석**: 발바닥은 신(腎)·족태음·족소음 경락이 모이는 부위로, 반사요법은 그 반응점을 자극하는 방식으로 설명된다 → [[아시혈]] · [[지압]]

## 4. 임상 적용
- **항암 유발 말초신경병증**: 발 저림·야간 통증·수면 문제에 병행. 원문 프로토콜(회당 20분·주 1~2회·4~6주)이 진료실 적용에 가장 가깝다 → [[항암치료 유발 말초신경병증]]
- **수면·불안**: 항암·만성질환 환자의 이완 목적으로 사용. 약물 보조로 위치시킨다.
- **부종 관리**: 말초 부종 환자에서 부드러운 반사요법은 순환 보조로 쓰인다(단, 심부전·신부전·림프부종은 의뢰·전문 판단 우선).
- **고령자 접근성**: 침·주사가 부담스러운 대상에서 진입 장벽이 낮다.
- **기대 관리**: 근거 수준이 낮으므로 "치료를 대신하지 않는 병행 요법"으로 설명한다.

## 5. 주의·금기
- 시행 금기·중단: 혈소판 감소·출혈 경향, 활동성 감염, 발 피부 손상·궤양·[[당뇨발]] 병변 부위, 급성 심부정맥혈전증·림프부종(전문 판단 없이 시행 금지).
- **당뇨·항암 감각저하 환자**: 압력 인지가 어려워 손상 위험이 크다. 오일 마찰은 줄이고 상처·발톱 주위는 피하며, 시행 전후 발 피부를 시진한다.
- 뼈전이·병적 골절 위험, 임신 초기(일부 반사구 자극)에서는 강도를 낮추거나 회피한다.
- 항암 주기별 혈액검사 결과를 확인한 뒤 시행 여부를 결정한다.
