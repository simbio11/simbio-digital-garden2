# 초음파 유도 관절내 주사 (Ultrasound-Guided Intra-Articular Injection)

> **핵심 요약**: 실시간 초음파로 **바늘 끝을 보면서** 관절강 내에 약물을 투여하는 시술. 촉진·해부학적 랜드마크만으로 하는 맹검 주입보다 정확도가 높고(대퇴골두 기준 사체 연구 92.5% 대 72.5%), 방사선 노출이 없으며 연부조직·신경혈관 구조물을 실시간 확인할 수 있다. 2026-09-29 심층리뷰 3번은 동결기 [[유착성 관절낭염]]에서 **후방 접근법**으로 [[상완골두]]-관절와 사이에 히알루론산 60 mg/3 mL를 주 1회 × 3주 주입했고, 감독하 재활과 26주까지 동등한 결과를 보고했다.

---

## 1. 정의·기법

### 1.1 왜 초음파를 쓰는가
- 어깨 관절내 주사는 표적이 깊고(삼각근·[[극하근]]을 지나야 함) 구조물이 겹쳐 **맹검 주입의 정확도가 낮다**. 부정확한 주입은 효과 부족과 주변 조직(점액낭·건) 오주입으로 이어진다.
- 초음파는 ① 바늘 끝을 실시간 확인 ② 관절낭 팽창(주입액 확산) 즉시 확인 ③ 혈관·신경 구조 회피를 가능하게 한다.

### 1.2 장비·준비 (기술노트 기준)
| 항목 | 내용 |
| :--- | :--- |
| 탐촉자 | 고해상도 선형 배열 6~15 MHz |
| 무균 | 무균 프로브 커버, 무균 장갑, 천공 드레이프, 무균 초음파 젤 |
| 바늘 | 어깨 관절내 주사는 21~22 G(0.8 mm)·길이 3.5~3.8 cm 척추바늘이 통상 사용됨 |
| 주입액 | 적응증에 따라 히알루론산·스테로이드·국소마취제 혼합 |

### 1.3 접근법

**① 후방 접근법(posterior approach)** — 2026-09-29 리뷰 3번이 사용한 경로
1. 환자를 앉은 자세 또는 반측와위로 두고, 주사측 손을 반대쪽 어깨에 올리게 한다(또는 90° 굴곡해 침상에 얹는다).
2. 탐촉자를 **견갑극 바로 아래·바깥**에 두어 [[극하근]] 힘줄을 음향 창(acoustic window)으로 삼아 후방 관절와순·관절와·상완골두를 동시에 확인한다.
3. 표적은 [[상완골두]]의 저에코성 관절연골 바로 위, 후방 관절와순 유리연과 연골 사이 공간.
4. 탐촉자 바깥쪽 피부에서 바늘을 삽입해 **in-plane(바늘 전체가 보이는 방향)** 으로 외측→내측 진행.
5. 바늘 끝이 연골에 닿는 부드럽고 스펀지 같은 감촉이 확인되면 주입 시작. 저항 없이 주입액이 관절내에 퍼지는 것이 정확한 위치의 증거다. 저항이 있으면 바늘을 살짝 후퇴시키거나 사면(bevel)을 돌려 조정한다.
6. 주입 후 관절낭 팽창을 초음파로 확인한다.

**② 전방 회전근개 간극(rotator interval) 접근법**
- 앙와위에서 [[상완이두근]] 장두건을 따라 근위·내측으로 올라가 오구상완인대 아래 공간을 표적으로 삼는다. 유착성 관절낭염에서 병변이 시작되는 부위라는 점 때문에 선호하는 저자들이 있다.

### 1.4 진료실 시술 표

| 항목 | 내용 |
| :--- | :--- |
| 적응 | 유착성 관절낭염(동결기), 회전근개 질환, 점액낭염, 관절내 약물 투여가 필요한 견관절 병변 |
| 체위 | 앉은 자세(시술자가 뒤에 선다) 또는 반측와위 |
| 접근 | 후방 접근(기본) — 극하근 힘줄을 창으로 관절와순·상완골두 확인 |
| 확인 | 바늘 끝 → 관절연골 바로 위 / 주입 저항 없음 / 관절낭 팽창 |
| 빈도(유착성 관절낭염) | 히알루론산 60 mg/3 mL를 주 1회 × 3주(2026-09-29 리뷰 3번) |
| 병행 | 관절가동술 + 수동·능동보조 스트레칭 + [[회전근개]]·견갑 안정화 근력운동 주 2회 × 6주 |
| 재평가 | [[SPADI]], 능동·수동 굴곡·외전·외회전 ROM |

## 2. 작용 기전

- **정확도 자체가 기전**: 관절내 주입의 임상 효과는 주입액 특이 효과 + **주입 자체의 세척·희석·관절낭 팽창 효과** + 기대 효과가 섞여 있다. 초음파의 역할은 앞의 두 요소를 보장하는 것이다 → [[히알루론산]].
- **히알루론산이 주입액일 때**: 관절액 점탄성 회복(윤활), [[CD44]] 수용체 매개 항염·항산화 신호, 통각수용기 둔감화.
- **스테로이드가 주입액일 때**: 활막 염증의 신속한 억제 → [[트리암시놀론]]. 단 반복 사용 시 건 약화·연골 독성 우려로 연 3~4회 이내로 제한한다.
- **유착성 관절낭염에서의 위치**: 2026-09-29 리뷰 3번에서 주사 3회와 감독하 재활 6주가 **26주까지 동등**했으므로, 주사는 재활을 대체하는 것이 아니라 **대안 또는 재활 진입을 돕는 수단**으로 설명한다.

---

## 3. 임상 적용

- **한의원 진료 흐름에서의 판단**: 초음파 유도 주사는 시설·장비·면허 요건이 필요한 시술이다. 한의원에서는 ① 이 시험의 재활 구조(주 2회 × 6주, 회기 30분)를 도수·운동으로 그대로 구현하고 ② 필요 시 양방 의료기관 주사 치료를 **동등한 대안**으로 설명하는 것이 정확한 태도다.
- **환자 설명**: "어깨 주머니 안에 윤활제를 넣는 주사는 3주에 3번, 관절을 부드럽게 움직이고 근육을 키우는 재활은 주 2회 6주였습니다. 6개월 뒤 결과는 두 방법이 비슷했습니다."
- **비교 정확도**: 사체 80예 연구에서 초음파 유도 92.5% 대 랜드마크 72.5%. 류마티스 수련의 9개월차가 시행한 초음파 유도군(63%)이 경력 9년차 전문의의 맹검군(40%)보다 정확했다는 비교도 있다 — **술기 정확도는 경험보다 영상 확인이 결정한다**는 근거다.

---

## 4. 주의·금기

- **원문 미기재**: 2026-09-29 리뷰 3번에는 별도의 금기·중단 기준이 명시되지 않았고 치료 관련 이상반응은 0건이었다(원문 미기재).
- **일반 원칙(실무)**: 주사 부위 피부 감염·전신 감염, 조절되지 않는 항응고 상태는 시술 금기. 당뇨병 환자는 감염 위험이 높아 시술 전후 혈당 관리와 징후 관찰이 필요하다.
- **주입 후**: 일시적 통증·부종·열감(급성 가성 활막염)이 생길 수 있다. 감염성 관절염과 감별해야 하며, 발열·심한 통증·관절 운동 불능이면 즉시 의뢰한다.
- **기술적 함정**: 바늘 사면 방향에 따라 바늘이 휘어 경로를 벗어날 수 있다. 주입 저항이 있으면 밀어 넣지 말고 위치를 재확인한다. 연골을 반복 찌르지 않는다.

## 5. 논문 연결

- 2026-09-29 심층리뷰 3번 — Efficacy of ultrasound-guided intra-articular hyaluronic acid injection in the management of adhesive capsulitis: a randomized controlled trial. *J Rehabil Med*. 2026;58:jrm44901. [PubMed (PMID 42136070)](https://pubmed.ncbi.nlm.nih.gov/42136070/)
  - `[연구 요약]` 동결기 유착성 관절낭염 46명 RCT, 26주 추적. 초음파 유도 관절내 히알루론산(60 mg/3 mL, 주 1회 × 3주)과 감독하 재활(주 2회 × 6주, 30분)이 SPADI·ROM에서 모두 유의하게 개선됐으나 **군 간 차이는 없었다**(p>0.05). 이상반응 0건, HA 제조사 관계자 공저로 이해상충 가능성.
- 임상시험 등록 — NCT05983081 [ClinicalTrials.gov](https://clinicaltrials.gov/study/NCT05983081)
  - `[연구 요약]` 46명·26주 추적·1차 평가변수(SPADI, ROM)와 3회 주사 일정을 사전 지정한 등록 기록으로, 프로토콜과 결과 보고의 일치 여부를 확인할 수 있다.
