# 경부 심부굴곡근 훈련 (Deep Cervical Flexor Training, CCF)

> **핵심 요약**:
> 📍 정의: **상부경추(후두-환추-축추)의 미세한 굴곡**으로 [[장경근]]·[[두장근]] 등 심부 굴곡근의 **운동조절·지구력**을 재교육하는 운동. 목 전체를 뒤로 미는 **후인(retraction)** 과는 다르다.
> 🎯 기전: 심부 굴곡근의 지구력 회복 → 상부경추 과신전 감소·[[흉쇄유돌근]] 우세 교정 → 경추 부하 분산. **근력이 아니라 정밀한 운동조절 훈련**이다.
> 🩺 임상 위치: 만성 기계적 [[경항통]]·[[경추성 두통]]·거북목의 **1차 운동 처방**. 압력 바이오피드백을 동반하면 6주 추적에서 통증 NPRS 6.33→0.73까지 감소했다(PMID 33679948).
> ⚠️ 주의: 턱을 악물거나 힘을 세게 주면 **표층근 대체**로 오히려 악화된다. 턱관절 문제·현훈이 있으면 이완 치료·평가를 먼저 한다.

---

## 1. 정의·기법
### 평가 — CCFT(경추 굴곡 조절 검사)
- **자세**: 앙와위(무릎 굽힘), 경추 중립. 머리 아래(목이 아님)에 수건을 받쳐 중립 유지.
- **압력 바이오피드백 유닛(PBU)** 을 접어 후두부 아래에 넣고 **20 mmHg** 로 기준압 설정.
- **5단계 검사**: 22 → 24 → 26 → 28 → 30 mmHg, 각 **10초** 유지, 단계 간 30초 휴식.
- **해석**: 정상은 26 mmHg 이상 10초 유지 가능. 경항통 환자는 대개 **22~24 mmHg에서 무너진다** → **실패 단계 바로 아래**를 훈련 시작 강도로 삼는다.

### 동작 — CCF(상부경추 끄덕임)
- PBU 눈금을 보며 "천장을 보면서 천천히 고개를 끄덕여 '응' 하듯" **상부경추만** 굽힌다(압력 2 mmHg씩 상승).
- **금지**: 목 전체를 뒤로 밀거나 턱을 세게 당기는 후인(retraction), 어깨 으쓱임, 턱 악물기, 호흡 정지.
- **자가 확인**: 환자 손을 목 앞쪽에 올려 **[[흉쇄유돌근]]이 딱딱해지는지** 스스로 확인하게 한다.

### 용량(문헌 기반)
| 출처 | 용량 |
| :--- | :--- |
| Ashfaq 2021(PMID 33679948) | 22~30 mmHg 5단계 각 10초 유지, 세션 약 20분, 주 3회, 총 4주(+2주 자가운동) |
| Iqbal 2021(PMID 33521131) | 3세트 × 10회(1회 10초 유지), 세트 간 2분 휴식, 주 5일, 총 6주 |
| Jull 프로토콜 | 하루 2회, 현재 단계 10초 유지 × 10회(반복 간 3~5초 휴식) → 성공 시 +2 mmHg |

- **진행 규칙**: 무너짐 없이 **10초 × 10회** 성공 시 **+2 mmHg** 상승, 최종 목표 **30 mmHg**.
- **최소 기간**: 4~6주는 지속해야 지구력 변화가 나타난다(RCT 공통).

### 단계별 진행 예시(진료실)
| 주차 | 내용 |
| :--- | :--- |
| 1주 | PBU 없이(또는 손가락 2개를 후두부 아래에) 무통 범위 10초 × 5~10회, 하루 2~3회 — 동작 습득 |
| 2~4주 | PBU 실패 직전 단계 10초 × 10회, 하루 1~2세트 |
| 4~8주 | 30 mmHg 10초 × 10회 달성 → 좌위 자세교정·일상 적용으로 발전 |

## 2. 작용 기전
- **운동조절 회복**: 경항통 환자는 심부 굴곡근의 **지구력 저하·표층근(흉쇄유돌근·전사각근) 조기 동원** 패턴을 보인다. 저부하 정밀 훈련이 이 패턴을 교정한다.
- **분절 안정성**: 심부 굴곡근이 상부경추의 과신전·전단 부하를 제한해 분절 미세손상 반복을 줄인다.
- **통증 조절**: 저부하 반복 수축의 운동유발 진통 + 자세 재교육에 따른 부하 재분배([[운동유발 진통]]).
- **경추성 두통**: 상부경추·후두부 근막·C1~C3 신경 입력 정상화가 삼차신경-경추 복합체(trigeminocervical complex) 흥분을 낮추는 것으로 해석([[경추성 두통]]).

## 3. 임상 적용
- **적응증**: 만성 비특이성 경항통, 거북목·일자목, 경추성 두통, 사무직·스마트폰 과사용자, 경추성 현훈(어지럼 원인 평가 후).
- **진료실 3단계 지도**
  1. **평가**: CCFT로 실패 직전 단계 확인 → 시작 강도 처방. NPRS·NDI(또는 두통 빈도) 동시 기록.
  2. **시연·교정**: 이완 상태에서 시연 → 환자가 10초 유지 → 흉쇄유돌근 촉진으로 대체 여부 확인. 구호 통일 — "턱에 힘 빼고, 숨 쉬면서, 살짝만, 천장 보고 끄덕".
  3. **처방·추적**: 단계·횟수·빈도·주의사항을 서면 전달, 2주 후 재평가(CCFT 단계·NPRS·두통 빈도·진통제 복용 횟수).
- **좌위 통합**: 앙와위 훈련만으로는 일상 자세가 교정되지 않는다 → 요추 전만 유지 + 견갑 후인·하강 + 경추를 부드럽게 길게 늘인 자세를 **앉아서 하루 여러 번 5초씩**(알람 활용).
- **도구 없이**: 압력계가 없으면 **손가락 2개를 후두부 아래**에 넣고 "약간 눌리는 느낌이 커지는" 정도를 기준으로 지도. 종료 기준은 명확히 **무너짐 없이 10초 유지**.
- **한의원 접목**: 침·전침·추나로 통증·근긴장이 감소한 **직후가 교육 순응도가 가장 높다** — 치료 마지막 5분을 운동 교육에 배정하는 루틴을 만들면 재방문마다 교정이 누적된다. 경추성 두통 RCT(PMID 12221344)에서 도수치료와 특정운동 각각이 두통 빈도·강도를 유의하게 감소시키고 효과가 **12개월까지 유지**됐다.
- **작업환경 지도**: 모니터 눈높이 상향, 스마트폰은 눈높이로 들기, 베개 높이 조정, 30~40분마다 5초 자세 리셋.

## 4. 주의·금기
- **통증 기준**: 운동 중 통증 **2/10 초과** 또는 다음 날 악화 시 강도·시간 축소.
- **[[턱관절 장애]]**: 턱을 악물지 않고 교근·측두근을 이완한 상태로 시행. 악관절 통증·개구 제한·클릭이 있으면 **턱 근육 이완 치료를 먼저** 하고, 턱을 앞으로 내미는 대체 패턴이 보이면 중단·재교육.
- **현훈·어지럼**: 경추성 현훈 환자는 상부경추 과신전을 피한다. 운동 중 어지럼·이명이 새로 생기면 중단. **복시·구음장애·연하곤란·실신·양측 이상감각** 등 [[척추기저동맥 부전]] 의심 증상이면 운동 금지·평가 우선.
- **기타**: 고령·[[골다공증]]·경추 불안정성, 최근 경추 수술력은 전문가 감독 하에만. 임신 중 장시간 앙와위는 회피.
- **신경학적 증상**(방사통·저림·근력저하)이 있으면 운동보다 **평가 우선**.

## 📎 개념 학습 보충 (2026-09-25 논문 연계)
- **견인 중재의 '필수 병용 요소'로 위치 확인 (BMC Musculoskelet Disord 2024, PMID 39448969)**: [[경추성 두통]]을 동반한 [[경추 신경근병증]] 3군 시험의 **모든 군 공통 재활**에 ① 경추 관절가동술 ② 경부 근군 수동 신장 3회 × 30초(좌위) ③ **경추 신전근 등척성 강화 3회 × 10초**(좌위, 치료사 손 저항)가 포함됐다. 즉 견인의 이득은 이 병용 패키지 위에서 평가된 것이다 → [[견인치료]] · [[등척성 운동]]
- **임상 운용**: 견인·도수로 증상을 조절한 직후에 심부굴곡근(CCF)·견갑 안정화를 배치해 **'증상 조절은 견인, 재발 방지는 운동'** 으로 역할을 나눈다. 만성 [[긴장형 두통]]에서도 심부 경추 근육 위축이 보고되어 훈련 근거가 보강된다(PMID 37729231) → [[견갑 안정화 운동]] · [[긴장형 두통]]
- **용량 재확인**: CCFT로 시작 단계 설정 → 상부경추 끄덕임(CCF) 10초 유지 × 10회, 주 3~5회, 통증 NRS가 올라가지 않는 범위에서 단계 상향. 견인 세션과 같은 날 시행 시 견인 직후 5분 휴식 후 진행한다
