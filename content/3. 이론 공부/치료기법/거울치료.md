# 거울치료 (Mirror Therapy / Mirror Visual Feedback, MVF)

> **핵심 3줄 요약 (Key Summary)**:
> 🌿 환측 사지를 거울 뒤에 숨기고 건측 움직임의 거울상을 응시해 '환측이 통증 없이 움직인다'는 시각 착각을 만드는 중추 표적 재활 중재 — [[복합부위통증증후군]]·환상지통 재활의 대표 비약물 요법
> 🧪 기전은 시각·촉각·[[고유수용감각]] 입력의 불일치 교정과 운동 피질·[[체성감각피질]] 재조직 유도 — 말초 조직이 아니라 뇌의 몸 지도를 고치는 접근이다
> 🎯 편측 상지 [[복합부위통증증후군]] 제1형 RCT에서 매일 10분·6주로 안정 시 통증이 4.1 → 1.2, 움직임 시 5.9 → 2.3(10 cm VAS)로 감소하고 1개월까지 유지됐다. 다만 좌우 온도차는 개선되지 않았다

## 1. 정의·기법

### 1) 원리와 위상
- 거울상자(mirror box) 또는 대형 거울 하나로 시행하는 저비용·비침습 중재다. 환측 사지를 거울 뒤에 두고 건측 사지를 거울 앞에서 움직여, 거울에 비친 건측의 모습을 환측의 모습으로 지각하게 만든다
- [[복합부위통증증후군]]·환상지통에서 출발했고, 뇌졸중 후 편마비·관절 수술 후 강직 재활에도 적용된다. [[복합부위통증증후군]] 노트의 재활 섹션에 정리된 '거울 치료(Mirror Therapy)'와 같은 중재다
- 흔히 [[점진적 과부하]] 원리를 따르는 3단계 프로그램(GMI, graded motor imagery)의 마지막 단계로 운용된다 — ① 좌우 구분 훈련(내재적 운동심상) → ② 운동심상(움직임 상상) → ③ 거울치료 → ④ 기능 재개·부하

### 2) CRPS I 상지 시행법 — 환자 지도 가능 수준

| 항목 | 시행 기준 (근거 시험 프로토콜 기준) |
| :--- | :--- |
| 도구·교육 | 물리치료사가 환자별로 거울상자를 제공하고, 중재 전 방문에서 원리·목적을 설명한 뒤 동작을 함께 연습. 이후에는 가정 자가 시행 |
| 자세 | 환측 손은 거울 뒤에, 건측 손은 거울 앞에 둔다. 양측 시작 자세를 같게 맞추고 환측이 완전히 가려지는지 확인 |
| 동작 | 회내·회외, 손바닥 마주치기, 주먹 쥐기·펴기, 손가락 걷기(finger walking) 등을 환자 능력·선호에 맞춰 조합 |
| 시간 배분 | 10분 중 첫 5분은 환측 손을 움직이지 않고 거울상을 응시하고, 나머지 5분만 가벼운 움직임을 허용(요구하지 않음) |
| 용량·빈도 | 1일 1회 10분, 6주간(총 42일). 1일 1회 노출을 원칙으로 함 |
| 강도 판정 | 거울 속 손에 시선을 고정해 '환측이 움직인다'는 시각 착각이 유지되는 것이 핵심. 통증·이질감이 올라오면 시간을 줄이거나 중단 |

### 3) 일반 권장 범위
- 재활 문헌에서는 회당 5~10분, 1일 4~9회를 안내하기도 한다. 즉 '총 노출량'과 '동작 난도'를 단계적으로 올리는 것이 원칙이며, 단일 표준 프로토콜이 확정된 것은 아니다
- 거울상에 시선을 고정해 착각이 완성될 때까지 충분히 응시하는 것이 중요하고, 양측을 비동기(unilateral·asynchronous)로 움직이는 것은 피한다

## 2. 작용 기전
- **감각 입력 불일치의 교정**: 만성 통증에서는 시각·촉각·[[고유수용감각]] 입력이 서로 어긋나 뇌가 환측 사지를 '위험한 부위'로 표상한다. 거울상은 시각 입력과 고유수용 입력을 다시 일치시켜 이 오류를 줄인다
- **중추 재조직·[[체성감각피질]] 정상화**: [[복합부위통증증후군]]에서 관찰되는 체성감각 표현 영역의 왜곡(환부 표상의 축소·융합)과 시상·전대상피질 연결 변화를 거울 피드백이 정상화한다는 가설이 제시돼 왔다 → [[중추 감작]]
- **학습된 통증·무시 유사 증상 감소**: 환측을 보지 않고 움직임을 회피하는 보호 행동(무시 유사 증상, neglect-like symptoms)을 깨뜨려 '통증 없는 움직임'의 학습을 유도한다
- **주의**: 위 기전은 인접 신경영상·기전 연구에 근거한 설명이다. 이번 회차 시험은 임상 결과지표만 측정했고 뇌영상·신경생리 지표는 평가하지 않았다

## 3. 임상 적용
- 적응: 편측 상지 [[복합부위통증증후군]] 제1형(특히 원위 요골 골절·수술 후 유형), 환상지통, 뇌졸중 후 복합 통증·운동 회복 보조, 관절 고정 후 강직
- 진료실 운용: ① [[복합부위통증증후군]]이 의심되면 [[부다페스트 기준]]으로 진단을 먼저 정리 → ② 거울상자 1개로 즉시 시작하고 처방은 '매일 10분, 6주'처럼 단순하게 전달 → ③ 4주 시점에 안정 시·움직임 시 [[시각아날로그척도(VAS)]]와 관절가동범위·악력을 함께 기록해 반응을 판정 → ④ 반응이 없으면 [[점진적 과부하]] 원칙에 따라 좌우 구분 훈련·운동심상 단계로 되돌아간다
- 한의 병용: 거울치료는 부작용이 거의 없어 침·약침·[[추나]]·부종 관리와 병행하기 쉽다. 다만 환부에 강한 침습 자극·부항은 염증 폭풍(wind-up)을 유발할 수 있으므로 건측·원위 취혈을 우선한다 → [[전침]]·[[약침]]

## 4. 주의·금기
- **중단·감량 기준(즉시)**: 거울 앞에서 통증·이질감이 뚜렷이 악화되거나 어지럼·발한이 나타나면 즉시 중단하고 3~5분으로 줄여 재시작한다. 통증을 참고 관절운동을 강행하지 않는다
- 부적합: 개방창·감염, 불안정 급성 골절, 지시를 이해하기 어려운 인지·시각 문제. 외상 후 스트레스 증상이 뚜렷한 환자는 운동심상 단계를 건너뛰지 않는다
- 환측을 완전히 가리지 않아 환측이 보이면 착각이 깨져 효과가 흐려진다. 반지·시계·긴 소매를 정리하도록 교육한다
- 급성기 극심통 환자에게 단독 치료로 제시하지 않는다. 통증 조절·부종 관리·점진적 재활·심리적 접근과 병용하는 구성요소로 위치시킨다
- 좌우 온도차·부종 같은 자율신경·염증성 지표는 이 중재의 목표가 아니다. 온도차가 남아도 치료 실패로 해석하지 않는다

## 5. 논문 연결
- 2026-10-02 심층리뷰 2번(European Journal of Physical and Rehabilitation Medicine 2024;60(2):280-291, PMID 38197628 / DOI 10.23736/S1973-9087.23.07625-6, 반교차 RCT 27명): [[부다페스트 기준]]을 충족하는 편측 상지 [[복합부위통증증후군]] 제1형에서 매일 10분·6주 거울치료로 안정 시 통증 4.1 → 1.2, 움직임 시 5.9 → 2.3(10 cm VAS), 수장측 손목굴곡 37.7 → 71.9%, 악력 18.7 → 46.9%, 손·전완 부피차 11.6 → 2.7%, 삶의 질 66.8 → 79.2% — 72일 추적에도 유지. 좌우 손 온도차는 비유의
- Moseley GL. Pain. 2004;108(1-2):192-198 (PMID 15109523): 만성 [[복합부위통증증후군]] 제1형에서 GMI가 통증·부종을 줄였다는 초기 RCT로, 거울치료가 속한 3단계 프로그램의 근거 출발점 → [[점진적 과부하]]
- Ferraro MC, et al. Cochrane Database Syst Rev. 2023;6(6):CD009416 (PMID 37306570 / DOI 10.1002/14651858.CD009416.pub3): CRPS 성인에서 어떤 중재도 '높은 확실성' 근거가 없다고 정리한 개요 — 거울치료를 단독 만능 해법으로 제시하지 않는 이유 → [[GRADE 근거수준]]
- Johnson S, et al. Eur J Pain. 2012;16(4):550-561 (PMID 22337591): 실제 임상에서 GMI를 적용했으나 통증 개선에 실패한 결과 — 후기·중증 CRPS에서의 한계를 보여주는 반례
