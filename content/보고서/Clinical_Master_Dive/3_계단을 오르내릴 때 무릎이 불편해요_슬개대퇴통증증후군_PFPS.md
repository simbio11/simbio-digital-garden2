# 🩺 [Clinical Master-Dive] "계단을 오르내릴 때 무릎이 불편해요" — 실제 진료 흐름으로 보는 슬개대퇴통증증후군(PFPS)

## 🗨️ 1. 주제 + 핵심 질문

- **주제(환자 말투)**: "계단을 오르내릴 때 무릎이 불편해요"
- **의학적 주제**: 슬개대퇴통증증후군(PFPS) / 슬개골 연골연화증 감별
- **핵심 질문**: 이 무릎 앞쪽 통증, 위험한 것부터 배제하고 나면 결국 **PFPS인가, 반월판/인대 손상인가, 장경인대·거위발 같은 주변 연부조직 문제인가, 이미 시작된 퇴행성 관절염인가** — 그리고 오늘 이 자리에서 무엇을 묻고, 무엇을 검사하고, 무엇을 가르쳐 보낼 것인가?

---

## 🚩 2. 레드플래그 감별 — 진료실 들어오자마자 먼저 배제할 것

> ⚠️ 볼트에 전용 레드플래그 노트는 없어(검토 필요) 표준 임상 지식으로 정리했습니다. 아래에 해당하면 한의 치료 전에 우선 협진·전원을 고려합니다.

| 신호 | 의심 | 확인 포인트 |
| :--- | :--- | :--- |
| 뚝 소리(Pop) + 즉각 부종·체중부하 불가 | 십자인대/반월판 급성 파열 | 외상 직후 발생, 붓기가 수 시간 내 급속 |
| 진성 잠김(구부리다 완전히 걸려 안 펴짐) | 반월판 유리체 감돈 | 볼트 [[반월판 손상]]: "10~30도에서 잠기는 경우 많으며, 스프링 블록 같은 끝 느낌" |
| 급성 발적·열감·발열 | 화농성 관절염 | 움직임 자체가 불가할 정도의 통증, 전신 무력감 |
| 원위부 맥박 소실·족하수 | 슬와동맥/비골신경 손상 | 외상력 동반 시 즉시 확인 |
| 야간 안정 시에도 지속·악화되는 통증, 원인불명 체중감소 | 골종양(청소년 대퇴골 원위부·경골 근위부 호발) | 특히 젊은 환자의 국소 종괴 동반 시 |
| 청소년 급성 외상 후 경골조면 극심 압통 | 견열골절(Osgood-Schlatter와 감별) | 만성 경과면 [[Osgood Schlatter 병]]으로 무방 |

**→ 위 항목이 없으면 통상적인 과사용성 무릎 통증 진료 흐름(3~8단)으로 진행합니다.**

## 🖐 3. 이학적 검사 — 이 순서로 본다

1. **관찰**: 보행 시 슬개골 궤적, 내반슬/외반슬, 신발 밑창 마모 패턴(바깥쪽 뒤축이 닳으면 내반슬·오목발 동반 장경인대 증후군 시사 — [[무릎 통증]] §2)
2. **Clarke Test(Patellar Grind Test)**: 슬개골 상연을 하방으로 누른 채 대퇴사두근 수축 → 통증이면 PFPS 시사 ([[슬개대퇴 증후군]] §3)
3. **Patellar Tilt & Glide / J-sign**: 외측 지대 구축, 슬개골 외측 편위 확인 ([[슬개대퇴 증후군]] §3)
4. **[[Mcmurray test]]**: 최대 굴곡 후 외반+외회전 또는 내반+내회전하며 신전 — 딸가닥 소리·통증 시 반월판 단열 의심
5. **[[Steinmann test]]**: 반월판 보조 검사
6. **[[Lachman's test]]**: 20~30도 굴곡에서 경골 전방 견인 — 전방십자인대 단열 평가
7. **[[Ober test]]**: 측와위 외전 후 손을 놓았을 때 잘 안 떨어지면 대퇴근막장근·장경인대 구축(장경인대 증후군 시사)
8. **관절선 촉진**: 관절선 자체 압통이면 반월판/OA, **관절선 하방 2~5cm** 압통이면 거위발 점액낭염으로 감별 ([[거위발 점액낭염]] §4)
9. **측부인대 스트레스 검사**: 수동 내반·외반으로 안정성 확인 — [[측부인대 손상]]은 서서히, [[반월판 손상]]은 즉각적 기능 소실이라는 점이 감별점

## 🔍 4. 문진 — 감별을 좁히는 추가 확인

이학적 검사 결과를 확인한 뒤, 다음 질문으로 진단을 좁힙니다.

- **"어느 동작에서 더 아프세요? 오를 때? 내려갈 때?"** → 내려갈 때(원심성 부하)가 더 아프면 PFPS 쪽에 무게
- **"영화관처럼 오래 앉아 있다 일어날 때는 어떠세요?"** → 뻣뻣함·통증(영화관 징후, Movie-goer sign)이면 PFPS 특이 소견 ([[슬개대퇴 증후군]] §3)
- **"다치신 기억이 있으세요, 아니면 서서히 생겼나요?"** → 급성 외상이면 인대·반월판 우선 의심, 서서히면 PFPS·장경인대 증후군·퇴행성 변화 쪽
- **"움직이다가 무릎이 딱 걸려서 안 펴진 적 있으세요?"** → 있으면 반월판 잠김 의심, 정형외과 영상 협진 고려
- **"어떤 운동을 하세요? 달리기, 자전거, 등산…"** → 달리기·자전거는 PFPS·장경인대 증후군, 축구·농구는 인대 손상 위험
- **"통증이 무릎 어디쯤인가요? 앞쪽 전체, 안쪽 윗부분, 바깥쪽인가요?"** → 앞쪽 전체(PFPS), 안쪽 상부(거위발), 바깥쪽(장경인대 증후군)로 위치가 갈림
- **"체중을 실을 때 무릎에 힘이 훅 빠지는 느낌 있으세요?"** → 있으면 VMO 억제(관절성 근억제, AMI) 가능성 — 노인이면 관절염 동반도 고려
- **"연세, 그리고 최근 체중 변화는요?"** → 고령·체중증가 동반 시 퇴행성 슬관절염 동반 가능성 함께 고려

## 🩺 5. 진단 — 질환 감별 종합

문진·검사 소견을 종합해 아래 표로 정리합니다.

| 질환 | 핵심 병소 | 결정적 소견 | 볼트 근거 |
| :--- | :--- | :--- | :--- |
| **슬개대퇴통증증후군(PFPS)** | 슬개대퇴관절 활주 이상 | 계단 하강통, 영화관 징후, Clarke test 양성, 염발음, 급성 외상력 없음 | [[슬개대퇴 증후군]] |
| **반월상 연골판 손상** | 내·외측 반월판 | 관절선 압통, 잠김, [[Mcmurray test]] 양성 | [[반월판 손상]] |
| **십자인대 손상** | 전방/후방십자인대 | 외상력, [[Lachman's test]] 양성, 불안정감 | [[십자인대 손상]] |
| **측부인대 손상** | 내측(MCL)/외측(LCL) | 외반·내반 스트레스 통증, 서서히 발생 | [[측부인대 손상]] |
| **장경인대 증후군(ITBS)** | 대퇴골 외측상과-ITB 마찰 | 무릎 바깥쪽 통증, 30도 굴곡 최고통, [[Ober test]] 양성, 내리막·장거리 보행 악화 | [[장경인대 증후군]] |
| **거위발 점액낭염** | 봉공근·박근·반건양근 공통건 | 관절선 하방 2~5cm 압통, McMurray 음성 | [[거위발 점액낭염]] |
| **퇴행성 슬관절염(OA)** | 관절 연골 전반 마모 | 고령, 조조강직 30분 미만, 체중부하통, (영상 시) 관절강 협착 | [[퇴행성 슬관절염]] |
| **Osgood-Schlatter병** | 경골조면 견인성 골단염 | 청소년, 경골조면 국소 압통, 자가치유 경과 | [[Osgood Schlatter 병]] |
| **추벽 증후군** | 슬개골 주변 활액막 조직 띠 | 가동 시 마찰·이상음 | [[무릎 통증]] §4 |

**진단 결론 예시**: 젊은/중년 활동적 환자 + 급성 외상력 없음 + 계단 하강통·영화관 징후 + Clarke test 양성 + McMurray/Lachman 음성 → **PFPS로 잠정 진단**, 필요 시 슬개골 접선 X-ray로 골성 병변만 배제.

## 🦴 6. 해부·병태생리 (간략)

PFPS는 결국 **슬개골을 안으로 당기는 힘(VMO)과 밖으로 당기는 힘(외측광근·장경인대·Q-angle)의 균형이 무너진 것**입니다.

> 볼트 [[슬개대퇴 증후군]] §2 발췌:
> > [[내측광근]](VMO)의 근력 약화 vs [[외측광근]] 및 외측 지대의 단축·과긴장. [[중둔근]] 약화 → 대퇴골 내전·내회전(Dynamic valgus). 족부 과회내는 Q-angle을 기능적으로 증가시킴.

그리고 통증·부종이 있으면 **VMO가 가장 먼저, 가장 심하게 억제**됩니다(관절성 근억제, AMI) — 이는 "근육이 게을러서"가 아니라 "신경이 잠가둔 것"이라는 점이 치료·티칭 논리의 핵심입니다.

> 볼트 [[VMO]] §5 및 임상질문 [[2026-09-03_치료기법_슬관절염_근력운동_기전]] 발췌:
> > 관절강 내 삼출액이 20~30ml만 차도 척수 반사로 대퇴사두근 자발 활성이 최대 50% 감소하며 VMO가 가장 먼저 셧다운됨.

*(상세 근막 사슬·초음파 해부·모멘트암 수치 등은 필요 시 [[슬개골]]·[[VMO]]·[[내측광근]]·[[외측광근]] 노트 원문 참고)*

## 💉 7. 치료

### 7-1. 한의 치료 (PFPS 확정 시)

**변증** ([[슬개대퇴 증후군]] §4): 급성·스포츠 손상 후 국소 염증·야간통이면 **기체어혈(氣滯瘀血)**, 만성 경과·무력감·보행 지구력 저하면 **간신휴손(肝腎虧損)**.

**침·전침**: 독비·내슬안·양구(외측광근 TP)·혈해(내측광근 활성화)·족삼리·풍륭. 외측 슬개지대·[[외측광근]]은 이완 목적, [[내측광근]]은 2Hz 저주파 전침으로 VMO 선택적 수축 유도 ([[슬개대퇴 증후군]] §4, [[내측광근]] §7: 혈해 SP10 슬개골 내상각 상방 2촌 직자 20~30mm).

**약침**: 신바로약침·중성어혈약침·자하거약침을 슬개하 지방체(Hoffa's fat pad)·슬개건 부착부에.

**추나·도수**: 슬개골 내측·하방 글라이딩(단축된 외측 지대 신장), [[대퇴근막장근]]·[[장경인대]]·[[외측광근]]·[[슬괵근]] 트리거포인트 이완, 골반-고관절 교정(대퇴골 과내회전 교정) — [[슬개대퇴 증후군]] §4.

**본초·처방(변증에 따라)**:
- 마르고 허약, 시림 동반 → **[[대방풍탕]]**: "마르고 허약한 사람의 무릎 통증(학슬풍), 대퇴사두근 근위축 완화" — 단, 부자 함유로 열증 관절염 금기
- 물살·태음인 비만형, 무릎에 물이 참 → **[[방기황기탕]]**: "근육이 물렁하고 흰 태음인, 뚱뚱한 중년 여성 퇴행성 슬관절염" — 단, 음허화왕 신중
- 핵심 본초 **[[우슬]]**: "숙우슬은 보간신·강근골하여 무릎 연골 재생·계단 오르내림 통증 완치"
- 보조 본초 **[[오가피]]**: "대퇴사두근·슬관절 건 탄력성 복원, 계단을 오르내릴 때의 통증을 완화"

### 7-2. 양방 협진이 필요한 시점

- 급성 외상 후 뚝 소리+즉각 부종(인대 파열 의심) → 정형외과 영상(MRI)
- 진성 잠김(반월판 유리체 감돈) → 정형외과
- 슬관절 불안정성(Instability), 반복적 아탈구 → MPFL 손상 감별 영상
- 보존치료(침·운동·테이핑) 6개월 이상 무반응, 연골연화증 진행 의심 → 영상 재평가·협진
- 방사선: 슬개골 접선 촬영(Sunrise/Merchant view)로 Q-angle·아탈구 평가, 고령 퇴행성 변화 감별 시 표준 슬관절 X-ray

## 📖 8. 티칭 — 환자에게 무엇을 설명하고 보낼 것인가

1. **원인 설명(순응도의 핵심)**: "무릎이 약해서가 아니라, 무릎 안쪽 근육(VMO)이 부기·염증 때문에 신경학적으로 눌려 있는 것"이라고 설명 — 근력운동을 겁내지 않게 함 ([[2026-09-03_치료기법_슬관절염_근력운동_기전]]).
2. **당장 피할 동작**: 90도 이상 깊은 쪼그려 앉기, 장시간 무릎 굽힌 채 앉아 있기(영화관 자세) 이후 바로 일어서기 전 무릎 펴서 스트레칭.
3. **집에서 할 운동 (VMO 강화, [[VMO]] §7 · [[내측광근]] §7 발췌)**:
   - **터미널 니 익스텐션(TNE)**: 무릎 30도→0도로 펴며 마지막 15도에서 VMO 쥐어짜듯 수축
   - **볼 스퀴즈 스쿼트**: 무릎 사이 미니볼을 끼우고 안쪽으로 조이며 얕은 스쿼트(0~30도)
   - **후방 사슬 스트레칭**: 슬괵근·비복근 (단축 시 슬개대퇴 접촉압 상승)
   - **중둔근 강화**: 클램쉘, 옆으로 누워 다리 들기 — 착지 시 대퇴골 내회전(Dynamic valgus) 방지
4. **테이핑/보조기**: 급성기에는 McConnell 테이핑(슬개골을 내측으로 당겨 고정)으로 통증을 즉시 낮춘 뒤 운동 지속 가능함을 안내. 족부 과회내(평발) 있으면 인솔·신발 교체 권유.
5. **경과 예후 안내**: 대부분 4~6주 내 통증 감소 시작, 근력운동은 아파도 "무리하지 않는 범위 내 계속"이 원칙(운동을 완전히 쉬면 AMI가 더 심해짐).
6. **재내원 기준(레드플래그 재교육)**: 무릎이 갑자기 걸려 안 펴지거나, 급성 부종·발열, 계단에서 힘이 빠져 주저앉는 일이 반복되면 바로 재내원하도록 안내.
