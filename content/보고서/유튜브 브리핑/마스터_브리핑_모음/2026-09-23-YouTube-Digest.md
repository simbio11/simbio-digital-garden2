### 2. [[분석 AI 에이전트-인간 협업 플랫폼 'Buzz(버즈)' 분석 오픈소스 슬랙과 암호화 릴레이 아키텍처의 혁신]]
- **채널명**: 코드팩토리 | **원제**: [슬랙을 오픈소스로 풀어버린 Buzz. AI와 휴먼의 협업 툴](https://www.youtube.com/watch?v=m3JEiSQcagg)

> [!abstract] 핵심 요약 (Executive Summary)
> - **멀티 AI 시대의 컨텍스트 파편화 해결**: ChatGPT, Claude Code, Grok, Codex 등 다수의 AI 도구 활용 시 발생하는 컨텍스트 분산 및 사용량 제한 문제를 하나의 스레드/채널로 통합하여 해결합니다.
> - **로컬 구독 환경의 직교 활용**: 별도의 고비용 API 키 발급 방식 대신, 사용자가 로컬에서 기존에 구독 중인 AI 클라이언트 및 모델 자격 증명을 그대로 활용할 수 있습니다.
> - **암호화 서명 기반 탈중앙 무결성**: 슬랙과 달리 중앙 서버가 아닌 사용자/에이전트 고유의 개인키(Private Key)로 모든 메시지와 커밋을 암호화 서명하여, 서버 권한자도 위·변조가 불가능한 데이터 신뢰성을 확보합니다.
> - **릴레이(Relay) 서버 및 고성능 기술 스택**: Rust 언어로 작성된 릴레이 서버가 메시지 보관/전달을 담당하며, PostgreSQL, Redis, MinIO, 해시 체인(Hash Chain) 감사 로그를 결합한 견고한 아키텍처를 제공합니다.
> - **내장 Git 서버를 통한 코드 공동 작업**: 별도의 GitHub 연동 없이도 릴레이 서버가 직접 Git 레포지토리 역할을 수행하여 에이전트와 사람 간의 코드 커밋 및 작업 이력을 완벽히 추적합니다.
> - **팀 단위 24시간 실시간 협업 지원**: WSS(Websocket) 프로토콜 기반의 지속적 연결을 위해 VPS(예: 8GB RAM, 2 VCPU 사양)에 릴레이를 셀프 호스팅하여 24시간 팀 협업 환경을 구축할 수 있습니다.
> - **슬랙 완벽 대체를 지향하는 UX/UI**: 다이렉트 메시지(DM), 스레드, 반응 이모지, SNS형 방명록 기능인 Pulse 등 익숙한 협업 툴의 경험에 AI 에이전트를 영구적인 팀원으로 편입시킵니다.
