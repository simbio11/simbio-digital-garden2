> [!abstract] 핵심 요약 (Executive Summary)
> - **도구의 본질**: `Insane-search`는 "사용자가 브라우저에서 볼 수 있는 공개 웹페이지라면 AI 에이전트도 접근할 수 있어야 한다"는 철학으로 개발된 클로드 코드(Claude Code) 전용 플러그인입니다.
> - **403 Forbidden 우회**: 기존 크롤러나 AI 에이전트가 쿠팡, 네이버, 해외 쇼핑몰 등에서 겪던 차단(403 Forbidden) 및 봇 탐지 문제를 단계별 수집 전략으로 해결합니다.
> - **합법적/윤리적 스크래핑**: 로그인이나 결제가 필요한 비공개 영역은 접근하지 않으며, 오직 공개된 웹페이지의 데이터만 법적·윤리적 테두리 내에서 순차적으로 탐색합니다.
> - **유튜브 자막 수집**: 특정 유튜브 URL 입력만으로 영상의 메타데이터와 한국어 자동 자막을 완벽하게 추출하여 학습 및 요약 문서로 재가공할 수 있습니다.
> - **네이버 쇼핑 스크래핑 실증**: 네이버 쇼핑 핫딜 페이지를 분석하여 내부 API 구조를 파악하고, 308개의 상품 데이터를 중복 제거 후 CSV 파일로 자동 정리·저장했습니다.
> - **고도화된 차단 우회 메커니즘**: 알리익스프레스와 같이 봇 탐지가 강하게 적용된 사이트에서도 내부 API 프리패치 호출 및 Playwright 자동화를 활용하여 데이터를 연속 시도 및 수집합니다.
> - **업무 생산성 혁신**: 개발자가 직접 Python/Selenium 크롤링 코드를 짜지 않고도 마케터, 커머스 셀러, 연구자가 몇 줄의 자연어 명령만으로 가격 비교 및 시장 조사를 완료할 수 있습니다.

### 📑 세부 주제별 심층 정리 (Detailed Breakdown)

#### 1. Insane-search의 등장 배경 및 윤리적 스크래핑 원칙
- **개발 배경**: 기존 클로드 코드(Claude Code)나 코덱스(Codex) 환경에서 쿠팡, 네이버, X(트위터), 레딧 등의 웹페이지 데이터를 수집하려 할 때, 사이트 보안 장치로 인해 '403 Forbidden' 에러가 발생하는 불편함에서 시작되었습니다.
- **핵심 철학**: 개발자 '지피타쿠'가 공개한 이 도구는 "포기는 배추 셀 때나 쓰는 말이다"라는 슬로건 아래, 일반 사용자가 웹 브라우저에서 볼 수 있는 정보는 AI 에이전트도 동일하게 수집 및 활용할 수 있어야 한다는 목표로 제작되었습니다.
- **작동 및 우회 원칙**: 단순히 단일 웹 요청을 보낸 후 실패하는 기존 방식과 달리, 기본 HTTP 요청부터 시작하여 공식 API, 내부 API, 브라우저 자동화 엔진까지 수집 단계를 단계적으로 상향(Escalation)시키는 방식을 취합니다.
- **윤리적 한계 준수**: 불법적인 해킹이나 로그인 우회, 결제 벽(Paywall)을 넘는 우회 도구가 절대 아니며, 비로그인 상태로 일반인에게 완전 공개된 정보만을 수집 대상으로 한정합니다.

#### 2. 환경 구축 및 설치 단계 (WSL & Claude Code 플러그인)
- **실행 환경**: 리눅스 환경인 WSL(Windows Subsystem for Linux) 상에서 클로드 코드를 실행하여 안정적인 CLI 작업을 진행합니다.
- **디렉토리 구성**: 작업의 독립성을 유지하기 위해 `mkdir lab_insane_search` 명령어로 전용 디렉토리를 생성하고, `cd` 명령어와 드래그 앤 드롭 기능을 활용해 해당 위치로 이동합니다.
- **플러그인 설치 명령어**: 클로드 코드 내부에서 내장 명령어 사용 방식으로 플러그인 마켓플레이스(`GPTaku`) 등록 후 `Insane-search` 플러그인을 순차 설치합니다.
- **세션 갱신**: 설치 완료 후 `/reload-plugins` 명령어를 수행하여 현재 채팅 세션에 플러그인 스킬을 즉시 적용하고 사용 준비를 마칩니다.

#### 3. 실전 검증 I: 유튜브 메타데이터 및 자막 자동 추출
- **테스트 시나리오**: 학습이나 정보 요약을 위해 길고 복잡한 유튜브 영상의 자막과 메타데이터를 텍스트 형태로 빠르게 추출하는 과제를 수행합니다.
- **처리 과정**: 대상 영상의 URL을 클로드 코드에 제공하고 자막 추출을 요청하면, `Insane-search` 스킬이 즉시 작동하여 유튜브의 자막 트랙을 감지합니다.
- **결과 검증**: 한국어 자동 생성 자막을 포함한 영상 전체의 자막 텍스트와 메타데이터가 단 한 번의 요청으로 완벽히 추출되어 반환됩니다.
- **활용성 확장**: 추출된 자막 텍스트를 기반으로 클로드 코드가 직접 요약 웹페이지나 학습용 마크다운 문서를 2차적으로 자동 생성할 수 있는 기반을 제공합니다.

#### 4. 실전 검증 II: 네이버 쇼핑 핫딜 데이터 수집 및 CSV 변환
- **테스트 시나리오**: 네이버 쇼핑 핫딜 카테고리(키즈, 푸드, 라이프 등)의 전체 상품 정보를 긁어와 CSV 파일로 정제·저장하는 미션을 부여했습니다.
- **수집 메커니즘**: 에이전트가 패스 페이지의 구조를 파악한 후, 백엔드에서 작동하는 내부 API를 자율적으로 탐색하여 상품 데이터를 추출합니다.
- **실제 정제 수치**: 핫딜 페이지 내 총 **308개**의 상품 데이터를 수집하였으며, 이 과정에서 발생하는 중복 데이터를 자동으로 제거하여 데이터 정제도를 높였습니다.
- **데이터 실증**: 수집된 CSV 파일 내에 '파리바게뜨 망고밤 케이크' 등 실제 네이버 쇼핑 핫딜에 게시된 실시간 상품명과 가격 정보가 오차 없이 저장되었음을 확인했습니다.

#### 5. 실전 검증 III: 알리익스프레스 등 고도화된 차단망 우회 및 실무 적용점
- **해외 이커머스 테스트**: 강력한 안티크롤링 솔루션(보탐지)이 적용된 알리익스프레스 식료품 페이지에서 100개 상품 데이터를 수집하도록 명령했습니다.
- **자동 우회 파이프라인**: 1차 접근 막힘 발생 시, AI 에이전트가 포기하지 않고 페이지 내부 API 프리패치(Pre-fetch) 구조를 분석하거나 헤드리스 브라우저(Playwright)를 구동하는 방식으로 스크래핑 기법을 전환합니다.
- **실무진의 생산성 혁신**: 과거 파이썬(Python), 셀레니움(Selenium), 뷰티풀스프(BeautifulSoup) 코드를 수십 줄 작성하고 에러를 수정해야 했던 작업을 '자연어 지시 한 줄'로 대체합니다.
- **비즈니스 활용가치**: 마케터의 경쟁사 가격 비교 분석, 커머스 셀러의 핫딜 동향 파악, 최저가 모니터링 등 일상적인 업무를 몇 분 만에 자동화하는 강력한 비서 역할을 수행합니다.

> [!tip] 🔍 주요 키워드 & 데이터 사전
> - **Insane-search (인세인 서치)**: 개발자 '지피타쿠'가 제작한 클로드 코드(Claude Code) 전용 플러그인. 403 차단을 우회하여 공개 웹페이지 데이터를 단계적으로 수집함.
> - **403 Forbidden / 봇 탐지**: AI 에이전트나 크롤러의 접근을 차단하는 웹사이트 보안 시스템. 본 도구는 합법적 우회 프로세스를 거쳐 이를 해결함.
> - **내부 API 프리패치 (Pre-fetch)**: 웹페이지 렌더링 시 내부적으로 데이터를 미리 불러오는 API 호출 방식으로, 크롤링 차단을 우회하는 핵심 통로로 활용됨.
> - **Playwright**: 헤드리스 브라우저 제어 라이브러리. 단순 API 호출 실패 시 실제 브라우저 환경을 모사하여 데이터를 가져오는 최종 단계로 사용됨.
> - **실증 수치 데이터**: 네이버 쇼핑 핫딜 스크래핑을 통해 중복 제거 후 총 **308개**의 상품 데이터를 성공적으로 추출 및 CSV 저장 완료.
