> [!abstract] 핵심 요약 (Executive Summary)
> - **AI 기반 PRD 기획 문서화**: AI에게 단일 프롬프트로 앱 제작을 곧바로 요청하기보다, 벤치마킹 캡처 이미지와 핵심 기능을 제공하여 제품 요구사항 문서(PRD)를 사전 정의하는 것이 정확한 개발의 핵심입니다.
> - **'앱 공장' 모노레포(Monorepo) 구조 도입**: 플러터(Flutter), 네온 DB(Neon), 쇼버드(Shorebird) 기반의 모노레포 아키텍처를 1회 구축하여 디자인, 인증, 백엔드 로직을 재사용함으로써 연쇄적인 앱 개발 속도를 비약적으로 향상시킵니다.
> - **AI 자율 개발 및 자동화 테스트**: 클로드 데스크탑을 활용해 DB 연동 및 기능 코딩을 수행하며, 에뮬레이터 상에서 회원가입부터 주요 기능·탈퇴까지 AI가 알아서 테스트하고 결과를 시각적으로 캡처·보고합니다.
> - **구글 플레이 14일 테스터 함정 극복**: 구글 플레이 개인 개발자 계정 배포 시 발생하는 '12명 14일 테스트' 제약 조건을 개발자 커뮤니티 품앗이, 전문 외주 업체 활용, 또는 사업자 조직 계정 생성을 통해 우회/해결합니다.
> - **스토어 심사 없는 무심사 배포(OTA)**: 쇼버드(Shorebird) 솔루션을 프레임워크에 사전 이식하여, 네이티브 코드 변경 없는 앱 업데이트 시 스토어 재심사 절무 과정 없이 즉시 유저 단에 수정본을 배포합니다.

### 📑 세부 주제별 심층 정리 (Detailed Breakdown)
#### 1. [기획 문서화(PRD) 및 '앱 공장(모노레포)' 기초 아키텍처 수립]
- 단순 텍스트 프롬프트로 앱 제작을 시도할 경우 의도와 다른 결과물이 나오므로, 클로드 데스크탑(Claude Desktop) 환경에서 레포지토리 폴더를 지정하고 레퍼런스 앱 캡처 화면과 구체적인 기능 정의를 엮어 PRD(Product Requirement Document)를 먼저 생성합니다.
- 새로운 앱마다 바닥부터 개발하지 않도록 디자인 시스템, 로그인 인증, 유틸리티, 공통 백엔드 자원을 통합 관리하는 모노레포(Monorepo) '앱 공장' 구조를 설계합니다.
- 개발 스택은 크로스 플랫폼 프레임워크인 플러터(Flutter), Serverless Postgres DB인 네온(Neon DB), 그리고 라이브 업데이트 솔루션인 쇼버드(Shorebird)를 기본 표준 스택으로 채택하여 개발 환경의 완성도를 높입니다.

#### 2. [클로드 AI를 활용한 실전 개발, DB 연동 및 자율 에뮬레이터 테스트]
- 네온(Neon) 사이트에서 프로젝트를 생성하여 데이터베이스 URL, 베러어스(Better Auth) URL, 데이터 API 키를 클로드 환경(메모장 및 채팅)에 전달하고 네이티브 인프라 환경을 연동합니다.
- PRD 문서에 기반해 AI가 플러터 코딩을 진행하며, 개발이 완료되면 AI가 스스로 에뮬레이터를 구동하여 회원가입, 로그인, 운동 기록 생성, 통계 조회, 회원 탈퇴까지 전 과정을 자동 테스트합니다.
- 테스트 완료 후 최종 구동 스크린샷과 함께 보고서를 사용자에게 제공하며, 디자인 자산(앱 아이콘 3개 시안 중 선택, 스토어 홍보용 스크린샷) 역시 AI 프롬프트로 일괄 자동 생성하여 사용자의 작업을 대폭 단축시킵니다.

#### 3. [구글·애플 앱스토어 배포 노하우 및 심사 우회(OTA) 전략]
- 플러터의 단일 코드베이스를 기반으로 iOS(애플 앱스토어 커넥트: 년 $99)와 안드로이드(구글 플레이 콘솔: 최초 $25) 양대 플랫폼용 빌드 파일을 각각 생성합니다.
- 구글 플레이 개인 계정의 엄격한 규제인 '12명의 테스터 14일 간 유지를 통한 심사 자격 획득'은 개발자 품앗이 카페, 전문 서비스 업체 이용, 또는 사업자 명의 조직 계정(14일 테스트 면제) 전환을 통해 해결합니다.
- 배포 이후 발생할 기능 수정 및 버그 수정은 쇼버드(Shorebird) 오버더에어(OTA) 업데이트 기능을 활용해, 복잡한 스토어 심사 승인 대기 시간 없이 즉시 실제 사용자 앱에 반영될 수 있도록 시스템화합니다.

> [!tip] 🔍 주요 키워드 & 데이터 사전
> - **PRD (Product Requirement Document)**: 제품 요구사항 문서. 앱의 목적, 기능, 화면 흐름 등을 명시해 AI가 오작동 없이 코드를 작성하도록 돕는 가이드라인.
> - **모노레포 (Monorepo)**: 여러 프로젝트/앱의 코드를 단일 저장소에서 관리하며 로그인, 디자인, DB 등의 공통 모듈을 재사용하는 개발 구조.
> - **Flutter & Neon DB**: 모바일 크로스플랫폼 프레임워크(Flutter)와 Serverless Postgres 데이터베이스 솔루션(Neon DB).
> - **Shorebird (쇼버드)**: 플러터 앱에서 네이티브 코드 변경 없이 앱 스토어 재심사 과정을 우회하여 즉시 코드 패치를 적용할 수 있게 해주는 OTA(Over-The-Air) 업데이트 도구.
> - **구글 플레이 14일 테스터 규정**: 구글 플레이 개인 개발자 신규 계정에 적용되는 규정으로, 최소 12명의 테스터가 14일 이상 앱을 비공개 테스트해야 정식 출시 심사 신청 가능.
> - **계정 등록 비용**: 구글 플레이 콘솔 등록비 $25 (최초 1회), 애플 개발자 프로그램 연회비 $99 (매년).
