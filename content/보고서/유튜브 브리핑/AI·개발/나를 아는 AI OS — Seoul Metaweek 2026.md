> [!abstract] 핵심 요약 (Executive Summary)
> - AI는 "도구(3rd brain)"가 아니라 **나(1st) + 내 지식(2nd) + AI(3rd)** 3계층을 하나로 묶은 OS로 설계해야 하며, 격차는 모델 성능이 아니라 **내 컨텍스트를 어떻게 저장하고, 이 순간 필요한 것만 선별해 넣는가**에서 갈린다.

## 1. 핵심 주장 (그대로)
- 발표자: Brian. 유튜브 채널 **Brain Trinity** 운영. 주간에는 대기업 AI lab에서 조직 AX 업무, 저녁에는 컨설팅·콘텐츠 공유. 발표 구성: ① 트렌드 ② AIOS 정의 ③ so what.
- **"AIOS = AI + 지식베이스의 융합."** 온라인에서 "나만의 Anthropic OS", "Claude OS"로 불리는 것들의 실체.
- 새롭지 않다. 1945년 미국 과학자 Bush의 **"Memex(Memory Extender)"** — 읽고 생각한 것을 기계에 아웃소싱하는 발상. 이후 Second Brain(Tiago Forte, 2021~2022)으로 대중화.
- **AIOS·LLM Wiki·Second Brain·harness engineering** — 이름만 다르고 같은 개념.(harness engineering 오역 가능)
- 주장의 급소: **대중은 3rd brain(도구)에만 관심을 갖는다. 그러나 더 중요한 건 데이터를 어떻게 저장하는가이고, 그보다 더 중요한 건 내가 그것을 어떻게 활용하는가다.**
- 트렌드(지난 반년): Codex·Claude Code 같은 코딩 도구와 OpenInterpreter·**Hermes agent**가 동시 급등. AI 모델도 쏟아짐(ChatGPT 5.6, "Fable" — 오역 가능). 미국 정부가 위험하다고 판단해 수출 통제를 걸어 약 2주간 대부분 사용 불가, 일부 기관만 접근 가능했다는 일화.
- 활용 트렌드는 2축 — **① Creation(창작) ② Personal assistant(개인 비서)**
  - Creation: 코딩 도구가 지식 노동 도구로 전용. Claude Code는 2025년 2월 베타 → 5월 22일 정식 공개, 원래 목적은 코딩 성능 향상(파일 직접 제어). 그런데 사람들이 문서 편집·마케팅 전략·PPT 제작에 쓰기 시작. 근거: **"문서도 결국 코드로 되어 있다"** → PPT·엑셀·영상까지 AI 코딩으로 생성. ("한 줄의 코드로 PPT 끝", "PPT는 죽었다" 류 콘텐츠의 이유)
  - Personal assistant: 과거엔 컴퓨터에 고정. 지금은 오픈소스 에이전트(Hermes 등)를 컴퓨터에서 실행하고 **gateway**로 Discord·Telegram·Slack에 통합 → 폰에서 언제든 "나를 아는 AI" 사용. 부작용: **Mac Mini 대란** — 최저가 890,000원이 품절 후 1,300,000원까지 폭등(2월). 중국에서는 오프라인에 모여 1인 1에이전트를 세팅하는 흐름.(오역 가능)
- 기름을 부은 사건: **Andrej Karpathy**(OpenAI 공동창업자, 전 Tesla AI 디렉터, 현 Anthropic)가 4월 초 X에 **"LLM Wiki"** 를 언급하며 폭발.
  - LLM Wiki = **AI와 함께 편집하는 지식베이스.** 원본 PPT·PDF·웹 문서를 AI가 소화·분해·사용하기 쉬운 포맷으로 정리·연결("grooming")해 저장하는 것.
- 두 기둥: **① AI 모델**(메모리 개선으로 장기 히스토리 회상. 2026년 6월 4일 Anthropic이 self-improvement 수준 도달 발표 — 오역 가능) **② 지식베이스**(AI가 스스로 문서를 읽고 활용). 이 결합이 "My Own AIOS" 시대.

## 2. 두뇌 3계층(나·지식·AI) 구조 설명
발표자의 프레임 이름: **Three Brains / "Brain Trinity"**(채널명과 동일).

| 계층 | 정체 | 역할 |
|---|---|---|
| 1st brain | 나의 뇌 | 관찰·판단·영감·**결정**. 전두엽. 인간만 가능 |
| 2nd brain | 내 컴퓨터 위의 지식·정보 | 1st brain이 선택·관리한 것이 저장·정리되는 곳 |
| 3rd brain | 생성형 AI 기반 에이전트 | 인간이 느끼고 경험하고 저장한 데이터를 **확장·적용·구현** |

- 역할 분담 근거(발표자): "나는 지금 여러분을 보며 긴장하고 있다. AI가 이 긴장을 느낄 수 있는가? 느낄 수 없다." → 느낀 것(1st)을 기록하면 2nd에 저장되고 3rd가 확장.
- 상호작용 예시(맛집): ① 온라인에서 좋은 식당 발견·저장(Obsidian=2nd brain) ② AI에게 "이번 주말 아내와 서울에서 좋은 식당 가려는데 후보?" ③ AI가 2nd brain에서 내가 저장한 것을 검색·추천 ④ "이걸로 계획 만들어줄까?" → yes ⑤ 문서 생성해 Obsidian에 다시 저장 ⑥ 내가 보고 기억을 강화하거나 결정.
- **설계상 함의**: 이 순환이 곧 개인의 OS이며, 저장(2nd)과 활용(1st의 판단)이 도구(3rd)보다 중요하다.

**2nd brain으로 Obsidian을 고른 이유(발표자 제시)**
1. **로컬 기반** — 모든 노트가 내 컴퓨터에 저장, 클라우드 아님. "클라우드에 있으면 궁극적으로 내 데이터가 아니다."
2. **Markdown 기반** — AI가 생성·읽기·이해할 수 있는 포맷. 내 컴퓨터의 Markdown 파일을 Claude Code·Codex가 그대로 읽고 이해 → "AI에 최적화된 앱".
3. **무료** — 비즈니스 용도까지 무료.
4. **노트 간 상호연결** — 인간은 연결·연상으로 사고한다. 그 원리대로 기록하면 AI가 그 연결을 따라가 관련 파일을 인출한다.
- 사용 이력: 2021년부터. 그래프 뷰의 점 하나 = 노트 하나, 2~3년치(이전 것은 아카이브). 개인 생각·저널·영감·목표가 전부 안에 있음. "컴퓨터를 도난당하면 하드웨어보다 그 안의 데이터가 더 소중하다."

## 3. 실제 시연한 워크플로 (계획·기록·콘텐츠·회고)
**① 계획(Planning) — Hermes agent + Obsidian 플래너 자동 기입**
- 아침 이동 중 Hermes agent에게 "오늘 계획할 것?" → AI가 캘린더·투두·지난 주/월 기록을 확인해 **우선순위를 먼저 제시**(예: MetaCon 발표 마무리, 라이브 초안 확인이 최우선).
- "플래너에 등록해줘" → 비어 있던 Obsidian 내부 플래너가 자동으로 채워짐. 집에 있는 **Mac Mini가 등록·반영**(원격 실행 → 볼트 동기화).
- 효과: 무엇을 할지 결정하는 시간 감소, 이동 중 계획 수립, 일정 자동 등록.

**② 지식 입력·기록 — 커스텀 템플릿 정리 + 자동 연결**
- 뉴스레터 **Long Black**(롱블랙, 오역 가능) 구독. 매일 아침 7~8시 고품질 아티클. "끝없는 노력(striving)의 시대에 내려놓기" 글에 감동 → 대충 메모.
- 폰에서 대충 기록 → **음성으로 프롬프트 입력** → "이 노트 정리해줘".
- **커스텀 템플릿** 정리 항목: ① 언제·어디서 읽었는지 ② 무엇을 생각했는지 ③ **내 삶에 어떻게 적용할 수 있는지**.
- AI가 자기 관찰을 덧붙임: "이 노트는 당신의 핵심 본질(core essence)과 유사하다"는 식.
- 마지막에 볼트 내 관련 노트로 **자동 확장·연결** → 새 생각마다 기존 노트 다발에 접붙여진다. "대충 써도 AI가 잘 쓰려면 일정한 템플릿으로 정리돼야 한다."

**③ 콘텐츠 제작 — 발산은 사람, 구조화는 AI**
- 자기 진단: **구조화는 어려워하지만 발산적 사고는 누구보다 낫다.**
- 실사례(이번 강연 준비): ① **30분간 의식의 흐름대로 쏟아냄** ② "구조화해줘" ③ AI가 관련 정보 + 이메일 내용 + 커뮤니케이션 핵심 포인트를 가져와 개요 작성 ④ 메시지 전달 순서·**내러티브 아크**를 고려해 흐름 구조화 ⑤ 슬라이드·스텝별 **와이어프레임** ⑥ "PPT 만들어줘" → 초안 → 사람이 편집. AI는 이미 수집·정리해 둔 지식(2nd brain)을 재활용해 내용까지 업데이트한다.

**④ 회고(Reflection) — 라이프로깅 + 새벽 2시 자동 배치**
- 라이프로깅: **노트북 화면 1초마다 캡처**, **24시간 녹음**(녹음 목걸이 착용). 활동 데이터를 일정 기준으로 연결 → "실제로 한 일"의 기록 생성.
- **매일 새벽 2시 자동 실행.** 입력: 투두, 폰 사용 이력, 저널, **AI와의 채팅 이력**, 컴퓨터 화면. 출력: "오늘 너는 이것저것 했고, 개인적 내러티브·감정은 이랬다"는 **한 줄 요약**. "나를 잘 아는 다른 사람이 그날의 성과를 알려주는 느낌."
- 확장: **요약의 요약** — 주·월·분기 리뷰 → 연간 리뷰·계획 시 원본 기반 압축본 확보.
- 개인 대시보드: 2분기 차트, 목표 달성률, 월별 시간 투자율, 강연 횟수, 주간 집중도(3~4월 시작, 데이터 부족 자인). 발표자 근거: "시간이 가장 희소한 자원이고, 기록하지 않으면 증발한다."

**다른 사람들 사례**
- Strate의 김재경(고유명사 오역 가능): Obsidian + 에이전트로 **AI끼리 대화**시킴. Andrej Karpathy·Steve Jobs 같은 페르소나를 "대화"시켜 의사결정에 도움.
- 최대 AI 커뮤니티 **Deepiters**(표기 오역 가능): Open-Claude(오역 가능) 기반 에이전트끼리 대화·**자동 작업 위임**. 지식 + 역할 부여 → 지시를 따라 자율 작업.
- 한림대 미디어과 안창현 교수(오역 가능): AI와 Obsidian을 **둘 다 개조**해 자기만의 인터페이스 제작. 공공기관의 **HWP(한글) 파일**을 AI가 쓰기 쉬운 포맷으로 변환해 활용(자막 "AR"은 오역 가능).

## 4. 격차는 어디서 오는가 (저자의 답)
- 결론: **"결국 나로 돌아온다. 가장 중요한 건 나다."** 비인간적인 것이 늘어날수록 인간의 본질, '나다움'이 중요해진다.
- 격차 요인 ① **개인 지식(내 데이터)을 제공했는가** — 세상 AI는 이미 온갖 데이터로 학습됐다. 그 안에서 **새로운 것은 내 경험과 고유함뿐**이다.
- 격차 요인 ② **"이 순간의 컨텍스트"를 제공했는가 — 3종 컨텍스트**
  1. **지속적 나(Persistent)** — 변하지 않는 나. 목표, 내가 누구인지, AI에게 무엇을 시키는 사람인지.
  2. **프로젝트 컨텍스트** — 몇 달짜리 프로젝트의 목적·타깃 독자·이해관계자·규모·목표.
  3. **태스크 컨텍스트** — 지금 프롬프트는 그 프로젝트의 여러 태스크 중 하나일 뿐이므로 이 태스크의 맥락도 넣어야 한다.
- 발표자 표현: "이 자리에 온 사람마다 기대와 이유가 다르다. 그것이 각자의 컨텍스트다."("7월 4일 오후"로 발표 날짜를 언급 — 확인 필요)
- **선별 원칙(핵심)**: 컨텍스트는 **이 순간 관련된 것만** 넣는다. 전부 넣으면 환각·중요도 상실·생산성 저하·**비용 증가**, 관련된 것만 넣으면 정확·빠름·원하는 품질.
- **MAP — AIOS가 담아야 할 요소**(발표자는 "these three elements"라 말한 뒤 4개를 나열 — 자막 오류 가능)
  - **Me** — 나는 누구인가. 내 인생·이력·정체성을 정의한 AI 참조용 문서.
  - **Assets** — 내가 아는 것, 지식·자원·**최고의 산출물**. 항상 재활용되도록 제공.(자막 "belongs to the human domain" = 사람 영역에 속한다, 오역 가능)
  - **Action** — AI가 할 구체적 행동. 수단 제공: **skills, MCP, workflows, loops**.
  - **Persona** — AI는 어떤 존재인가. 내 Claude·Codex·Hermes(3rd brain)의 역할.
  - 결론 문장: **"MAP를 제공하고 필요한 컨텍스트만 주면, 진짜 나를 아는 AI가 만들어진다."**
- 개인 vs 조직: 개인은 쉽다(지식 저장·관리 합의만 하면 됨). 조직은 ① 데이터가 엉망 ② 워크플로·매뉴얼 정립이 잘 안 됨 ③ 보안 이슈 ④ 복잡성 증가로 변경관리(change management)가 오래 걸림.
- 최종 답: **"나 자신에게 충실한 것"**. 내가 좋아하는 것·우선순위를 AI에 제공하면 **Claude든 Codex든 어떤 도구를 써도** 나를 아는 AI가 된다.
- 마무리: AIOS 구축은 한 번 쓰고 버리는 게 아니라 **내 컨텍스트 기반으로 평생 함께 자라는 시스템**을 만드는 것. 모델·앱·에이전트를 바꿔도 **시스템 자체는 계속 성장**한다. 개인·팀·대조직 모두 자기 AIOS를 만들려 할 것이다.

## 5. 우리 볼트에 적용할 점
- **MAP 4종을 볼트 루트에 명시적 파일로 승격**: `Me`(정체성·목표·취향·우선순위) / `Assets`(재활용할 최고 산출물·지식 인덱스) / `Action`(스킬·MCP·워크플로) / `Persona`(에이전트 역할). 지금은 넷이 흩어져 세션마다 재설명이 발생한다.
- **컨텍스트 3층(지속/프로젝트/태스크)을 파일 구조로 분리**하고 태스크 시 필요한 조각만 주입 — 발표자가 지적한 환각·비용 증가를 피하는 지점.
- **노트 템플릿 표준화**: "언제·어디서 / 무엇을 생각했나 / 어떻게 적용하나" 3항목 + AI 관찰 한 줄. 템플릿이 없으면 AI가 재활용하기 어렵다는 것이 발표자의 주장.
- **새 노트마다 기존 노트 연결 의무화**(링크 0개 금지). 그래프 연결이 곧 AI 검색 경로다.
- **회고 자동화**: 일 단위 배치(발표자는 새벽 2시) → 주·월·분기 "요약의 요약" 계층 + 월별 시간 투자율·집중도·완료율 같은 자기 지표 대시보드 노트. 볼트의 일정·작업 기록을 입력으로 묶으면 리뷰 시간이 줄어든다.
- **콘텐츠 파이프라인 고정**: 사람이 30분 발산 → AI 개요 → 내러티브 흐름 → 와이어프레임 → 초안. 순서를 스킬로 박아 프롬프트 재작성을 없앤다.
- **도구 종속 회피**: 자산은 볼트(Markdown·로컬)에 남기고 모델·에이전트는 교체 가능한 소비 계층으로 취급.

## 6. 주의·한계
- **근거 등급**: 전부 발표자 개인 실사용 사례·의견이며 정량 검증 없음. "개인은 쉽고 조직은 어렵다", "환각·비용이 준다"는 주장으로만 수용.
- **오역 위험(원문 확인 필요)**: ChatGPT 5.6·"Fable", 2026년 6월 4일 Anthropic self-improvement 발표, Claude Code 정식 출시 5월 22일, Mac Mini 890,000원→1,300,000원, Long Black·Deepiters·Strate 김재경·한림대 안창현 교수 등 고유명사, "harness engineering", "Open-Claude", "AR". 영어 자동번역 자막이므로 수치·기관·인명은 원문 확인 없이 인용 금지.
- **표기 혼재**: MetaCon / Metacon / Metaweek. 자막의 발표 날짜("7월 4일 오후")가 행사 표기(Seoul Metaweek 2026)와 어긋날 수 있음.
- **MAP 설명의 모순**: "these three elements"라 하고 Me·Assets·Action·Persona 4개를 나열. 약어 대응은 원음 확인 필요.
- **프라이버시·법적 리스크**: 1초 화면 캡처, 24시간 상시 녹음, 폰·채팅 이력 수집은 타인 대화 포함·동의 문제·조직 보안 위반 소지가 큼. 업무 환경 이식 금지.
