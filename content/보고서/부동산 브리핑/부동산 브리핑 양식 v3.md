# 부동산 브리핑 양식 v3 (자가마련 및 시장 전용)

- 작성 원칙: 모든 수치는 번들 데이터(`realestate_briefing_bundle.json`)에 기반할 것. 억 환산 = 만원 ÷ 10,000. 전세가율 교차검증 필수.
- 분량: 3,500자 이상, 심도 있고 풍부하게.
- 코너 구성:
  1. 📊 시장 지도 (토요일은 지방 10곳 전체 표 + 월별 추이)
  2. 🎯 자가마련 레이더 (전세가율 50%+ 지역 등 진입 전략)
  3. 📍 오늘의 지역 (토요일은 지방 특집 딥다이브 1곳)
  4. 🏡 지방 특집 심화 (토요일 전용: 지방 청약·분양 소식, 수도권 vs 지방 비교)
  5. 📰 뉴스 + 해석 (부동산 / 경제 신호 / 정치·정책, 각 1줄씩 자가마련 해석)
  6. 📚 공부 (A. 개념 1개 및 용어 노트 추가, B. 데이터 읽는 법, C. 퀴즈)
  7. ✅ 정리 (배운 것 3가지 + 비비 한 줄)
