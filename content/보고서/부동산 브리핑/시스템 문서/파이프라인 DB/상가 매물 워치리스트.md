# 🏪 상가 매물 워치리스트

> [!info] 사용법
> - 후보지 리서치·매물 스크리닝(양식 v2 §2-1)에서 **커트라인(전용 30~40평, 월 임대료+관리비 300~400만 원 이내, 엘리베이터·주차 가능)을 통과한 매물**만 등록.
> - **예측을 반드시 적는다** ("이 자리에 6개월 내 어떤 업종이 들어올까") → 나중에 재조회로 검증 (양식 v2 §9).
> - 매주(추천 목요일) 재조회: 현재 상태(공실/입점 업종/영업 여부)를 `재조회 로그`에 추가. 6개월~1년 후 어떤 업종이 들어왔고 잘 살아남는지 추적.
> - 상태: 🔵 관찰 중 / 🟡 협상·딥리서치 / 🟢 계약 검토 / ⚪ 해제 / ❌ 블랙리스트 전환
