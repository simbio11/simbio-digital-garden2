# 🔴 실시간 위젯 데모 (노트 안에서 움직임)

> [!tip] 사용 전 1회만
> 옵시디언에서 설정 → 커뮤니티 플러그인 → **Custom Frames 끄기 → 켜기** (설정 반영)
> 그 다음 이 노트를 **읽기 모드**로 보면 위젯이 실시간으로 움직입니다.

## 📈 티커 테이프 (핵심 8지표)

```custom-frames
frame: 티커 테이프
style: height: 110px; border: 0;
```

## 🗺️ S&P 500 섹터 히트맵 (실시간)

```custom-frames
frame: S&P 히트맵
style: height: 560px; border: 0;
```

## 🌏 시장 개요 — ① 지수 / ② 금리·환율·변동성 / ③ 원자재·대안 / ④ 관심종목

```custom-frames
frame: 시장 개요
style: height: 420px; border: 0;
```

# ⭐ TV차트 — 지수·국채·VIX (임베드 위젯 제한 우회, TradingView 차트 그대로)

> TradingView **임베드 위젯**은 지수·국채·VIX 원지수 시세를 제공하지 않아요(계약 제한).
> 그래서 **TradingView 차트 페이지**를 띄우는 방식으로 만들었어요 — 실제 차트·보조지표·그리기 도구까지 그대로 사용 가능!
> (시세·뉴스가 함께 보고 싶으면 `frame: 실시간 VIX` 처럼 '실시간' 프레임도 있습니다)
