# 🖥️ 실시간 위젯 넣는 3가지 방법

> [!question] "캡처해서 넣어야 되나?"
> **아니요!** 용도에 따라 3가지 중 고르면 됩니다.

## ① 노트 본문에 실시간 (Custom Frames 플러그인) ⭐ 설치·설정 완료!

**등록된 프레임 4개** (2026-09-14 비비가 미리 설정함):

| 프레임 이름 | 내용 |
|---|---|
| `티커 테이프` | 관심종목·금리·유가·VIX·환율 |
| `S&P 히트맵` | S&P 500 섹터 히트맵 (실시간 색상) |
| `QLD 차트` | QLD 고급 차트 (심볼 변경 가능) |
| `시장 개요` | 지수 / 금리·원자재 탭 |

**노트에 넣는 방법** (그대로 붙여넣기):
```custom-frames
frame: S&P 히트맵
```

> ⚠️ `frame:` 뒤에는 **위 표의 이름 그대로** 써야 합니다 (URL 직접 입력 방식 아님)
> ▶ 처음 1회: `Ctrl+P` → **"Reload app without saving"** 로 설정 반영
> ▶ 데모 노트: [[🔴 실시간 위젯 데모]]

## ② 옵시디언 패널에서 실시간 (TradingView Widget 플러그인)

- `Ctrl + P` → **"Open stock view"** → 패널에서 실시간
- 노트와 **스플릿** 배치 + workspaces-plus로 "📈 장전 세팅" 저장 추천

## ③ HTML 대시보드 (여러 위젯 한 화면)

- `대시보드\live_dashboard.html` → 브라우저로 열기
- 매일 자동 갱신 (크론: `make_live_dashboard.py`, 관심종목 자동 반영)

## 📸 캡처(PNG)는 언제?

| 용도 | 캡처 필요? |
|---|---|
| 브리핑 본문 기록 · 구글 드라이브 공유 | ✅ PNG (아무 데서나 보임) |
| 아카이브 ("그때 시장 어땠지") | ✅ PNG |
| 실시간 확인 | ❌ (①②③) |
