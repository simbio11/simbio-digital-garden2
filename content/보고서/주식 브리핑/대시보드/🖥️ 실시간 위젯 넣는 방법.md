# 🖥️ 실시간 위젯 넣는 방법 (2026-09-14 검증판)

## ⚠️ 먼저 알아둘 제약 (브라우저 실측)

| 구분 | 표시 가능? | 비고 |
|---|---|---|
| 미국 주식·ETF (NVDA·AAPL·SOXX·QLD…) | ✅ | 위젯에서 값 정상 |
| CFD·프록시 (SPXUSD·NSXUSD·VXY·DXY·WTI·금·구리·BTC) | ✅ | 실측 확인 |
| **지수·국채·VIX 원지수** (SP:SPX·NDX·US10Y·VIX·KOSPI) | ❌ 위젯 불가 | "이 심볼은 트레이딩뷰에서만 쓸 수 있습니다" → **실시간 페이지 프레임** 사용 |

## 📋 등록된 프레임 (24개)

**① 위젯형 (임베드)**
| 프레임 | 내용 |
|---|---|
| `티커 테이프` | 핵심 8지표 한 줄 |
| `📊 TV히트맵(실시간)` | **TradingView 전체 페이지 히트맵 (계속 갱신)** — 임베드 위젯판(`S&P 히트맵`)은 갱신 안 됨 |
| `시장 개요` | ①지수 ②금리·환율·변동성 ③원자재·대안 ④관심종목 |
| `QLD 차트` | 레버리지 ETF 캔들 |
| `차트 <티커>` | 종목별 캔들 (NVDA·AAPL·AVGO·MU·QQQ·QLD·SOXX·RKLB) |

**② TV차트형 (지수·국채·VIX 원지수 — 차트로 보기)** ⭐
| 프레임 | 내용 |
|---|---|
| `TV차트 VIX` | 공포지수 차트 |
| `TV차트 미10년물` · `TV차트 미2년물` | 미국 국채 금리 차트 |
| `TV차트 S&P500` · `TV차트 나스닥100` · `TV차트 코스피` | 주요 지수 차트 |
| (`실시간 VIX` 등) | 같은 심볼의 시세·뉴스 페이지 (보조) |

## 🔧 지표 추가·변경

`profiles\vivi\scripts\widget_spec.py` 수정 → 아래 2개 실행:
```
python make_widget_frames.py     # 노트용 프레임 재등록
python make_live_dashboard.py    # HTML 대시보드 갱신
```

## 📌 보조 수단

- **TradingView Widget 플러그인** (`Ctrl+P` → "Open stock view"): 실제 사이트 → 모든 심볼 값 확인 가능
- **HTML 대시보드**: `대시보드\live_dashboard.html` (브라우저, 클릭 시 차트 열림)
