# 🖥️ 실시간 위젯 넣는 방법 (2026-09-15 검증판)

## ⚠️ 먼저 알아둘 제약 (브라우저 실측)

| 구분 | 위젯 표시 | 실시간 갱신 | 비고 |
|---|---|---|---|
| 미국 **상장** 주식·ETF (SPY·QQQ·NVDA·AAPL·SOXX·VXX·IEF·SHY·QLD…) | ✅ | ✅ **오버나잇·프리마켓까지 실시간** | 차트에 `오버나잇` 배지가 붙으면 살아있는 것 |
| **CFD·프록시 원지수** (FOREXCOM:SPXUSD·NSXUSD) | ✅ | ⛔ **정규장 밖 정지** | 등락률도 정규장 종가와 달라 오해 소지 → 2026-09-15 폐기 |
| **지수·선물·국채·VIX 원지수** (SP:SPX·NDX·US10Y·CBOE:VIX·**CME_MINI:ES1!·NQ1!**·KOSPI) | ❌ 위젯 불가 | — | "이 심볼은 트레이딩뷰에서만 쓸 수 있습니다" |
| TradingView **전체 페이지** (`/heatmap/`, `/chart/`, `/symbols/`) · Finviz 맵 | 옵시디언 ✅ / **사이트 ❌** | 옵시디언 ✅ | 사이트는 iframe 차단(frame-ancestors) → 회색 빈화면 |

> **핵심**: 지수를 실시간으로 보려면 **ETF 프록시**가 유일한 길. `S&P500 = SPY(지수÷10)` · `나스닥100 = QQQ` · `VIX = VXX` · `미10년 = IEF` · `미2년 = SHY`.

## 📋 등록된 프레임 (28개 + 사이트 래퍼)

**① 위젯형 (임베드 — 사이트·옵시디언 공통)**
| 프레임 | 내용 |
|---|---|
| `티커 테이프` | 핵심 8지표 한 줄 (SPY·QQQ·WTI·VIX선물·원/달러·반도체·NVDA·AAPL) |
| `시장 개요` | ①지수(SPY·QQQ·IWM·SMH) ②금리·환율·변동성 ③원자재·대안 ④관심종목 |
| `차트 <티커>` | 종목별 캔들 (NVDA·AAPL·AVGO·MU·QQQ·QLD·SOXX·RKLB) |
| `QLD 차트` | 레버리지 ETF 캔들(1시간) |

**② 페이지형 (옵시디언 전용 — 웹뷰라 가능)**
| 프레임 | 내용 |
|---|---|
| `📊 TV히트맵(실시간)` · `📊 TV히트맵(ETF)` | TradingView 전체 페이지 히트맵 (계속 갱신) |
| `🔥 히트맵(실시간)` · `🌍 히트맵(월드)` | Finviz 맵 |
| `TV차트 VIX·미10년물·미2년물·S&P500·나스닥100·코스피` | 원지수 차트 |
| `실시간 VIX` 등 | 같은 심볼의 시세·뉴스 페이지 |

**③ 사이트(Quartz) 전용 대체물 — 옵시디언 이름 그대로 쓰면 자동 변환**
| 옵시디언 이름 | 사이트에서 실제로 보이는 것 |
|---|---|
| `TV차트 S&P500` / `실시간 S&P500` | **SPY(SPDR S&P500 ETF)** 차트 — 오버나잇·프리마켓 실시간 |
| `TV차트 나스닥100` / `실시간 나스닥100` | **QQQ** 차트 |
| `TV차트 VIX` / `실시간 VIX` | **VXX** 차트 |
| `TV차트 미10년물` / `미2년물` | **IEF** / **SHY** 차트 |
| `📊 TV히트맵(실시간)` · `🔥 히트맵(실시간)` · `🌍 히트맵(월드)` | **3분마다 자동 새로고침되는 히트맵 위젯** (`static/live_widgets/heatmap_live.html`) |
| `TV차트 코스피` | 링크(임베드 가능한 프록시 없음) |

- 히트맵은 **정규장 종가 기준**이라 프리마켓·오버나잇은 반영되지 않습니다(구조적 한계). 그 시간대 실시간 값은 **티커 테이프·차트 위젯**에서 보세요.

## 🔧 지표 추가·변경 (순서 중요)

```
python widget_spec.py 저장                     # ① 지표 정의 수정
python make_widget_frames.py                   # ② 옵시디언 프레임 재등록
python export_quartz_widgets.py                # ③ 사이트 매핑 + 감사(누락 경고)
python sync_obsidian.py                        # ④ 볼트→사이트 복사·변환·커밋·푸시
```

- **새 프레임 이름을 노트에 쓰기 전에 ③을 먼저** 돌려 `[감사] 매핑 누락` 경고를 확인하세요. 매핑이 없으면 사이트에서는 *"임베드할 수 없어 생략했습니다"* 로 **되돌릴 수 없게** 바뀝니다.
- 사이트 반영은 **GitHub Pages 빌드 15~30분** 소요(연속 푸시는 서로 취소). 배포 확인: `gh run list --repo simbio11/simbio-digital-garden2 --workflow "Deploy Quartz site to GitHub Pages"`.
