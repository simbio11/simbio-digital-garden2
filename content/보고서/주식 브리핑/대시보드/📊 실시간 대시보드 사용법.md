# 📊 실시간 시장 대시보드 — 사용법

> [!info] 두 가지 방법 (역할이 달라요)
> **① 옵시디언 안 (TradingView Widget 플러그인)** = 패널에서 **실시간으로 움직이는** 차트
> **② HTML 대시보드** = 브라우저에서 여러 위젯을 **한 화면에**

## ① 옵시디언 패널 (실시간)

1. `Ctrl + P` → **"Open stock view"** 실행 → 실시간 위젯 패널이 열림
2. 패널 **⚙️** 에서 위젯 종류(히트맵·티커·심볼 요약·고급 차트)·심볼·테마 선택
3. **🔄** = 새로고침
4. 오른쪽에 이 패널, 왼쪽에 그날 브리핑 노트 → **노트 보면서 실시간 시장**
5. (권장) workspaces-plus로 **"📈 장전 세팅"** 워크스페이스 저장 → 원클릭 복원

## ② HTML 대시보드 (한 화면에 여러 위젯)

- 파일: `00.봇/보고서/주식 브리핑/대시보드/live_dashboard.html` (실제 경로: `_생활\보고서\주식 브리핑\대시보드\`)
- 열기: 파일 더블클릭(브라우저) 또는 바탕화면 바로가기
- 내용: 티커 테이프(관심종목·금리·유가·VIX·환율) + S&P 500 섹터 히트맵 + 대표종목 차트 + 시장 개요
- **매일 자동 갱신**: `make_live_dashboard.py` (크론이 브리핑 생성 시 실행)

## ⚠️ 왜 노트 안에 못 넣나?

- 옵시디언 노트(마크다운)는 **자바스크립트를 실행하지 않아** TradingView 위젯이 노트 본문에서는 움직이지 않음
- 그래서 **패널(플러그인)** 또는 **브라우저(HTML)** 로 보는 방식이고, **노트 본문에는 정적 스냅샷 PNG**를 임베드해서 기록을 남김
