### 9. TypeSafe AI 'Jev' — $870M 투자, 밸류 $7.5B (출시 몇 주 만에)

- 🎯 **활용**: LLM에게 물어보던 "분기 판단"을 **결정 프리미티브**로 코드에 직결. 비용·속도가 동시에 필요한 자동화의 핵심 부품.

### 23. REA — Reverse Engineer Anything (에이전트용 리버스 엔지니어링 MCP)
- 📌 **핵심**: 코딩 에이전트가 **프로그램 자체를 검사하고 동작을 설명**하게 하고, 분석한 기능을 **변경·재구현**까지 하게 돕는 도구. GitHub 트렌딩 상위(약 18k★).
- ⚙️ **원리/디테일**: 기존 리버스 엔지니어링 도구들을 **MCP 서버로 코딩 에이전트에 연결**하는 구조. 앱 동작 수준부터 네이티브 바이너리까지 분석 범위.
- 🎯 **활용**: 레거시·사내 바이너리 동작 분석 → 문서화 → 재구현. 아까 그 어도비 클론들이 가능해진 이유이기도 한 계열의 도구.
- 🔗 **링크**: https://github.com/morluto/rea

### 24. Melty — 게임 머시업 플랫폼 (Y Combinator 백킹)
- 📌 **핵심**: **이미 보유한 게임 두 개를 합쳐** 하나의 새 게임으로 플레이. "Play game mashups in one click".
- ⚙️ **원리/디테일**: 예시 — **SkyCraft**(Skyrim을 Minecraft 플레이어로), Skate Warfare, Super Mario Ring, Portal Life, Elden Craft, Spartan Warfare. 원클릭 설치(필요한 것 자동 설치 후 실행), **언인스톨 시 파일 원복**, 초대 링크 기반 멀티플레이·공개 로비. **Melty의 지시문을 Claude Code·Codex에 붙여넣으면 에이전트가 내 머시업을 만들어 배포**해 줍니다. 무료, 업로드는 위험 파일 검사.
- 🎯 **활용**: 게임 모드·머시업 제작. "에이전트가 게임을 합친다"는 사례로, 리버스 엔지니어링 + 코드 생성 조합의 실전 예.
- 🔗 **링크**: https://melty.gg

### 25. Google Playground · Unity Spark (보조)
- **Google Playground** — 코딩 경험이 없어도 게임을 만드는 실험적 게임 플랫폼(사진 넣고 바로 개발). **Unity Spark** — 프롬프트만 넣으면 에이전트가 게임을 만들고 웹 기반 에디터에서 다듬어 다음 단계로 끌어올리는 도구. Unity는 에디터를 에이전트에 최대한 개방하는 방향. 🔗 확인 불가.
