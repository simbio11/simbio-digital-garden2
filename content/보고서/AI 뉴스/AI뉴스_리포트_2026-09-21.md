## 🥇 1. Jev(제브) — 텍스트를 버리고 '결정'만 하는 모델

![[01_jev_intro.jpg]]

- 📌 **핵심**: TypeSafe AI가 9/15 공개한 첫 "System One" 모델. 문장을 생성하지 않고 **타입이 있는 결정(typed decision)**만 출력합니다.
  - 창업자 Diogo Almeida는 InstructGPT 논문 공동저자(=ChatGPT 계보)이며, 회사는 $40M 펀딩.
- ⚙️ **원리**: LLM은 다음 토큰을 순차 생성하느라 느림 → Jev는 **출력 형식을 미리 고정**하고 그 안에서만 결정.
  - **Choice**: A/B/C 중 하나 선택(예: "A부서 담당 61%")
  - **Nul**: 예/아니오 이진 판정
  - **Score**: 확률·점수로 표현
  - 새 아키텍처 + 새 샘플러 + 새 학습 알고리즘 **RLCD**(Reinforcement Learning for Calibrated Decisions) 사용. 모든 결정에 신뢰도(confidence)가 붙어 소프트웨어가 불확실성을 처리할 수 있음.
- 📊 **실측 수치**: 공식 표기 **193.6배 빠름 / 444.6배 저렴** (동일 System One 작업 기준, 0.114초 vs 8.566초).
  - OpenRouter Eval: Jev 1.13 = **154ms**, 다음으로 빠른 GPT-5.6 Luna 860ms → 약 **5배** 차이.
  - 가격: 입력 100만 토큰당 $0.042, **출력 토큰 무료**.
- 🎯 **활용**: 실시간 게임 판단, 투자 롱/숏 결정, 뉴스 384건→15개 브랜드 분류, 리플레이 로그 원인 분류, 테슬라 FSD(1시간 내 학습 사례).
  - 조코딩 데모: 비트코인 차트 실시간 연동 → 롱/숏 자동 결정, 평균 응답 0.5초.
- 🔗 **링크**
  - 공식: https://typesafe.ai/ · 기술 블로그: https://typesafe.ai/blog/introducing-system-one-models-and-jev
  - API 문서(서드파티): https://www.jevtypesafeai.com/docs
  - 보도: https://www.theregister.com/ai-and-ml/2026/09/16/typesafe-ai-debuts-model-for-machines-that-plays-doom/5296711
