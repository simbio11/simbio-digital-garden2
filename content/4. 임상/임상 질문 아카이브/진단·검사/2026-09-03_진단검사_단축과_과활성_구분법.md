# 임상에서 근육 "단축(shortness)" vs "과활성(overactivity)" 구분법

## 질문
> 근육이 타이트할 때, 단축인지 과활성인지를 임상에서 어떻게 구분하는가? (2026-09-03, 디스코드 채널 질문 — 햄스트링 중심)

## 핵심 답변
**단축 = 신장성(viscoelastic) 문제, 과활성 = 수축성(contractile/신경 활성) 문제.** 수동 신장 검사로 "길이"를, 능동 기능 검사(움직임 패턴·발화 순서)로 "활성"을 평가해 교차 확인함. 길이 검사상 정상인데 "뻣뻣함"을 호소하면 대표적인 과활성/과긴장(또는 신경 기계적 과민) 신호.

## 근거 요약 (구분 로직)
1. **이론적 프레임 (Mense & Simons; Musculoskeletal Key 인용)**
   - 근 긴장 = ① 기본 점탄성 특성(viscoelastic, "길이") + ② 수축 기구의 활성 정도(contractile, "활성")
   - 점탄성 문제 → 단축·강직·유연성 감소(extensibility↓)
   - 수축성 문제 → 실제 근 수축 활성 증가(taut band, 방추긴장 등)
   - 임상적으로는 둘이 혼재하는 경우가 많아 **검사 조합**이 필요
2. **"단축" 확인 — 수동 신장 검사 (길이 평가)**
   - Active Knee Extension (AKE): 고관절 90° 굴곡 유지, 슬관절 신전 각도 >20° 결손이면 단축(신장성 감소) 기준. 검사자내 신뢰도 높음(ICC 0.86–0.99)
   - Passive SLR (PSLR) < 70–80° → 단축 의심
   - **주의**: AKE와 PSLR은 서로 낮은 상관(r≈0.28) — 각각 다른 구성요소(능동/수동, 신경 포함)를 측정. 단일 검사 gold standard 함정 피하고 여러 검사 조합할 것 (PMC6449015)
3. **"과활성/과긴장" 확인 — 능동 기능 검사 (발화 패턴 평가)**
   - **Janda prone hip extension (PHE) 검사**: 복와위 능동 고관절 신전 시 발화 순서 관찰 — 정상: 대둔근 → 동측 척추기립근 → 반대측 기립근 → 햄스트링. 햄스트링이 먼저/과도하게 발화하거나 **슬관절이 굴곡되며 들리면(hamstring dominance)** → 햄스트링 과활성(대둔근 억제 동반 흔함)
   - PHE 검사는 주관성 한계가 있으나 LBP군 분류 연구에서 83–87% 판별력 (Clin Biomech 2024)
   - 교각 시 대둔근 대신 햄스트링 우세 활성, 촉진 시 대둔근 위축/억제 동반 여부
4. **"느껴지는 타이트함 ≠ 단축" (중요!)**
   - "perceived hamstring tightness"를 호소하는 사람의 상당수는 실제 길이 감소가 없음(Kuilart et al.)
   - 원인은 신경 기계적 과민(neural mechanosensitivity): Slump test로 감별 — 경추 굴곡 추가 시 슬관절 신전 ROM 변화/재현되는 증상 → 신경성. 이 경우 스트레칭보다 신경 가동술(slider 등)
5. **치료 반응으로 사후 확인**
   - 단축형: 스트레칭/신장 위주 접근에 ROM 개선
   - 과활성형: 오히려 **신장 위치에서의 강화(lengthened strengthening)**가 torque-angle 곡선 이동(구조적 길이 증가)에 유효, 단순 스트레칭은 stretch tolerance만 증가(일시적) (J Bodyw Mov Ther RCT)

## 임상 적용 포인트 (실전 프로토콜)
1. **길이 먼저**: AKE 또는 PSLR 측정 → 20° 이상 결손/70° 미만이면 진짜 단축 후보
2. **신경 감별**: Slump test 양성, 발끝 들기(족관절 배측굴곡)로 증상 변화 → 신경 가동성 문제 먼저 배제
3. **패턴 관찰**: PHE, 교각, 스쿼트/런지에서 대둔근-햄스트링 발화 순서·슬관절 굴곡 여부 확인
4. **자세 교차 검증**: APT(전방 골반경사)에서는 햄스트링이 과신장+과활성 위치 → "타이트하니 풀자"보다 강화·억제 관리 우선
5. **치료 선택**: 진성 단축 → 신장 + lengthened strengthening / 과활성 → 대둔근 활성화, 햄스트링 과발화 패턴 교정(억제), 신경성 → 신경 가동술

## 메모
- 참고: Kuilart, "perceived tightness without reduced length"; Janda lower crossed syndrome의 발화 순서 개념
- PHE 검사의 과학적 근거는 아직 발전 중 — 3D/EMG 연구(Clin Biomech 2024)에서 LBP 판별 유망하나 프로토콜 표준화 필요
- 추후 주제: 대둔근 억제의 실제 기전(상호억제 vs 疼痛 억제), lengthened strengthening 프로토콜 세부
