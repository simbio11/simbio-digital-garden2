# 00. 개념 학습 MOC (논문 × 개념)

> 매일 오후 3시(KST) 임상 논문 심층 리뷰(한의학 1 + 현대의학 2)에서 나온 **핵심 개념을 별도 파일로 만들어 논문과 함께 학습**하는 시스템의 총괄 목차. (2026-09-03 규칙 확정 · 1차 시범: 2026-09-01 리뷰)

## 학습 규칙
1. 논문 리뷰가 저장된 **요일별 테마 폴더**에 `YYYY-MM-DD_테마_개념학습.md` 동반 파일 생성 — 논문 제목·링크·결론을 간단히 + 그 아래 핵심 개념 요약(논문 1편당 3~5개 이상)
2. 핵심 개념 파일 처리: **이미 있으면 → 보충·업데이트** / 없으면 → 아래 분류 폴더에 신규 생성
3. 개념 분류에 맞는 양식 사용, 분류가 애매하면 `의학개념` 폴더 활용 — **새 분류가 필요하면 폴더 추가/변경 가능**
4. 가상의 논문·PMID·DOI·수치 절대 금지 — 실제 존재 확인된 출처만
