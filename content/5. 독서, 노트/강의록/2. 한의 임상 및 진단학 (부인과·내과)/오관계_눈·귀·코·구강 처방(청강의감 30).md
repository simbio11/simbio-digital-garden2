# 오관계_눈·귀·코·구강 처방(청강의감 30)

> **핵심 요약 (Key Summary)**:
> 눈에는 [[청간명목탕]]·[[기국양혈탕]], 귀에는 [[가감통성산]](방풍통성산)·[[가미형교탕]]·[[자음보원전]], 코에는 [[청연산]], 구강·설에는 [[청격산]], 풍치·안면 부종에는 [[승형산]]이 제시되지만, 강의의 요지는 **"로컬에서 오관 처방을 낼 일이 거의 없다 — 처방이 의미하던 옛 병(실명 위험 눈병, 중이염, 콧물감기 등)을 이해하라"**입니다.
> 눈 처방의 실체는 **백내장·녹내장(수정체 단백질 변성·방수 순환 장애)**이라는 혈류·울혈·혈압·혈당 문제이며, "눈을 좋아지게 하는 처방"이라는 통념은 옛 안경 없는 시대의 실명 질환 대응이었습니다.
> 귀 질환의 핵심은 중이염(유스타키오관 경유 세균 감염 → 항생제)과 **내이 림프액 과다(메니에르·이명) → 이수통림 처방(오령산 위주)**, 코 질환의 핵심은 **"콧물엔 마황이 메인"**, 그리고 안이비인후 점막 염증엔 [[형개연교탕]]이 범용이라는 실전 프레임입니다.

## 1. 강의 개요 및 처방 지도

**청강의감 처방 스터디 30회차** — 오관계(눈·귀·코·구강) 처방을 정리한 강의(영상 1시간 15분, 자막 기반 정리). 강의자는 "원장님들이 로컬에서 쓸 일이 없다"는 이유로 원래 하지 않으려 했던 파트라고 소개합니다.

| 부위 | 처방 | 강의의 실전 평가 |
| :--- | :--- | :--- |
| 눈 | [[청간명목탕]], [[기국양혈탕]] | 백내장·녹내장(혈류·울혈) 대응이 본질 — 구조·순환(침추나)이 더 효과적 |
| 귀(중이염) | [[가감통성산]] | 대승기탕 느낌(대황·광물 하제) — 중이염엔 항생제가 1순위 |
| 귀·비인후 점막 | [[가미형교탕]](형개연교탕 가감) | **범용약** — 무난하게 사용 |
| 귀(이명·난청) | [[자음보원전]] | 육미+사물+안신 — 현대 원인불명 이명·현훈엔 오령산(림프액) 접근 |

## 2. 눈 — 청간명목탕, 기국양혈탕

### 2.1 처방 구조 분석
- [[청간명목탕]](세간명목탕): [[생지황]], [[작약]], [[당귀]], [[천궁]](=[[사물탕]]) + [[시호]], [[황금]](=소시호탕 뼈대) + [[연교]], [[형개]], [[방풍]], [[감국]], [[백질려]], [[만형자]], [[강활]], [[길경]], [[치자]], [[황련]], [[박하]], [[감초]] — **사물탕 + 황련해독탕 + 소시호탕 + 두면부 혈류·염증 약물**의 복합체.
- [[기국양혈탕]]: [[숙지황]], [[당귀]], [[작약]], [[구기자]], [[천궁]], [[감국]], [[맥문동]], [[백질려]], [[방풍]], [[형개]], [[박하]], [[감초]] — 청간명목탕의 **축소판**(사물탕+뇌혈관 약물). 강의는 "둘을 구별할 이유가 없다, 청간명목탕 하나로 대표하면 된다"고 말합니다.

![[청강의감30_02_안과처방_청간명목_기국양혈.gif|340]]

### 2.2 "눈이 좋아지는 처방"의 실체 — 백내장·녹내장
- 현대 환자가 눈 때문에 한약을 받을 일: 결막염은 안과, 시력 저하(근시·난시·노안)는 안경·라식, 건조증은 인공눈물 — **사실상 없습니다.**
- 그런데 고전에는 淸肝明目 본초가 넘쳐나는 이유: 옛날에는 안경도, 안과도 없었고, 치료하지 않으면 **실명**으로 가는 [[백내장]]·[[녹내장]]이 가장 큰 화두였기 때문. "淸肝明目 처방·본초는 백내장·녹내장 관련 약물로 이해해도 무방."
- [[백내장]]: 수정체 단백질 변성·혼탁(계란 흰자를 가열하면 하얘지는 것과 같은 원리). 노화·염증·**혈류 장애·울혈**이 단백질 변성을 촉발 → 중심 시야 흐림.
- [[녹내장]]: 방수액(모양체가 만드는 액) 배출 장애 → **안압 상승 → 시신경 압박·망막 혈류 장애 → 시신경 세포 손상**(비가역 실명 위험, 주변 시야 소실). 더 위험한 질환.
- 백내장·녹내장 모두 결국 **혈압·혈당·체온과 직결**: 망막은 단위면적당 인체에서 산소·혈류·포도당 요구량과 발열이 가장 높은 조직이라, 관리되지 않는 당뇨·혈압이 5~10년 지나면 눈(당뇨병성 망막병증)부터 망가집니다.

![[청강의감30_08_백내장_녹내장_증상차이.jpg|340]]

### 2.3 눈의 혈류 — 이마 온도가 뇌 온도인 이유
- 눈 혈관은 얼굴 피부 혈관(외경동맥)이 아니라 **내경동맥 → 윌리스 고리(Wills circle) 분지(안동맥) → 눈 영양 → 측부순환으로 이마 정맥**으로 빠지는 구조. 그래서 뺨 온도가 아니라 **이마 온도가 뇌 온도를 대변**하며, 감기 때 이마 온도를 재는 이유입니다.

![[청강의감30_10_안동맥_정맥_주행.gif|340]]

### 2.4 울혈 개념 — 편두통과 같은 시스템
- 청간명목탕의 실체는 편두통과 같은 **울혈(혈관 확장 → 순환 장애) 해소**: 형개·연교·방풍·만형자·강활(두면부 혈류 조절) + 사물탕(혈액 공급) + 황련·치자·감국·백질려(수정체 염증·재생). 저혈압·고혈압 양쪽 다 커버하는 구조.
- **구조·순환 치료의 중요성**: 후두하근·후두부(풍지 주변)를 풀어주면 눈이 맑아지는 경험 — 거북목·상경추 정렬 문제가 눈 혈류에 영향. "녹내장·백내장도 한약보다 **침·추나(구조·순환)가 더 효과적일 가능성이 높다**"고 강의는 단언합니다.

## 3. 귀 — 중이염·이명·난청

### 3.1 중이염과 [[가감통성산]](방풍통성산 가감)
- 중이염의 경로: 중이는 **공기로 찬 공간**이며, 감염은 귀로가 아니라 **유스타키오관을 타고 비강 → 중이**로 들어옵니다(어린이는 유스타키오관이 평평해 호발, 수영장 오염수 → 코 → 중이염).
- 방풍통성산 조성(동의보감): [[활석]], [[감초]], [[석고]], [[황금]], [[길경]], [[방풍]], [[천궁]], [[당귀]], [[작약]], [[대황]], [[마황]], [[박하]], [[연교]], [[망초]], [[형개]], [[백출]], [[치자]], [[생강]]
- **강의의 해부**: 표증약(형개·박하·연교·치자·석고) + 사물탕 + **대황·망초·활석·석고(광물성 하제)** + 마황·황금·길경 → "그냥 **대승기탕의 느낌**" — 복압을 확 빼는 급성기용 약.
- **대황 경고(핵심 임상 팁)**: 대황은 '짧게(2~3일~1주) 쓰면 좋은 약'. **2주 이상 장복 시 반드시 폐증**(피부가 물러지고 회복 못 함) — 강사는 과거 여드름 환자에 방풍통성산 수개월 투여로 수십 명을 나쁘게 만든 실패 경험을 고백하며, "한의사들이 자기 아토피를 망가뜨리는 1번 처방이 대황 처방"이라고 경고합니다.
- 광물성 약재 정리: [[활석]](마그네슘 규산염 — 마그밀 류, 설사 유발), [[망초]](함수황산나트륨 — 삼투성·염류성 하제), [[석고]](황산칼슘 2수화물) — 광물성 약재는 땀·대변·소변으로 빠지는 무기질 불균형을 잡는 약물.
- 실전: 급성 중이염(고열·귀 진물) = **이비인후과 항생제**, 만성·재발성 중이염·비염 동반 = 형개연교탕 같은 부드러운 처방.

### 3.2 [[가미형교탕]] = 형개연교탕 가감 — 안이비인후 범용약
- 구성: [[형개]], [[연교]], [[방풍]], [[시호]], [[현삼]], [[생지황]], [[당귀]], [[작약]], [[천궁]], [[감국]], [[길경]], [[지각]], [[황금]], [[박하]], [[감초]] (동의보감 형개연교탕에 시호·현삼을 더한 가감).
- **활용 스펙트럼**(강의): 영풍유루·알레르기성 결막염·지루성 피부염·비염·부비동염·외이도염·중이염·편도염·감기·코로나 — "상기도 및 안이비인후 점막 염증·감염에 그냥 형개연교탕."
- 가감 공식: 밥 못 먹으면 인삼·백출 추가 / 열 많고 콧물이면 마황·석고(마행감석·소청룡 개념) / 손발 차면 육계·계지류 / 근육통이면 강활·독활.

### 3.3 [[자음보원전]] — 신허 이명·난청의 재해석
- 구성: [[숙지황]], [[산약]], [[산수유]], [[당귀]], [[작약]], [[천궁]], [[복신]], [[택사]], [[목단피]], [[원지]], [[석창포]], [[지모]], [[황백]], [[생강]], [[대추]] — 육미지황탕 + 사물탕 + 복신·원지·석창포(안신) + 지모·황백.
- 강의 비판: "이명·난청이 왜 腎虛인지 모르겠다" — 현대의 이명·난청·현훈은 노인성보다 **메니에르·돌발성 난청·이석증·스트레스성·바이러스(코로나 후유증)**가 대부분.
- **림프액 모델(핵심)**: 내이는 림프액으로 차 있으며, 스트레스·울혈로 림프액이 과다해지면 ① 세반고리관(전정기관): 어지럼(메니에르), ② 달팽이관: 이명(북이 빵빵하면 작은 자극에도 울리는 원리). 양방의 '내림프 감압술'이 물을 빼는 수술이라면, 한의학의 대응은 **이수통림 → 오령산(위령탕) 위주** 처방. 육미지제도 복령·택사 때문에 의미가 있습니다.
- 구조적 접근: 목 주변(흉쇄유돌근·후두하근) 긴장이 내림프 압력을 높일 수 있으므로 구조·순환 치료도 병행.

## 4. 코 — 청연산과 "마황이 메인"

- [[청연산]]: 형개연교탕 + [[마황]]·승마 등 — **형개연교탕에 마황을 더한 것**(콧물감기·비연 처방).
- **핵심 공식**: "비염(수양성 콧물·재채기·비갑개 부종)에는 **마황이 없으면 효과가 거의 없다** — 마황은 메인이고, 나머지는 사이드 메뉴."
  - [[소청룡탕]]: 계지탕 구조+마황·세신·건강 — **찬바람 맞으면 콧물**(환절기 수양성 콧물).
  - 마행감석탕·월비탕 = 마황+석고 처방(석고가 마황 효과를 배가).
  - 태음인 비만형 비염에는 마황이 들어간 [[태음조위탕]]·[[조위승청탕]]류도 가능.
- 주의: 항생제·스테로이드·항히스타민을 2년 이상 써서 **점막이 위축·섬유화된 만성 비염(콧물 없이 코막힘·비중격 변형)**에는 마황 적응이 아니므로 감별 필요.

## 5. 구강·설·치아 — 청격산, 승형산

- [[청격산]](구내염): 만성 구내염(헤르페스성) 환자는 이미 스테로이드 복용력이 있는 경우가 많아 한약 적응이 제한적 — "옛날에는 이렇게 썼구나" 수준.
- [[승형산]](구성: 승마·갈근·형개·연교·박하·백지·세신 — 음성 강의 언급): 풍치(잇몸병)·치통·안면 부종(볼거리 등)에 쓰던 처방 — 현대에는 풍치=치과, 볼거리=MMR 접종으로 "알 필요 없다"고 정리.

## 6. 임상 꿀팁 — 실전 운영 요약

- **눈**: 청간명목 = 백내장·녹내장(울혈·혈류) 개념. 약보다 후두하근·경추 구조·순환(침추나)과 혈압·혈당 관리가 우선. "눈 좋아지는 처방" 요구에는 체질(마르면 보익, 뚱뚱하면 감량)에 맞는 처방이 곧 그 역할.
- **귀**: 급성 중이염=항생제, 만성 재발=형개연교탕 계열, 메니에르·이명·현훈=**오령산·위령탕**(복령·택사·저령·백출·육계 가감) 위주 + 목 주변 구조 치료.
- **대황·광물성 하제 원칙**: '실증 단기(2~3일~1주) 사용'이 생명 — 2주 이상 장복 금지, 여드름·피부염에 장기 대황은 폐증 유발.
- **코**: 콧물·비염 시즌엔 마황 함유 처방(청연산·소청룡탕·마행감석·월비탕 등) 중 사이드 메뉴만 골라 쓰기.
- **범용 처방**: "모르겠으면 형개연교탕" — 안이비인후·상기도 점막 염증/감염의 기본.
