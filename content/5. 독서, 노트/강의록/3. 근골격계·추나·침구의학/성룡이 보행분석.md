# 시간-거리 변수
(환자 보행영상에서 랜덤하게 5번의 걸음주기에서 평균을 냈습니다.)
-보폭: 양발이 지면에 닿는 거리 
-보장: 한쪽 발에서 반대쪽 발까지의 거리
-보행 속도: 일정 시간 동안의 보행 거리
-보행 주기: 한 발이 지면에 닿고 다시 닿기까지 걸리는 시간
-스텝 수: 분당 걸음 수
-입각기와 유각기 비율

-보폭 감소: 근력 약화, 균형 문제, 통증의 가능성
-보행 속도 감소: 신경계 문제 또는 고령화에 따른 변화
-보행 주기 불균형: 편마비, 근골격계 이상

# 관절의 움직임
-고관절, 무릎, 발목의 각도 변화를 관찰
-관절의 가동 범위
-발의 착지 방식(heel strike, toe-off)
### 고관절 
![[성룡이 보행분석-1749717529140.png]]
-무릎 과신전: 근력 불균형, 전방 십자인대 손상 가능성
-고관절 굴곡 제한: 대퇴직근 또는
-고관절 구축 가능성
-발목의 부족한 발등 굽힘: 낙상 위험 증가

# 근육의 활성도
-주요 근육군(둔근, 대퇴사두근, 슬괵근, 비복근 등)의 활성 패턴 분석
-근육의 조기 활성화 또는 지연 활성화 여부
![[성룡이 보행분석-1749717754953.png]]
![[성룡이 보행분석-1749717764722.png]]
-특정 근육의 과활성: 보상 패턴의 가능성
-근육 비활성화: 신경 손상 또는 근력 부족

# 지면 반발력
-발이 지면에 닿을 때 발생하는 수직 반발력과 전후 방향 반발력을 분석
-질량중심(center of mass)의 이동과 균형 평가

-비정상적 지면 반발력 패턴: 보행 불안정, 관절 부하 증가
-양측 차이: 근력 불균형, 부상 위험

# 신체 정렬
-상체와 하체의 정렬 상태 확인
-제간 기울기, 골반 경사, 하지 정렬

-체간 기울어짐: 균형 문제 또는 근육 약화
-골반의 비정상적 움직임: 고관절 기능 장애 가능성

# 발 보행 패턴
-발의 아치 상태: 우측 아치 무너져 구조적 평발/ 좌측 아치 약간 구조적 평발  
-발 착지 순서 
-발의 회내 또는 회외 여부: 우측 과회내, 외번/ 좌측 약간 회내 
-편평족: 발목 및 무릎 통증의 원인
-과도한 회내: 무릎 부상 위험 증가

# 대칭성
-양측 보행의 대칭 여부 확인
-시간-거리 변수와 관절 움직임의 양측 차이를 평가
-비대칭 보행: 편마비, 골반 문제, 근력 불균형

# 환자의 주관적 보고 및 기능 평가
-환자의 보행 시 통증 여부: 없음(1-2년 전에는 양쪽 발목 외측에 통증 있었음)
-보행 시 피로감 기능적 이동성 평가: 피로감은 심하지 않음 


우측 평발 심함/ 좌측 평발 약간 
FADDIR 좌측 잘 안나옴 > 좌측 외회전근 잡힘 
FABER 우측 잘 안나옴 > 우측 내회전근 잡힘 
-> 양측 평발로 인해 경골, 대퇴골 내회전 경향, 우측은 심해서 심하게 내회전 되어 있음 + 우측 회내가 심해 외전으로 팔자걸음 양상 심하게 나타남
