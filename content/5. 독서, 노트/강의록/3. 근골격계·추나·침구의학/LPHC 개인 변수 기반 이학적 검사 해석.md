## 1. LPHC(Lumbopelvic-Hip Complex) 개념과 중요성
- 정의: 요추, 골반, 고관절이 하나의 기능 단위로 움직이는 복합체
- 허리에서의 조절 장애는 요추에서 내려오는 중력의 힘과 고관절에서 떠받치는 힘이 골반에서 안정화되면서 발생하고, 골반의 움직임 장애는 요추, 고관절의 과한 운동을 유발할 수 있음 -> 움직임 복합체의 리듬의 중요성 
- ex) 요추 안정화 근육의 문제로 인한 요추의 비틀림은 골반 내 비틀림을 발생시키고 기능적 부정렬을 발생시킬 수 있음, 고관절 근육의 불균형은 골반의 변위를 발생시켜 요추 기능적,  구조적 부정렬 상태를 유발할 수 있음.  
-> 허리 환자의 진단과 치료에 있어서 허리-골반-고관절 복합체를 고려하는 것이 좋음.

## 2. 기존 검사 해석의 한계
- 동일한 기준각·자세로 검사 → 개인 차이 무시
- 위양성: 실제 정상인데 구조적 특성 때문에 제한처럼 보임
- 위음성: 실제 제한 있는데 보상 움직임 때문에 정상처럼 보임
- 원인: PI(골반 지수), 골반 전방/후방경사 가동성, 요추 전만/후만 패턴 등 LPHC 변수 미고려

## 3. LPHC 변수 고려의 필요성
1) PI(Pelvic Incidence): 구조적으로 요추-골반-고관절 지표를 의미하며, PI가 클수록 요추 전만은 심해짐.(골반 경사는 커질수도, 작아질수도 있음)(PI는 성인에서 개인 고유의 상수에 가까우며, 요추 전만/골반 정렬 패턴을 규정)
	-> PI가 클수록 토마스 검사나 SLR 검사에서 골반 경사의 움직임에 따른 허리 들림 현상이 정상적이지 않을 수 있음. 
2)  골반 경사 가동성:
	-> 후방경사 제한 → SLR, 토마스 검사 조기 제한
	-> 전방경사 제한 → FABER 검사 각도 제한

## 4. 예시 검사 ① — 토마스 검사(Thomas Test)
- 목적: 장요근/대퇴직근/TFL 단축 여부, 요추 전만·골반 경사 패턴 확인을 위해 골반을 후방경사시켜 가동성과 붙는 근육들의 움직임을 보는 것. 
- 정확도 핵심:
  1) 골반 후방경사 유지(대측 대퇴를 120도까지 당기도록 유지)
  2) 요추 전만 감소 확인(요추 전만 상태, 골반 경사 상태에 따라 PI를 고려하여 요추 전만 소실 정도를 확인)
- 위양성: 후방경사 과도  → 과도하게 전방 근육들을 당겨서 신전 제한처럼 보임/ PI가 큰데 후방경사되어 있는 경우, 허리가 심하게 뜸 -> 장요근 단축으로 보임 
- 위음성: 전방경사 동반 → 신전이 잘 나오지 않고, 대퇴가 뜨거나 무릎이 신전될 수 있는 상태여도 정상처럼 보임
- PI 변수:
  - PI↑(여자): 전만 완전 소실 안 돼도 변화량 중심 판정
  - PI↓(남자): 전만 변동 폭 크므로 고정이 더 중요
- The modified Thomas test is not a valid measure of hip extension unless pelvic tilt is controlled

## 5. 예시 검사 ② — SLR Test
- 목적: 신경긴장(좌골신경), 햄스트링 길이 평가
- LPHC 관점 확장:
  - 후방경사 제한, 요추 전만 심함 → 햄스트링 조기 당김, 가성 제한(SLR은 신경긴장/슬괵근 길이뿐 아니라, 골반 후방경사 가용성이 제한되면 조기 당김이라는 가성 제한을 만든다.)
  -> 양성 반응은 슬괵근 단축을 보여주는 것이 아닌 골반, 요추 구조적, 기능적 문제를 보여주는 것일 수도 있다. 
- Straight Leg Raise Test: Influence of Lumbosant© and Assistant Examiner in Hip, Pelvis Tilt and Lumbar Lordosis -> 검사 전의 골반 경사와 검사 중에 관골 후방 경사가 일어나는 정도를 고려해야 정확한 검사가 가능하다.(논문에서는 골반을 아예 고정시켜야 햄스트링 단축을 확인할 수 있다는 결론)
## 6. 예시 검사 ③ — FABER Test
- 목적: 고관절 외회전·외전 가동성, 천장관절 끼임 여부
- LPHC 변수 영향:
  - 전방경사 제한, 후방경사 변위에 외회전이 제대로 나타나지 않음 → 내회전 근육이 당겨져 있기에 외회전 가동성 제한처럼 보임
  - 후방경사 과도에 외회전, 외전이 과하게 나타남 -> 외회전 근육의 단축이 아니어도 가동성 과다처럼 보임
-> 하지만 치료에 있어서는 외회전, 외전 근육이 골반 경사에 영향을 준 것이든, 골반 경사가 근육에 영향을 끼쳤든 근육을 치료포인트로 가져갈 수 있기에 함께 치료할 수  있음. 

## 7. 그럼 대체 어떻게 해야할까..  – LPHC 상태 기반 맞춤 검사
- 같은 검사도 환자별 골반 구조·가동성·요추 정렬 상태를 먼저 평가해야 함(환자가 적다면 개인 특성을 기록해두고 집중 치료 가능) + 요추에서 기원하는 문제인지, 하지에서 기원하는 문제인지 확인하여 원인을 파악하여 치료에 적용 
- if) 환자가 많거나 초진 환자가 많은 경우 = 요추, 골반 구조적 문제는 촉진, 시진을 통해 시행/ FABER 테스트와 FADIR 테스트를 통해 하지 근육 경결과 요추-골반-고관절 복합체의 가동성 확인해서 치료 진행
- 위 방법을 통해 최대한 위양성/위음성 줄이고, 치료·교정 방향 명확하게 설정 가능

# 8. 활용할 수 있는 촉진 및 시진법 
## 1) PSIS와 ASIS 위치, 대칭성, 돌출 정도 확인
- **방법:** 기립 자세에서 양측 PSIS(후상장골극)와 ASIS(전상장골극)를 촉진해 좌우 대칭, 전후 위치 차이, 상하 높이 차를 확인
- **의미:**
    - 전방경사형: ASIS가 PSIS보다 현저히 하방, PSIS가 덜 돌출
    - 후방경사형: ASIS와 PSIS 높이차 감소, PSIS 돌출 증가
    - 비대칭: 골반 회전, 장골 높이 차, 천장관절 부정렬 가능성
## 2) 요추 전만 정도, 측굴 
- **방법:** 시진으로 요추 전만의 깊이와 곡률 확인, 손끝으로 극돌기 라인을 따라 촉진
- **의미:**
    - 과도한 전만: 전방경사·PI 증가 가능성, 장요근 단축 경향
    - 전만 감소: 후방경사·PI 감소 가능성, 슬괵근 단축 또는 복부근 과활성
    - 측굴 관찰 시 한쪽 기립근 긴장 증가나 골반 높이 차 파악 가능
## 3) 관골 잡고 앞뒤로 흔들기 
- **방법:** 양측 장골능(iliac crest) 또는 ASIS, PSIS를 손으로 잡고, 환자 골반을 전방·후방으로 움직이게 하거나 검사자가 수동으로 가동
- **의미:**
    - 전방·후방 경사 범위의 제한 여부 파악
    - 한쪽만 잘 움직이거나 제한 시, 해당측 천장관절·고관절 기능 제한 가능성
    - 경사 시 요추 전만 변화 패턴도 함께 관찰 → PI 해석에 참
## 4) 시진을 통한 PI의 대략적인 확인법 
- **ASIS–PSIS 상하 위치 차 촉진:** 기립 시 높이 차가 크면 PI 클 가능성, 작으면 PI 작을 가능성
- **PSIS~대퇴골두 거리 촉진:** 대퇴 외회전 시 대퇴골두 중심 위치를 잡아 PSIS와 거리 측정 → 거리가 멀면 PI 크고, 짧으면 PI 작음
- **천골 상연(S1 상연) 경사 촉진:** PSIS 내측에서 천골 기저면의 기울기 확인 → 기울기 크면 PI 큼
- **기립 시 전만-경사 연계 관찰:** 골반 전방경사 시 요추 전만이 즉각적으로 커지면 PI 작을 가능성, 변화가 적으면 PI 클 가능성(PI가 큰 경우는 이미 요추 전만이 만들어져 있기 때문)
- 시상면 관찰: 시상면에서 둔부에서 가장 돌출된 부위와 무릎 중심점을 잇는 선과 허벅지 중간축선 사이의 각도를 확인하여 각도가 크면 PI가 큰 것으로 추정
