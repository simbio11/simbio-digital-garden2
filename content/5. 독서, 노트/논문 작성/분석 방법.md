개요: 본 연구에서 사용한 각 분석 방법에 대해 적용 대상, 분석 목적, 전제 조건, 해석 방식까지 상세히 정리하였다. 변수 성격에 따라 적절한 분석 기법을 선택하였으며, 분석 결과의 해석 기준 또한 병기하였다.

## 독립표본 t검정 (Independent Samples t-test)

- 적용 대상: 지식 점수(B총), 정책 태도(D1, D3), 진료 인식 점수(C1)
- 분석 목적: 전공자(한의대생)와 비전공자(일반대학생) 간 평균 점수 차이가 통계적으로 유의미한지를 검정
- 전제 조건: 두 집단은 서로 독립된 표본이어야 하며, 종속변수는 정규성을 만족하고 등분산성을 전제로 한다 (정규성 검정: Shapiro-Wilk, 등분산 검정: Levene's Test)
- 해석 방식: p값이 0.05 미만일 경우, 두 집단 간 평균 차이는 통계적으로 유의함. 함께 제시되는 평균, 표준편차, t값으로 효과 방향과 크기 판단 가능

## 일원분산분석 (One-way ANOVA)

- 적용 대상: H1b - 학년에 따른 지식 점수(B총) 비교
- 분석 목적: 1학년~4학년까지 4개 이상의 독립 집단 간 평균 차이가 유의미한지를 검정
- 전제 조건: 각 집단의 데이터는 정규분포를 따르며 등분산성을 만족해야 함
- 해석 방식: ANOVA에서 F값과 p값이 제시되며, p < 0.05일 경우 적어도 한 집단 이상이 통계적으로 유의한 평균 차이를 가짐. 사후검정(Tukey HSD 등)을 통해 어떤 집단 간 차이가 유의한지 추가 확인
    

## 단순 선형 회귀분석 (Simple Linear Regression)

- 적용 대상: H1b (학년 → 지식), H4 (지식 → 정책 태도(D1, D4))
- 분석 목적: 한 연속형 독립변수가 종속변수에 미치는 영향을 검정하고 예측 가능성을 평가
- 전제 조건: 독립변수와 종속변수 모두 연속형이며, 두 변수 간 선형 관계가 존재해야 함. 잔차 정규성, 등분산성, 독립성 등의 회귀 가정 필요
- 해석 방식: 회귀계수 β, 결정계수 R², p값을 함께 제시. β값은 독립변수가 종속변수에 미치는 방향과 영향력의 크기를 나타내며, p < 0.05일 경우 회귀계수는 유의미함

## Pearson 상관분석 (Pearson Correlation)

- 적용 대상: H4 - 지식 점수(B총)와 정책 태도(D1, D4)의 상관 관계
- 분석 목적: 두 연속형 변수 간 선형적 관계(동시 증감 또는 반비례)를 검정
- 전제 조건: 두 변수는 연속형이며 정규분포를 따름
- 해석 방식: 상관계수 r은 -1.0 ~ 1.0 범위의 값을 가지며, 값이 클수록 선형 관계 강함. p < 0.05일 경우 상관관계가 통계적으로 유의함. 예: r = 0.42, p = .003 → 정적 중간 상관
    

## 교차분석 (Chi-square Test)

- 적용 대상: C2, C3 (전공별 진료 인식), D2 (전공별 정보 제공 수단 선호)
- 분석 목적: 두 범주형 변수 간 분포 차이가 통계적으로 유의미한지를 검정
- 전제 조건: 두 변수 모두 명목형 또는 범주형이며, 기대도수(expected count)가 충분히 확보되어야 함
- 해석 방식: 카이제곱 통계량(χ²)과 자유도(df), p값을 함께 제시. p < 0.05일 경우 분포 차이가 유의미함. 셀별 관찰값과 기대값의 차이를 통해 특정 선택지에서의 집단 차이 해석 가능
