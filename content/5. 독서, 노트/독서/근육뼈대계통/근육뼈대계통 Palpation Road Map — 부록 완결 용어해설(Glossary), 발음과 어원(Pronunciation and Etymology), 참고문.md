## **1. 용어해설 (Glossary of Terms) — A~V 전수 정리 (PDF pp.481–482 / 인쇄면 pp.470–471)**

### ---

**1.1 해부학·운동학·촉지 핵심 용어해설 전체 일람표 (PDF pp.481–482 / 인쇄면 pp.470–471)**

| 용어 (한글 / 영문, 구용어) | 원문 정의 및 해설   |
| :---- | :---- |
| **배 (abdomen, 복부)** | 가로막(횡격막)과 골반 사이의 영역 |
| **절구 (acetabulum, 관골구)** | 볼기뼈(관골) 바깥면의 둥근 공간; 엉덩관절(고관절)을 형성하기 위해 넙다리뼈머리(대퇴골두)는 절구(관골구)와 관절한다 |
| **유착 (adhesion, 유착)** | 연루된 구조들의 정상적 탄력성을 제한하는 외상 후의 고정이나 수술의 합병증으로 주변조직에 아교섬유(교원섬유)들이 비정상적으로 유착되는 것 |
| **해부학적 자세 (anatomical position)** | 얼굴은 정면을 향하고 양팔은 몸통 옆에 두고, 아래팔(전완)은 뒤침(회외)하고(손바닥이 정면을 향한 것), 손가락과 엄지는 폄(신전)된 상태의 기립자세 |
| **대항근 (antagonist)** | 작용근과 협동근의 반대 작용을 수행하는 근육 |
| **팔꿈치앞 (antecubital, 전주)** | 팔꿈치(주관절)의 앞면 |
| **앞 (anterior, 전방)** | 앞면 또는 배쪽면을 향하고 있는 |
| **골반의 앞쪽기울임 (anterior tilt of pelvis, 골반의 전방경사)** | 위앞엉덩뼈가시들(ASISes, 전상장골극들)을 통과하는 수직면이 두덩결합(치골결합)을 통과하는 수직면의 앞에 놓이기 위해 기울어지는 것 |
| **팔다리 (appendage, 부속지)** | 팔과 다리와 같이 신체에 부착되는 구조 |
| **위팔 (arm, 상완)** | 어깨관절(견관절)과 팔꿉관절(주관절) 사이의 팔 부분 |
| **관절학 (arthrology)** | 관절에 대한 연구 |
| **관절면 (articular facet)** | 뼈, 특히 척추뼈의 작은 관절면 |
| **관절돌기 (articular process)** | 척추뼈의 활에서 발견되는 한 쌍의 작고 편평한 돌출로서 관절면을 포함하고 있다 |
| **관절 (articulation)** | 뼈들의 관절 또는 연결 |
| **고리뼈 (atlas, 환추)** | 첫째목뼈로서 뒤통수뼈(후두골)와 관절하고 중쇠뼈(축추)의 치아돌기를 중심으로 돌림을 함 |
| **중쇠뼈 (axis, 축추)** | 둘째목뼈 |
| **양쪽 (bilateral)** | 양쪽 다 관계된 것 |
| **윤활주머니 (bursa, 활액낭)** | 두 구조들 사이에서 마찰을 감소시키는 체액으로 차 있는 작은 주머니 |
| **연골관절 (cartilaginous joint)** | 연골에 의해 두 뼈의 관절면들이 연결되는 관절; 2가지 종류에는 유리연골결합(synchondroses)과 섬유연골결합(symphyses)이 있음 |
| **꼬리쪽 (caudal, 미측)** | 아래쪽, 머리에서 먼 쪽 |
| **머리쪽 (cephalic, 두측)** | 머리 쪽을 향하는 |
| **아교질 (collagen, 교원질)** | 결합조직섬유들의 단백질 |
| **동심성수축 (concentric contraction, 구심성수축)** | 수축 동안 근육의 짧아짐; 등장성 운동의 유형 |
| **관절융기 (condyle, 과)** | 뼈의 맨 끝에 있는 둥근 관절면 |
| **결합조직 (connective tissue)** | 바탕질과 섬유성 조직들로 구성된 인체의 지지조직들로 많은 다양한 형태가 있음 |
| **수축 (contraction)** | 전체 길이의 변화가 있는 또는 없는 상태에서의 근장력 변화 |
| **관상 (coronal) / 이마면 (frontal plane, 전두면)** | 시상면에 수직인 평면으로 신체를 앞쪽과 뒤쪽으로 나누며 이마면(전두면)/관상면이라 함 |
| **관상축 (coronal axis)** | 좌우로 뻗어 있는 수평선으로 이 축에 대해 굽힘(굴곡)과 폄(신전) 움직임이 일어남 |
| **머리쪽 (cranial, 두측)** | 위쪽, 머리 쪽을 향하는 |
| **다리 (crural)** | 종아리(하퇴)나 넙다리(대퇴)가 있는 곳 |
| **깊은 (deep, 심부)** | 신체 표면에서 먼 곳; 얕은(표층)의 반대 |
| **먼쪽 (distal, 원위)** | 정중선이나 중심 또는 가슴(흉곽)에서 먼 곳 |
| **등쪽 (dorsal, 배측)** | 뒤쪽에 관한 것; 뒤쪽 |
| **편심성근수축 (eccentric muscle contraction, 원심성근수축)** | 작업부하에 대한 수축 또는 저항 동안 근육의 길이가 길어지는 것 |
| **부종 (edema)** | 신체 조직이 과도한 양의 체액을 가지고 있는 국소적 또는 광범위한 상태 |
| **면 (facet)** | 작은 평면 또는 오목한 면 |
| **근막 (fascia)** | 성긴(소성) 또는 치밀섬유성결합조직의 층 또는 층들을 이르는 일반적인 용어 |
| **섬유관절 (fibrous joint)** | 뼈들이 섬유조직에 의해 연결되는 관절 |
| **유연성 (flexibility)** | 자세나 정렬의 변화에 쉽게 적응하는 능력; 정상적인, 제한된, 또는 과도한으로 표현됨 |
| **아래팔 (forearm, 전완)** | 팔꿉관절(주관절)에서 손목관절(수관절) 사이의 팔 부분 |
| **밖굽이무릎 (genu valgum, 외반슬)** | "충돌무릎(knock-knees)", 관절을 구성하는 뼈들 중 먼쪽(원위) 뼈의 먼쪽끝 부위가 가쪽으로 이동한 것 |
| **안굽이무릎 (genu varum, 내반슬)** | "활모양 다리(bow-legs)", 관절을 구성하는 뼈들 중 먼쪽(원위) 뼈의 먼쪽끝 부위가 안쪽으로 이동한 것 |
| **부딪힘 (impingement, 충돌)** | 신경이나 근육과 같은 연부조직이 차지하고 있는 공간에 대한 침범 |
| **아래쪽 (inferior, 하방)** | 머리에서 먼쪽 |
| **닿는곳 (insertion, 정지)** | 좀 더 가동적인 근육의 뼈 부착부위; 반대쪽 끝은 이는곳(기시) |
| **사이질 (interstitial, 간질) / 사이질액 (interstitial fluid, 간질액)** | 기관이나 조직 내의 공간 / 세포를 에워싸는 체액 |
| **등척성 (isometric)** | 근길이가 변하지 않는 장력에서의 증가 |
| **등장성 (isotonic) / 등장성수축(동적) [isotonic contraction (dynamic)]** | 근길이가 변하는 장력에서의 증가(짧아지면 동심성, 길어지면 편심성 수축; 움직임을 수행하는 근육 수축) |
| **운동학 (kinesiology)** | 움직임의 연구 |
| **뒤굽음증 (kyphosis, 후만증)** | 측면에서 관찰했을 때 등뼈(흉추)의 볼록한 만곡이 비정상적으로 증가된 상황 |
| **가쪽 (lateral, 외측)** | 정중선에서 먼쪽 |
| **가쪽기울임 (lateral tilt, 외측경사)** | 엉덩뼈능선(장골능)이 다른 쪽에 비해 한쪽이 더 높은 골반의 기울임 |
| **종아리 (leg, 하퇴)** | 무릎관절(슬관절)에서 발목관절(족관절) 사이의 다리 부분 |
| **인대 (ligament)** | 뼈와 뼈를 연결하는 섬유성결합조직 |
| **세로축 (longitudinal axis, 장축)** | 머리쪽(두측)에서 꼬리쪽(미측)으로 뻗어 있는 수직선으로, 이 축에 대해 돌림 움직임이 일어남 |
| **앞굽음증 (lordosis, 전만증)** | 측면에서 관찰했을 때 허리뼈(요추)의 오목한 만곡이 비정상적으로 증가된 상황 |
| **림프절 (lymph node) / 림프의 (lymphatic)** | 림프관을 따라 위치하고 있는 계란형의 작은 구조 / 체액(림프)의 배출에 연루된 관들의 계통에 속하는 것 |
| **안쪽 (medial, 내측)** | 정중선 쪽을 향하는 |
| **근육 (muscle) / 근수축 (muscle contracture) / 근막 (myofascial)** | 수축을 위해 특수화된 3가지 근조직(뼈대근, 심장근, 내장근) 중 하나로 구성된 기관 / 수축성 기전 활성으로 유발된 장력 증가 / 섬유성결합조직으로 싸고 있는 근조직의 일부 |
| **뒤통수관절융기 (occipital condyles, 후두과)** | 큰구멍(대후두공) 양 측면에 있는 뒤통수뼈(후두골) 밑면의 계란형 긴 관절면으로 고리뼈(환추)와 관절함 |
| **치아돌기 [odontoid process (or dens), 치돌기]** | 중쇠뼈몸통(축추체)으로부터 위쪽으로 돌출되어 나온 돌기로, 이 돌기를 중심으로 고리뼈(환추)는 돌림함 |
| **이는곳 (origin, 기시)** | 좀 더 고정적인 근육의 뼈 부착부위; 반대쪽 끝은 닿는곳 |
| **손바닥쪽 (palmar, 장측)** | 손바닥 쪽을 향하는 |
| **촉지 가능한 (palpable) / 촉지하다 (palpate)** | 접촉할 수 있는, 접근 가능한 / 대개 진단의 목적으로 신체의 기관이나 영역을 접촉에 의해 검사나 탐색하는 것 |
| **척추옆 (paravertebrals, 부척추)** | 척주의 옆 또는 근처 |
| **다리이음뼈 (pelvic girdle, 골반대) / 골반 기울임 (pelvic tilt) / 골반 (pelvis)** | 2개의 볼기뼈(관골)들 / 중립위치에서 골반이 앞·뒤·가쪽으로 기울임하는 상태 / 2개의 볼기뼈, 엉치뼈, 꼬리뼈로 구성된 것 |
| **뼈막 (periosteum, 골막)** | 뼈의 표면을 감싸고 있는 섬유성결합조직 |
| **뒤쪽 (posterior, 후방) / 골반의 뒤쪽기울임 (posterior tilt of pelvis, 후방경사)** | 뒤면 또는 등쪽면 쪽을 향하는 / 위앞엉덩뼈가시들을 통과하는 수직면이 두덩결합을 통과하는 수직면의 뒤쪽에 놓이기 위해 기울어지는 것 |
| **작용근 (prime mover, 주동근)** | 동작을 수행하는 근육 |
| **몸쪽 (proximal, 근위)** | 신체의 정중선이나 중심에 가까운 |
| **가동범위 (range of motion, 능동 active / 수동 passive)** | 관절이 움직일 수 있는 범위(도 degree로 표시; 근수축에 의한 능동가동범위와 외력에 의한 수동가동범위) |
| **지지띠 (retinaculum, 지대)** | 대개 결합조직의 띠에 속하는 망상구조 |
| **시상축 (sagittal axis) / 시상면 (sagittal plane)** | 앞쪽에서 뒤쪽으로 뻗어 있는 수직선(벌림·모음 움직임 축) / 신체를 오른쪽과 왼쪽으로 나누는 평면 |
| **종자뼈 (sesamoid, 종자골)** | 뼈 표면 위에서 힘줄(건)의 지레 역할을 하는 뼈나 섬유연골 |
| **연부조직 (soft tissue)** | 대개 근막조직을 말하거나, 미네랄(가령, 뼈)을 함유하고 있지 않은 어떤 조직들 |
| **얕은 (superficial, 표층) / 위쪽 (superior, 상방)** | 신체 표면에 가까운 곳(깊은의 반대) / 머리 쪽을 향하는 |
| **장딴지 (sural, 비복) / 표면해부학 (surface anatomy)** | 종아리의 장딴지(calf)에 해당하는 곳 / 신체의 표면에서 확인할 수 있는 구조들의 연구 |
| **섬유연골결합 (symphysis, 결합) / 유리연골결합 (synchondrosis, 연골결합)** | 섬유연골에 의해 형성된 두 뼈들 사이의 연결 / 유리연골(초자연골)이나 섬유연골에 의해 형성된 두 뼈들 사이의 연결 |
| **협동근 (synergist)** | 주동근(작용근)을 지지하는 근육 |
| **윤활관절 (synovial joint, 활막관절)** | 윤활물질(활액)을 함유하고 있으며 안쪽이 윤활막이나 윤활주머니로 된 관절 |
| **촉각 (tactile) / 힘줄 (tendon, 건)** | 접촉에 속하는 것 / 뼈대근육(골격근)을 뼈에 연결하는 섬유성조직 |
| **넙다리 (thigh, 대퇴) / 가슴 (thorax, 흉곽) / 몸통 (trunk, 체간)** | 엉덩관절과 무릎관절 사이의 다리 부분 / 목과 배 사이의 영역 / 팔과 다리가 부착된 신체의 일부 |
| **타이트니스 (tightness, 단축)** | 근길이의 경도에서 중등도의 감소를 의미; 근육이 길어지는 방향으로의 움직임이 감소됨 |
| **가로면 (transverse plane, 횡단면)** | 인체를 위쪽과 아래쪽(또는 몸쪽과 먼쪽)으로 나누는 평면 |
| **한쪽 (unilateral, 편측) / 배쪽 (ventral, 복측)** | 한쪽에 관계된 것 / 앞쪽의 동의어, 대개 몸통에서 사용됨 |
