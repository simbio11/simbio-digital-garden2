## 1. 개요 및 마스터 요약 (Executive Summary)

1. **선천성 흉곽 기형 (Plates 4-1)**: 오목가슴(Pectus excavatum)은 하부 흉골·늑연골의 함몰로 검상돌기-흉골체 접합부가 최저점이며, 원인은 불명이나 늑연골 부위의 **불균형 성장(unbalanced growth)**이 가장 유력한 설명이다. 증상은 매우 드물지만 자세 이상·기능성 심잡음·우축 편위 ECG를 동반하고, 증상 또는 유의한 진행 시 **3~7세에 수술(늑연골 절제 + 흉골 골절개 + 내고정)**하는 것이 결과가 가장 좋다. 함몰가슴(Pectus carinatum)은 빈도가 약 $1/10$이며 수술의 주된 이유는 미용이다.
2. **척추후측만증과 심폐부전의 연쇄 (Plates 4-2, 4-3)**: 중증 척추 기형 → 흉곽 순응도 저하 → 호흡일 증가 → **빠르고 얕은 호흡** → 만성 폐포 저환기 → 동맥 저산소혈증·고탄산혈증·호흡성 산증 → 제한된 폐혈관상과 저산소성 폐혈관수축에 의한 폐고혈압 → **폐성심(Cor pulmonale)**. 만성 고탄산혈증 환자는 $CO_2$ 자극에 둔감해져 말초 화학수용체의 저산소 구동에 의존하므로, 치료 시 고농도 산소와 호흡억제제를 모두 피해야 한다.
3. **선천성 횡격막 탈장(CDH) (Plate 4-4)**: 보흐달레크공(흉막복막열공, 낭 없음) 탈장이 영아·소아의 약 **90%**, 좌측 85%, 양측 5%. 증상 중증도는 **폐 저형성 정도**가 결정하며, 생존율 약 60%로 사망은 폐 저형성·폐고혈압에 기인. 소생 시 **bag-mask 금지(탈출 장관 가스 팽창 방지)**, 비위관 저압 흡인, 그리고 수술 전 **주술기 안정화**가 사망률과 ECMO 필요를 줄인다.
4. **기도·폐의 선천성 기형 (Plates 4-5 ~ 4-9)**: 기관식도누공은 상부 맹낭 + 하부 기관 누공형이 **90~95%**로 최빈도이고 진단은 조영제 대신 **방사선 불투과 카테터 통과(T2-T3 높이에서 멈춤)**로 한다. 폐 발달 정지의 3단계(무발생-무형성-저형성)는 기관지·혈관·실질의 잔존 여부로 구분되며, 폐엽내·폐엽외 **폐 격리증**은 체동맥(대개 대동맥)에서 혈액을 받고 각각 폐정맥·체정맥으로 배액된다는 점이 결정적 차이다.
5. **만성 기침의 체계적 접근 (Plate 4-10)**: 기침은 흉강 내 압력 $300\ \text{mmHg}$까지, 호기 속도 $28{,}000\ \text{cm/sec}$(음속의 85%)까지 도달해 요실금·늑골 골절·실신 등 합병증을 만든다. 진단의 두 축은 **기침 반사의 구심성 신경해부(해부학적 진단 접근)**와 **지속 기간 분류(급성 $<3$주, 아급성 $3\sim8$주, 만성 $>8$주)**이며, 만성 기침의 대표 원인은 상기도 기침 증후군($28\sim41\%$), 천식($24\sim33\%$), GERD($10\sim21\%$)이고 최소 20%는 여러 질환이 동시에 기여한다.
6. **후두 병변과 성대 기능부전 (Plates 4-11 ~ 4-13)**: 성대 결절·폴립·낭종은 고유판 천층(Reinke space)의 외상성 염증 병변, 후두 육아종은 **기관내삽관**이 가장 흔한 원인(종종 자연 퇴행), 재발성 호흡기 유두종증은 HPV 수직 감염에 의한 이봉 분포(5세 미만, $20\sim30$세) 질환이다. VCD는 **흡기 시 역설적 성대 내전**으로 천식과 달리 흡기성 천명·유량-용적 곡선의 흡기 유량 감쇠·"saw-tooth" 양상을 보인다.
7. **천식의 정의와 진단 (Plates 4-14 ~ 4-20)**: 천식은 **가변적 기류 폐쇄 + 기도 과반응성 + 세포성 염증**의 임상 증후군(유병률 $5\sim15\%$). 진단은 $FEV_1$ 및 $FEV_1/FVC$ 감소의 가역성($\beta_2$-작용제 후 $FEV_1 >12\%$ 개선 + 최소 200 mL, 또는 PEF 변동 $>20\%$)으로 확립하며, 경증 천식에서는 증상이 비특이적이므로 "천명하는 모든 것이 천식은 아니다"를 명심해야 한다.
8. **천식의 병인·병리·치료 (Plates 4-21 ~ 4-27)**: 5q31-33의 Th2 사이토카인 군집(IL-4, IL-5, IL-13, GM-CSF), 11q(FcεRIβ), 20p13(ADAM33)이 관여하고, Th2 편향 면역 반응이 IL-4/IL-13로 B세포의 IgE class switch를, IL-5로 호산구를 유도한다. 병리적으로 기도벽 두께가 치사성 천식에서 $50\sim300\%$ 증가하고 점액 마개·배상세포 증식·기저막 비후가 나타나며, 치료는 단계별로 저용량 ICS → ICS+LABA → 고용량/경구 스테로이드·오말리주맙으로 올라가고 급성 악화에서는 $\beta_2$-작용제 반복 흡입 + 전신 스테로이드가 기본이다.

## 2. 플레이트별 정밀 분석 (Plates 4-1 ~ 4-27)

### Plate 4-1 | 선천성 흉곽 기형 (Congenital Deformities of the Thoracic Cage)
![[Netter_V3_Plate4-1.png]]
- **오목가슴(Pectus excavatum, funnel chest) 개요**: 검상돌기·흉골체 접합부를 최저점으로 하부 흉골과 인접 늑연골이 함몰되는 전흉벽 기형. 별칭은 funnel chest, chonechondrosternon, trichterbrust. **유전되는 형질**이며 만곡족(clubfoot), 합지증(syndactyly), 클리펠-파일 증후군(Klippel-Feil syndrome) 등 근골격 기형과 공존할 수 있다.
- **병태생리**: 원인은 여전히 불명확하다. 짧은 중심건과 횡격막의 근육 불균형이 지목되어 왔고, 최근 저자들은 **늑연골 부위의 불균형 성장**으로 설명한다.
- **임상**: 증상은 매우 드물고, 오히려 뚜렷한 기형을 가진 소아에서 **심리적 영향**이 문제가 된다. 목·어깨의 전방 변위, 상부 흉추 후만, 복부 돌출 같은 자세 이상이 동반된다. 이들에게 **기능성 심잡음**과 양성 부정맥이 흔하며, 심장 변위로 심전도에서 **우축 편위(right-axis deviation)**가 보일 수 있다. 고령 환자에서는 만성 기관지염·기관지확장증의 빈도가 의미 있게 증가한다.
- **해부 소견**: 함몰은 흉골병-흉골체 접합부에서 시작하고, 검상돌기는 이분되거나 염전·편위될 수 있다. 늑연골은 제2~3연골부터 미측으로 내측 각형성(internal angulation)를 이룬다. 대체로 대칭이나 한쪽이 더 함몰되어 흉골이 정중선에서 벗어나기도 하며, **앙와위에서 함몰부에 물을 채워 함몰 용적(cavitary volume)을 추정**할 수 있다.
- **영상·검사**: 표준 방사선 촬영에서 심장이 좌측으로 편위되고, 측면상으로 흉골체의 후방 변위가 확인된다.
- **치료**: 증상이 있거나 유의한 진행을 보이는 환자에서 수술 교정. 수술의 상당수가 미용 목적이므로 **3~7세에 시행할 때 결과가 가장 좋다**. 술식은 양측 비후 늑연골 절제 + 흉골병-흉골체 접합부 골절개(osteotomy) + 핀/막대를 이용한 내고정(추후 제거). 고령 환자에서는 재발 방지를 위해 금속 지지대나 철사 고정이 필요하며, 초기 과교정에도 어느 정도 재발할 수 있다.
- **함몰가슴(Pectus carinatum, pigeon breast)**: 전흉벽 돌출 기형으로 오목가슴과 무관하고 빈도는 약 $1/10$. 두 가지 주형이 있다. (1) **연골흉골병형(chondromanubrial)** — 검상돌기에서 돌출이 최대이고 흉골체가 후방을 향해 이차적 함몰(saucerization)이 나타남. (2) **연골흉골체형(chondrogladiolar)** — 흉골체 부근에서 가장 돌출. 병인은 오목가슴보다 더 잘 알려져 있지 않으나 연골의 불균형/과성장설이 타당하다. 기능적 심장·호흡 장애가 관찰되기도 하지만 **수술 교정의 주된 이유는 미용**이며, 경미하면 치료가 필요 없다. 수술 시에는 개개 환자의 전반적 생활 상황을 고려해 기형에 맞춘 술식을 선택한다.
- **이분 흉골(Bifid sternum)**: 흉골대(sternal bands)의 융합 실패로 전흉벽 결손이 생긴다. 흉골 분리는 완전/불완전할 수 있고 **심장외위(ectopia cordis)**와 동반될 수 있다. 불완전 결손은 수술 교정 가능하며, 일차적 흉골 분절 봉합이 불가능하면 보철물이나 연골 자가이식을 사용한다.
- **기타 흉벽 기형**: 경부 늑골(cervical ribs, 상완신경총·동맥 압박 동반 또는 비동반), 늑골 부분 결손, 과잉 늑골, 흉곽-골반-지골 이영양증(thoracic-pelvic-phalangeal dystrophy)이 있다.
- **신생아 호흡곤란을 보이는 골격 질환**: 늑골 성장 제한에 의한 폐 성장 이상 — 골연골 이형성증(질식성 흉곽 이영양증, 치사성 왜소증, 상기도 폐쇄를 동반하는 diastrophic dysplasia), 또는 뼈·연골·콜라겐 발달 이상(저인산효소증, 무연골발생증, 골형성부전증)으로 작거나 비정상적인 흉곽이 만들어져 호흡곤란이 발생한다. 도판에는 20주 태아의 치사성 골격 이형성증(thanatophoric dysplasia)에서 보이는 **심한 늑곽 저형성**이 제시된다.

### Plate 4-2 | 척추후측만증 (Kyphoscoliosis)
![[Netter_V3_Plate4-2.png]]
- **개요**: 척추후측만증은 오래전부터 심폐부전의 원인으로 인식되어 왔으나, 임상상·생리학적 측정·부검 해부 소견의 조합을 통해 그 자연사가 명확해진 것은 비교적 최근이다.
- **중증도가 결정적**: 기관지염이나 폐기종 같은 독립적 폐질환이 없다면 **중증 척추 기형 환자만이 심폐부전의 후보**다. 경미한 기형은 일관되게 무증상이며, 중증 기형 — 특히 상당한 왜소증(dwarfing)이 동반된 경우 — 은 노작성 호흡곤란으로 활동이 제한된다. 이들은 상기도 감염이 겹칠 때 심폐부전에 가장 취약하다. 장애와 심폐부전 가능성의 관점에서 기형의 종류(후만/측만/혼합)는 **기형의 중증도와 왜소증에 비해 중요하지 않다**.
- **폐용적 기반 분류**: 총폐용량(TLC), 폐활량(VC), 일회호흡량(TV)이 정상에 가까울수록 무증상으로 남는다. 폐용적이 심하게 감소하면 **폐성심(Cor pulmonale)**의 무대가 준비된다. 진행 정도에 따라 TLC·VC·TV는 점진 감소하고 잔기량(RV)은 상대적으로 증가한다.
- **호흡일과 호흡 패턴**: 압력-용적 곡선으로 추정한 호흡일(work of breathing)은 흉벽 팽창성의 심한 제한에 기인한 과도한 부하를 보인다. 순응도(compliance)가 현저히 감소하기 때문에 환자는 **빠르고 얕은 호흡(rapid, shallow breathing)** 패턴을 무의식적으로 채택한다. 이는 일과 에너지 면에서는 경제적이지만 **사강 환기를 위해 폐포 환기를 희생**한다.
- **가스교환 결과**: 결과적 폐포 저환기는 전도 기도를 과환기하고 폐포를 저환기함으로써 동맥 저산소혈증, 고탄산혈증, 호흡성 산증을 초래한다. 따라서 무증상 척추후측만증 환자는 동맥혈가스가 정상인 반면, 중증 환자는 청색증과 함께 저산소혈증·고탄산혈증을 보인다. 두 극단 사이에는 노작성 호흡곤란을 호소하며 가스수치가 위험 경계에 머무는 환자군이 있고, 이들은 기관지염이나 폐렴 한 차례로 심폐부전에 빠진다.
- **폐동맥압과 폐고혈압**: 무증상자에서는 안정 시 폐동맥압이 정상이고 운동 시 임상적으로 무의미한 수준으로만 상승한다. 반면 중증 환자는 안정 시에도 높고 가벼운 운동에도 급격히 상승한다. 기전은 두 가지다 — (1) 기형이 폐와 폐혈관을 압박·왜곡해 생기는 **폐혈관상의 제한**, (2) **저산소증의 폐압 상승 효과**. 운동 시에는 제한된 혈관상으로의 폐혈류 증가와 운동 유발 저산소증에 의한 폐혈관수축이 겹쳐 두 효과가 최대로 나타난다. 부검에서 우심실 확대가 확인된다.
- **상기도 감염의 위험**: 상기도 감염 시 동맥 저산소증의 폐압 상승 효과가 충분히 심해져 폐동맥압이 매우 높아지고 우심실부전이 촉발될 수 있다.
- **고탄산혈증의 두 얼굴**: 만성 폐포 저환기로 지속적 폐고혈압이 생긴 환자에서는 고탄산혈증이 항상 동맥 저산소혈증과 동반된다. 고탄산혈증은 유발하는 호흡성 산증을 통해 폐고혈압에 기여하는데(산증이 저산소증과 상승작용하여 폐혈관수축), 그 주된 효과는 심장·순환보다 **중추신경계**에 있다. 만성 고탄산혈증 자체는 일반적으로 임상적 발현이 없다.

### Plate 4-3 | 척추후측만증의 폐기능 (Pulmonary Function in Kyphoscoliosis)
![[Netter_V3_Plate4-3.png]]
- **화학적 구동에 대한 둔감**: 만성 고탄산혈증이 있는 척추후측만증 환자에서는 흡입 $CO_2$에 대한 환기 반응이 무증상자나 비고탄산혈증 환자에 비해 저하되어 있고, 이는 호흡의 주요 화학적 자극에 대한 반응성 손상을 반영한다. 그 대가로 **말초 화학수용체를 통한 저산소 구동(hypoxic drive)에 더 크게 의존**하게 된다. 도판의 그래프에서 5% $CO_2$ 흡입 시 분당환기 증가는 정상 $200\sim400\%$인 데 비해 중증도에 따라 $+327\%$, $+161\%$, $+81\%$로 감소한다.
- **급성 고탄산혈증의 신경학적 파국**: 상기도 감염 중 급성 고탄산혈증이 발생하거나 기존 고탄산혈증이 심해지면 인격 변화, 통상적 자극에 대한 무반응, 혼수로 진행할 수 있다. 동반되는 변화는 뇌혈관 확장, 뇌부종, 뇌척수액압 상승이며, 두개내압 상승이 심하면 **시신경유두 욕혈로 뇌종양을 모방**한다.
- **내인성 폐질환의 증폭 효과**: 합병증이 없는 척추후측만증의 모든 장애는 내인성 폐질환에 의해 크게 악화된다. 따라서 **흡연과 그에 따른 기관지염은 호흡부전 위험을 높이고, 폐렴은 치명적일 수 있다**.
- **병인 연쇄의 재구성**: 중증 흉곽 기형 → 흉곽 순응도와 폐 팽창 감소 → 호흡일·에너지 비용 급증 → 무의식적 빠르고 얕은 호흡 → 만성 폐포 저환기. 작고 갇힌 폐는 호흡일 증가에 기여할 뿐 아니라 폐혈관상의 용적과 팽창성을 제한한다. 폐동맥 고혈압은 대사에 맞는 정상 폐혈류와 제한된 혈관상 사이의 불균형에서 발생하며, 동맥 저산소혈증이 교정된 뒤에도 적혈구증가증, 고혈량증, 심박출량 증가가 폐고혈압을 유지한다. 최종 결과가 **우심실 확대(폐성심)**이며, 여기에 추가적 폐고혈압 기전 — 특히 상기도 감염 — 이 더해지면 심부전이 촉발된다.
- **고탄산혈증의 내성과 급성 악화**: 고탄산혈증은 동맥 저산소혈증과 항상 동반되며, 폐포 저환기가 급격히 심해지지 않는 한 대체로 잘 견딘다. 그러나 $PaCO_2$의 급성 상승은 중추신경계의 심각한 장애를 유발하고 폐고혈압·우심실부전에 기여한다.
- **응급 치료 원칙**: 치료는 병인 연쇄를 역전시키는 데 목표를 둔다. 대개 상기도 감염이 촉발한 응급 상황에서는 **보조 환기와 약간 농축된 산소 혼합기($\leq 25\sim40\%$)**로 견딜 만한 혈액가스를 달성한다. 만성 고탄산혈증 환자는 $PaCO_2$ 증가에 둔감하고 환기 구동의 상당 부분을 말초 화학수용체의 저산소 자극에 의존하므로 **과도하게 높은 산소 혼합기는 위험**하며, 호흡억제제는 호흡을 완전히 정지시킬 수 있어 역시 위험하다. 항생제와 보조 요법으로 급성 감염 위기를 넘기고, 치료 목표는 급성 삽화 이전의 임상 상태로 회복시키는 것이다. 경도 저산소혈증과 약간의 고탄산혈증이 남는 경우도 있으나, 적절한 치료가 환자를 위기 전 상태로 되돌리는 데 놀라울 정도로 성공적이다.
- **도판 자료**: 폐용적 곡선(TLC·VC·TV의 진행적 감소와 RV의 상대적 증가), 압력-용적 곡선(정상 대 중증 척추후측만증, 증가한 호흡일을 분홍 음영으로 표시), 여러 중증도에서의 $PaO_2$·$PaCO_2$, 5% $CO_2$ 흡입 시 분당환기 증가율, 안정 시·운동 시의 폐동맥압(폐혈류 $L/min/m^2$ 대 평균 폐동맥압 관계).

### Plate 4-4 | 선천성 횡격막 탈장 (Congenital Diaphragmatic Hernia)
![[Netter_V3_Plate4-4.png]]
- **횡격막의 해부**: 흉강과 복강을 나누는 중격으로, 늑골·흉골·요부 기원의 근육·건 요소가 돔 모양을 이룬다. 흉골부는 흉골체 후면에서 기시하는 두 개의 편평대, 늑골부는 최하위 6개 늑골에서 기시하여 복횡근과 교차하며, 요부는 외측·내측 요늑궁에서 기시한다.
- **진성 CDH의 4가지 경로**: 발생학적 결손으로 생기는 진성 선천성 횡격막 탈장은 (1) **흉막복막열공(보흐달레크공)** — 둘러싸는 낭이 없음, (2) 횡격막 돔 부위, (3) **모르가니공**, (4) 좌측 횡격막 반쪽의 무형성에 의한 결손을 통해 발생한다.
- **빈도와 해부**: 가장 흔한 두 형은 보흐달레크공과 모르가니공 탈장이다. 보흐달레크 탈장은 영아·소아 횡격막 탈장의 약 **90%**를 차지하고 좌측이 85%, 양측이 5%다. 좌측에서는 위, 소장·대장 일부, 비장, 신장 상극이 결손을 통해 흉막강으로 탈출하여 흉곽 정점까지 자유롭게 올라갈 수 있다. 환측 폐 성장은 저해되고, 종격동이 건측으로 밀려 그쪽 폐도 압박되므로 **반대측에도 저형성이 올 수 있다**. 도판은 임신 24주의 좌측 보흐달레크 탈장과 그로 인한 좌폐의 심한 저형성·우폐의 중등도 저형성을 보여준다.
- **임상 발현**: 증상의 발현 시기와 중증도는 **폐 저형성의 정도**에 달려 있다. 중증에서는 출생 직후 심한 호흡곤란으로 나타나고 소생이 어렵다.
- **추정 진단**: 출생 직후 청색증·호흡곤란이 나타나면서 **심첨박동(cardiac impulse)의 위치가 비정상**인 경우 의심한다. 흉곽에서 연동음(peristaltic sound)이 들리고 복부는 부드럽고 주상(scaphoid) 모양이다. 현재는 대부분 임신 2~3삼분기의 일상적 초음파로 **산전 진단**된다.
- **영상**: 출생 후 표준 흉부 방사선에서 종격동 이동과 환측의 점유성 병변(예: 좌측 반흉곽을 차지하는 장관 고리)이 보인다.
- **감별 진단**: 신생아 호흡곤란의 다른 원인 — 횡격막 거상(eventration), 폐의 낭성 선종양 기형, 종격동 낭성 기형종, 국소성 수기흉(loculated hydropneumothorax). 우측 탈장은 구역성 허탈이나 흉막삼출과 혼동될 수 있으나, 측면 투영에서 종괴가 **후방에 위치**하고 심장이 이동한 점이 도움이 된다. 확진은 초음파, 비위관 위치, 바륨 식사로 한다.
- **초기 처치**: 분만실에서 소생이 필요한 영아는 **기관내삽관**해야 하며, **bag-mask 소생은 금기**다 — 탈출 장관이 가스로 팽창해 호흡 곤란이 더 악화되기 때문이다. 저압 흡인에 연결된 비위관을 삽입한다. CDH 영아는 기흉 위험이 증가하며 양측 폐가 모두 저형성이므로 어느 쪽에도 기흉이 생길 수 있다.
- **수술 시점과 예후**: 과거에는 흉강 내 장관 제거와 결손 봉합으로 폐 팽창이 이루어져 가스교환이 개선되리라 기대하며 출생 직후 교정을 가정했으나, 연구들은 **주술기 안정화 기간**이 사망률과 체외막산소화(ECMO) 필요를 감소시킴을 입증했다. 생존율은 약 **60%**이고 사망 원인은 폐 저형성, 폐고혈압 또는 둘 다다. 추적 관찰에서는 재탈장, 위식도 역류, 폐기능 이상, 청소년기에도 운동 불내성이 나타날 수 있다.
- **태아기 중재**: 자궁 내 탈장 교정 시도는 유망하지 않았다. 태아 폐액의 정상적 유출을 막으면 폐가 커지고 탈출 내장이 줄며 폐 성장이 촉진된다는 실험 모델 발견에 근거해 **기관의 일시적 폐쇄**(외부 클립, 최근에는 내부 풍선 마개)가 시행되었고, 장기 결과 개선 여부는 적절히 설계된 무작위 시험으로 판정해야 한다.
- **모르가니공 탈장**: 전방 흉골주위 부위(Laney space)의 선천 결손으로 생긴다. 대개 우측이고 주로 **간과 대망**이 포함되며, 심낭낭종(pericardial cyst)과 감별해야 한다. **칸트렐 오징(pentalogy of Cantrell)의 일부**로 나타날 수 있다. 전방 탈장은 신생아기에 대개 무증상이지만 흉부 방사선에서 우연히 발견되면, 복강 장기의 교액(strangulation)이 생길 수 있으므로 교정해야 한다.

### Plate 4-5 | 기관식도누공과 기관 기형 (Tracheoesophageal Fistulas and Tracheal Anomalies)
![[Netter_V3_Plate4-5.png]]
- **개요와 분류**: 기관식도누공(TOF)과 식도폐쇄는 각각 독립 질환으로는 드물고 다양한 조합으로 나타난다 — 식도폐쇄 + 상부 누공, 하부 누공, 이중 누공. 식도폐쇄 영아의 약 **10%는 누공이 없고** 식도 분절 사이에 긴 간격(long gap)이 있다. 식도폐쇄 없이 **고립성 기관식도누공(H형 또는 N형 누공)**이 생길 수 있다. 원인은 잘 알려져 있지 않고, 식도폐쇄는 대개 산발적이며 드물게 가족성이다.
- **산전·출생 후 단서**: 모체 양수과다증(polyhydramnios)과 산전 초음파에서 태아 위 거품(gastric bubble)이 작거나 없는 것이 식도폐쇄를 시사한다. 출생 후에는 점액이 과다하고 분비물을 제대로 처리하지 못하는 신생아에서 의심한다. 흡인은 일시적 완화만 주고 분비물은 계속 축적·넘쳐 흡인과 호흡곤란을 일으킨다. 수유도 역류·흡인된다. **TOF는 호흡 기체와 위 팽창에 낮은 저항 경로를 제공**하며 이후 파열되면 환기가 더 악화된다.
- **진단**: 과거에는 바륨이나 Gastrografin(메글루민 디아트리조에이트) 조영 검사로 진단했으나 이 물질을 폐로 흡인할 위험이 있다. 현재는 비강이나 구강을 통해 **상당히 큰 방사선 불투과성 플라스틱 카테터**를 맹낭까지 통과시킨다. 카테터가 위로 진행되지 않으면 그 자리에 고정하고 지속적 약한 흡인에 연결해 맹낭을 타액으로부터 청결하게 유지하고 흡인성 폐렴 가능성을 최소화한다. 흉부 방사선에서 카테터 끝은 대개 **제2~3흉추(T2-T3) 높이**에 위치한다. 조영 검사가 선호되면 **0.5 mL 이하**의 조영제를 직립 자세에서 카테터로 주입하고, 전형적 식도 폐쇄를 확인한 뒤 즉시 흡인해야 한다.
- **초기 관리와 수술**: 근위 맹낭에 **10-Fr 이중 내강 Replogle 관**을 넣고 지속적 저압 흡인으로 기도를 분비물에서 자유롭게 유지한다. 이상적 술식은 누공 절단과 **식도의 단단문합(end-to-end anastomosis)**이다. 식도 분절 사이 긴 간격이 있으면 **최대 3개월까지 수술을 지연**하여 맹낭이 늘어나고 비후되도록 하며, 그 동안 위루(gastrostomy)를 통해 수유하고 상부 맹낭을 분비물에서 청결하게 유지한다.
- **기관 기형·협착**: 기관 기형은 매우 드물다. 기관 협착이 있으면 공기 통과가 국소적으로 막힌다. **연골이 없으면 기관이 허탈되어 호기 시 폐쇄**되고, **연골 변형이 있으면 흡기·호기 모두에서 폐쇄**된다. 비정상 분기(abnormal bifurcation)가 있으면 우상엽 또는 좌상엽 기관지(또는 둘 다)가 기관에서 독립적으로 기시한다.
- **임상 형태와 진단**: 임상적으로 협착은 국소성과 미만성으로 나뉜다. 국소성은 호흡 점막의 막(web)이나 기관 연골의 과성장으로 생긴다. 미만성은 기관에서 연골과 연골환 사이 **탄성 섬유조직의 선천적 결여** 또는 연골 결여로 생긴다. 기관 폐쇄는 만성 호흡곤란, 청색증(특히 운동 시), 반복적 호흡기 감염을 일으키며, 진단은 **기관지경과 방사선 촬영**으로 확립한다.
- **치료**: 국소 폐쇄는 확장술 또는 절제 후 단단문합의 수술이 바람직하다. 기관 절제·문합은 **최대 6개의 기관 연골환**까지 가능하다. 전반적 협착(generalized stenosis)에는 보조 요법만 가능하다.
- **도판 소견**: A 기관식도누공. B 누공의 변형과 희귀 기관 기형 — **최흔형(90~95%)은 상부 식도가 맹낭으로 끝나고 하부 식도가 분기부 직상방 기관에서 기시**하며 두 분절이 고형 색(solid cord)으로 연결될 수 있다. C 이중 누공(상부 식도가 기관에 끝나고 하부 식도 길이는 다양). D 식도폐쇄 없는 누공. E 누공 없는 식도폐쇄. F 기관 무발생(치사). G 기관 협착(web, hourglass, 흡기/호기). H 연골 결여. I 연골 변형. J 분기 이상.

### Plate 4-6 | 폐 무발생·무형성·저형성 (Pulmonary Agenesis, Aplasia, and Hypoplasia)
![[Netter_V3_Plate4-6.png]]
- **3단계의 발달 정지**: (1) **무발생(agenesis)** — 한쪽 또는 양쪽 폐가 완전히 없고 기관지·혈관 공급·실질 조직의 흔적도 없다. (2) **무형성(aplasia)** — 흔적적인 기관지만 남아 맹낭으로 끝나며 폐혈관과 실질이 없다. (3) **저형성(hypoplasia)** — 폐 발달이 불완전해 무게와 용적이 작고, 기도 분지·폐포·동맥·정맥의 수가 감소한다.
- **역학**: 폐 무발생의 발생률은 낮다. 뚜렷한 성별 우세가 없고 한쪽에 더 흔하지도 않다. 흰쥐 태아 실험에서 비타민 A가 결핍된 모체의 자손에서 폐 무발생 빈도가 높았으나, 인간에서 이런 정도의 영양실조가 생길 가능성은 낮다.
- **동반 기형과 예후**: 폐 결여는 영아기에 생명을 종결시키는 다른 선천 기형과 동반되는 경우가 많지만, 단일 폐를 가진 많은 환자가 성인기까지 잘 생존한다. **무발생 환자의 60%**에서 다른 선천 기형이 발견되며, 가장 흔한 동반 기형은 동맥관개존증, 팔로사징, 대혈관 기형, 기관지원성 낭종이다. 단일 폐는 아마 비대해져 생명을 지탱할 수 있다. 그 자체로 무증상일 수 있으나, 기능하는 폐가 하나뿐이면 **폐렴·이물 등에 의해 폐기능이 더 쉽게 손상**된다. **우폐가 없는 경우 사망률 75%, 좌폐가 없는 경우 25%**이며, 이 차이는 우폐 결여 시 심장 기형 빈도가 높기 때문이다.
- **이차성 폐 저형성의 원인**: 양수량 감소, 흉강 내 공간 감소, 태아 호흡운동 감소(신경학적 이상·신경근 질환), 유전 질환(18삼염색체증 또는 21삼염색체증), 영양실조(비타민 A 결핍), 모체 흡연, 글루코코르티코이드 투여 같은 약물이 있다.
- **영상·이학 소견**: 무발생·무형성·전폐 저형성에서는 예상대로 통기되는 폐가 완전히 또는 거의 완전히 없다. 용적 소실은 **늑골의 접근(approximation of ribs), 동측 반횡격막 거상, 심장과 종격동의 빈 반흉곽으로의 이동**으로 표시된다. 그러나 남은 기능 폐 조직이 팽창해 종격동을 넘어 탈장하면서 **호흡음이 양측에서 들릴 수 있어 청진만으로는 진단적이지 않다**.
- **진단**: 기관지경·기관지조영술과 단층촬영·혈관조영술로 환측 주기관지의 결여와 폐동맥의 결여를 입증한다. 저형성 폐의 조직학적 검사에서는 흉막면 아래에 작고 발육이 나쁜 기관지가 있을 뿐 기관지·폐포 조직이 없다.
- **폐엽의 선천 결여**: 유사하지만 덜 극적인 소견을 보인다. 이학·방사선 검사에서 환측 반흉곽 용적 감소, 심장·종격동의 환측 이동, 동측 반횡격막 거상이 나타난다. 기관지조영술로 결여된 엽의 기관지 부재를 입증해 진단하고 혈관조영술로 확인한다.
- **치료와 예후**: 병발 질환이 생길 때마다 관리한다. 환자는 감염을 피하도록 주의해야 하고 예후는 항상 신중하게 판정해야 한다 — 성인기까지 생존한 환자도 폐기능이 점진적으로 감소하기 때문이다.

### Plate 4-7 | 선천성 폐 낭종 (Congenital Lung Cysts)
![[Netter_V3_Plate4-7.png]]
- **분류**: 선천성 폐 낭종은 세 군으로 구분된다 — 발생 과정에서 기관기관지나무의 비정상 출아·분지로 생기는 **기관지원성 낭종(bronchogenic cyst)**, 폐포성, 그리고 혼합형.
- **기관지원성 낭종의 특징**: 원주 또는 입방 섬모세포로 구성된 호흡세포 점막이 강(cavity)을 피복한다. 정상 폐 구조 밖에 있을 수도 안에 있을 수도 있으며, **감염되지 않는 한 기관기관지나무와 교통하지 않는다**.
- **감별 진단**: 후천성 기관지확장증과 구별해야 한다. 기관지확장증은 폐의 의존부(dependent portion)에 더 흔한 반면, **다발성 선천 낭종은 상엽에 호발**한다. 또한 척추체 기형과 동반되는 **신경장성(neurenteric) 낭종**, 위장 중복 낭종(gastroenteric duplication cyst), 선천 대엽성 폐기종, 폐간질성 폐기종에 합병된 후천 낭종, 기관지폐 이형성증(bronchopulmonary dysplasia)이 감별 대상이다.
- **위치와 임상 양상**: 낭종은 특징적으로 기관분기부(carina) 근처에 있으나 기관주위·분기부·폐문·식도주위 부위에도 생길 수 있다. **위치가 임상 양상을 결정**한다. 낭과 기관기관지나무 사이에 교통이 있는 폐내 낭종은 일방향 판막(check valve) 기전을 만들어 **낭이 급속히 확장**할 수 있다. 중심성으로 위치하면 신생아기에 기관이나 주기관지를 압박해 증상(기침·천명, 특히 울 때)을 일으킨다. 말초에 위치한 낭종은 대개 이후 감염이나 출혈로 발현하거나 흉부 방사선에서 우연히 발견된다.
- **선천성 낭성 선종양 기형(CCAM)**: 증식하는 기관지·입방 상피로 피복된 낭종 덩어리로 구성된 병변이다. 3형으로 나뉜다 — **제1형** 다수의 크고 얇은 벽 낭종, **제2형** 다수의 균등한 간격의 낭종, **제3형** 작고 균등한 간격의 낭종을 가진 부피가 크고 단단한 덩어리. 현재는 산전 초음파로 자주 진단되지만 이렇게 발견된 일부는 삼분기 중에 퇴행한다. 환자의 약 **25%는 사산**이며 대개 태아수종(hydrops)이 있고 제3형 병변을 가진다. **50%는 조산**한다. 영아는 병변 크기에 따라 출생 직후 호흡곤란을 보일 수 있고, 그 외 반복 감염, 객혈, 흉부 방사선 우연 소견으로 발현한다. 병변은 **전암성(premalignant)일 수 있다**. 생명을 위협하는 호흡곤란이 있는 영아는 주산기 수술이 필요하며, 무증상 환자의 치료는 논란이 있으나 감염·기흉·악성화 위험이 증가하므로 영아기 중재를 고려해야 한다.
- **선천성 폐 림프관확장증(lymphangiectasis)**: 폐 림프관이 확장되고 배액이 막히는 상태로, 신체 다른 부위의 림프부종과 동반될 수 있다. 대부분의 영아가 출생 시 심한 호흡곤란을 보이고 대다수가 사망한다. 방사선 소견은 확장된 림프관을 나타내는 **미세하고 미만성인 과립상 음영을 동반한 유리알(ground-glass) 양상**이며, 다른 선천 폐 이상과 마찬가지로 폐액 흡수가 지연될 수 있다. 검사상 폐는 부피가 크고 엽 구분이 두드러지며 얇은 벽의 낭성 공간으로 확장된 림프관이 다수 있다.
- **도판 소견**: 기관분기부(분기부) 낭종이 식도를 압박하고 기관을 왜곡하는 종격동 낭종, 입방 상피로 피복된 낭벽, 기관지나무와 교통하며 점액을 함유한 폐내 낭종, 섬모 원주 상피와 점액선·연골을 포함한 낭벽, 폐 상엽의 낭성 선종양 기형, 제3형 CCAM의 입방 상피로 피복된 불규칙하고 작은 공기공간, 선천성 림프관확장증이 제시된다.

### Plate 4-8 | 폐 격리증 (Pulmonary Sequestration)
![[Netter_V3_Plate4-8.png]]
- **정의**: 폐 조직 덩어리가 원래의 기관기관지나무와도, 폐혈관나무와도 연결이 없고 **체동맥(systemic artery)에서 혈액을 공급받는** 선천 기형이다. 체동맥은 대개 횡격막 상방 또는 하방의 **대동맥**에서 기시하고, 때때로 늑간동맥에서, 드물게 완두동맥(brachiocephalic, innominate artery)에서 기시한다. 격리 조직은 **폐엽내(intralobar)**와 **폐엽외(extralobar)** 두 형태로 나타난다.
- **폐엽내 격리증**: 폐엽의 장측 흉막(visceral pleura) 내에 있는 비기능성 폐 부분이다. 대부분의 경우 하행 흉대동맥 또는 복대동맥에서 체동맥 공급을 받는다. **정맥 배액은 반드시 폐정맥을 통해** 이루어져 동맥-동맥 교통(arterio-arterial communication)을 만든다. 발생학적으로는 정상 폐동맥이 폐의 말초 일부를 공급하지 못한 것으로 보이며, 따라서 원시 배대동맥(primitive dorsal aorta)의 **지속적인 복측 분지**에서 동맥 공급이 유래한다.
- **폐엽외 격리증**: 원시 전장(foregut)에서 이차적이고 더 미측(caudal)으로 발생한 구조가 봉쇄되어 폐가 성장하면서 미측으로 이동한 것으로 볼 수 있다. **정맥 배액은 체순환**으로, 대개 기정맥(azygos), 반기정맥(hemiazygos), 대정맥으로 이루어진다. 해부학적으로 **90% 이상에서 좌측 반횡격막과 관련**되며, 하엽의 횡격막면과 횡격막 사이 또는 횡격막 실질 내에 위치할 수 있다.
- **병리**: 병리 검사에서 병변은 낭성이고 공간은 점액으로, 감염된 경우 화농성 물질로 채워진다. 낭성 공간은 원주 상피 또는 편평 입방 상피로 피복된다.
- **임상 발현**: 폐엽내 격리증의 **20%만이 신생아기에 발현**하며, 때때로 광범위한 동맥-정맥 단락으로 심부전이 생길 수 있다. 폐엽외 격리증은 신생아기에 드물게 발현하지만 선천성 횡격막 탈장 교정 수술 중 우연히 발견될 수 있다. 후기 발현은 이차 감염, 폐렴, 흉막삼출, 농흉이며, 격리 폐가 감염되면 발열, 흉통, 기침, 혈성 점액화농성 객담을 동반한 **만성 폐농양**의 양상을 보인다.
- **영상 진단**: 산전 초음파에서 비정상 폐가 흉강 내 또는 복강 내 **반향성(echogenic) 종괴**로 보인다. **50%에서 흉막삼출**이 있고 양수과다증이 흔한 합병증이다. 출생 후 방사선 검사에서 흉부 X선 **좌측 영역의 후내측부에 치밀한 병변**이 있으면 의심해야 한다. 폐엽외 격리증은 대개 횡격막에 가까운 **치밀한 삼각형 병변**으로 보인다.
- **치료**: 두 형 모두 **수술적 절제**가 원칙이다. 이차 감염과 출혈의 위험 때문에 환자가 무증상일 때도 수술을 권고하며, 감염이 발생하면 완전 제거가 필수적이다.
- **도판 소견**: 부기관지(accessory bronchus)에 의해 공급되는 폐엽외 격리엽, 좌폐의 폐엽외 격리엽(흉대동맥 또는 복대동맥에서 동맥 공급, 반기정맥으로 정맥 환류), 큰 종괴로 좌폐가 왜곡되고 압박·종격동 이동으로 우폐가 저형성된 폐엽내 격리증, 공동화(cavitation)를 동반한 폐엽내 격리증(동맥 공급은 흉·복대동맥, 정맥 환류는 폐정맥), 식도에서 교통이 있는 폐엽외 격리엽(위 분문부와의 교통도 관찰됨)이 제시된다.

### Plate 4-9 | 선천성 대엽성 폐기종 (Congenital Lobar Emphysema)
![[Netter_V3_Plate4-9.png]]
- **개요**: 신생아기의 드문 호흡곤란 원인이다. 과팽창한 엽(또는 엽들)이 남은 정상 동측 폐를 압박하고 종격동을 반대측으로 현저히 밀어 **호흡곤란, 청색증, 때로 순환부전을 동반한 환기 위기**를 초래한다.
- **병인의 3범주**: 첫째 군에서는 **기관지 연골의 결손**(연골환의 결여 또는 불완전)이 있으며, 이 이상은 연골외배엽 이형성증(chondroectodermal dysplasia) 또는 **엘리스-반 크레벨드 증후군(Ellis-Van Creveld syndrome)**에서도 기술되었다. 둘째 군에서는 **명백한 기계적 기관지 폐쇄** — 볼밸브(ball valve)로 작용하는 점막 주름, 이상 동맥 또는 섬유대, 종양, 끈적한 점액 마개 — 가 있다. 셋째이자 가장 큰 군에서는 과팽창 외에 국소 병리 병변이 보이지 않으나 **인지되지 않은 세기관지염**이 가능한 원인으로 생각된다. 각각의 경우 흡기 시 기관지가 넓어지면서 엽이 정상적으로 팽창하지만, 호기 시 폐쇄가 생겨 **공기 포착과 과팽창**이 발생한다.
- **침범 부위**: 상엽이 가장 흔히 침범되며(**80%**), 특히 좌측(**43%**)이다. 우중엽(**32%**)이 두 번째로 흔하다. 다엽성 양측 침범은 드물다. 감별해야 할 질환은 종말기관지 기흉(endobronchial pneumothorax), 횡격막 탈장, 긴장성 낭종(tension cyst), 종말기관지 이물이다.
- **임상 경과**: 환자의 **1/3은 출생 시 증상**이 있고 약 **절반은 출생 후 수일 내 증상**을 보인다. 심한 호흡 증상과 빠른 악화로 사망에 이를 수 있다. 영아는 호흡곤란과 흉벽 함몰(recession)이 증가하고, **청색증은 50%**에서 나타나며 울 때 더 뚜렷하다. **6개월 이후 발현은 5%**에 불과하다.
- **이학적 소견**: 환측 반흉곽의 과공명(hyperresonance)과 팽륭(bulging)이 있고 기관·종격동이 반대측으로 이동한다.
- **영상 소견**: 방사선에서 환측의 과투과성(hyperlucency)이 보이고, 늑골이 정상보다 넓게 벌어지며 횡격막은 낮아지고 편평해진다. 침범되지 않은 엽은 무기폐될 수 있다. 종격동이 반대측으로 이동하고 그쪽 폐는 상대적으로 방사선 불투과성이지만, 무기폐에서처럼 횡격막이 거상되지는 않는다. 침범 폐에서 **폐혈관 음영이 보이는 점이 기흉과의 감별에 도움이 된다**.
- **치료**: 지속적이거나 진행성인 호흡부전 환자에는 **폐엽절제술(lobectomy)**이 적응이며, 신생아기에 유의한 호흡곤란이 있는 영아는 조기 폐엽절제술이 필요하다. 비교적 경미한 증상으로 발현하거나 흉부 방사선에서 진단된 환자는 **보존적으로 치료**할 수 있다.
- **도판 소견**: 벽에 연골이 거의 없는 상당히 큰 기관지 단면(주변 폐조직 폐기종의 유력한 원인), 국소적으로 큰 낭종을 동반한 선천성 폐기종, 좌측 폐동맥에 낮게 삽입된 섬유성 동맥관에 의한 좌측 주기관지 압박과 좌상엽의 수포성 폐기종, 두꺼워진 점막 주름과 치밀한 점액에 의한 기관지의 볼밸브 폐쇄로 인한 대엽성 폐기종이 제시된다.

### Plate 4-10 | 만성 기침 (Chronic Cough)
![[Netter_V3_Plate4-10.png]]
- **기침의 임상적 의미**: 건강한 사람은 거의 기침하지 않으며, 기침을 할 때도 임상적 의의가 없다. 그러나 기침이 지속되어 괴로우면 큰 임상적 의의를 갖는다. 기침이 감염 확산의 중요한 요인이 되기도 하지만, 그것이 환자가 가장 흔한 진료 이유 중 하나로 의학적 도움을 구하고 약값을 지출하는 이유는 아니다 — **기침이 삶의 질을 여러 방식으로 악화**시키기 때문이다.
- **기침의 물리적 위력**: 격렬한 기침 시 흉강 내 압력은 최대 $300\ \text{mmHg}$, 호기 속도는 최대 $28{,}000\ \text{cm/sec}$(약 500 mph, **음속의 85%**), 흉강 내 에너지는 최대 $25\ \text{J}$에 달한다. 이는 하기도의 과다 분비물과 이물을 제거하고 심폐소생을 제공하는 효과적인 수단이 되게 하지만, 동시에 신체적·심리사회적 합병증을 만든다.
- **합병증의 범위**: 심혈관, 전신 증상, 위장, 비뇨생식, 근골격, 신경, 안과, 심리사회, 삶의 질, 호흡기, 피부과적 결과에 이른다. 특히 괴로운 것으로는 **요실금, 늑골 골절, 실신, 자의식과 중병에 대한 공포** 같은 심리사회적 합병증이다.
- **대표 합병증의 기전**: 기침 유발 요실금은 여성, 특히 고령이며 출산 경험이 있는 여성에서 특히 문제가 된다. 기침 유발 늑골 골절은 **골다공증이 없어도 발생**할 수 있고, 전거근(serratus anterior)과 광배근(latissimus dorsi)이 교차하는 **후외측부**에 전형적으로 생긴다. 기침 실신은 기침의 힘이 뇌척수액에 충격파를 일으키면 갑작스럽게, 심박출량 감소에 의한 저혈압이 원인이면 더 점진적으로 나타난다.
- **현대적 관리 개념의 출발**: 기침 반사 구심성 신경해부(neuroanatomy)에 근거한 체계적 평가 방식과 **지속 기간에 따른 분류**가 제시되면서 기침 증상 관리의 현대적 시기가 열렸고, 두 개념 모두 검증되었다. 구심성 위치를 체계적으로 평가하는 **해부학적 진단 접근(anatomic diagnostic approach)**이 정확한 진단에 이를 가능성이 가장 높다. 불수의적 기침이 전통적으로 미주신경(vagus nerve)만으로 매개된다고 여겨졌으나, 실험 데이터는 다른 신경도 관여함을 시사한다.
- **해부학적 접근의 성과**: 이 접근으로 폐외 원인 — 다양한 비부비동(rhinosinus) 질환에 의한 **상기도 기침 증후군(upper airway cough syndrome)**, 흡인 없이 발생하는 **위식도 역류질환(GERD)**에 의한 기침 — 이 발견되었다.
- **지속 기간 분류**: **급성($<3$주)**, **아급성($3\sim8$주)**, **만성($>8$주)**으로 나누는 분류는 진단 가능성의 스펙트럼을 좁혀 주기 때문에 기침 평가의 가장 중요한 부분이 되었다.
- **원인별 정리**: 급성 기침의 가장 흔한 원인은 상기도 감염(URI, 예: 감기), 세균성 부비동염, **Bordetella pertussis 감염**, 천식 악화, 만성 기관지염, 알레르기 비염, 환경 자극성 비염이다. 아급성은 감염 후 기침(예: B. pertussis 감염 후), 세균성 부비동염, 기존 질환(천식, 비부비동 질환, 기관지확장증, 만성 기관지염)의 악화가 주요 원인이다. 만성은 상기도 기침 증후군, 천식, **비천식성 호산구성 기관지염(nonasthmatic eosinophilic bronchitis)**, GERD, 만성 기관지염, 기관지확장증이 주요 원인이다.
- **치료 반응에 의한 확진**: 검증된 진단 프로토콜을 체계적으로 따르고 추정 원인에 대해 **충분한 용량**의 특이 치료를 처방하면 대다수에서 기침이 호전되거나 사라진다. **최소 20%**에서는 만성 기침이 동시에 기여하는 여러 질환에 의해 발생하며, 기침의 원인은 특이 치료에 반응할 때에만 확정할 수 있다.
- **도판 자료**: 기침 반사의 신경해부(수용체, 삼차신경, 미주신경, 횡격신경, 피질 입력, 기침 중추)와 만성 기침의 흔한 원인 — **상기도 기침 증후군 $28\sim41\%$(미주 자극), 천식 $24\sim33\%$, GERD $10\sim21\%$(미주 자극)**. 또한 **비정상 흉부 X선을 동반한 만성 기침의 원인**(폐결핵, 폐암, 낭성섬유증·기관지확장증)과 기침의 합병증(복압 상승에 따른 요실금, 늑골 골절, 실신)이 함께 제시된다.

### Plate 4-11 | 흔한 후두 병변 (Common Laryngeal Lesions)
![[Netter_V3_Plate4-11.png]]
- **성대 결절·폴립·낭종**: 높은 음성 요구가 있는 사람(교사, 가수, 어린 소아)에서 쉰 목소리의 흔한 원인이다. 과도하거나 남용적인 음성 사용이 **고유판 천층(lamina propria superficial layer, Reinke space)** 내에 반복적 외상과 염증을 일으켜 전방 진성 성대에 상피하 병변을 형성한다. 이 병변의 질량 효과가 성대 진동을 방해하고 발성 시 성대 사이의 기류를 방해해 쉰 목소리가 된다.
- **치료(결절·폴립·낭종)**: 다면적 접근이 필요하다 — 음성 남용 행동의 제거, 후두 위생의 최적화, 알레르기·감염·후두인두 역류(laryngopharyngeal reflux) 같은 관련 염증 상태에 대한 약물 치료. 보존적 조치에 반응하지 않는 지속 병변에는 현대 **음성현미경수술(phonomicrosurgery)** 기법을 이용한 수술적 절제가 적응이다.
- **후두 육아종(Laryngeal granuloma)**: 후두 후방의 **피열연골(arytenoid cartilage) 성대돌기(vocal process)**에서 발생하는 염증성 병변으로 단측 또는 양측일 수 있다. 가장 흔한 원인은 **기관내삽관**이며 이 때문에 과거에는 삽관 육아종(intubation granuloma)이라는 용어가 쓰였다. 기관내관의 압력이 피열연골 성대돌기를 덮는 얇은 연골막에 염증과 미란을 일으켜 육아종이 형성된다. 다른 흔한 원인으로 만성 기침이나 목 가다듬기(throat clearing), 과도한 음성 사용, 후두인두 역류가 있다. 국소 외상이나 기저 염증 상태가 해결되면 자연 퇴행하는 경우가 흔하며, **냉기구(cold steel) 또는 $CO_2$ 레이저 절제**는 불응성 병변이나 후방 성문 기도를 폐쇄하는 큰 육아종에 국한한다.
- **재발성 호흡기 유두종증(RRP)**: 바이러스성 질환으로 소아·성인 모두에서 호흡소화관(aerodigestive tract)의 다발성 외생 병변을 특징으로 한다. 후두 침범이 흔해 진행성 쉰 목소리와 기도 폐쇄를 일으킨다. 후두 외 확산(기관·폐)은 덜 흔하지만 이환율 증가와 잠재적 사망과 관련된다. 발병 시기는 소아기 또는 성인기로 **이봉 분포(bimodal)**를 보여 5세 미만에서 첫 번째 정점, $20\sim30$세에서 두 번째 정점을 이룬다. **소아 발병 RRP가 더 흔하고 가장 공격적인 형태**이며, 감염된 모체로부터 자궁 내 또는 분만 중 **인유두종바이러스(HPV)의 수직 감염**으로 획득된다. 양성이지만 상·하기도 내 위치, 공격적인 내과적·수술적 치료에도 잦은 재발, 시간 경과에 따른 **악성 변성 가능성** 때문에 유의한 이환을 초래한다.
- **편평세포암(Squamous cell carcinoma)**: 후두의 가장 흔한 악성 종양이다. 잘 분화된 저등급 종양(사마귀상암종 verrucous carcinoma — 절제만으로 치료 가능하고 예후가 우수)에서 저분화 고등급 암종(공격적 다중 치료에도 예후 불량)까지 범위가 넓다.
- **종양 위치의 의의**: **성문암(glottic cancer)**은 진성 성대로부터 발생하며 작은 병변도 증상성 쉰 목소리를 일으켜 조기에 진단되고, 국소 림프관·원격 전이율이 비교적 낮다. 반면 **성문상암(supraglottic cancer)**은 후두개나 가성 성대에서 발생해 종양이 연하곤란·기도 폐쇄를 일으킬 만큼 커진 진행기에 진단되며, 국소 림프절 침범률이 높고 폐 등 원격 전이 가능성이 크다. **성문하암(subglottic cancer)**은 드물지만 예후가 비교적 나쁘다. **장기간의 흡연과 음주**가 후두암의 가장 중요한 위험 인자이며 병용 시 상승작용을 보인다.
- **도판 소견**: 양측 성대 결절, 기관내삽관 후 발생한 양측 후두 육아종(자연 퇴행 흔함), 후두 RRP, 좌측 진성 성대의 사마귀상암종, 전방 진성 성대의 편평세포암, 기관의 RRP, 출혈성 좌측 성대 폴립, 좌측 성대 낭종. 병인 설명은 성인에서 **기관내관이 피열연골 성대돌기를 압박**하고 기계적 환기 중 관의 움직임이 미란을 일으켜 육아종이 생기며, 소아에서는 후두가 작아 관이 **피열간(interarytenoid) 공간**에 위치해 성문하 육아종이 생길 수 있음을 보여준다.

### Plate 4-12 | 후두 및 기관 협착 (Laryngeal and Tracheal Stenosis)
![[Netter_V3_Plate4-12.png]]
- **취약성의 이유**: 후두와 기관의 독특한 해부와 섬세한 조직은 손상에 반응해 반흔과 협착이 생기기 쉽게 만든다. 흔한 원인은 장기간의 기관내삽관, 장기간의 기관루(tracheostomy), 세균성·바이러스성 감염, 전신 염증 질환, 신생물, 외상이다. 많은 경우 협착은 초기 병리 과정의 비교적 늦은 후유증이며, **증상성 기도 폐쇄(천명 또는 호흡곤란)나 후두 기능 장애(쉰 목소리)**로 진행될 때까지 인식되지 않는다.
- **후두 협착**: 후두 내 어느 높이에서도 생길 수 있다. **성문상·성문 협착**은 대개 외부 외상이나 장기간 삽관의 결과이고, 부식제 섭취, 흡입 화상, 수술 후 반흔에서도 나타난다. **성문하 협착(subglottic stenosis)이 후두 협착의 가장 흔한 형태**다. 장기간 기관내삽관은 윤상연골(cricoid cartilage)의 얇은 내측 연골막을 손상시켜 **원주상 반흔과 반흔조직(cicatrix)**을 만든다. 장기간의 기관루관도 상방 이동으로 윤상연골환을 파괴해 성문하 협착을 일으킬 수 있다. 다른 흔한 원인은 후두인두 역류, 베게너 육아종증(Wegener granulomatosis), 그리고 소아에서 보이는 선천형이다.
- **특발성 성문하 협착(ISS)**: 특정 원인을 찾을 수 없을 때 이 용어를 사용한다. ISS의 많은 증례가 적어도 부분적으로는 **인지되지 않은 후두인두 역류나 자가면역 질환**에 기인할 가능성이 있다.
- **기관 협착**: 호흡부전으로 기계적 환기를 위해 커프가 있는 관을 필요로 하는 환자에서 장기간 기관내삽관과 기관루의 **잠재적으로 파괴적인 후유증**이다. 기관의 전벽과 측벽에서 점막과 연골환 사이를 지나는 수직 혈관은 팽창한 커프나 풍선에 쉽게 압박된다. 혈액 공급 감소는 **연골막염(perichondritis), 무혈관성 괴사, 기관 연골의 분절화**를 일으킨다. 결과적 협착은 전방 연골궁의 약화와 측벽 허탈 때문에 횡단면에서 **삼각형 형태**를 띠는 경우가 많다. 후벽은 막성 기관(membranous trachea)이 더 유연하고 혈관 공급이 압박될 가능성이 낮아, **삽관 후 또는 기관루 후 풍선 협착의 약 50%에서 후방 기관벽이 보존**된다.
- **영상 진단**: 협착의 특성과 범위는 정면·측면 투영의 전통적 단층촬영이나 관상·시상면의 CT 영상으로 확인한다. 협착 분절은 하나의 기관환만 침범하는 좁고 막상(weblike) 병변일 수도 있고, 2~5개의 기관환을 침범하며 점진적 경계(tapering margin)를 보이는 더 긴 분절일 수도 있다.
- **기관연화증(tracheomalacia)**: 병변이 얇거나 유연하면 흡기 또는 호기 시에만 폐쇄가 생기는데, 병변이 **흉강 외(경부)**에 있으면 흡기 시, **흉강 내(흉부)**에 있으면 호기 시 폐쇄된다. 기관연화증은 방사선 소견보다 기능 장애가 더 클 수 있다. 동적 허탈이 의심되면 **흡기 또는 호기 유량 감소를 보이는 유량-용적 곡선**이나 **흡기/호기 허탈을 보여주는 굴곡성 기관지경**이 유용한 진단 도구다. 서로 다른 길이의 관이나 이중 커프 관을 사용한 뒤에는 여러 개의 협착이 생길 수 있다.
- **예방과 치료**: 저압 커프의 도입과 임상 감시의 강화에도 삽관 후·기관루 후 풍선 협착은 여전히 심각한 문제다. 기관 점막의 과도하게 긴 압박을 피하기 위해 **커프를 주기적으로 감압**하도록 권고되지만, 커프가 완전히 비워지지 않을 수 있고 충전에 권장되는 최소 고정 공기량으로 재팽창하면 과팽창이 생길 수 있다는 문제가 있다. 적절한 커프 압력은 **양압 환기 시 공기 누출이 없어질 때까지 청진 조절 하에 팽창**시켜 달성하는 것이 가장 좋다. 이런 조치에도 협착이 발생하면 **내시경 레이저 절개·확장술 또는 기관 절제·문합술**이 필요할 수 있다.
- **도판 소견**: 상부 기관의 혈액 공급(하갑상동맥에서 나온 기관식도 분지가 연골간 공간으로 원주 혈관을 보내고 점막하에 수직 상행·하행 분지를 형성)과 팽창한 기관내 풍선에 눌린 혈관, 기관 협착, 성문하 협착. 절제 표본을 위에서 본 단면은 연골 분절화와 궤양을 동반한 완전 원주 협착을 보여준다. 전방·측방 연골벽만 침범하고 후방 섬유근벽이 온전한 협착, "weblike" 협착, 기관의 더 긴 분절을 침범한 협착, 연골막염으로 연골환이 가려져 정상 조직의 경계를 정하기 위해 연속 횡단 절단이 필요할 수 있는 유리잘시개(hourglass) 협착이 제시된다. 또한 윤상연골 높이의 원주 협착·반흔 형성을 보여주는 성문하 협착 내시경 사진과 유리잘시개 협착의 시상 CT 영상이 포함된다.

### Plate 4-13 | 성대 기능부전 (Vocal Cord Dysfunction)
![[Netter_V3_Plate4-13.png]]
- **정의와 정상 생리**: 성대 기능부전(VCD)은 역설적 성대 운동(paradoxical vocal cord motion, PVCM)이라고도 하며, **흡기 시 성대가 부적절하게 내전(폐쇄)**되는 비교적 잘 이해되지 않는 후두 질환이다. 정상 호흡주기에서는 흡기 시 성대가 외전(개방)되고, 호기 말이나 발성 시작 시에만 내전이 시작된다.
- **생리적 배경**: 생리적으로 호기 말의 성대 부분 내전은 **양압 호기말압(PEEP)을 생성해 폐포 개방을 유지**한다. 성대의 완전 내전은 정상적으로 발성 시 일어나는데, 폐에서 나온 공기가 닫힌 성문에 부딪히면 성문하 기압이 상승해 성대를 진동시켜 음성을 만든다. 이와 대조적으로 VCD 환자에서 흡기 시 일어나는 **역설적 내전은 급성·간헐적 기능성 기도 폐쇄**를 초래한다.
- **증상과 감별**: 가장 흔한 증상은 **흡기성 천명(inspiratory stridor)**, 호흡곤란, 쉰 목소리, 목 조임, 기침이다. 이 증상들은 비교적 비특이적이어서 천식, 후두개염(epiglottitis), 혈관부종(angioedema), 아나필락시스와 혼동될 수 있다. 많은 VCD 환자가 천식으로 진단되어 공격적으로 치료받았으나 호전되지 않았다. 천식과 달리 VCD의 기도 폐쇄는 호기보다 **흡기 시** 발생하므로, **후두 천명을 기관지 천명으로 오인하면 안 된다**.
- **폐기능검사**: 폐기능검사는 천식을 배제하고 VCD 진단을 지지하는 데 도움이 되며, **유량-용적 곡선에서 흡기 유량의 감쇠**가 나타난다. 천식과 VCD가 함께 있는 경우가 흔하며, 이때는 메타콜린 유발검사(methacholine challenge)가 도움이 된다.
- **후두경 진단**: 진단은 **비강경 유연성 굴곡성 후두경(transnasal flexible fiberoptic laryngoscopy)**으로 더 확실해진다. 폐기능검사와 마찬가지로 **환자가 증상을 느끼는 동안** 시행해야 한다. VCD가 삽화성(episodic)이므로 운동, 지속적 발성 과제(sustained vocal task) 또는 알려진 유발 인자로 먼저 급성 악화를 유발해야 할 수 있다. 유연성 후두경에서 **구조적으로 정상인 후두 + 흡기 시 역설적 성대 내전**이 확인된다. 이 소견은 코보다 **입으로 숨쉴 때 더 현저**한데, 구강 호흡이 성대 외전에 더 강한 신경 자극을 제공하기 때문이다. **성대 전방 2/3의 내전과 후방 성문의 다이아몬드형 틈**이 가장 흔히 기술되며, 추가로 가성 성대 내전과 전후방 성문상 협착이 보고된다.
- **원인론의 변천**: 원인은 잘 알려져 있지 않다. 명확한 기질적 병리가 없고 기저 정신과 질환의 빈도가 높기 때문에 VCD는 역사적으로 **심인성 장애**로 간주되어 왔고, "Munchausen's stridor", "factitious asthma" 같은 고어(古語)도 그 증거다. 일부 환자에서 신체화(somatization)나 전환 장애(conversion disorder)의 발현일 수 있지만 **비심인성 원인도 고려해야 한다**. 뇌간 압박, 상·하 운동신경원 손상, 운동 장애가 VCD와 연관되었다. **후두인두 역류(LPR)**에 의한 후두 과반응성도 잠재적 원인 인자로 지목된다. LPR 진단은 유연성 후두경에서 후방 후두 홍반, 피열간 점막 비후(interarytenoid mucosal pachydermy), 후방 인두 조약돌상(posterior pharyngeal cobblestoning)으로 지지된다.
- **치료**: 다면적 접근을 취한다 — 잠재적 자극이나 유발 인자의 확인과 제거, 기저 심인성·병적 상태에 대한 약물 치료, 그리고 경험 있는 언어치료사(speech-language pathologist)와의 집중 행동 치료(후두 이완과 횡격막 호흡 기법에 초점). 필요하면 심한 발작을 **항불안제, 헬리옥스(heliox), 지속적 양압 환기(CPAP)**로 급성 관리한다. 대부분의 VCD 환자는 적절한 치료와 시간이 지나면 호전된다.
- **도판 소견**: 후두의 표면 해부(설근/설편도, 후두개, 심실주름[가성 성대], 피열후두개주름, 설상결절, 피열간 절흔, 기관, 이상와, 각상결절, 식도, 진성 성대, 정중설후두개인대)와 함께, VCD 환자의 유량-용적 곡선에서 **잘린 흡기 유량(truncated inspiratory flow)과 특징적인 "saw-tooth" 패턴**이 흡기 시 성대의 부적절한 내전에 상응하여 나타난다. 정상 흡기 시 성대는 외전, 정상 발성 시 성대는 내전 위치에 있음을 함께 보여준다.

### Plate 4-14 | 기관지 천식 (Bronchial Asthma)
![[Netter_V3_Plate4-14.png]]
- **정의와 유병률**: 천식은 이 문제가 평가된 대부분의 국가에서 인구의 **$5\sim15\%$**에 영향을 미친다. 천식은 **가변적 기류 폐쇄(variable airflow obstruction)**, 비특이적 흡입 자극에 의해 유도되는 수축에 대한 기도의 반응성 증가(**기도 과반응성**), 그리고 **세포성 염증(cellular inflammation)**을 특징으로 하는 임상 증후군이다.
- **증상과 기전**: 천식 증상은 특징적으로 삽화성(episodic)이며 호흡곤란, 천명, 기침, 흉부 압박감으로 구성된다. 이는 기도 평활근 수축, 기도벽 부종, 기도 염증, 점액선의 과다 분비에 의한 기류 폐쇄 때문이다. 천식 기류 폐쇄의 주요 특징은 **자연적으로 또는 치료의 결과로 부분적 또는 완전히 가역적**이라는 점이다.
- **증후군으로서의 천식**: 천식이 증후군인 이유는 임상상이 흔히 매우 특징적이지만 **병인 인자가 다양**하기 때문이다. 과거에는 외부 자극이 원인임을 의미하는 extrinsic asthma와 명확한 외부 원인을 찾을 수 없는 intrinsic asthma라는 용어가 쓰였다. 현재는 **거의 모든 천식이 어떤 외부 자극에 의해 시작되며**, 가장 흔히 확인되는 것이 환경 알레르겐이라는 점이 인식되고 있다.
- **알레르기성 천식(Allergic asthma)**: 주로 **소아와 젊은 성인**에서 발생한다. 알레르기 비염, 결막염, 습진 같은 다른 알레르기 발현의 개인력(atopy)이 흔하고 아토피의 가족력도 흔하다. 아토피는 환경 및 직업성 알레르겐에 대한 **피부 반응 양성**과 **혈청 면역글로불린 E(IgE) 상승**으로 확인된다. 도판에서는 젊은 환자, 가족력 양성, 특정 항원(꽃가루, 음식, 약물, 먼지, 비듬)과 관련된 발작, 피부 반응 양성, 유아기 습진 병력, "알레르기 멍(allergic shiner)", IgE 연관성이 특징으로 제시된다.
- **비알레르기성 천식(Nonallergic asthma)**: 대개 **성인기에 증상이 발생**하는 환자에서 확인된다. 호흡기 감염 후 증상이 발생할 수 있고, 때때로 **Chlamydia pneumoniae나 Mycoplasma spp.** 같은 감염원이 원인으로 지목된다. 직업성 감작제(occupational sensitizer)도 중요한 원인이므로 **상세한 직업력 청취가 환자 평가의 핵심 요소**다. 비알레르기성 천식은 만성 부비동염, 비만, 위식도 역류 같은 동반 질환과 흔히 관련된다.
- **유발인자와 악화인자의 구분**: 천식을 **유발하는(inducers — 질병을 일으키는)** 자극, 예를 들어 환경 알레르겐과 직업성 감작제와, **악화시키는(inciters — 악화나 일과성 증상을 일으키는)** 자극을 구분하는 것이 중요하다.
- **호흡기 바이러스 감염**: 바이러스 감염은 천식의 중요한 유발인자이며 천식 환자에서 여러 중요한 임상적 결과와 관련된다 — 영아와 어린 소아에서 천명 관련 질환의 발생, **생후 첫 10년 내 천식 발생**, 급성 천식 악화 유발(특히 라이노바이러스), 기도 반응성 증가를 포함한 기도 생리의 변화.

### Plate 4-15 | 비알레르기성 천식의 임상 양상과 유발인자 (Nonallergic Asthma: Clinical Features / Inducers and Inciters)
![[Netter_V3_Plate4-15.png]]
- **도판의 임상 특징**: 비알레르기성 천식의 특징은 **35세 이상의 성인 환자**, 대개 **음성인 가족력**, 감염·운동·기타 자극과 관련된 발작, 대개 **음성인 피부 검사**, 유아기 습진 병력 없음, **IgE 비연관성**이며, 원인으로 **직업성 천식**을 반드시 고려해야 한다.
- **환경 알레르겐**: 알레르겐은 천식을 유발하고 천식 증상을 악화시키는 양쪽 역할을 한다. 실제로 일부 천식 환자는 알레르겐에 노출될 때만 **계절성 증상**을 경험한다. 알레르겐에 감작된 환자가 알레르겐을 흡입하면 **$10\sim15$분 내에 급성 기관지수축**이 나타나 대개 2시간 내에 해소되는데(조기 천식 반응, early asthmatic response), 이후 **$3\sim6$시간 후에 기관지수축이 재발**할 수 있다(지연 천식 반응, late asthmatic response). 지연 반응은 더 천천히 발달하며 심한 기관지수축과 호흡곤란을 특징으로 하고, 염증세포 — 특히 **호염기구와 호산구** — 의 점진적 유입 때문에 발생한다. 기관지수축은 대개 24시간 내 해소되지만 환자에게는 **1주 이상 지속될 수 있는 기도 반응성 증가**가 남는다.
- **직업성 감작제**: 직업성 천식은 **성인 발병 천식의 흔한 원인**이다. 직장에서 200가지 이상의 물질이 확인되었는데, 동물 비듬, 밀가루, 차전자피(psyllium), 효소 같은 알레르겐은 IgE 매개 반응으로 기도 협착을 일으키고, 화학물질(흔히 저분자량, 예: **톨루엔 디이소시아네이트**)은 비IgE 매개 기전으로 천식을 일으킨다. 업무 관련 노출과 흡입 사고는 신규 발병 천식의 유의한 위험이다. 감작된 사람이 직업성 화학 감작제를 실험실에서 흡입하면 알레르겐과 유사한 **조기 천식 반응**이 흔히 유발되고 이어 **지연 천식 반응**이 올 수 있다. 직업성 감작제에 의한 기도 염증 반응은 환경 알레르겐 등 다른 천식 원인과 실질적으로 다르지 않아 보인다.
- **운동**: 운동은 매우 흔히 경험되는 천식 악화 인자다. 기관지수축은 운동 후에 발생해 **운동 종료 $10\sim20$분 후 최대**가 되고 대개 1시간 내 해소된다. 운동 중에 기관지수축이 생기는 경우는 매우 드물다. 기관지수축은 운동 중 흡입되는 많은 양의 공기가 체온으로 조절되고 완전히 포화되면서 **기도가 냉각·건조**되기 때문에 발생하며, 천식 환자가 매우 차고 건조한 공기를 흡입할 때도 유사한 증상을 겪는다. 운동 유발 기관지수축은 **운동 $5\sim10$분 전 흡입 $\beta_2$-작용제 전처치**로 대개 예방할 수 있다.
- **대기 오염물질**: 다양한 대기 오염물질이 천식 악화 인자다 — **이산화질소($NO_2$), 이산화황($SO_2$), 오존**, 그리고 직경 $10\ \mu m$ 미만의 흡입 입자(**$PM_{10}$**). 그 밖의 환경 자극으로 향수 같은 강한 냄새, 자동차 배기가스, **간접 흡연(secondhand tobacco smoke)**이 있다.
- **아스피린 감작**: **아스피린 감작, 천식, 비용종(nasal polyposis)의 삼증(Samter triad)**이 천식 환자의 약 **5%**에서 인지되고 있다(비용종이 아스피린 감작 천식 환자에 반드시 동반되는 것은 아니다). 천식 증상은 아스피린 복용 **20분 내**에 발생하며 매우 심하고 때때로 생명을 위협한다. 이 감작은 **cyclo-oxygenase(COX-1) 억제제인 모든 약물**에 존재하고 때때로 타르트라진(tartrazine)에도 있다. **아세트아미노펜과 COX-2 억제제**는 대부분의 아스피린 감작 천식 환자에서 사용하기에 안전해 보인다.

### Plate 4-16 | 천식의 임상 양상 (Clinical Presentation)
![[Netter_V3_Plate4-16.png]]
- **증상의 스펙트럼**: 천식의 증상·징후는 매우 간헐적이고 대개 천식 유발 인자 노출 후 나타나며 이후 상당한 관해가 오는 경미하고 분리된 호흡곤란·천명·기침 삽화에서, 중증도가 오르내리는 지속적이고 만성적인 증상까지 다양하다. 어떤 환자든 특정 시점에 증상이 경도·중등도·중증일 수 있고, **경증 간헐성 천식 환자도 생명을 위협하는 중증 악화를 겪을 수 있다**. 천식 악화는 특히 진행성일 수 있음을 아는 환자에게 공포스러운 경험이다.
- **악화의 시작과 선행 요인**: 악화 증상은 대개 점진적으로 발달하지만 때로 갑작스러울 수 있다. 대개 천식 악화는 **바이러스성 상기도 감염**이 선행한다. 많은 환자가 흉골후 압박감(retrosternal chest tightness)을 호소한다.
- **호흡기 증상**: 호기성 천명과 종종 흡기성 천명이 들리고 다양한 정도의 호흡곤란이 동반된다. 기침이 있을 가능성이 크고 **화농성 객담**이 나올 수 있다.
- **중증 악화의 전신 소견**: 환자는 **앉은 자세를 선호**하고, **비익 확장(nasal alar flaring)**과 **호흡 보조근 사용**이 보여 호흡일 증가를 반영한다. 불안과 우려는 대개 악화의 강도와 관련된다. 빈호흡은 공포, 기도 폐쇄 또는 혈액·조직 기체압이나 pH의 변화의 결과일 수 있다. 고혈압과 빈맥은 카테콜아민 배출 증가를 반영하지만, **맥박수 $110\sim130$회/분 초과는 유의한 저산소혈증($PaO_2 < 60\ \text{mmHg}$)과 삽화의 심각성을 시사**한다.
- **기이맥(pulsus paradoxus)**: 기이맥($\geq 10\ \text{mmHg}$)은 폐 과팽창과 동반되며, **$FEV_1$이 대개 예측 정상의 30% 미만**일 때 발생한다.
- **중증 저산소혈증·고탄산혈증**: 심한 저산소혈증과 고탄산혈증이 호흡성 산증과 함께 발생하면 환자는 대개 **청색증, 피로, 혼돈, 초조**를 보인다.
- **흉부 검사**: 과공명 타진음(hyperresonant percussion note), 낮은 횡격막, 그 밖의 과팽창 증거가 나타난다. **호기는 연장**되고 환자는 전반적인 흡기·호기 천명을 보인다.
- **저등급 폐쇄에서의 함정**: 저등급 폐쇄에서는 천명이 미미하거나 심지어 없을 수 있으나 빠르고 깊은 호흡으로 강조될 수 있다. **기류가 심하게 감소하면 흉부가 역설적으로 무음(paradoxically silent)이 될 수 있다.** 이 불길한 소견은 호흡을 억제하는 최면제·진정제·진정약물의 투여로 의도치 않게 유발되거나 악화될 수 있다. 기류가 너무 감소해 흉부가 무음이 되는 시점에는 **기침이 비효과적이 되고 환기부전이 닥치므로**, 즉각적이고 집중적인 치료가 필요하다.
- **도판 소견**: 천식의 기원에서 흔한 촉발 인자를 도해한다 — 천식의 유발인자(inhalant allergens, irritant inhalants / trigger mechanisms)와 천식 **증상의 유발인자**(부비동염, 감염, 심리적 스트레스, 약물, 기관지염·세기관지염)로 구분하고, 곰팡이 포자, 가구 충전재, 깃털, 꽃가루(잡초·목초·수목), 집먼지, 담배 연기, 연기·산업 화학물질, 찬 공기, 웃음, 신체적 운동, 여러 약물, 아스피린, 대기 오염물질, 휘발유, 페인트, 동물 비듬, 감기나 기타 바이러스 감염을 제시한다.

### Plate 4-17 | 천식의 진단 (Diagnosis of Asthma)
![[Netter_V3_Plate4-17.png]]
- **진단의 중요성**: 천식은 대부분 환자에서 평생 질환이므로 증상이 처음 나타날 때 정확한 진단을 내리는 것이 중요하다. 하지만 때로 이것이 이루어지지 않아 환자가 부적절하게 치료되기도 한다. **천식의 어떤 증상도 병리특이적(pathognomonic)이지 않으며**, "천명하는 모든 것이 천식은 아니다(all that wheezes is not asthma)"라는 격언은 천명뿐 아니라 기침, 흉부 압박감, 호흡곤란도 다른 호흡기·심장 질환의 증상임을 상기시킨다. 진단은 **특징적 증상 + 가변적 기류 폐쇄의 존재 또는 흡입 기관지수축 매개물질에 대한 기도 과반응성**으로 내려야 한다.
- **가변적 기류 폐쇄의 측정**: 가변적 기류 폐쇄는 **유량-용적 곡선을 포함한 폐활량측정(spirometry)**으로 측정하는 것이 가장 좋으며, $FEV_1$과 **$FEV_1$/FVC 비**의 감소를 보이고 **$\beta_2$-작용제 흡입 후 호전**을 입증한다. $FEV_1$이 **12% 초과** 개선되고 **최소 200 mL**의 변화가 있으면 가역적 기류 폐쇄의 입증으로 통상 인정된다.
- **PEF 대체 측정**: 일부 진료 환경에서는 폐활량측정에 접근할 수 없으므로 **최대호기유량(PEF)** 측정의 변동성을 진단과 모니터링에 사용할 수 있다. $\beta_2$-작용제 흡입 후 **20% 초과(또는 $>60\ \text{L/min}$) 개선**이나, 2주간 측정에서 **PEF의 일중 변동(diurnal variation) 20% 초과**도 가변적 기류 폐쇄를 확인해 준다.
- **기도 과반응성 검사**: 천식과 일치하는 증상이 있으나 폐기능이 정상인 환자에서는 **직접 기도 유발검사(흡입 메타콜린, 히스타민)** 또는 **간접 유발검사(흡입 만니톨, 운동 유발)**에 대한 기도 반응성 측정이 천식 진단을 확립하는 데 도움이 될 수 있다. 기도 반응성 측정값은 증상을 일으킬 수 있는 인자에 대한 기도의 **"민감도(sensitivity)"**를 반영하며, 검사 결과는 대개 $FEV_1$을 주어진 만큼 감소시키는 **유발 농도(또는 용량)**로 표현한다.
- **검사의 해석**: 이 검사들은 천식 진단에 **민감하지만 특이도가 제한적**이다. 즉 음성 결과는 흡입 글루코코르티코스테로이드 치료를 받지 않는 환자에서 **지속성 천식의 진단을 배제하는 데 유용**하지만, 양성 결과가 항상 천식을 의미하지는 않는다. 이는 알레르기 비염 환자와 다른 원인(예: 낭성섬유증, 기관지확장증, 만성 폐쇄성 폐질환)에 의한 기류 제한 환자에서도 기도 과반응성이 기술되었기 때문이다.
- **도판 소견(유발검사 프로토콜)**: 메타콜린 유발검사는 **비강무화 메타콜린을 증가하는 용량으로 흡입하고 매 용량 후 폐활량측정**을 하며, **$8\ \text{mg/mL}$ 이하의 농도에서 $FEV_1$이 기준선에서 20% 이상 감소하면 양성 반응**으로 판정한다. 운동 유발검사는 **예측 최대 심박수의 85% 또는 최대자의적환기(MVV)의 80%로 $6\sim8$분간 운동**하고 기준선과 운동 후 5분 간격으로 폐활량측정을 하며, **$FEV_1$이 기준선에서 15% 이상 감소하면 양성**이다. 도판에는 기관지수축 전후의 용적-시간 곡선과 PEF·FVC·FEV1 지표, 그리고 시간에 따른 %기준선 $FEV_1$ 변화 곡선이 함께 제시된다.

### Plate 4-18 | 진단을 위한 검사 (Investigations That May Be Considered to Establish a Diagnosis)
![[Netter_V3_Plate4-18.png]]
- **방사선 촬영의 가치**: 방사선 촬영의 일차적 가치는 다른 질환을 배제하고 **폐렴, 무기폐, 기흉, 종격동기종, 기관지확장증**의 존재 여부를 판정하는 데 있다. **경증 천식**에서는 흉부 방사선이 정상이다.
- **중증 폐쇄의 방사선 소견**: 심한 폐쇄가 있으면 특징적인 **가역적 폐 과투과성(reversible hyperlucency)**이 나타나고, **늑골간격의 확장, 횡격막의 하강, 흉골후 공기(retrosternal air)의 증가**가 동반된다. 폐기종에서는 혈관 분지가 감쇠·왜곡되는 것과 달리, **천식에서는 혈관의 직경과 분포가 대체로 교란되지 않는다**는 점이 감별점이다.
- **국소 무기폐**: 국소 무기폐는 천식의 합병증으로 **점액 매복(mucus impaction)**에 의해 발생한다. 소아에서는 엽 전체의 허탈까지 관찰될 수 있다. 무기폐 음영은 점액 매복이 한 폐 구역에서 다른 곳으로 옮겨가면서 일시적일 수 있고, 객담이 배출되면 이러한 양상이 해소된다.
- **그 밖의 영상 검사**: 방사선 촬영은 **동반된 부비동염**을 평가하는 데도 유용하다. 위식도 역류가 의심되면 상부 위장관 조영 검사가 필요할 수 있고, 폐색전이 천식을 모방한다고 판단되면 **폐 환기-관류 스캔 또는 CT 혈관조영술**이 필요할 수 있다.
- **객담 검사**: 자연적으로 배출된 객담과 유도 객담 모두 천식 진단을 확정하고 치료 요구량을 결정하는 데 도움이 된다. 자연 객담은 점액성, 화농성 또는 두 가지의 혼합일 수 있다. 중요하게도 **화농성 객담이 항상 세균 감염의 존재를 의미하지는 않는다**.
- **객담의 특징적 소견**: 객담에서 길이가 수 cm에 이르는 **얇은 나선형 세기관지 주형(Curschmann spirals)**이 보이면 천식을 강력히 시사한다. **섬모 원주 기관지 상피세포**가 흔히 발견된다. **Creola bodies**는 움직이는 섬모가 있는 기관지 상피세포 덩어리로 중증 천식에서 관찰된다.
- **객담 세포 조성**: 천식에서는 객담 호산구와 호중구가 모두 증가할 수 있고, 세포 침윤이 주로 호산구성 또는 호중구성, 때로는 **소과립구성(paucigranulocytic)**일 수 있다. **객담 호산구증가의 중요성은 흡입 코르티코스테로이드(ICS) 치료가 불충분하거나 순응도가 낮다는 것을 시사**한다는 데 있다. 천식의 급성 악화는 대개 객담 호산구 또는 호중구 수의 증가와 관련된다.
- **피부 단자 검사**: 천식 환자에서 **아토피의 존재**, 특히 환경 알레르겐이 천식 증상의 중요한 촉발 인자인지 확립하는 것이 중요하다. 피부 검사는 가능하면 흔한 항원(곰팡이, 꽃가루, 진균, 집먼지, 깃털, 음식, 동물 비듬)의 **수성 추출액을 이용한 피부 단자(skin prick)** 방식으로 시행한다. 항원에 대한 피부 감작 항체가 있으면 **$15\sim30$분 내에 팽진-발적(wheal-and-flare) 반응**이 생기고, 생리식염수 희석액 대조 검사는 반응이 거의 또는 전혀 없어야 한다. 최적으로는 병력과 피부 반응성이 일치하지만, 병력은 양성인데 검사는 음성인 환자도 있고, 병력은 음성인데 검사가 양성인 경우도 있어 이는 **임상적으로 무의미한 면역 반응성**을 나타낸다.
- **혈액 검사**: 천식 진단에는 드물게만 유용하지만, **radioallergosorbent test(RAST)**는 특정 알레르겐에 대한 알레르기의 존재를 확인하는 데 사용된다. 또한 혈중 호산구 수가 천식 환자에서 증가할 수 있으나 진단에 민감하지도 특이하지도 않다.
- **호기 산화질소**: 상승된 **호기 산화질소(exhaled nitric oxide, eNO)** 수치는 적절한 임상 상황에서 천식과 관련된 호산구 염증을 시사할 수 있으나, 이 검사의 임상적 유용성은 아직 불확실하다.
- **감별 진단의 범위**: 소아에서는 천식으로 오진될 수 있는 질환이 만성 비부비동염, 위식도 역류, 낭성섬유증, 기관지폐 이형성증, **흉강 내 기도 협착을 일으키는 선천 기형**, 이물 흡인, 원발성 섬모이상운동증(primary ciliary dyskinesia), 면역결핍, 선천 심장병이다. 성인에서는 낭성섬유증, 진폐증, 폐를 침범한 전신 혈관염도 고려해야 한다.
- **도판 소견**: 객담 도말의 저배율 도식(대식세포, **Charcot-Leyden 결정**, 다형핵 호중구, Curschmann spirals, 호산구, 기관지 상피세포 덩어리[Creola bodies]), 기관지 주형 육안 사진, 염색 도말의 호산구, 고배율에서의 Charcot-Leyden 결정·호산구·상피세포가 제시된다.

### Plate 4-19 | 천식의 추가 검사와 생리학적 이상 (Differential Diagnosis / Physiologic Abnormalities in Asthma)
![[Netter_V3_Plate4-19.png]]
- **피부 검사의 술기**: **A. 긁기 검사(scratch test)** — 대조액과 의심 항원 한 방울씩을 전완 굴측면(또는 다른 무모 피부면)에 떨어뜨리고, 각 방울을 통해 작은 천자나 긁기를 가하며 각각 청결한 주침(clean stylet)을 사용한다. **B. 피내 검사(intradermal test)** — 더 민감한 방법이지만 **전신 반응을 일으킬 가능성이 더 크다**. **C. 판독** — 음성(또는 대조), 가성족지 없는 발적과 팽진, 가성족지(pseudopodia)를 동반한 15 mm 팽진 + 발적. 도판에는 에피네프린 주사기와 지혈대, 상용 검사 항원 배열이 함께 제시된다.
- **천식의 주요 생리 장애**: 천식에서 일차적 생리 장애는 **기류 폐쇄**이며, **호기에서 더 현저**하다. 이 폐쇄는 중증도와 침범 부위가 가변적이고 정의상 어느 정도 가역적이다. **평활근 수축, 염증, 부종, 점액 과다 분비**의 다양한 조합이 이 기류 장애를 만든다. 또한 낮은 폐용적과 말초 공기공간 허탈(terminal airspace collapse)이 기도 폐쇄를 가중시킬 수 있다.
- **중심 기도와 말초 기도의 차이**: 큰 기도에서는 단단한 연골환이 개방성을 유지하는 데 도움이 된다. 그러나 말초 기도에는 연골이 적어 평활근 작용에 대항할 구조가 거의 없어, 개방성이 **폐용적에 의해** 영향을 받는다(폐 실질에 묻혀 부분적으로 지지되기 때문).
- **저항의 변화**: 천식 발작의 시작이나 경증에서는 폐쇄가 광범위하지 않다. 천식이 진행하면 **기도 저항이 유의하게 증가**한다. 흡기 저항도 증가하지만, 폐가 비워지면서 기도가 좁아지거나 닫히기 때문에 **호기 시 이상이 더 두드러진다**. 이 시점에서 추가적인 호기 노력은 호기 유량의 증가를 만들지 못하고 오히려 **기도 허탈을 심화시킬 수 있다**.
- **호흡근의 역할 변화**: 이러한 기계적 저항 때문에 호흡근은 더 큰 정도의 흉곽 팽창을 만들어야 한다. 더 중요하게는 **폐의 탄성 반동만으로는 "수동적" 호기에 불충분**해져 호흡근이 호기에 **능동적 역할**을 해야 한다. 폐쇄가 심하면 **공기 포착(air trapping)**이 생겨 **잔기량(RV)과 기능적 잔기량(FRC)이 증가**한다.
- **불균등한 폐쇄의 결과**: 기도 폐쇄는 불균등해 폐포로의 기체 분포도 불균등해진다. 이와 다른 자극들이 **빈호흡**과 그에 따른 호흡주기 단축을 초래하는데, 기관지 폐쇄는 적절한 환기를 위해 오히려 호흡 시간의 **연장**을 요구한다. 발작이 계속되는 동안 이 상충하는 요구는 조정될 수 없다.
- **폐활량측정 소견**: 폐쇄의 중증도는 호기 용적과 기류의 폐활량측정치에 반영된다. **급성 발작 중에는 $FEV_1$, FVC, 흡기용량(IC)이 모두 감소**한다.
- **말초 기도의 숨은 폐쇄**: 말초 기도는 총 단면적이 비례적으로 크기 때문에 그 저항이 정상적으로 **전체 기도 저항의 20%만** 차지한다. 따라서 임상 소견에만 의존하면 **작은 기도의 광범위한 폐쇄를 놓칠 수 있다**. FVC와 $FEV_1$의 감소는 $PaO_2$ 감소와 좋은 상관을 보이며, **이산화탄소 저류는 $FEV_1$이 약 1 L 또는 예측치의 25%가 될 때까지는 발생하지 않는다**.
- **진행성 폐쇄와 과팽창**: 폐쇄가 진행하면 호기가 점점 연장되고 RV와 FRC가 증가한다. 이 용적 변화는 환자에게 **내재적인 생리적 반응**일 수 있는데, 더 높은 폐용적으로 호흡하면 말초 기도의 폐쇄를 막을 수 있기 때문이다. 이 현상들의 전체 효과는 **폐포 과팽창(alveolar hyperinflation)**이며, 기도벽에 더 큰 측방 힘을 가해 기도 직경을 더 증가시킨다. 이 과팽창은 가스교환을 부분적으로 보존할 수 있지만 **훨씬 더 많은 일이 필요해 $O_2$ 소비가 증가한다**는 점에서 불리하고, IC와 폐활량(VC)을 희생시킨다. 호흡곤란과 피로 증상도 부분적으로 이 과정에서 비롯된다. 마지막으로 **호흡 기류 속도가 심하게 감소해 기침의 효과가 손상**된다.
- **저환기 폐포군의 비율**: 천식의 불균등한 기도 폐쇄 때문에 흡입된 공기가 말초 호흡 단위로 고르게 분포하지 않는다. 폐쇄된 기도에 의해 저환기되는 폐포가 정상 또는 과환기 폐포와 뒤섞여 존재하므로, **천식의 중증도는 저환기 폐포군과 양호하게 환기되는 폐포군의 비율에 직접 비례한다**.

### Plate 4-20 | 기관지 천식의 대표적 감별 진단 (Representative Differential Diagnosis of Bronchial Asthma)
![[Netter_V3_Plate4-20.png]]
- **동맥 저산소혈증의 기전**: **동맥 저산소혈증이 천식에서 가스교환의 일차적 결함**이며, 이는 환기-관류($\dot V_A/\dot Q_C$) 비의 불균등성에 기인한다. 낮은 $\dot V_A/\dot Q_C$ 비를 가진 폐포 단위의 수가 (진행하는 폐쇄 때문에) 증가할수록 저산소혈증의 정도도 심해진다. 일부 기도가 완전히 폐쇄되면 $\dot V_A/\dot Q_C$ 장애가 가중되어 **우좌 폐내 단락(right-to-left intrapulmonary shunt)** 효과가 동맥 저산소혈증을 만든다.
- **이산화탄소 제거**: 정상적인 $\dot V_A/\dot Q_C$ 비를 가진 폐포-모세혈관 단위의 수가 낮은 비의 단위에 비해 여전히 많으면 **이산화탄소 제거는 손상되지 않는다**. 기도 폐쇄가 진행하면 저환기 폐포가 점점 더 많아진다. 동시에 호흡 일, 호흡수, 호흡 깊이의 적절한 증가가 일어난다. 이런 반응은 처음에는 생리적 사강의 증가를 최소화하지만 결국 한계에 이르고, **폐포 환기가 마침내 신체의 대사 요구를 지지하지 못하게 된다**. 이제 이산화탄소 저류가 증가하는 저산소혈증과 함께 발생하며, 이는 **환기부전(ventilatory failure)** 상태이고 **$FEV_1$이 예측치의 25% 미만일 때 흔히 발생**한다.
- **감별 진단 목록**: 도판에 제시된 감별 대상은 다음과 같다.
  - **기도 질환**: 기관지염 또는 세기관지염(급성·만성), 기관지확장증이나 기타 폐질환(감염성, 신생물성, 육아종성), 기관기관지 종양.
  - **심혈관 질환**: **울혈성 심부전(심장성 천식, cardiac asthma)**, 폐색전, 대동맥류, 선천성 협착성 혈관륜(congenital constrictive vascular rings).
  - **흡입·환경 요인**: 자극성 흡입물(산업 또는 가정), 흡인(음식 또는 이물), 농부폐(Farmer's lung — 이중 천식 반응을 동반한 알레르기 폐포염).
  - **해부학적·기타**: 열공 탈장(hiatal hernia)과 역류, 종격동 종괴(종양, 림프절).
  - **상기도 원인**: **성대 기능부전(vocal cord dysfunction)**, 후두 종양 또는 낭종(볼밸브형일 수 있음), 후두 부종(크룹).
  - **전신 반응**: 아나필락시스.
- **임상적 의의**: 이 감별 목록은 천명·기침·흉부 압박·호흡곤란이 천식 이외의 여러 호흡기·심장 질환의 증상이라는 "천명하는 모든 것이 천식은 아니다"라는 원칙을 구체화한 것이다. 특히 VCD와 후두 병변은 상기도 폐쇄를 일으켜 천식으로 오진되기 쉬운 대표적 질환이며, 심장성 천식은 심부전의 호흡기 발현으로 반드시 배제해야 한다.
- **도판 소견**: 위의 감별 진단 인체 개요도와 함께, 천식에서 기도 폐쇄와 혈액가스·pH의 관계가 병기된다. 경증 천식에서는 (1) 기관지 폐쇄가 혈액 산소화를 감소시키고, (2) 저산소증·불안·호흡일 증가가 과환기를 일으키며, (3) 과환기가 $CO_2$ 제거를 증가시켜 저탄산혈증(hypocapnia)을 만들고, (4) 저탄산혈증이 호흡성 알칼리증을 초래한다. 중증 천식 및 천식지속증(status asthmaticus)에서는 (1) 더 심한 기관지 폐쇄가 산소화를 크게 감소시키고, (2) 환기 반응이 비효과적이 되며, (3) 진행된 폐쇄와 불충분한 호흡 때문에 환기가 실패해 $CO_2$ 저류(고탄산혈증)가 생기고, (4) 고탄산혈증이 호흡성 산증과 호흡부전을 초래한다.

### Plate 4-21 | 천식의 병인: 유전학과 세포 염증 (Pathogenesis of Asthma)
![[Netter_V3_Plate4-21.png]]
- **유전과 환경의 상호작용**: 유전적 요인과 환경적 요인이 복잡한 방식으로 상호작용해 천식 감수성과 천식 발현을 모두 만들어낸다.
- **5q31-33의 사이토카인 군집**: **5번 염색체 5q31-33의 여러 유전자**가 천식과 아토피에 동반된 염증의 발생이나 진행에 중요할 수 있으며, 여기에는 **인터루킨-3(IL-3), IL-4, IL-5, IL-9, IL-12, IL-13**과 **과립구-대식세포 집락자극인자(GM-CSF)**가 포함된다. 또한 **코르티코스테로이드 수용체**와 **$\beta_2$-아드레날린 수용체** 등 여러 다른 유전자가 천식 발생이나 병인에 역할을 할 수 있다. **5q32에는 $\beta_2$-아드레노셉터 유전자**가 있어 **다형성이 매우 높고**, 수용체 기능과 $\beta$-작용제에 대한 반응을 변화시키는 여러 변이형이 발견되었다.
- **다른 염색체 영역**: 알레르기나 천식 발생과 연결된 다른 영역으로 **11q**가 있으며 여기에는 **고친화성 IgE 수용체 $\beta$사슬(FcεRIβ) 유전자**가 있다. **12번 염색체**에도 인터페론-$\gamma$(IFN-$\gamma$), 줄기세포인자(SCF), IGF-1, **구성형 산화질소합성효소(cNOS)**를 포함한 여러 후보 유전자가 있다.
- **ADAM33**: **20p13의 ADAM33 유전자(a disintegrin and metalloproteinase 33)**가 천식과 유의하게 연관되어 있다. ADAM 단백질은 막에 고정된 단백분해효소다. **ADAM33이 중간엽세포(mesenchymal cell)에 제한적으로 발현되고 기도 과반응성(AHR)과 밀접하게 연관된다**는 점은 이것이 기도 평활근이나 기도 재형성(airway remodeling)에 연결된 사건에서 작용할 수 있음을 시사한다.
- **지속적 기도 염증**: 지속적 기도 염증은 **중증, 경증, 심지어 무증상 천식의 특징적 소견**으로 간주된다. 특징적 소견에는 염증세포의 기도 침윤, **기도 평활근의 비후**, 그리고 기저막 바로 아래 **망상층(lamina reticularis)의 비후**가 포함된다.
- **다세포성 염증 침윤**: 기도 염증 침윤의 중요한 특징은 **다세포성(multicellular)**이라는 점이며, 주로 호산구로 구성되지만 다양한 정도로 호중구, 림프구 및 다른 세포들도 포함된다. 호중구·호산구·T림프구는 순환에서 모집되는 반면, **비만세포는 기도의 상주세포**다. **비만세포 탈과립과 호산구 공포화(vacuolation)의 조직학적 증거**는 염증세포가 활성화되어 있음을 보여준다. 점막 비만세포는 수가 증가하지는 않지만 천식 환자에서 과립 분비의 징후를 보인다. 부검 연구는 천식 기관지와 폐 실질에서 비만세포 수가 겉보기에 감소한 것을 보여주는데, 이는 진짜 수 감소보다 **탈과립을 반영**한다.
- **호산구**: 호산구는 기관지폐포세척(BAL)과 기관지 생검 연구에서 관찰되는 **천식의 주된 가장 특징적인 세포**로 간주된다. 기관지 상피는 호산구로 침윤되며 이는 큰 기도와 작은 기도 모두에서 드러나고, 급성 중증 천식에서는 **근위 기도에서 더 강하게** 나타난다. 그러나 일부 연구는 중증 또는 치사성 천식에서 호산구가 사실상 없음을 보고하여 이 과정에 **이질성**이 있음을 시사한다.
- **대식세포와 림프구**: 폐포 대식세포는 정상인과 천식 환자 모두에서 **인간 폐에서 가장 흔한 세포**이며 활성화되면 광범위한 매개물질을 분비한다. 림프구는 천식 발생에 결정적이고 질병 중증도와 관련되어 기도에서 발견된다. 림프구의 기능과 기여는 다인성이며 **사이토카인 분비 능력**이 중심이다. 활성화 T세포는 **Th2 사이토카인(예: IL-4, IL-13)**의 원천이며, 이는 활성화 B세포가 **IgE를 생성**하도록 유도하고 세포부착분자 — 특히 **혈관세포부착분자-1(VCAM-1)** — 의 발현을 증가시킨다. 또한 **IL-5는 조직 내 호산구의 발달과 생존에 필수**적이다.
- **도판 소견**: 기도 폐쇄와 혈액가스 관계의 병기와 함께, 기도 염증의 세포 기전(비만세포 탈과립, 점막 비후, 기관지 평활근 비후, 점액선 증식)이 도식화된다.

### Plate 4-22 | 면역학적 이상 (Immunologic Abnormalities)
![[Netter_V3_Plate4-22.png]]
- **아토피의 개념**: 알레르기 천식과 다른 알레르기 질환(알레르기 비염, 아나필락시스)은 환경 알레르겐에 대한 **감작(sensitization)**과 이후 알레르겐을 다시 만났을 때의 **면역 매개 반응**의 결과로 발생한다. 이러한 알레르기 반응은 폐, 위장관, 피부 같은 특정 표적 장기에서 일어난다. 알레르기 반응을 일으키는 이 면역 과정이 임상적으로 **"아토피(atopy)"**라 불리는 질병 상태를 나타낸다. 면역 순서는 **감작 단계**에 이어 임상 증후군을 만들어내는 **유발 반응(challenge reaction)**으로 구성된다.
- **감작의 세포 기전**: 감작은 무해한 알레르겐을 처음 만났을 때 일어난다. 단핵구, 대식세포, 미성숙 수지상세포 같은 **전문 항원제시세포(APC)**가 항원을 포획해 짧은 면역원성 펩타이드로 분해한다. 절단된 항원 단편은 **MHC class II 분자**를 통해 **naïve CD4+ T-helper(Th) 세포**에 제시된다. 여러 요인 — 특히 **사이토카인 미세환경** — 에 따라 이 naïve T-helper 세포는 이후 **Th1 또는 Th2 림프구로 극화(polarization)**된다.
- **Th1과 Th2의 분기**: Th1 림프구는 주로 **IL-2, IFN-$\gamma$, 종양괴사인자(TNF)-$\beta$**를 분비해 **세포성 면역 반응**을 유도한다. 반대로 Th2 림프구는 **IL-4, IL-5, IL-9, IL-13** 사이토카인을 분비해 **체액성 면역 반응**, 특히 알레르겐 특이 IgE 생성을 위한 **B세포 class switch**를 유도한다.
- **Th2 편향**: 알레르기 천식에서는 Th1과 Th2 림프구 사이에 불균형이 존재하며, 면역이 Th1 양상에서 **Th2 양상으로 이동**한다. 따라서 알레르기 천식은 흡입 알레르겐에 대한 지속적 **Th2 편향 면역 반응**을 가진 **Th2 매개 질환(Th2-mediated disorder)**으로 흔히 언급된다.
- **IgE의 특성**: IgE는 $\gamma_1$-당단백으로 **혈청에서 가장 적게 존재하는 항체**이며, 정상인에서 농도가 **$150\ \text{ng/mL}$**(비교: IgG는 $10\ \text{mg/mL}$)다. 그러나 "아토피" 개인에서는 순환 IgE 농도가 정상의 **10배 이상**에 이를 수 있다. IgE 수치는 **기생충 감염**과 **고IgE 증후군(hyper-IgE syndrome)** 환자에서도 증가한다. 혈청 농도 증가가 해당 개인의 알레르기의 범위나 중증도를 반드시 특이적으로 나타내는 것은 아니다. IgE 분자는 비만세포나 호염기구 같은 세포의 표면에 부착하는데, **IgE를 함유한 비만세포는 상·하기도 점막과 폐의 혈관주위 결합조직에 분포**한다.
- **즉시형 과민반응**: 알레르겐에 대한 감작이 일어난 후 환자가 알레르겐에 다시 노출되면 급성 알레르기 반응, 즉 **즉시형 과민반응(immediate hypersensitivity reaction)**이 나타날 수 있다. 특정 항원에 접촉한 **IgE 감작 비만세포**는 미리 형성된 매개물질과 새로 합성된 매개물질 — **히스타민, 시스테이닐 류코트리엔(cysteinyl leukotrienes), 키닌, 프로스타글란딘과 트롬복산, 혈소판활성인자** — 를 분비한다. 또한 비만세포는 **전염증성 사이토카인의 원천**이다. **각 항원 분자는 세포 표면에 결합된 최소 2개의 IgE 분자를 연결(bridge)해야 한다**는 것이 필수 조건이다. 이후 기도 평활근 수축, 혈관수축, 점액 과다 분비와 함께 모세혈관 투과성 증가와 호산구·호중구 침윤의 염증 반응이 뒤따라 천식 증상을 만든다.
- **도판 소견(기도 병태생리의 도식)**: 알레르겐이 탈락 상피 부위를 통해 점막하로 침투하고, 활성화된 비만세포와 Th2 세포가 사이토카인·케모카인을 분비해 염증세포의 모집과 활성화를 일으킨다. 부착분자의 사이토카인 상향조절, 평활근 수축, 호산구·호염기구 유래 단백에 의한 상피 파괴와 상피 매개물질 소실이 **지연 천식 반응(late asthmatic response)**을 구성한다. 만성 천식에서는 **기저막 비후**, 만성 저등급 염증이 근육층을 넘어 확장되어 흡입 약물에 덜 반응하게 되고, 이 만성 염증이 **알레르겐이나 자극물에 대한 기도 과반응성**을 초래한다.

### Plate 4-23 | 천식의 병리학적 변화 (Pathologic Changes in Asthma)
![[Netter_V3_Plate4-23.png]]
- **지식의 출처**: 천식 병리에 대한 초기 지식은 치사성 천식의 부검, 다른 원인으로 사망한 천식 환자의 기도, 또는 폐 절제를 받은 환자의 기도 연구에서 나왔다. 모두 유사하지만 중증도가 다양한 병리 변화를 보였고, 기도의 염증 반응의 원인과 결과에 대한 핵심 지침을 제공했다.
- **점액 마개의 역할**: 천식 기도의 특징적인 **점액 마개(mucus plug)**는 기도 폐쇄를 일으켜 환기-관류 불일치를 만들고 저산소혈증에 기여한다. 점액 마개의 구성은 **점액, 혈청 단백, 염증세포, 세포 파편**(탈락 상피세포와 대식세포를 포함하고 종종 **나선형 배열, 즉 Curschmann spirals**를 이룸)이다. 치사성 천식에서 과도한 점액 생성은 **점막하선의 비후와 증식**에 기인한다. 점액은 또한 핵산, 당단백, 알부민의 양이 증가해 **더 점성이 높아진다**. 이렇게 변화된 점액 유변학(rheology)이 **섬모 상피의 소실**과 맞물려 **점막섬모 청소(mucociliary clearance)를 손상**시킨다.
- **기도벽 두께의 증가**: 천식에서는 기도벽 두께가 증가하며 **질병 중증도와 관련**된다. 비천식인과 비교해 기도벽 두께는 **치사성 천식 환자에서 50~300% 증가**, **비치사성 천식에서 10~100% 증가**한다. 더 두꺼워지는 것은 **평활근, 상피, 점막하, 외막, 점막선**을 포함한 대부분의 조직 구획이 증가하기 때문이다.
- **염증성 부종과 세포 변화**: 염증성 부종은 전체 기도, 특히 **점막하층**을 침범하며, **점막하선의 현저한 비후·증식**과 **배상세포 증식(goblet cell hyperplasia)**이 동반된다. 배상세포의 증식과 비후는 **상피세포의 소실**과 함께 일어난다. **근육층(muscularis)의 증식**과 기도 **외막층의 미세혈관 확장(microvascular vasodilation)**도 관찰된다.
- **혈관 변화**: 형태계측 연구는 천식 환자의 기관지 고유판(lamina propria)이 비천식인보다 **더 많은 수의 혈관이 더 큰 비율의 면적을 차지**하고 있으며, 일부 상황에서는 이것이 **질병의 중증도와 상관**됨을 보여주었다.
- **도판 소견(중증 천식의 병리)**: 육안 소견으로 **기도 내 끈적하고 점성인 점액 마개, 무기폐 병소(foci of atelectasis), 국소적 또는 미만성 과팽창**이 제시된다. 현미경 소견으로 **PAS 양성 기질**, 다형핵 호중구, 호산구, **Charcot-Leyden 결정**, Curschmann spirals, 상피세포 덩어리(Creola body)를 포함한 점액 마개, **상피 탈락(epithelial denudation)**, **기저막의 유리질성 비후(hyaline thickening of basement membrane)**, **평활근·점막선·배상세포의 비후**, 호산구와 부종을 동반한 염증성 삼출물, 울혈된 혈관이 제시된다. 또한 폐색된 천식 기도와 점액 마개로 막힌 기도의 단면, 그리고 정상 기도(A)와 고용량 흡입 스테로이드 치료 전 재형성(remodeling)을 보이는 천식 기도(B)의 비교가 포함된다.
- **도판 소견(제1형 과민반응 기전)**: A. 유전적으로 아토피인 환자가 특정 항원(도판에는 돼지풀 꽃가루)에 노출. B. 호흡기 점막 림프조직의 형질세포가 **면역글로불린 E(IgE)**를 방출. C. **IgE가 Fab 단편으로 비만세포와 호염기구의 세포막에 부착해 감작**(Fc 단편, 이황화 결합, 중쇄·경쇄 도시). D. 같은 항원에 재노출. E. 항원이 감작된 비만세포/호염기구 막의 **IgE 항체와 반응하여 약리학적 매개물질을 분비**(Ca²⁺, Mg²⁺ 관여). F. 말단 장기(기도) 반응 — 프로스타글란딘, 염증성 사이토카인, 시스테이닐 류코트리엔, 히스타민이 **평활근 수축, 점액선 과다 분비, 모세혈관 투과성 증가와 염증 반응, 호산구 유인**을 일으킨다. 탈과립은 히스타민·헤파린·세로토닌을 방출한다. 천식 반응에서의 백혈구 경로는 항원 → 항원제시 수지상세포 → **CD4+ T세포 → 도움 T세포** → B세포 → 형질세포 → IgE 항체이며, **IL-9, IL-4·IL-13, IL-5**가 각각 비만세포, IgE 생산, 호산구 모집에 관여한다. 감작 후 T-helper 세포가 **Th2 사이토카인 프로파일로 편향**되어 체액성 면역(IgE 생성)과 호산구·비만세포 활성화, 점액 분비가 일어나 모두 **기도 염증과 기도 협착**을 초래한다.

### Plate 4-24 | 천식의 장기 관리 (Long-Term Management of Asthma)
![[Netter_V3_Plate4-24.png]]
- **치료 목표**: 천식 치료 지침들은 목표와 목적을 놀라울 정도로 일관되게 제시해 왔다. 그것은 (1) 천식 증상을 최소화하거나 제거하고, (2) 가능한 최선의 폐기능을 달성하고, (3) 천식 악화를 예방하고, (4) 위 사항을 **가능한 한 적은 약물로** 달성하고, (5) 단기·장기 부작용을 최소화하고, (6) 환자에게 질병과 관리 목표를 교육하는 것이다.
- **추가 목표와 "천식 조절"**: 또 하나 중요한 목표는 일부 천식 환자에서 발생하는 **폐기능의 저하와 고정 기류 폐쇄(fixed airflow obstruction)의 발생을 예방**하는 것이다. 각 지침 문서는 "천식 조절(asthma control)"의 의미도 기술했는데, 위 목적들에 더해 **구제약(흡입 $\beta_2$-작용제)의 필요를 하루 1회 미만으로 최소화**하고, 천식의 특징인 **유량의 변동성을 최소화**하며, **정상적인 일상 활동**을 유지하는 것이 포함된다. 이 수준의 조절을 달성하는 것이 **환자가 치료 의사에게 처음 방문하는 시점부터 목표**여야 한다. 천식 환자의 약물 치료는 **천식 교육과 유발인자 회피라는 맥락에서만** 고려되어야 한다.
- **경증 지속성 천식(Mild persistent asthma)**: **저용량 흡입 코르티코스테로이드(ICS)**가 흔히 이상적인 천식 조절을 제공하고 경증 지속성 천식 소아·성인 모두에서 **중증 천식 악화 위험을 감소**시키므로 **치료 선택(the treatment of choice)**이 되어야 한다. ICS는 천식 치료에서 **가장 효과적인 항염증제**다.
- **병용 요법의 근거 부족(경증)**: ICS와 흡입 지속성 $\beta_2$-작용제(LABA)의 병용 요법을 규칙적으로 사용하는 것이 추가적 이점을 준다는 설득력 있는 증거는 없다. **류코트리엔 수용체 길항제(LTRA)**도 이 환자군에서 또 하나의 치료 옵션이지만 **저용량 ICS보다 효과가 떨어진다**.
- **반응의 개인차**: 어떤 치료든 반응에 개인 간·개인 내 차이가 상당하다. 성인과 소아 모두 ICS와 LTRA 치료 반응에서도 마찬가지다. 평균적으로 ICS가 거의 모든 천식 결과에서 LTRA보다 더 개선시키지만 일부 환자는 LTRA에 더 큰 반응을 보일 수 있다. **현재로서는 임상적·생리적·약물유전체적 특성으로 이런 반응자(responder)를 정확히 식별할 수 없다**.
- **ICS의 부작용 고려**: 경증 천식 환자에서 ICS 치료 시작을 결정할 때 반드시 고려해야 할 또 다른 문제는 부작용 가능성이다. **ICS는 폐에서 대사되지 않으며 폐로 투여된 ICS 분자는 모두 전신 순환으로 흡수된다.** 경증 지속성 천식 환자를 대상으로 한 모든 연구는 **저용량 ICS(최대 $400\ \mu g/\text{d}$)**를 사용했다. 성인에서 저용량 ICS의 안전성을 보여주는 풍부한 데이터가 있고 장기 사용에도 안전하다. 그러나 **소아에서 저용량 ICS로 성장 속도(growth velocity)의 유의한 감소가 입증**되었다. 다만 ICS 치료 소아를 최종 신장까지 추적한 한 연구에서 중등도 일일 ICS 용량에도 해로운 영향이 없었으므로, **최종 신장에 영향을 미칠 가능성은 낮다**.
- **도판 소견**: 중증 천식의 육안·현미경 병리(점액 마개, 무기폐, 과팽창, 상피 탈락, 기저막 유리질성 비후, 평활근·점막선·배상세포 비후, 염증성 삼출물, 울혈 혈관)와 정상 기도 대비 재형성된 천식 기도의 비교가 함께 제시된다.

### Plate 4-25 | 중등도·중증 지속성 천식의 치료 (Moderate and Severe Persistent Asthma Management)
![[Netter_V3_Plate4-25.png]]
- **중등도 지속성 천식(Moderate persistent asthma)**: **저용량 ICS로 잘 조절되지 않는** 천식 환자군이다. 천식 치료 지침은 이 환자들에서 **ICS와 LABA의 병용 요법**을 선호 치료 옵션으로 권고한다. 이는 중등도 지속성 천식에 대한 ICS+LABA 병용 치료가 **ICS 단독에 비해 모든 천식 조절 지표를 개선**하는 것으로 입증되었기 때문이다.
- **근거의 적용 범위**: ICS와 LABA 병용의 강화된 이점에 대한 증거는 **주로 성인 천식 환자에서** 존재한다는 점을 주의해야 한다.
- **유지 + 구제 병용 요법**: 중등도 천식 환자 관리에 대해 최근 기술된 또 다른 치료 접근은 **ICS 부데소니드(budesonide)와 LABA 포르모테롤(formoterol)의 복합 흡입기를 유지 요법과 구제 요법 모두로 사용**하는 것이다. 이는 연구된 다른 접근들에 비해 **중증 천식 악화 위험을 감소**시키고 **경구 코르티코스테로이드 사용의 감소**를 동반하는 것으로 나타났다.
- **LTRA 추가**: 성인과 소아 모두 중등도 지속성 천식 환자에서 ICS에 LTRA를 추가할 때의 임상적 이점을 비교한 여러 연구가 있다. ICS에 LTRA를 추가하면 ICS 단독에 비해 **중등도로(modestly) 천식 조절이 개선**될 수 있으나, 이 전략은 **ICS 용량을 증가시키는 것의 대체로 권장될 수 없다**. 또한 LTRA는 ICS와 병용할 때 **LABA보다 효과가 떨어진다**.
- **테오필린 추가**: **저용량 테오필린**도 ICS에 대한 추가 요법으로 평가되었으나 달성되는 이점의 크기가 **LABA보다 작다**.
- **오말리주맙(omalizumab)**: 중등도 천식 환자의 또 다른 잠재적 치료 옵션으로, **IgE에 대한 재조합 인간화 단클론 항체(recombinant humanized monoclonal antibody)**다. 이 항-IgE 항체는 **유리 IgE와 복합체를 형성해 IgE와 효과세포(effector cell) 사이의 상호작용을 차단**하고 **유리 IgE의 혈청 농도를 감소**시킨다. 중등도~고용량 ICS를 사용하는 환자에서 위약과 비교해 오말리주맙은 **천식 악화를 감소**시키고 **ICS 용량의 작지만 통계적으로 유의한 감소**를 가능하게 한다. 그러나 이 치료는 **LABA처럼 저렴하고 입증된 추가 요법과 비교된 적이 없다**. 따라서 이 치료는 현재 국제 지침에서 **중등도~중증 천식 환자**에게 권고된다.
- **중증 지속성 천식(Severe persistent asthma)**: **고용량 ICS와 LABA에도 적절히 반응하지 않는** 환자들이다. 이 집단은 천식 관련 의료 자원을 불균형적으로 소비한다. 생리적으로 이들은 흔히 **공기 포착(air trapping), 기도 허탈성(airway collapsibility), 높은 정도의 기도 과반응성(AHR)**을 가진다. 중증 난치성(difficult-to-treat) 천식 환자는 대개 **유의한 동반질환을 가진 성인**이며, 여기에는 중증 비부비동염, 위식도 역류, 비만, 불안 장애가 포함된다. 이들은 천식 조절을 달성하기 위해 ICS에 더해 **경구 코르티코스테로이드**가 필요한 경우가 많다.
- **급성 중증 천식 악화의 정의**: 급성 중증 천식 삽화(천식 악화)는 호흡곤란, 기침, 천명, 흉부 압박감 또는 이들의 조합이 점진적으로 증가하는 삽화이며, **PEF 또는 $FEV_1$ 측정으로 정량화할 수 있는 기류 폐쇄**를 특징으로 한다. 이 측정값들은 **증상의 정도보다 기류 제한 중증도의 더 신뢰할 만한 지표**다. 중증 악화는 잠재적으로 생명을 위협하며 치료에 면밀한 감독이 필요하다. 중증 악화 환자는 **신속히 진료를 받거나 급성 천식 환자를 위한 응급 진료를 제공하는 가장 가까운 병원으로 가도록** 권고해야 하며, **치료 반응에 대한 면밀한 객관적 모니터링**이 필수적이다.
- **일차 치료**: 중증 천식 악화의 일차 치료는 **속효성 흡입 $\beta_2$-작용제의 반복 투여**, 즉 첫 1시간 동안 **20분마다 2~4 퍼프**를 포함한다. 첫 1시간 이후 필요한 $\beta_2$-작용제 용량은 악화의 중증도와 이전에 투여한 흡입 $\beta_2$-작용제에 대한 반응에 달려 있다. **흡입 $\beta_2$-작용제와 항콜린제(이프라트로피움 브로마이드, ipratropium bromide)의 병용**이 어느 단일 약물보다 더 나은 기관지확장을 만들 수 있다. 산소는 비강 캐뉼라나 마스크로 투여하고 **맥박산소측정(pulse oximetry)에 맞추어 적정**해 만족스러운 산소포화도 **90% 이상(소아는 $\geq 95\%$)**을 유지해야 한다.
- **도판 소견**: 알레르기 천식의 일반 관리 원칙이 제시된다 — 양호한 건강 관리 조치(적절한 신체 활동과 운동, 치료 순응도, 충분한 휴식과 수면), **유발 원인의 제거 또는 조절**(위식도 역류, 부비동 감염과 비용종, 집먼지진드기 조절), 환경 인자 회피(애완동물, 유발 약물, 모직 담요, 깃털 베개, 먼지, 봉제인형, 카펫과 러그, 커튼, 꽃가루 및 그 밖의 모든 유발 알레르겐 — **린넨을 $130\ ^\circ F$에서 세탁, HEPA 필터 진공청소기 사용, 매트리스와 베개 커버 사용**), 일반 인자 회피(직업성 유해물, 곰팡이 핀 지하실, 밀집한 장소와 감기 환자, 극단적 온도, 담배 연기, 휘발성 화학물질).

### Plate 4-26 | 중증 천식 치료와 약물 기전 (Treatment of Severe Asthma and Mechanisms of Asthma Medications)
![[Netter_V3_Plate4-26.png]]
- **전신 글루코코르티코스테로이드**: 전신 글루코코르티코스테로이드는 **악화의 해소를 촉진**하고 **가장 경미한 악화를 제외한 모든 악화에 사용**해야 하며, 특히 초기 속효성 흡입 $\beta_2$-작용제 치료가 지속적인 호전을 달성하지 못할 때 사용한다. **경구 글루코코르티코스테로이드는 정맥 투여된 것과 대개 동등하게 효과적**이고 투여 경로가 덜 침습적이어서 선호된다.
- **치료의 목표**: 기류 폐쇄와 저산소혈증을 **가능한 한 빨리 완화**하고 **향후 재발 예방을 계획**하는 것이다. 천식 악화 중에는 **진정(sedation)을 엄격히 피해야 한다** — 항불안제와 최면제의 호흡 억제 효과 때문이다.
- **천식 관련 사망 고위험군**: 이들은 악화 과정 초기에 신속한 치료를 받도록 권고해야 한다. 해당 환자는 **삽관과 기계환기가 필요했던 치명적 천식(near-fatal asthma)의 병력**이 있는 사람, **지난 1년 내 천식으로 입원 또는 응급 진료를 받은 사람**, **현재 경구 글루코코르티코스테로이드를 사용 중이거나 최근에 중단한 사람**, **속효성 흡입 $\beta_2$-작용제에 과도하게 의존하는 사람**, **정신과 질환 또는 심리사회적 문제의 병력**이 있는 사람, **천식 약물 계획에 대한 불순응(noncompliance) 병력**이 있는 사람이다.
- **치료 반응의 평가와 입원 결정**: 치료 반응에는 시간이 걸릴 수 있으므로 환자를 **임상적 측정과 객관적 측정으로 모두 면밀히 모니터링**해야 한다. 증가된 치료는 **폐기능 측정치가 이전의 최상 수준으로 돌아오거나 흡입 $\beta_2$-작용제에 대한 반응이 정체기(plateau)에 이를 때까지** 계속하며, 이 시점에 이 값들을 근거로 입원 또는 퇴원을 결정할 수 있다.
- **퇴원 가능성과 입원 기준**: 안전하게 퇴원할 수 있는 환자는 **처음 2시간 이내에 반응**을 보이며, 이때 환자 처치(disposition)에 대한 결정을 내릴 수 있다. **치료 전 $FEV_1$ 또는 PEF가 예측치의 25% 미만**이거나 **치료 후 $FEV_1$ 또는 PEF가 예측치의 40% 미만**인 환자는 대개 **입원이 필요**하다. **치료 후 폐기능이 예측치의 $40\sim60\%$** 인 환자는 **지역사회에서 적절한 추적 관찰이 가능하고 치료 순응도가 보장된다면** 응급실에서 퇴원할 수 있는 경우가 많다.
- **퇴원 처방과 계획**: 응급실에서 퇴원하는 환자에게는 **성인에서 최소 7일간의 경구 글루코코르티코스테로이드 과정**, **소아에서는 더 짧은 과정($3\sim5$일)**을 처방하고 기관지확장제 치료를 계속한다. 기관지확장제는 증상적·객관적 호전을 토대로 필요 시 사용할 수 있다. 환자는 **흡입 글루코코르티코스테로이드를 시작하거나 계속**해야 한다. 환자의 **흡입기 사용 기법과 가정에서 치료를 모니터링하기 위한 최대호기유량계 사용**을 검토해야 한다. 악화를 촉발한 요인을 확인하고 향후 회피 전략을 시행해야 한다. 악화에 대한 환자의 대응을 평가하고 **천식 행동 계획(asthma action plan)을 검토하며 서면 지침을 제공**해야 한다.
- **약물 기전(도판) — 항염증제**: 코르티코스테로이드는 **호산구의 모집과 활성화를 감소**시키고, **사이토카인 생성을 억제**하며, **호산구 매개물질 분비를 억제**하고, **비만세포 이동을 감소**시키고, 코르티코스테로이드와 크로몰린(cromolyn)·네도크로밀(nedocromil)은 **비만세포 매개물질 분비를 억제**하며, 코르티코스테로이드는 **T세포 활성화를 억제**한다. **항류코트리엔제(antileukotrienes)**는 류코트리엔 생성과 수용체를 차단한다.
- **약물 기전(도판) — 기관지확장제**: **$\beta_2$-작용제**는 $\beta_2$-아드레날린 수용체 활성화 → 아데닐시클라제(adenyl cyclase) → ATP에서 cAMP 생성 → **평활근 이완**을 일으켜 기관지수축을 완화한다. 도판에는 알레르겐 → 항원제시세포(APC) → Th0 세포 → Th2 세포 → 사이토카인(IL-3, 4, 5, 6, 9, 10, 13, GM-CSF)과 IL-4·6·10·13 → B세포 → IgE → 비만세포 → 히스타민·프로스타글란딘, 류코트리엔의 경로가 함께 도시된다.

### Plate 4-27 | 천식의 응급실 관리 (Emergency Department Management of Asthma)
![[Netter_V3_Plate4-27.png]]
- **초기 평가 원칙**: **폐기능($FEV_1$ 또는 PEF)을 약물 투여 전과 후에 평가**하여 치료를 모니터링하거나 추가 검사의 필요성을 판단한다. **기관지확장제($\beta_2$-작용제) 치료를 즉시 시작**하고, 폐기능이 원하는 한계 내에 들어올 때까지 **간헐적 또는 지속적으로 유지**한다.
- **반응이 중증도보다 중요**: **초기 치료에 대한 환자의 반응이 악화의 중증도보다 추가 치료나 입원 필요성의 더 나은 지표**다. 이는 객관적 지표를 반복 측정해 치료 강도를 조정해야 함을 뜻한다.
- **첫 1시간의 처치**: **모든 천식 응급 상황에서 전신 코르티코스테로이드 치료(경구 또는 비경구)**를 시행한다. 필요에 따라 **산소를 공급**하고 **맥박산소측정과 동맥혈가스**를 확인한다.
- **퇴원 기준**: **정상적인 이학적 검사, 증상 없음, 그리고 마지막 치료 후 최소 1시간 동안 $FEV_1 \geq 70\%$**를 만족할 때 퇴원을 고려한다.
- **퇴원 처방**: 경구 코르티코스테로이드, 흡입 코르티코스테로이드, **장시간 및 단시간 작용 기관지확장제**, 그리고 **서면 천식 행동 계획(written asthma action plan)**을 제공한다.
- **도판 소견(폐기능 곡선과 처치 흐름)**: $FEV_1$의 용적-시간 곡선이 치료 전과 치료 후로 나누어 제시된다. 치료 전에는 **예측치 또는 최상 $FEV_1$에 대한 비율이 $<30\%$ 및 $<50\%$**인 경우가 도시되고, 치료 후에는 **$FEV_1 \geq 70\%$**를 달성한 상태가 표시된다. 처치 흐름도에는 기관지확장제($\beta_2$-작용제) 즉시 시작 및 유지, 전신 코르티코스테로이드, 필요 시 산소, 맥박산소측정과 동맥혈가스, 그리고 퇴원 기준과 퇴원 처방(경구·흡입 코르티코스테로이드, 장·단시간 기관지확장제, 서면 행동 계획)이 정리되어 있다.
- **임상 적용 요점**: 응급실 관리의 핵심은 (1) 객관적 지표($FEV_1$/PEF)의 반복 측정, (2) $\beta_2$-작용제의 조기·반복 투여와 항콜린제 병용, (3) 가장 경미한 경우를 제외한 모든 악화에서의 전신 코르티코스테로이드, (4) 진정제 회피, (5) 퇴원 시 재발 예방을 위한 코르티코스테로이드 과정과 서면 행동 계획 제공으로 요약된다.

| **보흐달레크 탈장 (4-4)** | 흉막복막열공 결손(낭 없음), 좌측 85%, 영아의 90% | 출생 직후 청색증, 심첨박동 위치 이상, 흉곽 내 연동음, 주상복부, 산전 초음파 | **bag-mask 금지**, 기관내삽관, 비위관 저압 흡인, 주술기 안정화 후 교정 |
| **모르가니 탈장 (4-4)** | 전방 흉골주위(Laney space) 결손, 대개 우측 | 간·대망 포함, 심낭낭종과 감별, 칸트렐 오징의 일부 | 무증상이어도 교액 위험으로 교정 |
| **기관식도누공 (4-5)** | 식도폐쇄 ± 누공, 최흔형 **90~95%**(상부 맹낭 + 하부 기관 누공) | 양수과다증, 태아 위 거품 소실, 점액 과다·수유 흡인, 카테터가 **T2-T3**에서 멈춤 | 10-Fr Replogle 관 저압 흡인, 누공 절단 + 단단문합, 긴 간격 시 3개월 지연 |
| **폐 무발생/무형성/저형성 (4-6)** | 기관지·혈관·실질의 잔존 여부로 구분 | 늑골 접근·반횡격막 거상·종격동 이동, **양측에서 호흡음 들려 청진 비진단적**, 우폐 결여 사망률 75% | 병발 질환 관리, 감염 예방, 예후 신중 |
| **기관지원성 낭종 (4-7)** | 기관기관지나무 이상 출아, 감염 전 교통 없음 | 기관분기부 근처, 상엽 호발(기관지확장증은 의존부), 감염 시 급속 확장(볼밸브) | 감염·기흉·악성화 위험으로 절제 고려 |
| **CCAM (4-7)** | 증식성 기관지·입방 상피로 피복된 낭종 덩어리(3형) | 산전 초음파, 25% 사산·III형, 50% 조산 | 생명 위협 시 주산기 수술, 무증상도 영아기 중재 고려 |
| **폐 격리증 (4-8)** | 기관기관지나무·폐혈관과 무연결 + **체동맥 공급** | **폐엽내 = 폐정맥 배액(90% 좌측 반횡격막·삼각형)** | 무증상이라도 **수술적 절제**(감염·출혈 위험) |
| **선천성 대엽성 폐기종 (4-9)** | 기관지 연골 결손/볼밸브 폐쇄/미인지 세기관지염 → 공기 포착 | 상엽 80%(좌 43%), 우중엽 32%, 청색증 50%, 환측 과투과성·늑골 확장·횡격막 편평화 | 지속·진행성 호흡부전 또는 신생아 중증 시 **폐엽절제술** |
| **만성 기침 (4-10)** | 기침 반사 구심성 신경해부 + 지속 기간 분류 | 급성 $<3$주 / 아급성 $3\sim8$주 / 만성 $>8$주, 상기도 기침 증후군 28~41% | 검증된 프로토콜 + 충분한 용량의 특이 치료(최소 20%는 다인성) |
| **성대 결절·폴립·육아종 (4-11)** | Reinke space 외상성 염증 / 삽관에 의한 피열연골 성대돌기 미란 | 고음 요구 직업, 기관내삽관 병력, 성대 전방 상피하 병변 | 음성 남용 제거·후두 위생·역류 치료, 불응 시 절제(냉기구/CO₂ 레이저) |
| **후두·기관 협착 (4-12)** | 장기 삽관·기관루에 의한 연골막 허혈 → 반흔·삼각형 협착 | 성문하 협착이 최흔, **후방벽은 약 50%에서 보존**, 기관연화증은 흡기/호기 시 폐쇄 | 커프 압력 청진 조절, 레이저 절개·확장, 기관 절제·문합 |
| **성대 기능부전 (4-13)** | 흡기 시 성대의 역설적 내전 → 기능성 상기도 폐쇄 | **흡기성 천명**, 유량-용적 곡선 흡기 유량 감쇠·**saw-tooth** | 유발 인자 제거, 후두 이완·횡격막 호흡 행동 치료, 항불안제·헬리옥스·CPAP |
* **성대 기능부전 (4-13) 진단적 단서 상세**: 후두경상 전방 2/3 내전 + 후방 다이아몬드형 틈.

### 2. 천식 진단·평가 및 치료 단계 매트릭스 (Plates 4-14 ~ 4-27)

| 구분 (Plate) | 핵심 내용 | 판정 기준/수치 | 임상 적용 |
| :--- | :--- | :--- | :--- |
| **정의 (4-14)** | 가변적 기류 폐쇄 + 기도 과반응성 + 세포성 염증 | 유병률 $5\sim15\%$, 기류 폐쇄는 부분적·완전 가역 | 증상은 삽화성: 호흡곤란·천명·기침·흉부 압박 |
| **알레르기성 vs 비알레르기성 (4-14, 4-15)** | 알레르기성: 소아·젊은 성인, 아토피·IgE 연관 / 비알레르기성: 35세 이상 성인, 피부검사 음성 | 환경 알레르겐 조기 반응 $10\sim15$분·2시간 내 해소, 지연 반응 $3\sim6$시간 | 비알레르기성은 **직업력** 필수, 동반질환(비만·부비동염·GERD) 확인 |
| **악화 인자 (4-15)** | 운동, $NO_2$·$SO_2$·오존·$PM_{10}$, 강한 냄새, 간접 흡연 | 운동 후 $10\sim20$분 최대, 1시간 내 해소 | 운동 $5\sim10$분 전 흡입 $\beta_2$-작용제로 예방 |
| **아스피린 감작 (4-15)** | Samter 삼증(아스피린 감작 + 천식 + 비용종), 천식의 약 5% | 복용 20분 내 증상, 모든 COX-1 억제제 감작 | 아세트아미노펜·COX-2 억제제는 대개 안전 |
| **중증 악화의 징후 (4-16)** | 앉은 자세 선호, 비익 확장, 보조근 사용, 청색증·혼돈 | 맥박 $>110\sim130$/분; 기이맥 $\geq10\ \text{mmHg}$ | **무음 흉부(silent chest)**는 진정제로 악화될 수 있는 불길한 소견 |
| **진단 (4-17)** | 폐활량측정의 가역성 + 기도 과반응성 | 가역성 $FEV_1 >12\%$ 개선 + 최소 200 mL, PEF $>20\%$ | 과반응성 검사는 **민감하나 특이도 제한** — 음성은 지속성 천식 배제에 유용 |
| **검사 (4-18)** | 흉부 X선은 주로 다른 질환 배제, 객담은 치료 순응도 지표 | 경증 정상·중증 과투과성; **Curschmann spirals·Creola bodies** | 화농성 객담이 항상 세균 감염은 아님 |
| **생리적 이상 (4-19, 4-20)** | 호기 우세 폐쇄, 말초 기도 저항은 전체의 20%만 차지 | 급성 발작 시 $FEV_1$·FVC·IC 감소; $CO_2$ 저류는 $FEV_1$ 약 1 L 이하 | 과팽창은 가스교환을 부분 보존하나 $O_2$ 소비↑·기침 효과↓ |
| **감별 진단 (4-20)** | 기관지염·기관지확장증·울혈성 심부전(심장성 천식)·폐색전 … | 경증: 저산소혈증→과환기→저탄산혈증→호흡성 알칼리증 / 중증: 환기부전→고탄산혈증→호흡성 산증 | $FEV_1 <25\%$ 예측치에서 환기부전이 흔히 발생 |
| **병인·면역 (4-21 ~ 4-23)** | 5q31-33 사이토카인 군집, 11q(FcεRIβ), 20p13(ADAM33); Th2 편향 | IgE 정상 $150\ \text{ng/mL}$, 아토피 10배 이상; 항원 2개가 IgE 연결해야 탈과립 | 점막 비만세포는 탈과립으로 수 감소, 호산구는 주된 특징 세포(중증에서는 결여 보고도 있음) |
| **병리 (4-23, 4-24)** | 점액 마개, 상피 탈락, 기저막 유리질성 비후, 평활근·점막선·배상세포 비후 | 기도벽 두께: 치사성 $50\sim300\%$↑, 비치사성 $10\sim100\%$↑ | 점액 유변학 변화 + 섬모 소실 → 점막섬모 청소 손상 |
| **장기 관리 (4-24, 4-25)** | 경증 ICS → 중등도 ICS+LABA → 중증 고용량/경구 + 오말리주맙 | ICS가 가장 효과적 항염증제, LTRA·테오필린 추가는 LABA보다 효과 작음 | 목표: 구제약 하루 1회 미만, 정상 일상 활동, 고정 기류 폐쇄 예방 |
| **응급 처치 (4-26, 4-27)** | 속효성 흡입 $\beta_2$-작용제 20분마다 2~4퍼프(첫 1시간) ± 이프라트로피움 | 퇴원: 증상 없음 + $FEV_1 \geq70\%$(1시간) | **진정 금지**, 퇴원 시 경구 스테로이드(성인 7일, 소아 3~5일) + 서면 행동 계획 |
* **천식 매트릭스 항목별 상세 원문 (Plates 4-14 ~ 4-27)**:
  * **중증 악화의 징후 (4-16)**: 맥박 $>110\sim130$/분 → $PaO_2 <60\ \text{mmHg}$ 시사; 기이맥 $\geq10\ \text{mmHg}$ → $FEV_1 <30\%$.
  * **진단 (4-17)**: $FEV_1 >12\%$ 개선 + 최소 200 mL, PEF 개선 $>20\%$(또는 $>60\ \text{L/min}$), 메타콜린 $\leq8\ \text{mg/mL}$에서 $FEV_1 \geq20\%$ 감소, 운동 후 $\geq15\%$ 감소.
  * **검사 (4-18)**: 경증은 정상, 중증은 가역적 과투과성(혈관 분포는 정상), **Curschmann spirals·Creola bodies**, 객담 호산구증가 = ICS 불충분.
  * **생리적 이상 (4-19, 4-20)**: 급성 발작 시 $FEV_1$·FVC·IC 감소, $CO_2$ 저류는 $FEV_1$ 약 1 L(예측 25%) 이하에서 발생.
  * **감별 진단 (4-20)**: 기관지염·기관지확장증·울혈성 심부전(심장성 천식)·폐색전·흡인·농부폐·혈관륜·열공 탈장·종격동 종괴·**VCD**·후두 병변·아나필락시스. 판정 — 경증: 저산소혈증 → 과환기 → 저탄산혈증 → 호흡성 알칼리증 / 중증: 환기부전 → 고탄산혈증 → 호흡성 산증.
  * **병인·면역 (4-21 ~ 4-23)**: Th2 편향 → IL-4/IL-13(IgE class switch)·IL-5(호산구). IgE 정상 $150\ \text{ng/mL}$(IgG $10\ \text{mg/mL}$), 아토피에서 10배 이상.
  * **병리 (4-23, 4-24)**: 점액 마개(Curschmann spirals), 상피 탈락, 기저막 유리질성 비후, 평활근·점막선·배상세포 비후.
  * **장기 관리 (4-24, 4-25)**: 경증 저용량 ICS($\leq400\ \mu g/\text{d}$); 중등도 ICS+LABA(부데소니드/포르모테롤 유지+구제); 소아에서 ICS로 성장 속도 감소(최종 신장 영향은 낮음).
  * **응급 처치 (4-26, 4-27)**: $O_2$로 $SpO_2 \geq90\%$(소아 $\geq95\%$); 입원: 치료 후 $FEV_1$/PEF $<40\%$.

## 4. 학습 점검 및 핵심 임상 질문 (Self-Assessment)

- **Q1. 신생아가 출생 직후 심한 호흡곤란과 청색증을 보이며, 심첨박동이 우측에 위치하고 좌측 흉곽에서 연동음이 들리며 복부가 주상(scaphoid)이다. 가장 가능한 진단과 즉시 해서는 안 되는 처치는?**
  A. 좌측 보흐달레크공을 통한 **선천성 횡격막 탈장(CDH)**이 가장 가능하다(영아·소아 횡격막 탈장의 약 90%, 좌측 85%). 진단은 산전 초음파로 이미 이루어졌을 가능성이 크고, 출생 후 흉부 방사선에서 종격동 이동과 좌측 흉강을 차지하는 장관 고리가 보인다. **즉시 해서는 안 되는 처치는 bag-mask 소생**으로, 탈출한 장관을 가스로 팽창시켜 호흡 곤란을 더 악화시킨다. 대신 **기관내삽관**과 **저압 흡인 비위관 삽입**을 시행하고, 주술기 안정화 후 교정한다. 생존율은 약 60%이며 사망 원인은 폐 저형성과 폐고혈압이다.

- **Q2. 기관식도누공이 의심되는 신생아에서 조영 검사 대신 어떤 방법으로 진단하며, 그 이유는?**
  A. 과거에는 바륨이나 Gastrografin 조영 검사를 사용했으나 **조영제를 폐로 흡인할 위험**이 있다. 따라서 **큰 방사선 불투과성 플라스틱 카테터를 비강이나 구강을 통해 맹낭까지 통과**시키는 방법을 쓴다. 카테터가 위로 진행되지 않으면 그 자리에 고정하고 지속적 약한 흡인에 연결해 맹낭을 타액으로부터 청결하게 유지하고 흡인성 폐렴 가능성을 최소화한다. 흉부 방사선에서 카테터 끝은 대개 **제2~3흉추(T2-T3)** 높이에 위치한다. 조영 검사가 필요하면 **0.5 mL 이하**를 직립 자세에서 주입하고 확인 즉시 흡인한다. 최빈형(90~95%)은 상부 식도 맹낭 + 하부 식도가 분기부 직상방 기관에서 기시하는 형태다.

- **Q3. 8주 이상 지속되는 기침 환자에서 감별해야 할 만성 기침의 3대 원인과, 각 원인별 도판에 제시된 빈도는? 그리고 진단을 확정하는 방법은?**
  A. 만성 기침($>8$주)의 3대 원인은 **상기도 기침 증후군(다양한 비부비동 질환에 의한, 미주 자극 경유, $28\sim41\%$)**, **천식($24\sim33\%$)**, **위식도 역류질환(GERD, 미주 자극 경유, $10\sim21\%$)**이며, 이 밖에 비천식성 호산구성 기관지염, 만성 기관지염, 기관지확장증이 있다. 검증된 진단 프로토콜을 체계적으로 따르고 추정 원인에 대해 **충분한 용량의 특이 치료**를 처방하면 대다수에서 기침이 호전되거나 소실되며, **기침의 원인은 특이 치료에 반응할 때에만 확정**할 수 있다. 최소 20%에서는 여러 질환이 동시에 기여한다는 점을 기억해야 한다.

- **Q4. 흡기성 천명과 호흡곤란을 호소하는 젊은 여성이 천식으로 수년간 치료받았으나 호전이 없다. 성대 기능부전을 시사하는 폐기능검사 및 후두경 소견은 무엇이며, 천식과의 핵심 차이는?**
  A. 폐기능검사(유량-용적 곡선)에서 **흡기 유량이 잘리고(truncated) 특징적인 "saw-tooth" 패턴**이 나타나는데, 이는 흡기 시 성대의 부적절한 내전에 상응한다. **비강경 유연성 굴곡성 후두경**을 환자가 증상 있는 동안(필요하면 운동이나 지속 발성 과제로 유발하여) 시행하면 **구조적으로 정상인 후두에서 흡기 시 역설적 성대 내전**이 보이고, 흔히 **성대 전방 2/3의 내전 + 후방 성문의 다이아몬드형 틈**이 관찰된다. 천식과의 핵심 차이는 폐쇄가 **호기(천식)가 아니라 흡기 시** 발생한다는 점이며, 따라서 **후두 천명을 기관지 천명으로 오인하지 않아야 한다**. 두 질환이 동반되는 경우도 흔해 메타콜린 유발검사가 도움이 된다. 치료는 유발 인자 제거, 후두 이완·횡격막 호흡을 중심으로 한 행동 치료이며 심한 발작에는 항불안제·헬리옥스·CPAP를 사용한다.

- **Q5. 천식 환자가 응급실에 왔다. 악화 중증도 판단에 쓰이는 지표와 입원·퇴원 결정 기준, 그리고 퇴원 시 반드시 포함해야 할 처방은?**
  A. 중증도는 증상의 정도보다 **객관적 측정치**가 더 신뢰할 만하다. 치료 전 **$FEV_1$ 또는 PEF가 예측치의 25% 미만**, 또는 치료 후 **$FEV_1$/PEF가 예측치의 40% 미만**이면 대개 입원이 필요하다. 치료 후 $40\sim60\%$ 예측치이면 지역사회 추적 관찰이 가능하고 순응도가 보장될 때 응급실에서 퇴원할 수 있다. **퇴원 기준**은 정상 이학적 검사, 증상 없음, 그리고 마지막 치료 후 최소 1시간 동안 **$FEV_1 \geq 70\%$**다. 퇴원 처방에는 **경구 코르티코스테로이드(성인 최소 7일, 소아 $3\sim5$일)**, **흡입 코르티코스테로이드**, **장·단시간 작용 기관지확장제**, 그리고 **서면 천식 행동 계획**이 포함되어야 한다. 치료는 속효성 흡입 $\beta_2$-작용제를 첫 1시간 동안 20분마다 2~4퍼프 반복하고(항콜린제 병용 가능), 산소로 $SpO_2$를 90% 이상(소아 $\geq95\%$)으로 적정하며, 가장 경미한 경우를 제외하고 전신 코르티코스테로이드를 사용한다. **악화 중 진정은 금지**다.

## 5. 첨부파일 이미지 로컬 추출 파이썬 스크립트 가이드

아래 스크립트는 원서 PDF에서 Plates 4-1 ~ 4-27의 이미지를 **150 DPI**로 렌더링하여 **256색 PNG**로 `첨부파일` 폴더에 저장합니다. 이 노트의 임베드 규격은 `![[Netter_V3_Plate4-N.png]]`이며, **PDF 페이지 = 도판번호 + 127** 공식을 사용합니다(Plate 4-1 → PDF p.128, Plate 4-27 → PDF p.154).

```python
import os
import fitz  # PyMuPDF
from PIL import Image

# ── 설정 ────────────────────────────────────────────────
PDF_PATH = "The Netter Collection - Volume 3, Respiratory System.pdf"
OUT_DIR = "./헤르메스/책 읽기/Netter_Vol3_호흡기계/첨부파일"
DPI = 150                      # 요청 해상도
PAGE_OFFSET = 127              # PDF 페이지 = 도판번호 + 127
PLATES = range(1, 28)          # Plate 4-1 ~ Plate 4-27

os.makedirs(OUT_DIR, exist_ok=True)
scale = DPI / 72.0             # PyMuPDF는 72 DPI 기준 배율을 사용
doc = fitz.open(PDF_PATH)
print(f"문서 페이지 수: {len(doc)} / 렌더링 {DPI} DPI")

for n in PLATES:
    pdf_page_no = n + PAGE_OFFSET            # 1-based 페이지 번호
    if pdf_page_no > len(doc):
        print(f"⚠️  [범위 초과] Plate 4-{n} → PDF p.{pdf_page_no}")
        continue
    page = doc[pdf_page_no - 1]              # 0-based 인덱스
    pix = page.get_pixmap(matrix=fitz.Matrix(scale, scale), alpha=False)
    out_path = os.path.join(OUT_DIR, f"Netter_V3_Plate4-{n}.png")
    pix.save(out_path)                       # 1차 저장(트루컬러)

    # 256색 PNG로 양자화(용량 축소, 옵시디언 임베드용)
    with Image.open(out_path) as im:
        im.convert("RGB").quantize(
            colors=256, method=Image.MEDIANCUT, dither=Image.FLOYDSTEINBERG
        ).save(out_path, optimize=True)

    size_kb = os.path.getsize(out_path) / 1024
    print(f"✅ Netter_V3_Plate4-{n}.png  (PDF p.{pdf_page_no}, {size_kb:.0f} KB)")

doc.close()
print("=== Plate 4-1 ~ 4-27 이미지 추출 완료 ===")
```

> ⚠️ **사용 메모**
> - `PAGE_OFFSET = 127`은 이 저장본 PDF의 실제 페이지 매핑입니다. 도판 헤딩 직후의 `===== PDF PAGE n | PLATE 4-N =====` 마커와 일치하므로, 다른 판본을 사용할 때는 최초 1~2개 도판을 눈으로 확인한 뒤 오프셋을 보정하십시오.
> - 256색 양자화는 도판의 색상 계조를 크게 해치지 않으면서 파일 크기를 줄이는 목적이며, 원본 화질이 필요하면 `quantize(...)` 블록만 제거하고 `pix.save()` 결과를 그대로 쓰면 됩니다.
> - 이미지 파일명은 노트의 임베드와 정확히 일치해야 옵시디언 미리보기가 표시됩니다(`Netter_V3_Plate4-N.png`, 소문자 확장자 `.png`).
