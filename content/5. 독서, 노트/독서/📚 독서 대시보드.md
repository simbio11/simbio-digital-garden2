# 📚 독서 대시보드

> [!info] 사용법
> 책 요약 파일의 frontmatter(`category`, `status`)를 기준으로 자동 분류돼요.
> - category: 의학·근골격 / 의학·통증 / 의학·기초 / 한의학 / 인문·심리
> - status: 완독 / 읽는중 / 보류
> 새 책 요약은 `templates/책 요약 템플릿.md`을 사용하세요!

## 📊 분류 현황

```dataview
TABLE rows.file.link AS "책", rows.status AS "상태"
FROM "5. 독서, 노트/독서"
WHERE contains(file.tags, "책요약")
GROUP BY category
```

## 📖 전체 책 목록 (최근 수정순)

```dataview
TABLE category AS "분류", status AS "상태", theme AS "주제", file.mtime AS "수정일"
FROM "5. 독서, 노트/독서"
WHERE contains(file.tags, "책요약")
SORT file.mtime DESC
```

## 📗 정리대기 (읽었지만 기록 전)

```dataview
TABLE category AS "분류", theme AS "주제"
FROM "5. 독서, 노트/독서"
WHERE status = "정리대기"
SORT file.name ASC
```

> 💡 "기록 시작해줘"라고 말씀하시면 비비가 템플릿 틀을 잡아드릴게요!
