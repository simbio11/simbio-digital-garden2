## 2. 부위별 세부 체크리스트

### 1) 어깨(Shoulder) 복합체 (Batch 1 - 완료)
- [x] [[대흉근]] : 3개 분절, 2중 건판, 가성 협심증, PECS 블록, 상완골 전방활주 연계 *(완료)*
- [x] [[견갑하근]] : 상/하견갑하신경, 상완골두 후하방 견인, 배꼽누르기/베어허그 검사, 후방자침법 *(완료)*
- [x] [[극상근]] : 견봉하 충돌, 회전근개 파열 1위, Empty/Full-Can, 초음파 Crass 뷰 *(완료)*
- [x] [[극하근]] : 상완골 외회전, 후방 관절낭 단축(GIRD), 천종혈 습부항, 슬리퍼 스트레칭 *(완료)*
- [x] [[소원근]] : 사각공간(QLS) 증후군, 135° 외전 촉진선, Hornblower 검사 *(완료)*
- [x] [[소흉근]] : 흉곽출구증후군(TOS), 오훼돌기 촉지법, 기흉 안전선, PECS II 블록 *(완료)*
- [x] [[전거근]] : 익상견갑, 상방회전 짝힘, 건부항 요법, 플러스 푸시업 *(완료)*
- [x] [[삼각근]] : 상완골 상방 활주, 비노혈 정지부 치료점, 승모근 연계, 점액낭 감별 *(완료)*
- [x] [[대원근]] : 소배근 역할, 결절간구 정지, 견정혈 치료점, 사각/삼각공간 경계 *(완료)*

### 2) 경부(Cervical) & 두경부 (Batch 2 - 다음 타깃)
- [ ] [[후두하근]] : 소/대후두직근, 상/하두사근, 경추성 두통, 대후두신경 포착
- [ ] [[전사각근]] & [[중사각근]] & [[후사각근]] : 사각근 삼각공간, 상완신경총, 전사각근 증후군
- [ ] [[흉쇄유돌근]] : SCM 쇄골지/흉골지 TP, 어지럼증, 자율신경 증상
- [ ] [[두판상근]] & [[경판상근]] : 정수리/후두통 방사, 침도 치료 포인트
- [ ] [[두반극근]] & [[경장근]] : 심부 경추 굴곡근/신전근 안정성
