# 소후두직근 (Rectus Capitis Posterior Minor, 작은뒤머리곧은근)

> **핵심 요약 (Key Summary)**:
> C1 환추 후궁 결절에서 기시하여 후두골 하항선 내측에 정지하며 두개골-경추 접합부를 안정화하는 후두하 심부 근육
> 심부 건성 섬유가 환추후두막을 관통하여 경추 경막(Dura mater)과 직접 연결되는 마이오듀랄 브릿지(MDB)를 형성
> 거북목 자세의 만성 단축으로 경막을 견인하여 발생하는 경추성 두통, 눈 뒤쪽 통증(TCC 연관통) 및 풍지·천주혈 심부 침구의 타깃

---

## 1. 해부학적 위치 및 정체성

| 항목 | 내용 |
| :--- | :--- |
| **근육명** | 소후두직근 (Rectus Capitis Posterior Minor / RCPM / 작은뒤머리곧은근) |
| **근육군** | 경추 심부 내재근 - 후두하근군 (Suboccipital Muscles) |
| **기시 (Origin)** | 제1경추(C1, 환추 Atlas)의 **후궁 결절 (Posterior tubercle of atlas)** |
| **정지 (Insertion)** | 후두골(Occipital bone)의 **하항선 (Inferior nuchal line)** 내측부 및 대후두공(Foramen magnum) 후연 |
| **신경 지배** | 제1경신경 후지(C1 posterior ramus)인 **후두하신경 (Suboccipital nerve)** |
| **특이 구조** | 후두하삼각(Suboccipital triangle)의 경계 안쪽에 위치하며, 경추 경막으로 섬유를 뻗는 **마이오듀랄 브릿지** 보유 |

## 2. 생체역학적 기능 및 마이오듀랄 브릿지 (Myodural Bridge)

```
                     [소후두직근 (RCPM)]
                              │
         ┌────────────────────┴────────────────────┐
         ▼                                         ▼
  [두개골 미세 신전 및 안정화]              [마이오듀랄 브릿지 (MDB)]
  환추후두관절(C0-C1) 신전                 환추후두막을 관통하여
  두개골의 전방 전단력 제어                경추 경막(Cervical Dura)에 직접 부착
  (풍부한 근방추 위치 감각 센서)           근육 단축 시 경막을 직접 견인
                                                   │
                                                   ▼
                                       [경추성 두통·뇌척수액 순환 장애]
```

1. **환추후두관절(C0-C1) 신전 및 자세 유지**:
   - 양측 수축 시 머리를 뒤로 젖히는 미세 신전(Extension)을 수행하며, 시각 수평선을 유지하기 위해 두개골을 미세 조정합니다.
   - 단위 부피당 근방추(Muscle spindle) 밀도가 매우 높아 머리의 위치와 회전 가속도를 뇌간으로 보고합니다.
2. **마이오듀랄 브릿지 (Myodural Bridge, MDB)**:
   - 1995년 해부학자 Hack 등에 의해 발견된 혁신적 구조로, 소후두직근의 결합조직 섬유가 환추후두막(PAOM)을 뚫고 척추관 내부의 **경추 경막(Dura mater)**과 물리적으로 직접 결합되어 있습니다.
   - 소후두직근이 경련하거나 단축되면 **경막을 직접 잡아당겨 통각 수용기를 자극함으로써 박동성 경추성 두통을 촉발**합니다.
   - 또한 저작 및 두부 움직임 시 뇌척수액(CSF)의 순환 펌프 역할을 담당합니다.

## 3. 임상 질환 및 연관통 패턴

### 1) 경추성 두통 (Cervicogenic Headache)
- 거북목(Forward head posture)이나 VDT 증후군으로 턱을 앞으로 내밀 때 소후두직근이 만성적으로 짓눌리고 단축됩니다.
- 후두부에서 시작하여 정수리를 타고 **눈 뒤쪽(안와 심부)까지 욱신거리는 연관통**을 방사합니다.

### 2) 3차경추복합체 (TCC) 연관통
- C1 신경의 자극이 뇌간의 삼차신경 척수핵(TCC)으로 입력되어, 편두통, 안구 건조감, 눈부심, 어지럼증을 유발합니다.

## 4. 한의학적 진단 및 치료 프로토콜

```
[소후두직근 병변의 복합 한의 치료]
  │
  ├─ 풍지(風池)·천주(天柱) 심부 침치료 ── 소후두직근 기시·정지부 직접 자침 이완
  ├─ [[신바로약침]] 국소 침윤 ────────── 마이오듀랄 브릿지 주변 무균성 염증 제거
  └─ 후두하근 이완술 (Suboccipital Release) ── 경막 장력 감압 및 C0-C1 관절 추나
```

1. **정밀 안전 침치료**:
   - 천주혈과 풍지혈 사이, C1 후궁 결절 부위(후두골 직하방 1cm)를 촉진하여 후두골 골면을 덧대며 안전하게 사자(斜刺)합니다.
   - 심부에는 척추동맥(Vertebral artery)과 연수가 위치하므로 절대 깊이 직자하지 않고 골면 접촉 수칙을 엄수합니다.
2. **신바로약침 및 소염약침 요법**:
   - 후두골 부착부에 0.3~0.5cc 약침을 침윤하여 후두하신경 포착과 경막 견인 긴장을 해소합니다.
3. **후두하근 이완 기법 (Suboccipital Release 추나)**:
   - 환자를 앙와위로 눕히고 검사자의 손가락 끝으로 후두골 하연의 소후두직근을 접촉하여 상방 및 두측으로 90초 이상 지속 압박 신장하여 경막의 장력을 감압합니다.
