# [기본의학] 흉통 — ACS·대동맥박리·폐색전증 초기 감별

**작성**: 2026-09-07 · **담당**: 닥터 허 · **대상**: 비오 원장(임상 한의사) · **관련**: [[00_기본의학_MOC|기본의학 MOC]]

---

## 한눈에 보기 (핵심 요약)

- 1차 진료 흉통의 흔한 원인은 대부분 양성(흉벽 통증 20–50%, 역류성식도염 10–20%, 늑연골염 13%)이나, 일차의료 흉통 환자의 **2–4%는 불안정형 협심증/심근경색**이며 8.4%는 생명 위협 질환이다(AAFP). **통증 강도가 심각도를 말해주지 않는다** — ACS·대동맥박리·폐색전증(PE)은 모호하게 올 수 있다(2021 AHA/ACC).
- 첫 판단은 단 하나: **"즉시 응급실 이송인가?"** 진료실 평가 = 병력 + 신체진찰 + **12-유도 심전도(가능하면 10분 이내)**. ACS 의심 ECG 소견(ST 상승·새 LBBB·Q파·새 T파 역전)이 있으면 지체 없이 응급 이송.
- 심근허혈 통증의 특징: **꾹 누르는·조이는 흉골하 압박감**, 운동 유발, 팔·어깨·턱 방사, 오심·식은땀 동반. 반대로 **날카롭고 짧고, 흉막성(숨 들이쉴 때), 자세 변화, 손으로 누르면 재현되는 통증은 ACS 가능성 낮음**(Swap & Nagurney 메타분석). 니트로글리세린 반응으로 심장 여부를 판정하지 않는다(AHA/ACC).
- **대동맥박리는 병력·진찰만으로 배제 불가** — 급성 흉통/등통 + **양팔 혈압·맥박 차이(pulse differential)**가 핵심 단서(LR+ 5.3, Ohle 메타분석) → 의심 즉시 응급실.
- **PE**는 호흡곤란·빈맥·흉통이 진단 환자의 97%에서 존재 → **Wells 기준**으로 층화하고, 임상 의심 낮을 때 **PERC 8항목** 모두 충족하면 PE <1%로 D-dimer·영상 생략 가능(AAFP).

## 1. 생명 위협 3대 질환 (감별 우선순위)

| 항목 | ACS(급성관상동맥증후군) | 대동맥박리 | 폐색전증(PE) |
| --- | --- | --- | --- |
| 통증 양상 | 압박·조임·무거움(흉골하), 운동·스트레스 유발 | **갑작스러운 극심한 찢는 듯한 통증**, 흉부→등(견갑골 사이) 이동 | 흉막성(숨 들이쉴 때 악화) 또는 모호한 불쾌감+호흡곤란 |
| 방사 부위 | 왼팔·양팔·어깨·턱·목 | 등·복부(이동) | 드묾 |
| 동반 증상 | 오심·구토·식은땀·호흡곤란, 실신 가능 | 실신, 신경학적 결손(뇌졸중 유사), 기좌 호흡 | 빈맥·빈호흡·저산소증, 객혈, 한쪽 하지 부종/통증(DVT) |
| 위험인자 | 연령·성별·고혈압·당뇨·이상지질혈증·흡연·가족력 | 고혈압, 마르판 등 결합조직병, 이엽 대동맥판, 대동맥 수술력 | 4주 내 수술·고정(침상 안정), 암, PE/DVT 과거력, 호르몬제 |
| 핵심 진찰 | (ECG 이상이 결정적) | **양팔 수축기 혈압차·맥압차**, 대동맥판막 폐색음 | 빈맥, SpO₂↓, 하지 비대칭 부종 |
| 확진 검사 | ECG + 고감도 트로포닌(hs-cTn, ED) | CT·경식도초음파(ED) | Wells 층화 → D-dimer → CT 폐혈관조영(ED) |
| 1차 의료 액션 | **즉시 응급실(119)** | **즉시 응급실(119)** | 중·고위험 즉시 응급실 / 저위험도 임상 의심 시 응급 평가 |

- **ACS 비전형 발현 주의**: 당뇨병·여성·고령은 호흡곤란·오심·피로·턱/등 통증만으로 올 수 있어 위험인자가 있으면 "가슴이 안 아프다"는 말로 낮게 보지 않는다(AAFP/AHA-ACC).
- ECG 판독 포인트(진료실·ED 공통): ACS 가능성을 높이는 소견 = **ST 분절 상승, 새로 생긴 좌각차단(LBBB), Q파, 새 T파 역전**(AAFP). 같은 소견이 심낭염·좌심실비대에서도 보일 수 있음.
- 고감도 트로포닌(hs-cTn)은 심근손상의 가장 정확한 조기 표지자(2021 AHA/ACC) — 측정·연속 알고리즘은 응급실 영역. 한의원에서 '일단 트로포닌 검사'를 기다리며 지체하지 말고 임상+ECG 기준으로 판단.

## 2. 흉통 병력의 가치 (ACS 가능성 증감)

- **ACS 위험 ↑**(Swap & Nagurney 메타분석): "압박감", "예전 심근경색 통증과 비슷", "지난번 협심증보다 심함", 운동 연관, 오심·식은땀 동반, 한쪽/양쪽 팔·어깨 방사
- **ACS 위험 ↓**: 흉막성, 자세 변화로 변함, **촉진으로 재현**, 운동과 무관
- 안정형 흉통에서는 검증된 위험 층화 도구 활용(AAFP 권고):

| 도구 | 항목(각 1점) | 해석 |
| --- | --- | --- |
| **Marburg Heart Score** | ① 여성 ≥65세/남성 ≥55세 ② 기존 혈관질환(CAD·뇌혈관·폐색성) ③ 운동 시 통증 악화 ④ 흉벽 촉진으로 통증 재현 안 됨 ⑤ 환자 본인이 심장 문제로 생각 | 0–1점: LR 0.04 → CAD 확률 극히 낮음 / 2–3점: LR 0.92 / 4–5점: LR 11.2 (유병률 10% 기준 0.4%→9.3%→55.5%) |
| **INTERCHEST** | 촉진 재현 –1점, 남성≥55/여성≥65 +1, 의사가 중증 의심 +1, 압박감 +1, 운동 연관 +1, CAD 과거력 +1 | –1~0점: CAD 0.3% / 1–2점: 6.9% / ≥3점: 64.4% |

- 해석: 고위험군(4–5점/3점+)은 심장내과·영상 평가 의뢰. 저위험군은 12-유도 ECG 정상 + 안정적 경과면 흉벽·역류성 등 비심장 원인 감별로 진행.

## 3. PE 평가 — Wells + PERC

- 진단 환자의 97%에서 호흡곤란·빈맥·흉통 중 하나는 있으나, 단일 증상·징후로 진단을 확정/배제할 수 없다(AAFP).

**Wells 기준(3단계)**:

| 항목 | 점수 |
| --- | --- |
| DVT 증상·징후(하지 부종·심부정맥 압통) | 3 |
| 다른 진단보다 PE 가능성이 높다고 판단 | 3 |
| 심박수 >100/min | 1.5 |
| 4주 내 수술·고정(침상 안정 >3일) | 1.5 |
| PE/DVT 과거력 | 1.5 |
| 객혈 | 1 |
| 활동성 암(6개월 내 치료 포함) | 1 |
| **합계** | **PE 확률(전체 9.2%)** |
| 0–1점 저위험 | 1.3% |
| 2–6점 중등위험 | 16.2% |
| >6점 고위험 | 37.5% |

- **PERC rule(8항목 모두 충족 시 PE <1%, 검사 생략 가능)** — 50세 이하, 심박수 <100/min, SpO₂ >94%, 한쪽 다리 부종 없음, 객혈 없음, 4주 내 수술/외상 없음, PE/DVT 과거력 없음, 경구 호르몬제 복용 없음. 단, 임상적 PE 의심이 낮은 경우에만 적용(Singh 메타분석).
- 중등도 이상/PERC 미충족 → D-dimer(저·중등위험) 또는 영상(고위험) — 응급실 평가.

## 4. 대동맥박리 — 놓치지 말아야 할 단서

- 병력·신체진찰의 진단적 가치는 제한적(배제 불가). 유일하게 강력한 진찰 소견 = **급성 흉통/등통 + 상지 맥압차**(LR+ 5.3; Ohle 2018 메타분석).
- 흉부 X-ray에서 종격동 확장이 없어도 박리를 배제할 수 없다(AAFP/AHA-ACC 요약).
- 의심 상황: 갑작스러운 "평생 최악의" 찢어지는 통증, 등·복부로 이동, 실신, 신경학적 결손(급성 뇌졸중처럼), 기존 고혈압·결합조직병.
- → **임상적 의심 = 즉시 응급실**. 영상(CT)으로 확인 전 항혈소판제·항응고제·혈압약 자가 복용을 권하지 않는다(치료 방향은 응급실에서 확정).

## 임상 적용 (한의원 실전)

- **문진 4포인트**: ① "언제부터? 갑자기? 얼마나 심하게? 어디로 퍼지나요?"(등·턱·팔) ② "운동하거나 걸을 때 심해지나요? 숨 쉴 때·자세에 따라 아픈가요? 여기(흉벽)를 누르면 아픈가요?" ③ 동반증상: 호흡곤란·오심·식은땀·실신·객혈·하지 부종 ④ 위험인자: 고혈압·당뇨·이상지질혈증·흡연·나이·암/수술/고정·호르몬제.
- **측정은 기본**: 양팔 혈압(차이 확인), 심박수·SpO₂, 호흡수. 12-유도 ECG 보유 시 10분 내 시행, ST 상승·새 LBBB·Q파·새 T파 역전 보이면 즉시 응급.
- **즉시 응급실(119) 기준**: ACS 의심(전형적 압박감+위험인자, ECG 이상), 대동맥박리 의심(급작스러운 극심한 통증+맥압차), PE 의심(Wells 중등도+·저산소증·실신). 이송 전 안정·반좌위 유지, 혼자 운전 금지 안내.
- **한의 시술 전 배제**: 등·견갑·흉추 통증으로 내원한 환자가 ① 운동 시 악화되는 압박감/호흡곤란/식은땀 ② 심혈관 위험인자(고령·HTN·DM·흡연) ③ 견갑간 극심 통증·맥압차(박리) ④ 한쪽 하지 부종+객혈(PE) → 시술(침·추나·부항·약침) 전 **심장·혈관 평가 선행**. 응급 의심 환자에게 시술 금지.
- **비교적 안전한 경우**: 흉벽 통증(늑연골염·근막통)으로 국한·ECG 정상·안정적이면 침·온열·생활 교육 가능. 단, 당뇨·여성·고령의 비전형 증상은 "가슴 안 아픔"으로 배제하지 말 것.
- **복약력**: 항혈소판·항응고제 복용자는 출혈 위험 — 침·약침 전 반드시 확인(모듈 03과 연계).

## 환자 설명 멘트

"가슴 통증은 대부분 근육이나 역류성이라 크게 걱정 안 하셔도 되는 경우가 많아요. 그런데 '걷거나 운동할 때 가슴이 조여 오고, 숨이 차고 식은땀이 나는' 통증, '갑자기 찢어지듯 등까지 아프면서 팔 혈압이 다르게 느껴지는' 통증, '숨쉬기가 힘들고 다리가 한쪽만 붓는' 통증은 심장이나 혈관 문제일 수 있어서, 그럴 때는 여기 치료보다 먼저 119로 응급실에 가시는 게 안전해요. 등·어깨가 아파 오신 분도, 가슴 통증·호흡곤란·식은땀이 함께 있으면 꼭 먼저 말씀해 주세요."
