# [기본의학] 호흡곤란·발열 — 폐렴·패혈증·COPD 악화 감별

**작성**: 2026-09-14 · **담당**: 닥터 허 · **대상**: 비오 원장(임상 한의사) · **관련**: [[00_기본의학_MOC|기본의학 MOC]]

---

## 한눈에 보기 (핵심 요약)

- 발열 + 호흡곤란 조합은 **감염성 호흡부전의 신호**다. 한의원에서 첫 판단은 하나뿐 — **"지금 즉시 응급 이송인가?"** 원인 추정은 그 다음이다.
- **폐렴**: 1차의료는 **CRB65**(의식혼탁·호흡수 ≥30·혈압 저하·65세 이상, 각 1점). 0점 = 사망률 <1%, 1–2점 = 1–10%, 3–4점 = >10%. **CRB65 ≥2는 병원 평가**, 1점은 공유의사결정, 0점은 재택 가능(NICE NG250, 2025).
- **패혈증**: **체온이 정상일 수 있다**(NG253 1.1.2). 지역사회 고위험 기준은 **호흡수 ≥25, 수축기혈압 ≤90(또는 평소보다 40 mmHg 이상 저하), 맥박 >130, 18시간 무뇨, 객관적 의식 변화, 청색증·반상출혈** — 하나라도 있으면 즉시 119 이송·사전 연락(NG253 Table 1).
- **COPD 악화**: 중증도는 치료 이용도가 아니라 **객관적 활력징후로** 분류한다(Rome 제안 → GOLD 채택) — 호흡곤란 VAS ≥5, 호흡수 ≥24, 맥박 ≥95, SpO₂ <92%(또는 평소보다 3%p 이상 저하), CRP ≥10 mg/L 중 3개 + 급성 고탄산혈증이면 **중증**.
- 한의원에서 반드시 재는 6가지: **호흡수(1분간)·SpO₂·체온·맥박·혈압·의식/평소와 다른 행동**. 이 중 **호흡수 증가**와 **의식 변화**가 가장 이른 신호이며, 폐렴의 CRB65·패혈증 고위험 기준·COPD 악화 중증도 기준 모두에 공통으로 들어간다.

## 1. 급성 호흡곤란 감별 지도 — 발열이 있으면 감염을 1순위로

| 질환 | 결정적 단서 | 초기 평가 |
| --- | --- | --- |
| **폐렴** | 발열·오한, 화농성 객담, 흉막성 흉통, 국소 수포음·타진 탁음, 호흡수 ↑ | 활력징후 + SpO₂ + 흉부 X-ray, CRB65(외래)/CURB65(병원) |
| **COPD·천식 악화** | 기존 진단, 천명, 호기 연장, 2주 내 점진 악화, 화농성 객담 변화 | SpO₂, 흉부 X-ray(감별), ABG(중증), CRP |
| **급성 심부전·폐부종** | 기좌호흡·야간 발작성 호흡곤란·하지 부종, 수포음, 경정맥 확장 | SpO₂, ECG, BNP, 심초음파 |
| **폐색전증(PE)** | 갑작스러운 호흡곤란·흉막성 흉통·실신, 편측 하지 종창, 4주 내 수술·고정·암 | Wells → D-dimer/CT 폐혈관조영 |
| **기흉** | 급성 편측 흉통 + 호흡음 소실, 편측 타진 과공명 | 흉부 X-ray(응급) |
| **대사성 산증(당뇨 케톤산증 등)** | 과호흡(Kussmaul), 탈수, 의식 저하, 혈당↑ | 혈당·혈액가스 |
| **아나필락시스·혈관부종** | 노출 직후, 두드러기·입술/후두 부종·천명·저혈압 | 즉시 adrenaline·119 (모듈 01 큐 '클리닉 응급 대응' 항목) |
| **심근경색** | 흉통·식은땀, 노인·여성·당뇨는 호흡곤란만으로 발현 | 12-유도 ECG ([[흉통_중증감별_2026-09-07]]) |

- 호흡곤란 원인 감별의 기본 원칙(AAFP, Am Fam Physician 2020-05-01): 병력·진찰로 계통(폐·심장·소화기·신경근·혈액)을 좁히고, **1차 검사는 맥박산소포화도 측정 + CBC·기본 화학검사·ECG·흉부 X-ray·폐활량검사**로 단계적 접근.
- COPD 악화로 보이는 환자에서 반드시 배제할 것(중복 진단, mimics): **폐렴·폐색전증·기흉·심부전·심근경색**, 드물게 아나필락시스·혈관부종·성대기능장애(Mein & Ferrera, CHEST Crit Care 2024).
- 발열만 보고 원인 없이 해열제를 남용하면 진단이 늦어져 치명적 폐렴이 될 수 있다(대한결핵및호흡기학회).

## 2. 폐렴 — 진단·중증도·치료

### 2-1. 중증도 점수 (NICE NG250, 2025 개정판: CG191·NG138·NG139 대체)

| 항목 | **CRB65** (1차의료, 혈액검사 불필요) | **CURB65** (병원) |
| --- | --- | --- |
| 의식 혼탁(AMT ≤8 또는 새로 생긴 지남력 장애) | 1점 | 1점 |
| 요소질소(BUN) >7 mmol/L | — | 1점 |
| 호흡수 ≥30회/분 | 1점 | 1점 |
| 혈압: 수축기 <90 또는 이완기 ≤60 mmHg | 1점 | 1점 |
| 나이 ≥65세 | 1점 | 1점 |
| 사망 위험 | 0점 <1% / 1–2점 1–10% / 3–4점 >10% | 0–1점 <3% / 2점 3–15% / 3–5점 >15% |

- 처치 장소 결정: **CRB65 2점 이상 → 병원 평가 고려**, 1점 → 공유의사결정(가정 기반 치료 등), 0점 → 재택 치료 고려(NICE NG250).
- 국내 지침도 **외래·의원급에서는 CRB-65**, 응급실 또는 혈액검사가 가능한 곳에서는 CURB-65 사용을 권고(대한감염학회, Infect Chemother 2018;50(2):160-198).
- 주의: 점수는 **임상 판단과 함께** 쓴다. CRB65가 낮아도 SpO₂ 저하·다엽 침윤·흉수·면역저하·탈보상 동반질환·혼자 거주 등이면 재택 불가.

### 2-2. 치료 (NICE NG250 1차의료 시각 요약)

| 상황 | 항생제 | 기간 |
| --- | --- | --- |
| 저중증도 1차 | 아목시실린 500 mg 1일 3회 | 5일 |
| 저중증도 대안(페니실린 알레르기·비정형 의심) | 독시사이클린 1일차 200 mg → 이후 100 mg 1일 1회 | 4일 |
| 고중증도(병용) | 클래리트로마이신 500 mg 1일 2회(베타락탐과 병용) | 5일 |
| 고중증도·페니실린 알레르기(임신) | 에리스로마이신 500 mg 1일 4회 경구 | 5일 |
| 플루오로퀴놀론(레보플록사신) | MHRA 2024-01 주의: **코르티코스테로이드와 동시투여 회피** | — |

- 2025 개정 핵심: 항생제 **중단은 5일**(미생물 결과 또는 불안정 시 연장), 고중증도 입원 성인에서 **코르티코스테로이드 추가 고려(4–7일 또는 퇴원 시까지)**, 소아(3개월–11세) 비중증은 3일로 단축.
- 재평가: **48–72시간 내 호전 없으면** 비정형 병원체·합병증(농흉·폐농양)·다른 진단을 재검토.
- 퇴원 보류 기준(병원, NG250): 최근 24시간 내 ① 체온 >37.5℃ ② 호흡수 ≥24 ③ 맥박 >100 ④ 수축기혈압 ≤90 중 **2개 이상**이면 퇴원하지 않는다.
- 국내 맥락(대한결핵및호흡기학회): 폐렴구균 페니실린 내성 73–75% 보고 → **마크롤라이드·테트라사이클린 단독요법 비권장**. 국내 폐렴 사망은 인구 10만 명당 9.4명(전체 사망원인 10위, 70세 이상 6위), 중환자실 입원 중증 폐렴 사망률 35–50%.

## 3. 패혈증 — 지역사회 선별(NG253)과 병원 스크리닝

### 3-1. 지역사회·비급성기관 위험 층화 (NICE NG253 Table 1, 2025)

| 범주 | **고위험**(하나라도) → 즉시 응급 이송 | **중등도–고위험**(하나라도) |
| --- | --- | --- |
| 병력 | **객관적 의식 변화** | 새로 생긴 행동·정신상태 변화(보호자 진술), 기능 급격 저하, 면역저하(질환 또는 경구 스테로이드 포함), **6주 내 외상·수술·침습적 시술** |
| 호흡 | **호흡수 ≥25회/분**, 새로 40% FiO₂ 이상 필요 | 호흡수 **21–24회/분** |
| 혈압 | **수축기 ≤90** 또는 평소보다 40 mmHg 이상 저하 | 수축기 **91–100** |
| 순환·수분 | **맥박 >130**, 18시간 무뇨 | 맥박 **91–130**(임신 100–130) 또는 새 부정맥, 12–18시간 무뇨, 도뇨 환자 시간당 0.5–1 mL/kg |
| 체온 | — | **고막 체온 <36.0℃** |
| 피부 | **얼룩덜룩·창백(회색) 피부, 입술·혀 청색증, 압박해도 사라지지 않는 자반** | 수술 부위 발적·종창·분비물, 상처 벌어짐 |

- 관리: 고위험 = **즉시 응급의료(ED/내과 응급병동) 이송 + 사전 연락**(일반적으로 999 구급차) / 중등도–고위험 = 확정 진단이 가능하고 원내 치료가 불필요한 경우가 아니면 동일하게 이송(NG253 1.7.1–1.7.2, 관리 시각 요약).
- **체온이 높지 않아도 패혈증일 수 있고**, 증상이 국소적이지 않을 수 있다(NG253 1.1.2). 반복 내원·"평소와 다름"에 대한 보호자 진술은 위험 신호로 취급(NG253 1.1.3, 근거검토 C).
- 평가 항목(NG253 1.3.1–1.3.6): 체온·맥박·호흡수·혈압·의식수준·SpO₂ + 피부(점상출혈·청색증·상처) + **최근 18시간 배뇨 횟수** + 최근 발열·오한 여부.

### 3-2. 병원 스크리닝 — NEWS2가 표준, qSOFA 단독은 금지

- NEWS2 밴드(NG253): **≥7점 고위험**, **5–6점 중등도**, 1–4점 저위험. 5점 미만이라도 단일 항목이 3점을 기여하면 임상 판단으로 원인 확인.
- 지역사회에서도 **연속 NEWS2 ≥5**면 시간-민감 이송·사전 연락 고려(NG253 1.7.4).
- Surviving Sepsis Campaign 2021은 **qSOFA를 단독 선별도구로 쓰지 말 것**을 강하게 권고(SIRS·NEWS·MEWS 대비 열등)하고, 패혈증 의심 시 **혈청 젖산 측정**을 제안.
- 항생제 시점(SSC 2021): 가능한 패혈증 쇼크이거나 패혈증 가능성이 높으면 **인지 즉시, 이상적으로 1시간 내** 투여 / 쇼크 없는 가능성 단계에서는 **신속 평가 후 감염 우려가 지속되면 3시간 내** 투여. — 한의원 역할은 투여가 아니라 **인지와 이송**이다.

## 4. COPD 급성 악화 — 중증도·입원 판단·치료

- 정의: 안정 상태에서 평소 일상 변동을 넘어서는 증상의 지속적 악화(호흡곤란 악화, 기침·객담량·객담색 변화)로 급성 발병, 약제 변경이 필요해지는 상태(NICE NG115).
- 중증도(Rome 제안 2021 → GOLD 채택, Celli 등 AJRCCM 2021;204(11):1251-1258): **호흡곤란 VAS ≥5, 호흡수 ≥24, 맥박 ≥95, SpO₂ <92%(또는 평소보다 3%p 이상 저하), CRP ≥10 mg/L 중 3개 이상** + **급성 고탄산혈증(PaCO₂ >45 mmHg, pH <7.35)** 이면 중증 → 입원 평가.

| 입원 쪽으로 기우는 소견 (NG115 Table 7) | 재택 쪽 |
| --- | --- |
| 중증 호흡곤란, 전신상태 불량·악화, 활동 저하·와상 | 경증 호흡곤란, 전신상태 양호, 자가 관리 가능 |
| **청색증, 말초부종 악화, 의식저하, 급성 혼동** | 청색증 없음, 의식 정상 |
| **SpO₂ <90%**, 흉부 X-ray 이상, **pH <7.35, PaO₂ <7 kPa** | SpO₂ 유지, 검사 이상 없음 |
| 빠른 발병 속도, 주요 동반질환(특히 심질환·인슐린 의존 당뇨), 장기산소요법 중, 독거·대처 불가 | 사회적 지지 양호 |

- 치료: 속효성 기관지확장제 증량(SABA/SAMA, 네뷸라이저·휴대용 흡입기 모두 가능) + **경구 프레드니솔론 30 mg 1일 5일**(NG115 1.3.16, 2019 개정) — 입원 환자는 금기 없으면 전원, 지역사회는 호흡곤란이 일상활동을 방해할 정도면 고려.
- 고탄산혈증·산증 환자에서 네뷸라이저는 **산소가 아닌 압축공기로 구동**(산소 필요 시 비강 캐뉼라로 병행) — 산소 구동은 고탄산혈증을 악화시킬 수 있다(NG115 1.3.11).
- 항생제는 NG114(급성 악화 항생제 처방)에 따르며, CRP 기반 판단 보조: CRP <20 mg/L 항생제 이득 낮음 / 20–40 mg/L 화농성 객담 동반 시 이득 가능 / >40 mg/L 이득 유력(NICE 2019 예외적 감시 보고서).
- 맥박산소포화도는 PaCO₂·pH 정보를 주지 않는다 — 중증 판단은 결국 ABG가 기준(NG115 1.3.28).

## 임상 적용 (한의원 실전)

- **문진 포인트(3분)**: ① 발열·오한·발병 속도(“며칠 만에 이렇게 됐나”) ② 객담 색·양·냄새 변화 ③ 흉막성 흉통·숨 들이쉴 때 악화 ④ 평소보다 다른 행동·말·반응 ⑤ **최근 18시간 소변 횟수** ⑥ 6주 내 수술·시술·입원 ⑦ 면역억제제·경구 스테로이드 복용 ⑧ COPD·천식·심부전 기저질환과 평소 SpO₂ ⑨ 최근 항생제 복용력.
- **측정 게이트(시술 전 필수)**: 호흡수(30초 이상, 가능하면 1분)·SpO₂·체온(고막)·맥박·혈압·의식. 호흡수는 환자가 의식하면 대개 빨라지므로 **환자가 모르게 세는 편**이 정확하다.
- **응급 이송 트리아지(하나라도 해당 시 침·약침·부항·추나 등 모든 시술 보류, 즉시 이송)**:
  - 호흡수 ≥25 또는 <10, 수축기혈압 ≤90(또는 평소 −40 mmHg), 맥박 >130, SpO₂ <92%(기저 폐질환자 88% 기준은 NG253의 산소요법 기준), 18시간 무뇨, 객관적 의식 변화·급성 혼동
  - 청색증·얼룩덩덩 피부·점상출혈, 경정맥 확장, 한쪽 폐 호흡음 소실, 흡기 시 흉곽 함몰
  - 폐렴 의심 + **CRB65 ≥2**(호흡수 ≥30, 수축기 <90 또는 이완기 ≤60, 혼탁, ≥65세 중 2개 이상) 또는 폐렴 의심 + SpO₂ 저하·28일 이상 지속 기침·객혈
- **한의 시술 전 배제할 것**:
  1. **발열 + 호흡기 증상 환자에서 부항·약침·침 전에 활력징후부터** — 폐렴·패혈증이 배제되지 않으면 시술 자체를 미루고 진단을 먼저 확정한다. 특히 항응고·항혈소판제 복용자에게 발열·탈수·식욕저하가 겹치면 출혈·신장 위험이 커진다(모듈 03 연계).
  2. **마황(에페드린) 함유 처방은 발열·빈맥·고혈압 상황에서 원칙적으로 배제** — 마황은 고혈압·부정맥·심근경색·뇌졸중과 연관(Haller & Benowitz, NEJM 2000;343:833-838; Shekelle 등 JAMA 2003;289:1537-1545). 심질환·고혈압·당뇨·갑상선질환·전립선비대·녹내장·MAOI 복용자는 사용 금기 대상(Health Canada 경고, CMAJ 2003). 고열·빈맥·탈수 상태에서 발한 승격 목적의 사용은 금한다([[고혈압_약물안전_2026-09-09]]의 감초 사례와 함께 볼 것).
  3. **경구 스테로이드·면역억제제 복용자**는 감염이 비전형적으로 진행되고 NG253 중등도–고위험 기준 자체에 해당 — 증상이 가벼워 보여도 임계를 낮춰 평가.
  4. COPD·천식 환자에서 **산소 공급은 저유량으로 목표 범위 유지**가 원칙이며, 한의원에서 무리한 산소 투여나 흡입제 임의 중단을 지시하지 않는다.
- **의뢰·협진 기준**: 폐렴 진단·항생제는 호흡기내과/내과 의뢰, 패혈증 의심은 내과·응급. 항생제 시작 후 48–72시간 반응 없거나, 발열 5일 이상 지속, 객혈·체중감소·야간 발한(결핵·종양 감별), COPD 환자의 잦은 악화(연 2회 이상 중등도 악화) 시 전문과 협진.
- **기록**: 발열 환자는 시술 전 6대 활력징후와 SpO₂를 차트에 남기고, 비시술·이송 판단 이유를 명시한다(모듈 08 이상반응·기록과 연결).
