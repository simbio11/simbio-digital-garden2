# [기본의학] 고혈압 — 진단·약물 계열별 특징·한의 치료 시 주의점

**작성**: 2026-09-09 · **담당**: 닥터 허 · **대상**: 비오 원장(임상 한의사) · **관련**: [[00_기본의학_MOC|기본의학 MOC]]

---

## 한눈에 보기 (핵심 요약)

- 고혈압 진단은 **진료실혈압 ≥140/90 + 가정·주간활동혈압 ≥135/85(또는 24시간 ≥130/80)** 확인(대한고혈압학회 2022). 진료실 한 번 측정으로 확진하지 않는다.
- 목표 혈압(KSH 2022): 합병증 없는 중저위험·노인 **<140/90**, 고위험·심혈관질환·CKD+알부민뇨·열공성뇌경색 **<130/80**. (해외는 더 적극적: ESC 2024 수축기 120–129, ACC/AHA 2017 <130/80)
- 1차 약제 5계열(ACEi/ARB·CCB·이뇨제·베타차단제·알파차단제), NICE는 A/C/D 스텝(55세 미만 ACEi/ARB → CCB/이뇨제 추가 → 3제 → 저항성은 spironolactone). **ACEi+ARB 병용 금지**, 노인 베타차단제 1차 기피.
- **저항성 고혈압 감별에 '한약제(감초·마황)'가 명시**되어 있다(KSH 2022) → 고혈압 환자 한약 처방 시 감초 장기·고용량, 마황 함유 처방 주의.
- 혈압 ≥180/120 + 표적장기손상 증상(혼돈·흉통·호흡곤란·신기능 악화·시야 이상)은 **당일 응급 의뢰**. 3제 이상에도 조절 안 되면 저항성 고혈압 → 이차성(특히 일차알도스테론증) 감별 의뢰.

## 1. 진단과 혈압 분류 (KSH 2022 제5판 기준)

### 혈압 분류

| 분류 | 수축기(mmHg) | 이완기(mmHg) |
| --- | --- | --- |
| 정상 혈압 | <120 | 그리고 <80 |
| 주의 혈압 | 120–129 | 그리고 <80 |
| 고혈압 전단계 | 130–139 | 또는 80–89 |
| 고혈압 1기 | 140–159 | 또는 90–99 |
| 고혈압 2기 | ≥160 | 또는 ≥100 |
| 수축기 단독 고혈압 | ≥140 | 그리고 <90 |

- 선별: 20세 이상 **2년마다** 진료실 혈압. 40세 이상·고혈압 가족력·고혈압전단계·비만 → **매년**.
- 진단은 진료실혈압과 **진료실 밖 혈압**으로 확정: 진료실 ≥140/90 + 가정·주간활동혈압 ≥135/85 또는 24시간 평균 ≥130/80. 백의고혈압(진료실만 높음)·가면고혈압(진료실 밖만 높음)을 구분한다.
- 표적장기손상·위험도 평가: 요단백(ACR)·혈뇨, HbA1c, 전해질·크레아티닌·eGFR, 지질, 안저, 12유도 심전도(NICE NG136 동일).
- 양팔 혈압 차이 **>15 mmHg** 반복 시 높은 쪽으로 측정, 지속되면 혈관(쇄골하·대동맥) 병변 감별(NICE).

### 측정·확진의 실전 포인트 (NICE NG136)

- 진료실 ≥140/90이면 같은 진료에서 2차 측정, 크게 다르면 3차 — **마지막 2회 중 낮은 값**을 진료실 혈압으로 기록.
- ABPM: 깨어있는 동안 시간당 ≥2회, **≥14회 평균**. HBPM: 아침·저녁 2회씩, 1분 간격 2회 연속, **4~7일간** 측정 후 첫날 값 버리고 평균.
- 확진: 진료실 ≥140/90 **그리고** ABPM/HBPM ≥135/85.
- 기립성 저혈압 의심 증상(낙상·기립 어지럼) 있으면 **누운 자세→기립 1분 후** 측정, 수축기 20 또는 이완기 10 mmHg 이상 감소 시 관리(약물 검토 포함) 및 기립 후 혈압 기준으로 추적.

## 2. 치료 목표 혈압 — 임상 상황별 (KSH 2022)

| 임상 상황 | 목표(mmHg) | 권고등급 |
| --- | --- | --- |
| 합병증 없는 중저위험 고혈압 | <140/90 | I/A |
| 노인 고혈압 | <140/90 | I/A |
| 고위험도* (합병증 없음) | <130/80 | IIa/B |
| 당뇨병 중저위험 | <140/90 | I/A |
| 당뇨병 고위험# | <130/80 | IIa/B |
| 심혈관질환† | <130/80 | IIa/B |
| 만성콩팥병, 알부민뇨 없음 | <140/90 | I/A |
| 만성콩팥병 + 알부민뇨 | <130/80 | IIa/B |
| 만성콩팥병 + 당뇨 | <130/80 | IIb/C |
| 뇌졸중 | <140/90 | I/B |
| 열공성 뇌경색 | <130/80 | IIa/B |

\* 무증상 장기손상 또는 심뇌혈관 위험인자 3개 이상 동반 · # 무증상 장기손상 또는 위험인자 3개 이상 동반 · † 관상동맥질환·말초혈관질환·복부대동맥류·심부전·좌심실비대

- 해외 기준과의 비교(참고): ACC/AHA 2017은 고혈압 자체를 ≥130/80으로 낮추고 목표 <130/80. ESC 2024는 'elevated BP(120–139/70–89)' 범주를 신설하고, 약물 복용 성인의 **수축기 목표 120–129**를 1차 목표로 제시(opt-out 방식, 허용 안 되면 가능한 한 낮게). 85세 미만·중등도 이상 노쇠가 아닌 노인도 젊은 성인과 같은 목표(Class I). 한국 임상에서는 KSH 2022 기준 적용이 표준.

## 3. 약물 치료 — 계열별 특징과 단계적 알고리즘

### 약물 시작 시점 (KSH 2022)

- 위험인자·동반질환 무관하게 혈압 ≥140/90이면 약물치료 가능.
- 저위험 1기: 적극적 생활요법 후 재평가 → 필요 시 약물. 중위험·고위험 1기: 바로 약물 시작. 2기(≥160/100): 생활요법과 **동시에** 약물.
- **≥160/100 또는 목표보다 20/10 이상 높으면 처음부터 2제 병용**(고정용량복합제 선호). 1일 1회 복용·지속형 선호(치료 지속성).

### 주요 1차 약제 계열 (KSH 2022 5계열)

| 계열 | 주요 적응증·선호 상황 | 주의·부작용 |
| --- | --- | --- |
| ACE억제제/ARB | 심부전·좌심실비대·관상동맥질환·CKD·당뇨병신장병증·뇌졸중 | 임신 금기. 고칼륨혈증, 양측 신동맥협착 시 급성신손상, ACEi는 마른기침. **ACEi+ARB 병용 금지** |
| 칼슘차단제(CCB) | 노인·수축기단독고혈압·협심증·흑인. 지속형(dihydropyridine) 우선 | 발목부종·안면홍조·두통·반사성 빈맥. 속효성 니페디핀(sublingual) 투여 금지. 비-DHP(베라파밀·딜티아젬)는 서맥·AV차단·변비 — 심부전·AV차단 주의 |
| 티아지드(유사) 이뇨제 | 노인·수축기단독고혈압·심부전. **chlorthalidone·indapamide 선호** | 저칼륨혈증·고요산(통풍)·혈당 상승. 루프이뇨제는 심부전·eGFR<30에서 |
| 베타차단제 | 협심증·심근경색 후·빈맥성 부정맥·심부전. 심박수 빠른 젊은 환자 | 천식·COPD·2~3도 AV차단 주의. 혈당·지질 대사 악화 → **노인 1차 기피**, 이뇨제와 병용 시 당뇨 위험↑ |
| 알파차단제 | 전립선비대 동반 | 기립성 저혈압 |

- **선호 병용**: RAAS억제제(ACEi/ARB) + CCB 또는 이뇨제 2제. 작용기전 다른 약 소량 추가가 용량 증량보다 유리. ARB+ACEi, BB+이뇨제(대사 모니터링 필요) 주의.

### 단계적 알고리즘 (NICE NG136 — A/C/D)

- Step 1: **55세 미만·흑인 아니면 ACEi 또는 ARB / 55세 이상 또는 흑인(당뇨 없으면) CCB**. CCB 불내성(부종)이면 티아지드유사 이뇨제. 임신 가능 여성 ACEi/ARB 금지(MHRA).
- Step 2: ACEi/ARB + (CCB 또는 티아지드유사). 심부전 증거 있으면 이뇨제.
- Step 3: ACEi/ARB + CCB + 티아지드유사 이뇨제(indapamide 등).
- Step 4(저항성): ABPM/HBPM으로 확인·복약 순응 점검 후, **혈중 칼륨 ≤4.5 → 저용량 spironolactone 추가**(eGFR 저하 시 고칼륨혈증 주의, 시작 1개월 내 전해질·신기능 확인). **칼륨 >4.5 → 알파차단제 또는 베타차단제**. 4제 최적용량에도 조절 안 되면 전문의 자문.

### 저항성 고혈압 (KSH 2022)

- 정의: **이뇨제 포함 작용기전이 다른 3제 이상을 최적 용량**으로 병용해도 <140/90로 안 되는 경우.
- 감별: 복약 불순응(가장 흔함), 부적절한 측정(백의고혈압·커프), 생활습관(비만·음주·수면무호흡·과염), 체액과잉, 약물(NSAIDs·피임약·스테로이드·**한약제(감초·마황)**), **이차성 고혈압 — 특히 일차알도스테론증**.
- 치료: 이뇨제 증량·교체(eGFR↓면 루프이뇨제), spironolactone·amiloride·doxazosin 추가.

## 4. 감초·마황 — 고혈압·전해질에 미치는 영향 (한의 처방 관점)

- **감초(Glycyrrhizae Radix)**: 주요 성분 **glycyrrhizic acid(GA)가 신장 11β-HSD2를 억제** → 코르티솔이 mineralocorticoid 수용체를 활성화 → **가성알도스테론증(pseudohyperaldosteronism): 혈압 상승 + 저칼륨혈증 + 부종 + 대사성 알칼리혈증**.
  - 체계적 고찰·메타분석(Nutrients 2024): **GA 우세 감초 섭취는 SBP·DBP 모두 상승**, liquiritin/flavonoid(LF) 우세 성분은 유의한 혈압 영향 없음 → '감초=무해' 아님, 성분 조성·함량이 변수.
  - 일본 Kampo 사례: 감초 6.0 g/일 함유 작약감초탕(芍藥甘草湯)은 고위험 처방으로 알려짐. 개인 감수성 차가 커 용량만으로 위험 예측 어려움(2026 narrative review).
  - 중증 증례: 감초 과다 섭취 후 혈압 190/80·칼륨 1.6 mmol/L까지 보고(2024 case series) → 저칼륨혈증 + 고혈압 동반 시 반드시 감초 노출 확인.
- **마황(Ephedra herba)**: ephedrine 등 교감신경작용 성분 → 심박수·혈압 상승 가능성. 정상 혈압 성인 4캡슐(ephedrine 약 19.4 mg) 투여 연구에서 심박수 유의 증가, 혈압은 변동(1997 J Clin Pharmacol).
- → 고혈압 환자 한약 처방에서 감초 고용량·장기 복용, 마황 함유 처방(체중조절·감기 등)은 특히 주의. KSH 2022가 저항성 고혈압의 약제 원인으로 **한약제(감초·마황)**를 명시한 것은 양방 가이드라인 차원의 공식 경고.

## 임상 적용 (한의원 실전)

- **문진 포인트**: 진료실 혈압 규칙 측정 + **가정혈압(아침·저녁 2회, 4~7일) 권장** — 백의고혈압/가면고혈압 구분. 복약력(약 이름·용량·순응도)·건강기능식품(감초·마황 함유 제품)·NSAIDs 병용 확인. 양팔 차이 >15 mmHg는 혈관 병변 가능성.
- **한의 치료 안전성**: 경구 항고혈압제 대부분은 침·약침·부항·추나의 출혈 위험을 의미 있게 높이지 않는다(항응고·항혈소판제와 다름). 다만 ① 노인 + 이뇨제/알파차단제/베타차단제 등 복용자는 **기립성 저혈압** 위험 → 추나·도수 후나 침 치료 후 기립 시 어지럼·낙상 주의, 천천히 일어나게. ② 베타차단제 복용자는 운동 시 심박수 반응이 억제됨. ③ 봉약침 등 주사 시술은 일반적인 아나필락시스 대비 원칙 동일.
- **한약 처방 전 배제/주의(감초·마황)**: 조절 중인 고혈압 환자에서 감초 다량(작약감초탕류·장기 보약), 마황 함유 처방은 회피 또는 용량·기간 제한. 혈압약 + 감초 병용 시 **저칼륨혈증·혈압 상승** 모니터링(특히 이뇨제·ARB/ACEi 복용자). 고혈압 환자에게는 감초 대체(감초 무함유 가감)나 단기 사용 원칙.
- **모니터링**: ARB/ACEi·이뇨제·spironolactone 복용자는 전해질·신기능 **연 1~2회 이상** 확인 권고(KSH). 한약 시작 전·후 혈압 변화 비교(1~2주 내 재측정).
- **의뢰/응급 기준**:
  1. **진료실 ≥180/120 + 표적장기손상 증상**(새로 생긴 혼돈·흉통·심부전 징후(호흡곤란 등)·급성신손상, 망막출혈·유두부종 의심 시야증상) → **당일 응급 의뢰**(NICE same-day specialist review).
  2. 무증상이라도 ≥180/120 반복 확인 후 지속되면 조속히 1차 진료·순환기내과 의뢰.
  3. **40세 미만 고혈압**(특히 중증·갑작 발현, 가족력 없는 경우) → 이차성 고혈압(신혈관·일차알도스테론증·갑상선 등) 감별 의뢰.
  4. 3제 이상(이뇨제 포함) 최적 용량에도 <140/90 조절 안 됨 → 저항성 고혈압 → **일차알도스테론증 등 이차성 감별 의뢰**(저칼륨혈증 동반 시 더 강하게). 한약(감초·마황)·NSAIDs가 원인인지 먼저 배제.
  5. 한의 치료 시작 후 혈압 유의 상승(처방 전후 비교) → 한약 원인 배제 후 양방 혈압 조절 재평가.

## 환자 설명 멘트

"혈압은 한 번 높게 나왔다고 바로 고혈압이 아니에요. 집에서 아침·저녁으로 1주일 정도 재어서 확인하는 게 정확합니다. 치료 목표는 대부분 140/90 미만, 당뇨나 심장·콩팥병이 있으면 130/80 미만으로 더 철저히 잡아요. 혈압약은 평생 끊지 말고 꾸준히 드셔야 하고요 — 저희가 드리는 한약 중에 감초나 마황 성분이 혈압을 올리거나 몸속 칼륨을 떨어뜨릴 수 있어서, 혈압약 드시는 분은 그런 약재를 빼거나 기간을 짧게 조절해서 드립니다. 약은 절대 임의로 끊지 마시고, 집에서 재신 혈압이 180/120 이상이면서 가슴이 답답하거나 숨이 차거나 정신이 혼미하면 바로 응급실로 가셔야 해요."
