# [기본의학] 신경계 진찰 총론 — MMT·심부건반사·감각·소뇌·보행 (토요일 딥다이브)

**작성**: 2026-09-12 · **담당**: 닥터 허 · **대상**: 비오 원장(임상 한의사) · **관련**: [[00_기본의학_MOC|기본의학 MOC]]

---

## 한눈에 보기 (핵심 요약)

- 신경계 진찰의 목적은 **병변 위치(국소진단)를 좁히는 것 하나**다. 절대값보다 **좌우 비대칭**과 **상·하운동신경원(UMN/LMN) 패턴**이 정보의 핵심이다.
- 근력은 **MRC 0~5 등급**(0=수축 없음 … 3=중력 대항 … 4=중력+저항 … 5=정상), 심부건반사(DTR)는 **NINDS 0~4 등급**(2~3 정상, 4=항진+간대성경련)으로 기록한다.
- 해석 원칙: **반사 저하·위축·근섬유다발수축 = LMN(신경근·말초·전각)**, **반사 항진·경직·Babinski = UMN(척수 위)**. 단 **급성 척수압박 초기에는 척수쇼크로 반사가 저하**되어 UMN이 LMN처럼 보이는 함정이 있다.
- 척수증(myelopathy)에서 **Babinski·clonus·Tromner는 민감도는 낮지만 특이도가 매우 높다** → 하나라도 양성이면 MRI 의뢰. 반대로 **21%는 진찰상 병적징후가 전혀 없다**(Rhee 2009) → 음성으로 배제 금지.
- 한의원에서는 침·약침·추나 전 **30초 신경 스크리닝**(양측 DTR · Hoffmann/Babinski · 발끝·뒤꿈치 걷기 · 안장감각·배뇨력 문진 · 좌우 근력)을 루틴으로 넣는다.

## 1. 병태생리·기전 — 왜 이렇게 진찰하는가

### 1-1. 반사궁과 UMN/LMN의 관계

DTR은 **근방추(Ia 구심섬유) → 척수 α운동뉴런 → 근수축**의 단일시냅스 회로이고, 이 회로는 **피질척수로가 상시 억제(dampening)**하고 있다. 따라서 병변이 회로 자체(말초신경·신경근·전각)에 있으면 반사는 **저하**되고, 회로는 멀쩡한데 그 위의 피질척수로가 끊기면 **억제가 풀려 반사가 항진**된다. StatPearls는 이를 "억제를 억제하면 항진된다(inhibiting the inhibitor causes hyperreflexia)"로 정리한다. 같은 환자에서도 병변 높이에 따라 **위쪽 분절은 반사 저하, 아래쪽은 항진**이 동시에 나타날 수 있다(예: C5 병변이 이두근 반사는 저하시키면서 삼두근 반사는 항진시킴).

### 1-2. 감각 2경로 — 해리성 감각소실이 왜 생기나

통각·온도는 **척수시상로(전외측계, 척수 내에서 교차)**, 진동·위치감각은 **후주계(교차 전 상행, 연수에서 교차)**로 간다. 두 경로가 해부학적으로 다른 부위에 있고 교차 시점도 다르므로, 척수 병변에서는 **한 경로만 선택적으로 소실되는 해리성 감각소실**이 가능하다. 그래서 감각 검사는 촉각 하나로 끝내지 않고 **① 가벼운 촉각(솜) ② 바늘 통각 ③ 진동(128 Hz 소리굽쇠) ④ 위치감각**을 따로 본다.

### 1-3. 소뇌·전정·고유수용 — 균형의 삼각

자세 유지는 ① 시각 ② 전정기관 ③ 고유수용감각(후주)의 3입력이 소뇌에서 통합·보정되어 유지된다. **소뇌는 '힘의 교정기(calibrator)'**라서 병들면 힘 조절이 어긋나 측정이상(dysmetria)·의도진전·진자운동 반사가 나타나고, **후주/말초 감각이 끊기면 시각을 빼는 순간 균형이 무너진다(Romberg 양성)**. Romberg 검사가 "눈을 감았을 때"만 의미를 갖는 이유가 여기에 있다.

## 2. 항목별 실제 기법과 해석

### 2-1. 근력 — MRC 0~5 등급과 그 한계

| 등급 | 판정 기준 |
| --- | --- |
| 5 | 정상 근력 (저항을 완전히 이겨냄) |
| 4 | 중력에 대항하며 **저항도 이겨냄** (4-/4/4+로 세분) |
| 3 | 중력에 대항해 **관절 전범위** 운동 |
| 2 | 중력 제거(gravity eliminated) 상태에서 관절 운동 |
| 1 | 근수축 흔적(flicker/trace)만 있음 |
| 0 | 수축 없음 |

- 근거: MRC 1943년 *Aids to the Investigation of Peripheral Nerve Injuries* (War Memorandum No. 7)에 처음 제시 → 현재 6판(*Aids to the Examination of the Peripheral Nervous System*, 2023)까지 이어지는 표준. Compston이 Brain 2010에 그 원문 등급을 그대로 재수록했다.
- **한계(반드시 기억)**: ① 등급 4와 5의 경계가 지나치게 넓고(등급 5 하나가 실제 힘의 85 N~650 N을 포괄한다는 보고) ② 검사자 간 일치도가 낮으며 ③ 4+ 세분화가 일치도를 개선하지 못한다는 연구도 있다. → **실전에서는 등급 숫자 하나에 의존하지 말고 좌우 차이 + 기능검사(발끝/뒤꿈치 걷기, 앉았다 일어서기, 한 발 서기)를 함께 기록**한다.

### 2-2. 심부건반사(DTR) — NINDS 0~4 등급, 분절 지도, 기법

| 등급 | 의미 |
| --- | --- |
| 0 | 반사 없음(무반사) |
| 1 | 저하(미약하거나 **강화법(reinforcement)으로만** 유발) |
| 2 | 정상 범위 하한 |
| 3 | 정상 범위 상한 |
| 4 | 항진(정상보다 과도, **간대성경련 동반 시 기재**) — 지속성 간대성경련은 항상 병적 |

| 반사 | 분절 | 말초신경 | 타진 위치 |
| --- | --- | --- | --- |
| 이두근 | C5–C6 | 근피신경 | 팔꿈치 앞쪽 |
| 상완요골근 | C5–C6 | 요골신경 | 손목 위 10 cm 요측 |
| 삼두근 | C7–C8 (주로 C7) | 요골신경 | 팔꿈치 뒤쪽 |
| 슬개건 | L2–L4 (주로 L4) | 대퇴신경 | 슬개골 아래 |
| 아킬레스 | S1 (일부 S1–S2) | 경골신경 | 아킬레스건 뒤 |
| 턱반사 | 뇌교 | 삼각신경 하악지 | 턱(이부) |

- **기법**: 관절을 90°로 늘어뜨려 완전 이완시키고(무릎·발목), 눈은 원위 움직임이 아니라 **근위 근육의 수축**을 본다. 반사는 **우측→좌측을 즉시 연속 비교**(오른팔-왼팔, 오른무릎-왼무릎 순서로 짝지어).
- **강화법(reinforcement)**: 이를 악물기, 대화로 주의 돌리기, **Jendrassik 술기**(양손 손가락을 걸고 힘껏 벌리기, 하지·턱반사에만 사용).
- **판독 원칙**: 절대 등급보다 **비대칭**이 중요하고, **대칭적 1+~3+는 다른 UMN/LMN 징후가 없으면 정상 범위**이다. 반사가 아래로 내려갈수록 점점 항진되면 **그 사이 높이의 척수 손상**을 시사한다.
- **임상 팁**: 아킬레스 반사 소실은 당뇨병성 말초신경병증의 예측 지표로, 신경병증 증상·당뇨 유병기간·망막병증보다 우수했다.

### 2-3. 근력 검사 키 머슬과 감각 키 포인트 (ASIA/ISNCSCI 기준)

| 신경근 | 키 머슬(운동) | 감각 키 포인트 |
| --- | --- | --- |
| C5 | 팔꿈치 굴곡(이두근·상완근) | 팔꿈치 주름 가쪽 |
| C6 | 손목 신전(ECRL·ECRB) | 엄지 근위지절 배측 |
| C7 | 팔꿈치 신전(삼두근) | 중지 근위지절 배측 |
| C8 | 손가락 굴곡(FDP) | 소지 근위지절 배측 |
| T1 | 손가락 벌림(골간근) | 팔꿈치 주름 안쪽 |
| T4 / T10 | (참고) | 유두 / 배꼽 |
| L2 | 고관절 굴곡(장요근) | 허벅지 앞안쪽(중간점) |
| L3 | 무릎 신전(대퇴사두근) | 무릎 위 안쪽(내측 대퇴과) |
| L4 | 발목 배굴(전경골근) | 안쪽 복사뼈 |
| L5 | 무지 신전(장모지신근) | 발등 제3중족지절 |
| S1 | 발목 저굴(비복근·가자미근) | 발꿈치 가쪽(종골 외측) |
| S3–S5 | (참고) | 항문주위(안장) |

- **요추 방사통에서 실전 조합**: L4 = 안쪽 복사뼈 저림 + 발목 배굴 약화 + 슬개건 반사 저하 / L5 = 발등·엄지 저림 + 엄지 신전 약화(반사는 대개 정상) / S1 = 발꿈치·발바닥 저림 + 발목 저굴 약화 + **아킬레스 반사 저하**. 즉 **"L5는 반사로 안 잡히고, S1은 반사로 잡힌다."**
- **분절 vs 말초 감별**: 감각소실이 **띠 모양으로 여러 말초신경 영역을 가로지르면 신경근(피부분절)**, **특정 말초신경 영역에 국한되면 말초신경 포착**이다. (관련 개념: [[좌골신경통]], [[신경인성 파행]], [[당뇨병성 말초신경병증]], [[신경전도검사]])

### 2-4. 소뇌 검사 vs 감각성 운동실조

| 항목 | 소뇌성 | 감각성(고유수용성) |
| --- | --- | --- |
| Romberg(눈 감음) | 대개 **뚜렷이 악화되지 않음** | **현저히 악화(양성)** |
| Finger-to-nose | 눈을 뜨고도 측정이상·의도진전 | 눈을 뜨면 교정됨 |
| 보행 | 넓은 보폭, 비틀거림, 방향 일정치 않음 | 발을 구르듯, **시각 의존** |
| 반사 | 대개 정상(저긴장 동반) | 저하·소실 동반 가능 |

- 소뇌 징후 암기: **DANISH** — **D**ysdiadochokinesia/dysmetria, **A**taxia, **N**ystagmus, **I**ntention tremor, **S**peech(구음장애·scanning speech), **H**ypotonia.
- 기법 주의: **Finger-to-nose는 천천히** 시행(빠르게 하면 초기 소뇌징후를 놓친다). **Heel-to-shin은 원을 그리듯** 정강이를 타고 올라오게(단순히 문지르면 초기 운동실조를 놓친다). **슬개건 반사 후 다리가 4회 이상 흔들리면**(진자운동 지연) 소뇌 기능저하를 시사.

## 3. 국소진단 — UMN vs LMN, 그리고 '가짜 LMN' 함정

| 항목 | UMN(척수 위) | LMN(전각·신경근·말초) |
| --- | --- | --- |
| 근긴장도 | 증가(경직, 칼날같은 저항) | 감소(이완성) |
| 심부건반사 | 항진 / 간대성경련 | 저하 / 소실 |
| Babinski | 양성(엄지 배측 굴곡) | 정상(저측 굴곡) |
| 근위축 | 경미·늦음(폐용성) | 빠르고 뚜렷(신경성) |
| 근섬유다발수축 | 없음 | 있음(EMG상 섬유자발전위) |
| 약화 분포 | 피라미드형(상지 신전근·하지 굴곡근이 더 약함) | 신경근·신경총·말초신경 분포 |

**함정 3가지**
1. **급성 척수손상·급성 압박 초기 = 척수쇼크**: 수 시간~수일간 이완성 마비·반사 소실로 나타나 **UMN인데 LMN처럼 보인다**. 이후 반사 항진·경직으로 전환된다. → "반사가 없다"를 말초 근거로 단정하지 말고 **시간축(급성/만성)**을 함께 본다.
2. **UMN+LMN 혼재**: ALS처럼 운동뉴런 자체가 광범위하게 침범되면 두 징후가 같은 부위에 동시에 나타난다.
3. **같은 척수 내 높이별 차이**: 병변 분절에서는 LMN(반사 저하·위축), 그 아래에서는 UMN(항진)이 동시에 관찰된다.

## 4. 병적반사와 레드플래그 — 진찰 자체가 의뢰 신호

### 4-1. 경추 척수증(DCM)에서 임상징후의 실제 진단 성능

Global Spine J 2023/2024 체계적 고찰·메타분석(대조군 포함 11~12개 연구 + 코호트 61편) 기준 **확인된 수치**는 다음과 같다.

| 징후 | 민감도 | 특이도 | 비고 |
| --- | --- | --- | --- |
| **Babinski** | 33% (Cook 2009) | **93% (Cook 2009)** | LR+ 4.50, 양성 시 후확률 73%. 코호트 가중평균 민감도 42% |
| **Clonus** | 13% (Rhee 2009) | **96% (Cook 2009)** / 100% (Rhee 2009) | 특이도 최상위군 |
| **Inverted supinator sign** | **61% (Cook 2009, 최고 민감도)** | — | LR− 0.5(후확률 25%) — 음성일 때 배제에 기여 |
| 서브라피펠라 반사 | 56% (Cook 2009) | — | |
| **Hoffmann** | 44% (Cook 2009) ~ 89% (Chang 2011), 3개 연구 58~62% | 50~86% | 연구 간 편차 큼 |
| **Tromner** | **93~94%** | 79~100% | 가장 민감한 축에 속함 |
| 하이퍼토니아(가중평균) | 0.96 | — | 가장 민감 |
| 피라미드(UMN) 징후(가중평균) | 0.86 | — | |
| 하이퍼리플렉시아(가중평균) | 0.79 (하지 0.85 > 상지 0.78) | — | |
| 경직성 보행 | 0.69 | — | 보행이상 일반은 0.47 |
| Romberg(정적) | 0.42 (Findlay 2009: 34%) | — | |
| **Romberg(보행 중 = walking Romberg)** | **74.5% (Oswestry, 척수증 50명 연속)** | — | Hoffmann 79%와 **둘 중 하나라도 양성이면 96%** |

**해석의 핵심**: ① 특이도 높은 징후(Babinski·clonus)는 **양성이면 강하게 의심**, ② 민감도 낮은 징후는 **음성이라고 배제 불가**, ③ **수술받은 척수증 환자의 21%는 진찰상 병적징후가 전혀 없었다**(Rhee 2009) → 진찰 음성을 MRI 생략 근거로 쓰면 안 된다.

### 4-2. 검사법과 레드플래그

- **Hoffmann**: 검사자가 중지의 원위지절간관절 직상부를 잡고 손톱을 튕김 → **엄지 벌림 + 나머지 손가락 굴곡**이 양성.
- **Babinski**: 발바닥을 뒤꿈치에서 가쪽 → 안쪽 첫 중족골 방향으로 자극 → **엄지 배측 굴곡 + 나머지 발가락 부채꼴**이 양성.
- **Clonus**: 발목을 급격히 배굴한 뒤 유지 → 규칙적 저항/이완 반복. **지속성 간대성경련은 항상 병적.**
- **경추 척수증을 놓치지 않는 임상 조합**(문진+진찰): ① 양손 저림·미세운동 둔화(단추 잠그기, 글씨, 10초 grip-and-release 20회 미만) ② 보행 불안정·계단 내려가기 어려움 ③ Lhermitte 징후 ④ 배뇨·배변 절박/실금 ⑤ 다리 증상이 동반된 손 저림(**수근관증후군·단순 경추신경근병증으로 오진되기 쉽다**). 진단까지 평균 2.2년·평균 5.2회 의사 방문이 걸린다는 보고가 있다.
- **마미증후군(CES) 적신호**: ① **안장(항문주위) 감각 저하** ② **새로 생긴 배뇨 기능장애**(요정체·잔뇨감·요실금·방광 충만감 소실) ③ 배변 조절 이상 ④ 성기능 저하 ⑤ 양측성 좌골신경통·하지 위약·보행 악화.
  - GIRFT 국가 경로: **CES는 척추외과적 응급(spinal surgical emergency)**으로 즉시 전문 평가·영상이 필요하며, 영국에서 척추수술 관련 소송의 **23%**가 CES와 관련된다.
  - BJGP 리뷰: 2020년 이후 영국 국가 지침은 **객관적 징후(항문주위 감각 이상·항문 긴장도 저하)가 없더라도 증상만으로 응급 영상 의뢰**하도록 권고하며, **1차 진료에서 직장수지검사는 권장되지 않는다**. 중심성 추간판탈출증은 전체 요추 추간판탈출의 약 **2~3%**, 그중 CES는 약 **0.12%**.
- **소뇌·보행 레드플래그**: 급성 소뇌 실조 + 어지럼·두통·구음장애·복시 → **후순환 뇌졸중(소뇌출혈/경색)** 감별, 응급 이송.

## 5. 임상 적용 (한의원 실전)

### 5-1. 시술 전 30초 신경 스크리닝 게이트 (루틴화 권장)

1. **양측 DTR 비교** — 이두근·삼두근·슬개건·아킬레스 (3+ 이상 항진 또는 좌우 차이 2단계 이상?)
2. **Hoffmann / Babinski** — 목·허리 통증 환자에서 매번, 특히 팔·다리 저림 동반 시
3. **발끝 걷기 / 뒤꿈치 걷기 / tandem gait** — 기능적 근력·고유수용 통합 확인(L5 배굴·S1 저굴·협착증)
4. **안장감각·배뇨력 문진** — "소변·대변 보는 게 예전과 달라졌나요? 안장 부위 감각이 이상한가요?"
5. **좌우 근력 대조** — 어깨 벌림(C5), 손목 신전(C6), 삼두근(C7), 엄지 신전(L5), 발목 저굴(S1)

### 5-2. 의뢰·응급 기준

| 상황 | 조치 |
| --- | --- |
| 새로 생긴 배뇨·배변 장애, 안장 감각 저하, 양측 하지 위약 | **즉시 응급실**(마미증후군 — 영상+감압 시간이 예후 결정) |
| UMN 징후 신규 출현(Hoffmann·Babinski·clonus 양성) 또는 진행하는 보행 악화 | 1~2주 내 **MRI + 신경외과/정형외과 의뢰**(척수증) |
| 좌우 차이가 뚜렷한 근위축 + 근섬유다발수축 + 반사 저하 진행 | **신경과 의뢰, EMG/NCS**(운동뉴런병·말초신경병 감별) |
| 급성 소뇌 실조 + 중추성 어지럼/복시/구음장애 | **응급 이송**(후순환 뇌졸중) |
| 경추 회전 시 어지럼·복시·구음장애·삼킴곤란·실신감, 안진 | **VBI 의심 — 경추 회전 유발검사 즉시 중단 후 의뢰** |

### 5-3. 한의 치료 안전 점검

- **경직(반사 항진) 환자**: 강한 침 자극·강압 수기로 반사성 경련·낙상 위험이 커진다 → 자극 강도·체위 안정을 먼저. 침대에서 일어날 때 보조.
- **감각 저하 부위**(말초신경병증, 척수병증): **뜸·부항 온자극 전에 온도·통각 감각을 먼저 확인**하고 화상 예방(온도 낮추고 시간 단축).
- **추나·도수치료**: **척수증 의심(UMN 징후 양성)에서는 경추 강압 회전 도수 금지** — MRI 먼저. 협착증·척수증 환자는 신경인성 파행 양상(앉으면 좋아지고 서서 걸으면 나빠짐)을 확인해 혈관성 파행([[신경인성 파행]])과 감별.
- **당뇨병성 말초신경병증**(아킬레스 반사 소실·진동감각 저하) 환자는 **낙상 예방 교육 병행** — 균형 저하가 이미 진행된 상태다. (관련: [[당뇨병성 말초신경병증]], [[신경병증성 통증]])
- **안면신경마비** 환자는 이 총론의 중추 vs 말초 감별 원칙이 그대로 적용된다(이마 주름·눈 감기 보존 여부). (관련: [[안면신경마비]])

## 환자 설명 멘트

- **반사 검사**: "무릎 아래 힘줄을 살짝 두드려서 다리가 얼마나 튀는지 보는 검사예요. 신경이 지나가는 길이 잘 통하는지, 그리고 오른쪽·왼쪽이 다른지 확인하는 겁니다."
- **Babinski / Hoffmann**: "발바닥(손가락)을 자극했을 때 발가락(엄지)이 위로 올라오면, 신경의 '중추' 쪽을 한 번 확인해 봐야 한다는 신호예요. 무조건 큰 병은 아니지만, 확실히 하려면 MRI가 필요합니다."
- **Romberg**: "먼저 눈을 뜨고 서 계세요. 이번엔 눈을 감고 서 보세요. 눈을 감았을 때 훨씬 심하게 흔들리면, 균형을 잡는 감각이 발에서 뇌로 잘 전달되지 않는 상태를 의심합니다."
- **근력 검사**: "힘을 주세요, 제가 밀어볼게요. 반대쪽과 비교해서 차이를 보는 게 중요합니다."
- **의뢰 안내**: "지금 증상은 한방 치료로 좋아지는 근육·관절 문제일 수도 있지만, 신경이 눌리는 문제는 아닌지 먼저 확인하는 게 안전합니다. MRI 한 번 찍어보고 결과에 따라 같이 치료해 나가시죠. 만약 소변·대변 조절이 안 되거나 안장 부위 감각이 이상해지면 그때는 바로 응급실로 가셔야 합니다."
