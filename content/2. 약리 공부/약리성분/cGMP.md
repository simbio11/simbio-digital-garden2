# cGMP (Cyclic Guanosine Monophosphate)

> **핵심 요약 (Key Summary)**:
> 산화질소(NO) 및 나트륨이뇨펩타이드 자극에 의해 생성되어 혈관 평활근 이완과 세포 기능을 매개하는 핵심 2차 전달자
> 구아닐릴 시클라아제(sGC/pGC)에 의해 GTP로부터 합성되고 단백질 인산화효소 G(PKG)를 활성화하여 세포 내 칼슘 감소 유도
> 한약재 활혈거어약의 eNOS 촉진 하류 혈관 확장 기전 및 PDE5 억제제(실데나필)의 발기부전·폐동맥고혈압 치료 표적

## 1. 분자생물학적 정체성 및 생화학적 구조

| 항목 | 내용 |
| :--- | :--- |
| **물질명** | cGMP (Cyclic Guanosine Monophosphate, 환상 구아노신 일인산) |
| **분자식 / 분자량** | C10H12N5O7P / 345.21 g/mol |
| **분자 분류** | 퓨린 뉴클레오티드 유도체 / 세포 내 2차 신호전달물질 (Second Messenger) |
| **합성 효소** | 구아닐릴 시클라아제 (Guanylyl Cyclase, GC): 가용성 sGC 및 막결합 pGC |
| **분해 효소** | 포스포디에스테라아제 (Phosphodiesterase, 특히 PDE5, PDE6, PDE9) |
| **주요 작용체** | 단백질 인산화효소 G (PKG), cGMP 개폐형 이온 통로 (CNG channels) |

## 2. 신호 전달 경로 및 분자 기전

```
              [혈관 내피세포: eNOS 활성화]
                           │
                      [NO 방출]
                           │ (평활근 세포로 확산)
             [가용성 구아닐릴 시클라아제(sGC) 결합]
                           │
                    GTP ───┴───► [[cGMP]] 축적
                                      │
                         ┌────────────┴────────────┐
                         ▼                         ▼
                  [PKG 활성화]              [PDE5에 의한 분해]
                         │                         │
            세포질 Ca2+ 농도 급감            5'-GMP로 불활성화
            MLCP 활성화 → 미오신 탈인산화       (PDE5 억제 시 cGMP 지속)
                         │
                  [혈관 평활근 이완]
```

1. **합성 경로 (NO-sGC-cGMP Pathway)**:
   - 혈관 내피세포에서 생성된 산화질소(NO)가 혈관 평활근 세포막을 단순 확산하여 세포질의 가용성 구아닐릴 시클라아제(sGC)의 헴(Heme) 부위에 결합합니다.
   - 활성화된 sGC는 GTP를 [[cGMP]]로 전환시켜 세포 내 농도를 수십 배 급상승시킵니다.
2. **혈관 평활근 이완 분자 메커니즘**:
   - [[cGMP]]는 단백질 인산화효소 G(PKG)를 결합·활성화합니다.
   - PKG는 세포막의 칼슘 채널을 차단하고 소포체 SERCA(칼슘 펌프)를 자극하여 세포질 내 유리 칼슘(Ca2+) 농도를 급격히 낮춥니다.
   - 미오신 경쇄 인산분해효소(MLCP)를 인산화·활성화하여 액틴-미오신 교차결합을 해제함으로써 평활근을 강력하게 이완시키고 혈관을 확장합니다.
3. **분해 및 조절 (PDE5)**:
   - [[cGMP]]는 포스포디에스테라아제-5(PDE5)에 의해 5'-GMP로 신속히 가수분해되어 신호가 종결됩니다.
   - 실데나필(비아그라), 타다라필(시알리스) 등의 약물은 PDE5를 경쟁적으로 억제하여 [[cGMP]]의 분해를 막고 고농도를 유지시킵니다.

## 3. 한의학 약리 기전 및 처방 연계

- **활혈거어약(活血祛瘀藥)의 혈관 확장 메커니즘**:
  - [[단삼]](탄시논 IIA), [[천궁]](천궁락톤), [[당귀]](페룰산) 등은 혈관 내피세포의 eNOS 발현을 유도하여 NO 방출을 증가시킴으로써 평활근 세포 내 [[cGMP]] 축적을 가속화합니다.
  - 이를 통해 심근 허혈, 협심증, 뇌혈류 장애 환자의 미세혈관을 재개통합니다.
- **평간식풍·청열해독약의 혈압 강하**:
  - [[야국화]](루테올린), [[조구등]](린코필린), [[하고초]] 등은 혈관 평활근 세포 내 [[cGMP]] 농도를 높여 말초 혈관 저항을 감소시키고 혈압을 안정화합니다.

---

## 4. 임상적 중요성 및 타깃 질환

- **발기부전(Erectile Dysfunction)**: 음경 해면체 평활근 내 [[cGMP]] 증가를 통해 혈류 유입을 촉진하여 발기 유도.
- **폐동맥 고혈압(Pulmonary Arterial Hypertension)**: 폐혈관 평활근 수축 억제 및 혈관 저항 감소.
- **심부전(Heart Failure)**: sGC 자극제(베리시구앗 Vericiguat)를 통해 [[cGMP]]-PKG 경로를 직접 자극하여 심근 재형성 억제 및 혈관 확장.
