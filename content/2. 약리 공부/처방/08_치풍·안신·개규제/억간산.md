# 구성:
[[당귀]], [[천궁]], [[백출]], [[복령]], [[시호]], [[감초]], [[조구등]]
- [[당귀]], [[천궁]]: 피를 맑게 함
- [[복령]], [[백출]]: 복강 순환이 좋지 않음
- [[시호]], [[감초]]: 순간순간 자극이 들어올 때 스트레스 받음
- [[조구등]]: 진정 작용, 공격성 완화
# 적응증:
- <font color="#fa7e7e">불수의적인 충동적이고 발작적인 감정, 운동의 환자에게 사용</font>
- 충동적 [[분노조절장애]], [[ADHD]] 과잉행동 장애, 공격성을 가진 치매, Tic Disorder(보상성 불수의적 운동과잉, [[틱장애]]), 야경증, 악몽, 진전 경련(불수의적, 충동적, 발작적 과긴장 운동)  환자에게 활용
- 외과 수술 후의 섬망, 마약성 진통제로 인한 이상흥분, 섬망, 불면, [[알츠하이머]], [[조현병]] 금연 시의 초조함 등에 활용
- 위장이 약할 때는 [[억간산]]에 [[반하]], [[진피]]를 함께 사용한다. 
# 약리작용
- 뇌내 흥분성 전달물질인 글루탐산을 제어하는 트랜스포터를 자극, 억제성 세로토닌 신경계 자극(세로토닌 수용체 감소), 항불안 작용, [[알츠하이머]] 모델에서 학습장애, 저불안상태, 과활동장애 개선, [[조현병]]에서 뇌내 [[글루타치온]] 농도 저하를 회복

# 뇌의 연결 지도
- 입력정보(과거+현재): 감각계(시, 청, 후, 미, 고유, 압, 촉, 온냉, 통), 변연계(내장감각, 과거의 기억과 경험), 시상하부(혈압, 혈당, 체온)
- 연산 정보(미래지향 통합 분석): 전두엽(통합, 생각, 분석, 판단, 예측), 변연계(저장, 감정)
- 출력 정보(움직임 대응): 운동계(움직임), 변연계(감정표현), 시상하부(자율신경 조절)

- 우리의 움직임은 억제 경로를 억제하여 개방하는 기전임(억제를 억제>개방)
- 가장 강력한 억제중추는 전두엽이다. 
- 변연계는 전두엽보다 빠르다.(ptsd, 마조히스트가 발생하는 이유)
- 공격성은 뇌(전두엽)을 거치지 않고 나가는 행동으로 과거의 정보과 감각의 항상성이라는 현재 정보만을 토대로 변연계의 반사적 연산정보로 표현되는 충동적인 감정과 표정, 행동임.
<font color="#fa7e7e">-> 내장 정보, 항상성 정보를 처리하여 칠정과 여러 증상(불면, [[두통]], 현훈, 이명 등)을 해결(귀비탕, 가미소요산, 온담탕)</font>
<font color="#fa7e7e">-> 조구등은 뇌에 직접 작용하여 진정작용을 한다.</font>
