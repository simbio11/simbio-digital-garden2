# 적응증
- 감염성 풍병에 의해 혼수상태, 마비, 인사불성 상태가 되었을 때 사용
# 참고
- 풍병은 계속 움직이는 감염성 질환을 일컫는다.(풍약은 감기약, 퇴행성 신경계약)
- 중풍에서 처음이 담음인 경우엔 이진탕, 어혈인 경우에 활혈거어, 허증이면 보하는 처방을 사용한다. 
- 현대에는 혈압 관리를 잘 하기 때문에 뇌출혈보다는 뇌경색이 잘 나타나는 경향이 있다.(나이가 들면 혈관에 노폐물이 끼면서 이로 이어지는 것)
