## 💊 A. 한의원 개원 관점 (상권·입지)

### 1️⃣ 유동인구 & 동선
- [ ] 평일/주말 시간대별 사람 흐름 (출퇴근·점심·저녁)
- [ ] 지하철역 출구 방향과 도보 5분 동선
- [ ] 버스 정류장 위치, 환승 동선
- [ ] 보행자 길목 vs 막다른 길 확인

### 2️⃣ 상권 구성
- [ ] 인근 음식점·카페 밀도 (점심/저녁 상권인지)
- [ ] 대형마트·병원·약국·은행 등 앵커 시설
- [ ] **경쟁 한의원·한방병원 위치와 규모** (도보 10분 반경)
- [ ] 공실 점포 비율 (상권 활력 짐작)

### 3️⃣ 배후 수요
- [ ] 인근 아파트 단지 수·세대 수 (도보 10분/차 5분)
- [ ] 직장인 밀집도 (오피스·산업단지·병원가)
- [ ] 학원가·학교 유무 (성장 수요)
- [ ] 노인 인구 비중 (만성통증 수요)

### 4️⃣ 점포·임대 조건
- [ ] 권리금·보증금·월세 수준 (인근 공인중개소 2곳 이상 확인)
- [ ] 층수·가시성 (1층/지하, 간판 노출)
- [ ] 주차 가능 대수 (치료 목적 내원엔 주차 중요!)
- [ ] 건물 상태·리모델링 가능성·전용면적

### 5️⃣ 규제·미래
- [ ] 용도지역 (2종/3종 일반주거, 상업지역)
- [ ] 개발 호재·재개발/재건축 예정지 여부
- [ ] 전월세/매매 가격 추이 (그 지역 카드와 대조)

## 🏡 B. 자가 마련 관점 (아파트 단지)

- [ ] 단지 → 역/버스 실제 도보 시간 (광고 시간 의심!)
- [ ] 남향·일조·조망 (오후 방문 시 그림자 확인)
- [ ] 층간소음·단지 관리 상태 (커뮤니티 시설 둘러보기)
- [ ] 주차장 실제 혼잡도 (세대당 대수와 실제 체감)
- [ ] 편의시설: 마트·병원·학군 도보/차량 거리
- [ ] 주변 공실·미분양·개발 예정지 (가격 변수)
- [ ] 실거래가/호가 대비 흥정 여지 (중개사무소에서 최근 거래 질문)
