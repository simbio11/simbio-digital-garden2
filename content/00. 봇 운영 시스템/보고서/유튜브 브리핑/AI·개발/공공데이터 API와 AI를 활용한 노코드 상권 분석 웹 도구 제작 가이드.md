# 📌 공공데이터 API와 AI를 활용한 노코드 상권 분석 웹 도구 제작 가이드

> [!abstract] 핵심 요약 (Executive Summary)
> - 정부가 제공하는 11,915개의 공공데이터 API를 활용하면 AI가 학습하지 못한 구체적이고 실시간성 있는 지역 정보를 보완하여 정확한 답변을 도출할 수 있음.
> - 공공데이터포털에서 API 키를 발급받는 과정부터 흔히 발생하는 오류(인코딩/디코딩 키 차이, 트래픽 제한 등)의 원인과 해결책을 제시함.
> - AI 도구(Claude Code)를 활용하여 코딩 지식이 없는 사람도 5줄의 프롬프트만으로 실제 작동하는 강남역과 방배역 상권 비교 분석 웹 도구를 직접 제작할 수 있음을 증명함.

---

### 📑 세부 주제별 심층 정리 (Detailed Breakdown)
#### 1. [도입 및 배경 / 주요 문제 제기]
- AI에게 "우리 동네 상권 어때?"와 같은 지역 밀착형 질문을 던졌을 때 엉뚱하거나 추상적인 답변이 나오는 이유는 AI가 해당 지역의 최신 데이터를 본 적이 없기 때문임.
- 정부는 공공데이터포털(data.go.kr)을 통해 상권, 부동산, 관광, 날씨, 공휴일 등 11,915개의 유용한 데이터를 무료로 개방하고 있으나, 활용법을 몰라 방치되는 경우가 많음.
- 본 영상은 소상공인시장진흥공단의 상가(상권)정보 API를 활용해 일반 사용자도 쉽게 데이터를 연동하고 시각화할 수 있는 방법을 제시함.

#### 2. [핵심 내용 심층 분석 / 본론]
- **API 키 발급 및 트러블슈팅**: 본인인증, 활용 신청 후 5분 만에 키 발급이 가능하며, 대다수가 막히는 원인인 '인코딩(Encoding) 키'와 '디코딩(Decoding) 키'의 차이 및 올바른 사용법을 설명함.
- **AI 기반 노코드 제작 프로세스**: 클로드 코드(Claude Code)에 프롬프트 5줄을 입력하여 상권 지도 웹 도구를 자동으로 구축함. 보안을 위해 인증키를 브라우저에 직접 노출하지 않고 서버 측에서 처리하는 구조 설계의 중요성을 강조함.
- **데이터 검산 및 비교 분석**: AI가 생성한 코드에서 발생할 수 있는 숫자 오류를 검산하는 과정을 거쳐, 강남역과 방배역의 반경 500m 상권 데이터를 객관적으로 비교·시각화함.

#### 3. [시사점 및 실천 적용점]
- 공공데이터와 생성형 AI를 결합하면 개발 지식이 없는 비즈니스맨이나 기획자도 자신만의 맞춤형 데이터 분석 도구를 손쉽게 만들 수 있음.
- 상권 분석뿐만 아니라 부동산, 관광 등 타 분야의 공공데이터 API로 손쉽게 확장하여 실생활 및 업무에 즉시 적용 가능한 인사이트를 도출할 수 있음.

> [!tip] 🔍 주요 키워드 & 데이터 사전
> - **공공데이터 API**: 정부와 공공기관이 보유한 공공데이터를 민간에서 활용할 수 있도록 실시간으로 제공하는 디지털 인터페이스.
> - **인코딩/디코딩 키**: API 요청 시 URL에 특수문자가 포함되는 것을 방지하기 위해 변환된 키(인코딩)와 원본 키(디코딩)의 차이로, 시스템 요구사항에 맞게 골라 써야 오류가 나지 않음.
> - **클로드 코드(Claude Code)**: 터미널 환경 등에서 자연어 명령으로 코드를 작성, 수정, 실행할 수 있는 고성능 AI 코딩 에이전트.
