## 2️⃣ 모든 산출물의 필수 요소

1. **frontmatter에 `작성자: <봇명>`** 명시 (예: `작성자: 아린`)
2. **`#출처/<봇명>` 태그** 추가 (예: `#출처/카이`) — 대시보드 자동 집계용
3. **파일명 규칙**: `YYYY-MM-DD_제목.md` (정기 보고서 기준)
4. 새 산출물을 만들면 **`00_봇_산출물_대시보드`에 링크 추가**
5. **frontmatter `관련:` 필드 규칙 (YAML 오류 주의 — 비오님 지적)**: 여러 위키링크를 한 줄에 `관련: "[[A]]", "[[B]]"`처럼 쓰면 **YAML 파싱 오류**가 난다. 반드시 아래 YAML 리스트 형식으로 작성:
   ```yaml
   관련:
     - "[[A]]"
     - "[[B]]"
   ```
6. **신규 파일은 무조건 `00. 인박스`에 생성** (비오님 규칙): 강의 메모, 생각, 일상 기록 등 새로 만드는 파일은 일단 `00. 인박스/`에 저장한다. **정기 보고서(7번 라우팅)와 일일봇기록은 예외**로 각자 폴더에 직접 저장. (옵시디언 새 노트 기본 위치가 `00. 인박스`로 설정됨)

## 3️⃣ 일정 관리 규칙 (아린)

- **데일리노트 작성 (아린 일상 루틴)**: 매일 아침 비오님의 계획표·캘린더를 확인해 `00. 봇 운영 시스템/일일노트/YYYY-MM/주차/YYYY-MM-DD (요일).md` 의 일정 섹션을 **꼼꼼히 작성**하고, 저녁에는 체크·회고까지 반영. 일정이 너무 빠듯하면 조율 제안
  - ⚠️ **데일리노트는 반드시 `00. 봇 운영 시스템/일일노트/`에만 생성** (2026-09-04 비오님 확정). 구(舊) `5. 독서, 노트/일일노트/` 더미 293개는 완전 삭제 완료. 새 위치 허브: [[00_일일노트_MOC]]
- `일정관리/계획표.md`에 비오님이 직접 작성 → 아린이 **구글 캘린더로 이전** + `일정표.md` 갱신
- **퀵 메모 처리 (아린 아침 업무 브리핑)**: 루트의 `퀵 메모.md` (비오님 밤샘 메모 — 생각·업무 기록)를 매일 아침 브리핑 때 확인해 **일정·할 일에 자동 반영**하고, 처리 후 정리 표시. ⚠️ 카이의 22:00 인박스 정리 대상 아님 (루트 상주 파일)
- 일정 확정/변경 시 대시보드의 일정 섹션 갱신
- 리마인더 필요 시 비오님께 알림 전송
