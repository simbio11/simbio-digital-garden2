# 🏷️ 태그 가이드

> 볼트 전체에서 **일관된 태그**를 쓰기 위한 규칙. 봇과 비오님이 같은 언어로 분류하게 합니다.

## 1️⃣ 필수 태그 3계열

### 📤 출처 (`#출처/`) — 봇 산출물 추적용 (필수!)
| 태그 | 의미 |
| :--- | :--- |
| `#출처/아린` | 아린이 만든 자료 |
| `#출처/카이` | 카이가 만든 자료 |
| `#출처/비비` | 비비가 만든 자료 |
| `#출처/닥터허` | 닥터허가 만든 자료 |
| `#출처/비오님` | 비오님이 직접 작성 |

> 모든 봇 산출물은 frontmatter `작성자:` + `#출처/<봇명>` 태그 필수. 대시보드 dataview가 자동 집계합니다.

### 📌 상태 (`#상태/`) — 파일 수명 주기
| 태그 | 의미 |
| :--- | :--- |
| `#상태/분류대기` | 인박스 — 아직 분류 안 됨 |
| `#상태/진행중` | 작업/공부 진행 중 |
| `#상태/완료` | 끝난 것 |
| `#상태/보관` | 오래됐지만 남길 것 |

### 🗂️ 유형 (`#유형/`) — 콘텐츠 종류
| 태그 | 의미 |
| :--- | :--- |
| `#유형/강의` | 강의 메모 |
| `#유형/논문` | 논문 리뷰·작성 |
| `#유형/케이스` | 환자 케이스 |
| `#유형/일일노트` | 데일리노트 |
| `#유형/보고서` | 봇 정기 보고서 |
| `#유형/브리핑` | 일일 브리핑 |
| `#유형/계획` | 계획·프로젝트 문서 |

## 2️⃣ 사용 예시

```yaml
---
날짜: 2026-09-01
작성자: 아린
태그:
  - "#출처/아린"
  - "#상태/분류대기"
  - "#유형/케이스"
---
```

## 3️⃣ 규칙

1. **`#출처/`는 항상** — 누가 만들었는지 추적 필수
2. **`#상태/`는 하나만** — 파일마다 현재 상태 1개
3. **`#유형/`는 필요한 만큼** — 여러 개 가능
4. 태그는 frontmatter `tags:`에 YAML 리스트로 작성
5. 폴더 이동보다 태그가 우선 — 파일은 어디 있어도 태그로 찾는다
