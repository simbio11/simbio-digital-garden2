# 📖 인물 사전 PWA 개발 프로젝트

> **목표**: 만난 사람을 기록하고 감정·관계·비즈니스 관계를 체계적으로 관리할 수 있는 PWA(Progressive Web App) 형태의 웹 애플리케이션 개발 및 배포.

---

## 👥 업무 분담 (칸반 보드: `person-dict`)

| 담당 | 역할 | 주요 내용 | 상태 |
| :--- | :--- | :--- | :--- |
| **비비 (Vivi)** | 기획 & 데이터 설계 | 인물 카드 데이터 구조(이름, 감정, 관계 레벨, 태그, 메모), UI 레이아웃 | ⏳ 진행 대기 |
| **카이 (Kai)** | 프론트엔드 & PWA | 웹앱 구현, 로컬스토리지 연동, PWA 매니페스트 및 서비스 워커 | ⏳ 진행 대기 |
| **아린 (Arin)** | 문서화 & 배포 | 프로젝트 마스터플랜 정리, 옵시디언 연동, Vercel 배포 | ⏳ 진행 대기 |

---

## 🚀 개발 마일스톤

1. **Phase 1: 기획 및 스키마 설계** (비비)
   - 데이터 필드 확정 (프로필, 첫만남, 감정 척도, 관계 유형, 비즈니스 연관성)
   - UI/UX 와이어프레임 구상
2. **Phase 2: 앱 구현 및 PWA 패키징** (카이)
   - 반응형 웹 UI 개발 (Tailwind CSS 등 활용)
   - 브라우저 로컬 데이터 저장 기능 (JSON 백업/복구 포함)
3. **Phase 3: 테스트 및 배포** (아린 + 전원)
   - 모바일/PC 테스트
   - 정식 웹 배포 (Vercel) → [[Vercel_배포_가이드|배포 가이드 참고]]
