# 📖 인물 사전 — UI/UX 기획 및 데이터 스키마 정의

> "만난 사람을 기록하고, 기억하고, 소중히 간직하는 나만의 인물 도서관."
> — 제품 컨셉: 만난 사람을 **이름, 장소, 감정, 관계 깊이, 관계 유형, 메모**라는 여섯 개의 빛으로
>   담아내는 로컬 우선(offline-first) PWA. 데이터는 사용자 기기에 영구 보관된다.

---

## 1. 제품 개요

| 항목 | 내용 |
| :--- | :--- |
| 제품명 | 인물 사전 (person-dict) |
| 형태 | 로컬 우선 PWA (HTML + Tailwind + Vanilla JS, localStorage 저장) |
| 대상 사용자 | 사람 만나는 일이 많은 비즈니스/사교 활동가. "아는 얼굴은 많은데 기억이 안 나는" 답답함을 해소 |
| 핵심 가치 | ① 만난 사람을 10초 만에 기록 ② 감정·관계 깊이를 시각화 ③ 백업으로 데이터 안전 보장 |
| 저장 | 브라우저 localStorage (`person-dict.v1`), JSON 백업/복원 |

### 1.1 페르소나 (사용자 시나리오의 주인공)

**심비오트 님 (40대, 병원 원장 & 사업가)**
- 하루에 수십 명을 만난다: 환자, 협력 병원 관계자, 지인, 모임 회원.
- "이름은 아는데 어디서 만났는지, 무슨 얘기했는지 기억이 안 나는" 순간이 잦다.
- 기록은 빠르고 간결하게, 다시 만나기 전에 30초 만에 훑어볼 수 있어야 한다.

→ 그래서 모든 입력은 **탭/선택 중심**으로 최소화하고, 메모는 자유롭되 **가이드 라벨**로 정리를 돕는다.

## 2. 데이터 스키마 정의

### 2.1 핵심 필드 명세 (v1 확정)

| 필드 | 타입 | 필수 | 기본값 | 설명 | 예시 |
| :--- | :--- | :---: | :--- | :--- | :--- |
| `id` | string | ✅ | 자동생성 | 고유 식별자 (생성 시각 기반 + 난수) | `"lxyz123"` |
| `name` | string | ✅ | — | 이름/별칭/호칭 (1~50자) | `"김비비"`, `"정대표님"` |
| `place` | string | — | `""` | 만난 장소 (1~100자) | `"커피빈 강남점"` |
| `metAt` | string(date) | — | `""` | 첫 만남 날짜 `YYYY-MM-DD` | `"2026-08-15"` |
| `emotion` | enum | — | `"neutral"` | 만날 때의 감정 상태 (3단계) | `"good"` |
| `level` | integer 1~5 | — | `1` | 관계 깊이 (1=인사 ~ 5=최고 친밀) | `3` |
| `tags` | string[] | — | `[]` | 관계 유형 태그 (중복 불가, 5종) | `["business","school"]` |
| `memo` | string | — | `""` | 주요 메모 (자유 텍스트, 최대 5,000자) | `"내일 3시 미팅…"` |
| `createdAt` | number | ✅ | 자동 | 최초 생성 시각 (epoch ms) | `1788250000000` |
| `updatedAt` | number | ✅ | 자동 | 마지막 수정 시각 (epoch ms) | `1788250000000` |

> **설계 원칙**
> 1. **필수는 name 하나뿐** — 만나는 현장에서 10초 안에 저장을 끝낼 수 있어야 한다. 나머지는 전부 선택.
> 2. **시스템 필드(id/createdAt/updatedAt)는 사용자 입력 금지** — 앱이 자동 관리.
> 3. **기존 데이터 호환** — v1 프로토타입(`person-dict.v1`)의 스키마를 그대로 확정. 별도 마이그레이션 불필요.

### 2.2 감정 상태 (emotion) — 3단계 정의

만날 때 느꼈던 **전반적인 인상/기분**을 한 번에 선택한다. 판단이 어려우면 "보통"으로.

| 값 | 표시 | 의미 (사용자 가이드 문구) | 색상 |
| :--- | :--- | :--- | :--- |
| `good` | 😊 좋음 | "기분 좋게 만났다, 다시 만나고 싶다" | 에메랄드 (emerald) |
| `neutral` | 😐 보통 | "무난했다, 아직 판단을 보류" | 슬레이트 (slate) |
| `hard` | 😅 어려움 | "대화가 어색하거나 부담됐다" | 로즈 (rose) |

> **감성 디자인**: 감정은 "평가"가 아니라 "기억의 온도"다. 색상으로 온도를 보여주되,
> hard(어려움)도 틀린 기록이 아니라는 안내 톤을 유지한다 (예: 빈 상태 문구에 위로 멘트).

### 2.3 관계 깊이 (level) — 5단계 정의

관계의 **현재 깊이**를 5단계로 표시한다. 점점 깊어질수록 레벨 도트(○○○○○)로 시각화.

| 레벨 | 라벨 | 정의 (사용자 가이드 문구) | 색상 |
| :---: | :--- | :--- | :--- |
| 1 | 인사 | 인사만 나눈 사이 (명함/얼굴 인지 수준) | 슬레이트 |
| 2 | 아는 사이 | 이름과 얼굴을 아는 사이, 가끔 대화 | 스카이 |
| 3 | 친분 | 연락처 교환, 필요 시 연락하는 사이 | 에메랄드 |
| 4 | 가까움 | 자주 연락, 개인적 이야기까지 나누는 사이 | 앰버 |
| 5 | 최고 친밀 | 가족 못지않게 가깝고 신뢰하는 사이 | 로즈(핑크) |

> **확장 규칙**: 레벨은 마음대로 수정 가능. "다시 만나서 친해지면 +1" 하는 방식의
> **관계 성장 기록** 활용법을 빈 상태/도움말에 제안한다.

### 2.4 관계 태그 (tags) — 5종 정의

관계의 **성격(유형)**을 나타내는 복수 선택 태그. 하나의 인물에 여러 개 부여 가능 (예: 비즈니스 + 학교).

| 태그 값 | 표시 | 의미 | 칩 색상 |
| :--- | :--- | :--- | :--- |
| `business` | 💼 비즈니스 | 업무·사업·거래 관계 | 스카이 |
| `personal` | 💛 사적 관계 | 개인적 친분, 사적 교류 | 에메랄드 |
| `family` | 👨👩👧 가족 | 가족·친척 | 로즈 |
| `school` | 🎓 학교 | 학교·학연 (동창, 선후배, 교수) | 바이올렛 |
| `community` | 🤝 모임/커뮤니티 | 동호회·모임·커뮤니티에서 만난 사이 | 앰버 |

> **비즈니스/사적 구분의 의미**: 통계 대시보드에서 `business` vs `personal` 수를 분리 집계한다.
> "사업적 인맥은 몇 명, 진짜 친구는 몇 명"을 한눈에 보여주는 것이 이 앱의 핵심 인사이트.

### 2.5 주요 메모 (memo) — 항목 정의 및 가이드

메모는 자유 텍스트(최대 5,000자)로 저장하되, 다시 만나기 전에 훑기 좋도록 **3가지 라벨 가이드**를 제안한다.
(저장 형식은 단일 문자열 — 가이드는 입력 도움말로만 제공, 파싱 의존 없음)

| 라벨 | 기록할 내용 | 예시 |
| :--- | :--- | :--- |
| 🗣 대화 | 나눈 대화 주제, 상대가 말한 중요한 것 | "자녀가 중3, 의대 지망이라고 하심" |
| 💕 취향 | 상대의 취향·관심사·성향 | "홍차 좋아함, 골프 18홀, 강아지 두 마리" |
| 📌 약속 | 다음 약속, 하기로 한 일, 기념일 | "9/15 점심 약속, 도서 견본 보내주기로" |

> **입력 UI 제안**: 메모 입력란 위에 작은 힌트 칩(`🗣 대화` `💕 취향` `📌 약속`)을 두고,
> 탭하면 `🗣 ` 접두어를 삽입해 준다. 저장은 평문 그대로 — 호환성 유지.

### 2.6 기계 판독용 스키마

- JSON Schema (draft-07): `docs/person-dict.schema.json` — 백업 파일 검증·데이터 이관 시 활용.
- localStorage 키: `person-dict.v1` (배열 형태, 변경 금지)

### 2.7 확장 예정 필드 (v2 후보 — 지금은 구현 금지)

| 필드 | 이유 |
| :--- | :--- |
| `contact` (연락처/이메일) | 개인정보 민감도 ↑, v1은 기록 최소화 원칙 |
| `photo` (사진) | localStorage 용량 제한, 추후 IndexedDB 전환 시 도입 |
| `lastMetAt` (최근 만난 날짜) | 재회 알림 기능과 연결 (v2) |
| `interactionCount` (만남 횟수) | 관계 성장 통계용 |
| `isFavorite` (즐겨찾기) | 상단 고정 |

## 3. 화면 설계

### 3.1 화면 구조 & 내비게이션 맵

```
                    ┌──────────────┐
                    │  메인(목록)   │ ← 앱 진입점
                    └──────┬───────┘
        ┌──────────────────┼───────────────────┐
        │ 상세보기(카드 탭) │ 추가(+ 버튼)       │ 편집(✎ 버튼)
        ▼                  ▼                   ▼
  ┌─────────────┐   ┌──────────────┐   ┌─────────────┐
  │ 인물 상세   │   │ 추가/편집 폼 │   │ (동일 폼)    │
  │ (읽기 전용) │   │ (모달/시트)  │   │  재사용      │
  └─────────────┘   └──────────────┘   └─────────────┘
```

- **1 Depth 원칙**: v1은 목록 → (모달) 2단계만 유지. 상세 화면은 v1.1에서 분리 가능(아래 3.3은 v1.1 제안).
- **모달 vs 화면**: v0.1 프로토타입은 상세/편집을 하나의 바텀시트 모달로 통합 → 기록 속도에 유리.
  모바일은 `items-end`(바텀시트), 데스크톱은 중앙 카드로 반응.

### 3.2 메인 화면 (목록) — 와이어프레임

```
┌──────────────────────────────────────────┐
│ 📖 인물 사전 · 만난 사람, 기억하세요   ⬇⬆ │  ← 헤더 (백업/복원)
├──────────────────────────────────────────┤
│  전체 12    💼 비즈니스 5    💛 사적 7    │  ← 통계 카드 3종 (탭하면 필터 적용)
├──────────────────────────────────────────┤
│  [전체] [💼비즈니스] [💛사적] [⭐최고] [🕐] │  ← 필터 칩 (단일 선택)
│  ┌────────────────────────────────────┐  │
│  │ 🔍 이름, 장소, 메모 검색             │  │  ← 검색 입력 (즉시 결과)
│  └────────────────────────────────────┘  │
├──────────────────────────────────────────┤
│  ┌────────────────────────────────────┐  │
│  │ 👤 김비비                    😊    │  │  ← 인물 카드
│  │ 📍 커피빈 강남점 · 2026-08-15      │  │     (탭 → 상세)
│  │ [💼 비즈니스] [🎓 학교]            │  │
│  │ ○○○○○ (친분)                       │  │
│  └────────────────────────────────────┘  │
│  ┌────────────────────────────────────┐  │
│  │ 👤 정대표님                   😐    │  │
│  │ 📍 병원 세미나실 · 2026-07-02      │  │
│  │ [💼 비즈니스]                      │  │
│  │ ○○○○○ (인사)                       │  │
│  └────────────────────────────────────┘  │
│                   ⋮                      │
├──────────────────────────────────────────┤
│              [ ＋ 인물 추가 ]              │  ← 하단 고정 FAB (항상 보임)
└──────────────────────────────────────────┘
```

**카드 요소 정의 (위→아래)**

| 요소 | 내용 | 규칙 |
| :--- | :--- | :--- |
| 아바타 | 이니셜 1자 원형 | 이름 첫 글자, 인디고 배경/흰 글씨 (이미지 없음) |
| 이름 | 본문 강조 | 1줄 말줄임 |
| 감정 | 이모지 + 색상 도트 | 우측 정렬 |
| 장소·날짜 | 보조 텍스트 | `📍 {place} · {metAt}` — 값 없으면 해당 부분 생략 |
| 태그 칩 | 최대 2개 표시 | 초과분은 `+N` 으로 축약 |
| 레벨 | 도트 5개 + 라벨 | 채워진 도트 색 = 레벨 색, 빈 도트 = 슬레이트-200 |

**통계 카드**: ① 전체 인물 ② 비즈니스 ③ 사적 관계. 숫자는 대형/강조.
탭하면 해당 필터가 활성화된다 (v1.1 제안 — v0.1은 표시 전용).

**빈 상태 (기록 없음)**
```
        🗂️
  아직 기록된 인물이 없어요.
  아래 [＋ 인물 추가] 버튼으로
  오늘 만난 사람의 첫 기록을 남겨보세요.
```

**폼 상호작용 규칙**

| 항목 | 규칙 |
| :--- | :--- |
| 이름 | 필수. 빈 값이면 저장 버튼 비활성 + 빨간 안내 |
| 감정/레벨/태그 | 탭 선택형 버튼. 선택 시 `border-indigo-400 + bg-indigo-50` 강조 |
| 태그 | 복수 선택 토글 (다시 탭하면 해제) |
| 메모 힌트 | 라벨 탭 시 `🗣 `/`💕 `/`📌 ` 접두어 삽입 |
| 삭제 | 신규(편집 아님)일 땐 숨김. 편집일 땐 표시, 탭하면 `정말 삭제할까요?` 확인 토스트 |
| 저장 | 폼 닫힘 + 토스트 `저장했어요 ✓` + 목록 갱신 |

### 3.5 검색 & 필터 명세

| 기능 | 동작 |
| :--- | :--- |
| 검색 대상 | `name` · `place` · `memo` (대소문자 무시, 부분 일치) |
| 검색 트리거 | 키 입력 즉시 (디바운스 200ms) |
| 필터 칩 | `전체` `💼비즈니스(tags⊇business)` `💛사적(tags⊇personal)` `⭐최고 친밀(level≥5)` `🕐최근 추가(createdAt 내림차순)` |
| 조합 규칙 | 검색어 AND 필터 동시 적용. 칩은 단일 선택 (전체로 복귀 가능) |
| 결과 없음 | `검색 결과가 없어요 🔍` 빈 상태 표시 |

### 3.6 상태 메시지 (토스트/빈 상태)

| 상황 | 메시지 | 톤 |
| :--- | :--- | :--- |
| 저장 성공 | `저장했어요 ✓` | 밝게 |
| 삭제 성공 | `기록을 지웠어요` | 담담하게 |
| 백업 | `백업 파일을 내려받았어요 ⬇` | 밝게 |
| 복원 성공 | `복원 완료! N명의 기록을 불러왔어요` | 기쁘게 |
| 복원 실패 | `복원할 수 없어요. 파일 형식을 확인해 주세요` | 정중히 |
| 검색 결과 없음 | `검색 결과가 없어요 🔍` | 담담하게 |

### 4.2 타이포 & 아이콘

| 용도 | 크기/무게 |
| :--- | :--- |
| 화면 타이틀 | text-lg / bold |
| 인물 이름 | text-base / bold |
| 카드 보조 텍스트 | text-xs / normal (slate-500) |
| 통계 숫자 | text-2xl / extrabold |
| 이모지 중심 (아이콘 폰트 없음) | 감정·태그·장소 모두 이모지 + 색상 |

### 4.3 컴포넌트 규칙

| 컴포넌트 | 규칙 |
| :--- | :--- |
| 카드 (`card`) | `bg-white rounded-2xl border border-slate-200 p-4`, hover 시 그림자 |
| 칩 (`chip`) | `rounded-full px-2.5 py-1 text-xs font-semibold` |
| 레벨 도트 | 8px 원형, 간격 3px |
| FAB | 하단 고정, `max-w-2xl` 중앙, `rounded-xl py-3.5 shadow-lg` |
| 모달 | 모바일 바텀시트(`items-end`), 데스크톱 중앙(`sm:items-center`) |
| 토스트 | 하단 중앙, `bg-slate-900 text-white`, 2초 후 사라짐 |

### 4.4 접근성 & 모션

- 모든 버튼 `active:scale-95` 피드백 (탭 감각).
- 폼 라벨은 `label` 태그 + `for` 연결. 아바타에 `alt` 텍스트.
- 애니메이션 최소화 (모달 fade/slide 150ms) — 기록 도구는 빠름이 미덕.
- 대비: 보조 텍스트도 WCAG AA 이상 (slate-500 on white).

## 5. 사용자 시나리오 (핵심 3가지)

### S1. "미팅 후 10초 기록" — 신규 등록
1. 미팅 끝나자마자 앱 실행 → `＋ 인물 추가` 탭.
2. 이름 입력 (필수) → 감정 `😊 좋음` 탭 → 레벨 `3·친분` 탭 → `💼 비즈니스` 탭 → 저장.
3. 토스트 `저장했어요 ✓`. 총 소요 약 10초.

### S2. "재회 전 30초 복습" — 검색 & 상세 확인
1. 약속 장소로 가는 길에 앱 실행 → 검색창에 이름 입력.
2. 카드 탭 → 메모의 `🗣 대화` `💕 취향` 훑기 → 대화 주제 회상.
3. 필요 시 `✎ 수정`으로 `📌 약속` 라벨에 오늘 약속 추가.

### S3. "인맥 점검" — 통계 활용
1. 메인 화면에서 통계 카드 확인: `전체 12 / 💼 5 / 💛 7`.
2. `⭐ 최고 친밀` 필터 탭 → 소중한 인연이 몇 명인지 확인.
3. 백업 버튼으로 주기적 보관 (기기 변경 대비).
