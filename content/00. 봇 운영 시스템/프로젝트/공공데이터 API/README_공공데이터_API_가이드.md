# 공공데이터포털 API 설정 가이드 (맛집 + 부동산)

> 참고 영상: 「정부가 공짜로 푸는 데이터 11,915개, 뭘 할 수 있는지 직접 만들어봤습니다」
> 정부가 무료로 개방한 공공데이터를 우리 도구에 연결하는 가이드입니다.

## 📌 준비된 것 (이미 설치 완료)

| 항목 | 위치 |
|---|---|
| API 클라이언트 | `공공데이터_API_클라이언트.py` |
| 인증키 설정 파일 | `.env` (SERVICE_KEY 입력란) |
| 이 가이드 | `README_공공데이터_API_가이드.md` |

## ⚠️ 남은 단계 (딱 하나: 키 발급)

API 키 발급은 **본인인증(휴대폰/i-PIN)이 필요**해서 대신 해드릴 수 없습니다.
아래 순서대로 5분이면 됩니다:

1. [공공데이터포털](https://www.data.go.kr) 회원가입 + 로그인 (휴대폰 인증 1회)
2. 검색창에 **`상가(상권)정보`** 입력 → `소상공인시장진흥공단_상가(상권)정보_API` → **활용신청** (자동승인)
3. 검색창에 **`아파트 매매 실거래가`** 입력 → `국토교통부_아파트 매매 실거래가 자료` → **활용신청** (자동승인)
4. 우측 상단 **마이페이지** → 개인 API 인증키 복사
5. `.env` 파일의 `SERVICE_KEY=` 뒤에 붙여넣기
6. 키를 카이에게 알려주면 바로 연결 테스트 진행

> 💡 키는 **계정당 1개**입니다. 새 API를 신청할 때 키를 또 받는 게 아니라, 그 키에 쓸 수 있는 서비스가 하나씩 붙는 구조예요. (키 받았는데 안 되면 → 활용신청이 안 된 것!)

## 🍽️ 맛집/상가 API

- **제공기관**: 소상공인시장진흥공단 (데이터 출처: 국세청/카드사)
- **엔드포인트**: `https://apis.data.go.kr/B553077/api/open/sdsc2/storeListInRadius` (반경내 상가업소 조회)
- **동작 원리**: 좌표(위도/경도) + 반경을 주면 그 안에 등록된 모든 가게를 반환 (상호명, 업종, 주소, 좌표 등 39개 필드)
- **업종 분류**: 대분류 10개(2자리) / 중분류 75개(4자리) / 소분류 247개(6자리)
  - 예: `I1`=음식(숙박·음식점업), `L1`=부동산, `Q1`=보건의료, `P1`=교육
  - `--업종` 옵션은 **코드 또는 이름** 모두 매칭 (예: `--업종 음식`, `--업종 성형외과`, `--업종 L1`)
  - 필터는 클라이언트에서 처리되므로 서버 필터 제약 없이 자유롭게 사용 가능
- **사용 예시**:
  ```bash
  # 강남역 500m 내 모든 가게
  python 공공데이터_API_클라이언트.py 맛집 --lat 37.4979 --lon 127.0276 --radius 500
  # 음식점만 (백반/카페/분식 등 1,152개)
  python 공공데이터_API_클라이언트.py 맛집 --lat 37.4979 --lon 127.0276 --radius 500 --업종 음식
  # 성형외과만 (강남역 500m = 139개!)
  python 공공데이터_API_클라이언트.py 맛집 --lat 37.4979 --lon 127.0276 --radius 500 --업종 성형외과
  ```
- **활용 아이디어**: 이사 갈 동네 편의점/병원 유무 체크, 창업 상권 분석(같은 업종 몇 개?), 강남 vs 방배 동네 성격 비교

## 🏠 부동산 실거래가 API

- **제공기관**: 국토교통부 (부동산 거래신고법 기반, 실제 계약서 금액)
- **엔드포인트**: `https://apis.data.go.kr/1613000/RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade`
- **동작 원리**: 법정동코드 앞 5자리(시군구) + 계약년월(6자리) → 그 지역/그 달의 아파트 매매 실거래 내역 (XML)
- **지역코드 예시**: 강남구 `11680`, 서초구 `11650`, 송파구 `11710`, 종로구 `11110`, 해운대구 `26350`
  - 전체 코드: [법정동코드 조회](https://www.code.go.kr)
- **사용 예시**:
  ```bash
  # 강남구 2026년 6월 실거래가
  python 공공데이터_API_클라이언트.py 부동산 --code 11680 --ym 202606
  ```
- **주의**: 데이터가 실제 거래 시점보다 1~2개월 늦게 반영됩니다. (영상에서도 "기준 시점은 두 달 전" 이라고 했죠)

## 🛠️ 공통 에러 코드

| 코드 | 의미 | 해결 |
|---|---|---|
| 22 | 일일 호출량 초과 | 다음 날 다시 (개발계정 기본 1만회/일) |
| 30 | 등록되지 않은 서비스키 | 키 오타 or 활용신청 안 됨 |
| 12 | 서비스 없음/폐기 | URL 확인 |
| 10 | 파라미터 오류 | 필수값/형식 확인 |

## 🔒 보안 주의

- API 키는 코드에 하드코딩하지 말고 `.env`에만 보관 (이미 그렇게 구성됨)
- 브라우저에 키 노출 금지 → 서버 백엔드에서만 호출 (영상에서 강조한 부분!)
- 사업 목적의 위치기반 서비스는 별도 신고/등록 필요 (개인 연습은 무관)

## 🎁 보너스: 영상에 나온 다른 API들
